# 星のホーム：見た目と操作の決まり（試作つき・2026-11-23）

試作：`home-inline.html`（そのまま開ける。上のボタンで8つの星を切りかえ）。組み立て：`python3 design/home/build.py`（`template.html` に絵を埋めこむ）。全部の星の中身の決まりは `docs/story-rewrite/星のホーム_共通の作り.md`（M-R258）。

## 1. 誰に向けた、どんな見た目か
- 15〜20歳。手のひらサイズのアートトイ・ミニチュアの「ぷっくりした3Dの箱庭」＋すりガラスのUI＋少しだけネオンの差し色。
- どの星も同じ画風。星ごとに変わるのは「色（accent）」「自分の場所の絵」「浮かぶ物の絵」「言葉」だけ。
- 字：Zen Maru Gothic（本文・ボタン）、Dela Gothic One（星の名前だけ）。

## 2. 画面の形（縦長・片手）
- 背景（`home-bg-<星>`）を全面に。下の約55%に自分の場所（画面の下16%〜46%がタップできる所）。名札は白い丸い札『{neo}の○○』。
- 上：星の英語名（小）と日本語名（大）、右に〔？〕（説明）と〔♡ 推し n〕。
- 説明の帯：星を開いた時だけ4.5秒出て、たたまれる。〔？〕で出し入れ。
- 空（画面の上27%〜47%）に、ダチ・推しの作品が7つまでふわふわ浮かぶ（6〜11秒でゆっくり揺れる）。名前の札つき（ダチ＝白い縁、推し＝ピンクの縁）。前に開いてから届いた物は、きらっと光る。
- 遠くの景色（画面の51%〜57%の左右のすみ）に、知らない人の作品が小さく薄く。15歳未満には出さない。
- 下：大きなボタン1つだけ（土星＝〔▶ 全部流す〕、ほか＝〔中に入る〕）。〔飛ばす〕のボタンは置かない（作って飛ばすのは月だけ。M-R263）。

## 3. 操作
- 浮かぶ作品をタップ → 下からシートが出る（作った人・ダチ/推しの印・作品・〔▶ 聞く/見る/読む/遊ぶ〕〔とじる〕）。知らない人の作品は〔♡ 推す〕。
- 長押し（0.48秒）→ 小さなメニュー〔ひらく〕〔推す/推しを外す〕〔見えなくする〕〔通報する〕。
- 自分の場所 or 大きなボタン → 中に入る（少し寄る動きのあと、星の色の背景の上に、自分の作品の棚が3列で並ぶ。〔← 外へ〕で戻る）。
- 土星だけ（M-R259）：新しく降ってきたコロリンがレコードの上に転がる。つつく・はじく（払う）・つまんで投げると、跳ねながら喋り（頭の上に名前と言葉の吹き出し）、聞き終わると溝に吸いこまれる。全部聞くと「今日のコロリン、全部聞いたね！」。〔▶ 全部流す〕は溝のコロリンを針のマイクの前でまとめて流すおまけ。
- 〔推す〕を押したら「♥ ○○を推した。次から、あなたの○○にも来る」と短く知らせる。
- 動きを減らす設定（prefers-reduced-motion）の人には、揺れ・きらめきを止める。

## 6. 決まったこと（2026-11-24）
- 見た目はアニメ版（`home2-bg-<星>`・`home2-sp-<物>`、住人は `res-<星>-<名前>`。星ごとの画風と頭身）。箱庭版は使わない。
- 土星は「転がるコロリンを触る」形（M-R259）。
- 土星の背景は `home2-bg-saturn-lowb`（約15度の低い角度から見た巨大なレコード。針は上がっていてレコードに触れていない）。コロリンは10/7の「ぷにぷに」（ツムツムのような丸いボールの顔。開発の `apps/web/components/puni/PuniPhysicsLayer.tsx`・`lib/puni/physics.ts` と、プロフィールから描く丸い絵 `PuniPicMaker`）。空から落ちてレコードの上に積み重なり、ぶつかるとつぶれてぷるんと戻る。つつくと凹んで跳ねて喋り、ドラッグで投げられる。試作の絵は `design/home/puni/*.png`（開発の `public/puni-test`）。

## 7. 土星の決定版（M-R262・2026-11-24）
- 背景：`home2-bg-saturn-cutea`（ぷにぷにに合うかわいいタッチ・低い角度・針は上がっている）。レコードの色は、はじめて土星に着いた時にシスターに聞かれて選ぶ。あとは月で{bati}に頼めば、いつでも変えられる（画面に色のボタンは置かない。M-R263）。色の付け方：`design/home/saturn-record-mask.png`（レコードの部分の形）に色を重ね、`mix-blend-mode: screen`、濃さ0.85。色の候補：黒（標準）・ピンク・ラベンダー・ミント・ゴールド・空色（あとで好きな色を選べるように）。
- 転がる物：つやのあるボール `ball-<mine|dachi|oshi>`（金・白・ピンク）。空から落ちて積み重なり、ぶつかるとつぶれて戻る。ドラッグで投げられる。
- タップ：ボールがシャボン玉のようにパチンと割れて（しぶきとキラキラ）、中からその人の2頭身のチビキャラ `chibi-<名前>` が元気よく飛び出し、吹き込んだ言葉を本人の声で喋る（吹き出し）。喋り終わると手を振って、レコードのまん中の溝へ。全部聞くと「今日のコロリン、全部聞いたね！」。
- チビキャラ：物語の人物は `chibi-user・kimorin・monban・mikie・brother・sister`。ユーザー一人ひとりのチビキャラは、2日目に作る自分の姿から自動で1体描く（まだない時は仮の丸い顔）。
- たこ焼き兄妹のレコード（物語の場面）：`home2-bg-saturn-tako-cute`。

## 8. ボタンを増やさない（M-R263・2026-11-24）
- 星は「見る」場所、月は「作る」場所。星のホームに〔飛ばす〕や設定のボタンは置かない。
- 見た目の変更（土星のレコードの色、木星のアトリエ、水星の島…）は、月で{bati}に頼む。{bati}「レコード、ピンクにしたよ！」。
