# 2日目「待ちなさい」〜ロケットに乗る豪華映像:作り直し(依頼主 2026-11-28)

- 01-boarding-back.jpg / 02-kimorin-obolon-monban.jpg: いまの本番の「ロケットに乗りこむ場面」(依頼主のスクリーンショット)。
- 依頼主の指示:
  - この区間は動画生成のミス(不自然・低品質)が多い。動画生成をやめ、画像生成で作り直してクオリティを上げる。
  - 天才アニメ映画監督として、セリフと物語に合うカット割り・カメラアングル・寄り/引き(画像を編集でズームするカメラワーク)・映像エフェクトを設計する。
  - 背景とキャラを同時に生成すると不自然になりやすいので、背景だけを素材として生成してよい。
  - 微妙な絵は、良くなるまで作り直す。
  - 場面に合った効果音を足す(低品質の効果音は使わない)。
  - 舞台の変更:地下のロケット場はやめる。地球の神殿の奥にある「結社大広間」に巨大なロケットがそびえ立つ。地下に降りず、結社の奥へ進み、大広間に着いて、ロケットに乗る前のくだりになる。
  - KIMORIN はユーザーの側から OBOLON を見ているのが正しい。OBOLON の横に並んでこちらを向いて話す今の形は不自然なので直す。
