## 1. ひとことで言うと

**話しかけるだけで、自分の曲・MV・キャラ・ゲームが生まれる。15〜20歳のための、完全招待制の「宇宙秘密結社」型クリエイティブSNS。月額88円。**

- 地球をホームに、8つの惑星を旅します。惑星ごとに「声」「シール」「曲」「MV」「DJ」「グッズ」「ゲーム」を作れます。
- 入口は、アニメのような7日間の物語です。毎日1つの星に行き、毎日1つ「自分だけの作品」が増えます。
- 相棒の「バティ」と一緒に作ります。バティは、自分の好きな食べ物から生まれるキャラクターです。

## 3. ターゲットと、毎日戻ってくる理由

- **ターゲット**：15〜20歳です。アニメ、推し活、音楽、ゲームが好きな層です。
- **毎日の物語**：1日分を終えると「また明日」と24時間のカウントダウンが出ます。毎日、新しい星と新しい作品が開きます。
- **8つの謎**：物語には、1周目・2周目・3周目・最終章で順に解ける謎があります。
- **3周の旅**：1周目は見学ツアー、2周目は会員として全惑星を回り、3周目は称号の旅です。
- **称号**：作ったもので称号がもらえます。たとえば、曲3曲でRECORDER、MV3本でMOVER、ゲーム1本でPLAYER。人気や連続ログインは条件にしません。
- **ダチ**：おたがいにフォローした友だちです。届く範囲は周ごとに広がります（1周目は自分だけ、2周目はダチ、3周目はみんな）。
- **88時間で消えるタイムライン**：投稿は88時間タイムラインに出たあと、本人の部屋やアトリエに戻って残ります。

## 5. 成長の仕組み

- **完全招待制**：招待されないと入れません。招待した人の名前が、招待状や物語の中に出てきます。
- **招待するほうがお金を払う**（設計中）：招待状には「マナジェム」（1つ88円）を添えます。マルチ商法とは逆の仕組みです。
- **招待の上限**（仮の値）：1人30日で10人まで、有効期限は14日。
- **口コミの導線**：家族や友だちへの直接の招待です。物語の中にも「母を招待する」話があります。
- **広告費がほとんどかからない**：招待が獲得の中心なので、広告に頼りません。

## 10. 規模ごとの裏側のしくみと経費

**試算の前提**
- 会員は全員有料（月88円）です。
- 毎日使う人は会員の50%、いちばん混む時間に同時に使う人はその10%とします。
- MANA の追加購入は「平均30円／人・月、粗利率7割」とします。
- 1人あたりの経費は、規模が大きくなるほど下がります。理由は、長期契約の割引、量による単価の値下がり、自社運用への切り替えです。
- 人件費は含みません。
- 1億人以上は世界展開になります。国ごとの物価に合わせた値付けで平均単価は下がる想定で、10章の最後に注記しています。

### 1万人：小さく、確実に回す

- **アクセスの量**：毎日5,000人、混む時間で同時に約500人。
- **裏側**
  - API はクラウドのサーバー1〜3台で、アクセスに応じて自動で増減します。
  - データベースは1台です（予備つきの冗長構成）。
  - 作曲用のGPUは1〜2台です。
  - 配信は Bunny の CDN、メールは Resend。
- **経費の中身**：固定費が目立ちます（GPU常時1台で月約15万円）。1人あたり約58円。
- **お金の流れ**：会費だけでも、ほぼ損益分岐です。追加購入があれば黒字になります。
- **チーム**：創業者＋エンジニア2〜3人で運営できる規模です。

### 10万人：自動化と「待ち行列」で混雑に耐える

- **アクセスの量**：毎日5万人、同時に約5,000人。1か月に作られる曲は約40万曲。
- **裏側**
  - API サーバーは10〜30台で自動増減します。
  - データベースに「読み取り専用の複製」を1〜2台足し、読み書きを分けます。接続をまとめる仕組みも入れます。
  - Redis を Google の Memorystore に移します。
  - 作曲・MVは待ち行列（Cloud Tasks）で順番に処理し、GPUを10〜20台に自動で増やします。
  - メールを大量送信向けのサービス（Amazon SES など、1通約0.015円）に切り替えます。

- **経費の中身**：GPUの稼働率が上がるので、1曲あたりが安くなります。1人あたり約48円。
- **規制**：使われていない MANA が1,000万円を超えるので、資金決済法の届出と供託を始めます。
- **チーム**：通報対応・見守りの担当を置き始めます。

### 100万人：長期契約と、高いところを自社に切り替える

  - 読み上げ（Fish Audio）を、自社GPUで動かすオープンな音声モデルに切り替えます。100万人が月30回使うと、外注では月 約1,200万円かかるためです。

### 1,000万人：GPUの自社運用と、複数の地域

- **アクセスの量**：毎日500万人、同時に約50万人。
- **裏側**
  - 東京と大阪など、複数の地域で同時に動かします。災害で片方が止まっても続けられます。
  - データベースは、世界規模で分散できるもの（Google の AlloyDB や Spanner）か、分割した PostgreSQL を何十台も並べる形にします。
  - いちばん大きな経費は GPU になります。長期予約の GPU を大量に確保するか、自社で GPU サーバーを持ってデータセンターに置きます。
  - 作曲・声・画像は、自社で小さく軽いモデルに作り直します（蒸留）。1回あたりの原価をさらに下げます。
  - 配信は複数の CDN を組み合わせ、通信会社と直接つなぎます。
- **決済**：カードに加えて、携帯キャリア決済やアプリストアにも対応します。アプリストア経由は手数料が15〜30%なので、自社決済との比率が利益を大きく左右します。日本ではスマホ新法（2025年12月施行）で外部決済が使えるようになりました。
- **規制**：使われていない MANA の残高が数億円規模になり、その50%以上を供託します（運転資金の計画に必要）。

### 1億人：世界展開

- **アクセスの量**：毎日5,000万人、同時に約500万人。

  - 個人データは、その国・地域の中に保存します（GDPR など各国の法律に対応）。
  - バティの会話は、自社で調整した小さな言語モデルに切り替え、外部 API への依存を減らします。
  - 文字起こしや読み上げの一部は、スマホの中で処理します。サーバー代がかかりません。
  - 物語と声を、言語ごとに作ります。翻訳だけでなく、その国の声優クローンで声を作ります。
- **値付け**：国ごとの物価に合わせます（例：「88」という数字はそのままにして、その国の通貨で88相当にする）。
- **経費の中身**：1人あたり約20円。
- **チーム**：安全対策と運営が数百人規模になり、各国に法人を置きます。

### 10億人：世界最大級のSNSと同じ土俵

- **アクセスの量**：毎日5億人。TikTok や Instagram と同じ規模です。
- **裏側**
  - 自社のデータセンター、または巨大クラウドとの長期の大型契約で動かします。
  - 生成の多くはスマホの中で動かします。サーバーで作るのは、高品質な曲と MV だけです。
  - 各国の通信会社の中に配信用のキャッシュを置きます（Netflix の Open Connect と同じ方式）。
  - 自社の生成モデル（音楽、声、画像）と、専用の計算チップの採用を検討します。
  - 150以上の国の法律、子どもの保護、決済規制に対応する体制を持ちます。
- **経費の中身**：1人あたり約13円。
- **注意**：国ごとの値付けで、平均単価は88円より下がる想定です。平均50円なら月の売上は約500億円になります。

### どの規模でも効く「強み」

1. **全員が有料なので、広告の仕組みがいらない**：ボットも割に合いません。
2. **1日88分の上限がある**：1人の最大経費に上限があります。見放題の SNS のように、配信費が青天井になりません。
3. **生成の大部分がオープンなモデル**：作曲は ACE-Step、MV の絵は FLUX.2 klein で、ライセンス料がかかりません。外注から自社 GPU へ、品質を変えずに切り替えられます。
4. **高価なモデルに縛られない**：同じ機能を複数の会社のモデルで動かせる設計です（Gemini と OpenAI、Runware と自社 GPU など）。

## 12. ロードマップ
