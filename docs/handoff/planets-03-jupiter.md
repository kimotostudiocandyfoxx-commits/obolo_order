# 惑星ホーム 本番への引き継ぎ 03：木星（アート）

物語セッション → 開発セッション。01（土台・共通の型）の上に作る。試作は `design/home/template.html`（`setupJup` `makeBf` `popBf` `openArt` `KKS` `TSTYLE` `kinTitle` `playJ` `WG`）。

## 1. ホーム
- 背景：絵画調の魔法の森（空に木星は出さない、M-R277）。右奥に自分の木の家（タップでプロフィール）。
- ダチ・推しは「蝶の羽の生えた2頭身ちび」で浮かぶ（8体まで、共通の型の JSLOT のまま）。姿は自分の姿9枚の木星の分。羽だけがぱたぱた動き、体は動かない。羽の折れ目は顔にかからない位置（試作の WB 表、キャラごと）。
- 本番では「羽だけ動かす」ために、木星の姿は**体と羽を分けた絵**が要る（または羽の位置を表で持つ）。描き方は開発で決めてよい。

## 2. 蝶をタップした時（アートを見る）
1. 蝶が左下へ寄り、名前が出る。画面が少し寄る。
2. 掛け軸が開き、アートが画面の幅の95%まで大きく出る（カメラの寄り方はランダムに5種類、掛け軸の柄は4種類からランダム。紙は正方形）。
3. 題名はアートの上に重ねて出す（作品ごとの字体と動き TSTYLE。漢字・カタカナ・ひらがなで字の大きさを変える chk）。題名の読み上げ（作った人の声）。
4. もう一度タップで閉じる（開くのも閉じるのも速く）。「NEW ART」などの文字は出さない。

### データで必要なもの
- アートごと：絵（正方形に切り出せること）、題名、題名の読み上げ音声（あれば）、題名の字体（作品ごとに選ぶ。作る時に決めて保存）。

## 3. 右上▶
1. 自分が木の家から出て、眺めが「木の家のポーチから森を見る」夜の景色（ほたる）に切り替わる。右下に自分の後ろ姿。
2. 蝶が1匹ずつ上から飛んで来て手前で止まり、2章と同じく掛け軸が開く。数秒見せて閉じ、次の蝶。
3. 全部終わると「🌳 今日のアート、全部見たね！」。■ または画面タップで止まる。

## 4. プロフィール（木星）
- 背景：アトリエ。その人のアートが金の額に入って壁に並ぶ（2列、縦にスクロール、少し傾いている）。
- 額をタップ：2章と同じく掛け軸で開く。

## 5. 確かめ方
- 羽だけが動くこと、羽が顔にかからないこと、タップで掛け軸が95%まで開く・題名がアートの上・読み上げ、▶でポーチから1匹ずつ、プロフィールの額。
- 決定：M-R277・M-R278・M-R283〜M-R286（木星）、M-R292（プロフィール）、M-R303（ドラッグ）。
