# 惑星ホーム 本番への引き継ぎ 02：水星（曲）

物語セッション → 開発セッション。01（データの土台・共通の型）の上に作る。試作は `design/home/template.html`（`setupMer` `makeSh` `popSh` `playM` `vinyl` `kinTitle` `lyricsStart`）。

## 1. ホーム
- 背景：夏のアニメの海。右奥に自分の島の家（タップでプロフィール）。
- ダチ・推しは船で浮かぶ（7隻まで：奥2・中3・手前2）。船は「自分の姿9枚」の水星の姿（船に乗ったその人）。知らない人を推した場合も、その人の船で来る。
- 船は左右に航行し、画面の端から反対側へ回りこむ。波でゆれる。ドラッグで動かせる（海の上だけ、01の3-2）。

## 2. 船をタップした時（曲を聴く）
1. 船が手前（画面中央の下）に来て大きくなり、画面が少し寄る。
2. 0.45秒後：その曲が流れ始める。**ピクチャーディスク**（ジャケットの絵がレコード全面に印刷され、溝が見える）が画面中央に回る。船はディスクの手前。
3. 歌詞が時間に合わせて1行ずつ出る（いま歌っている行が左から色づき、次の行がうすく下に出る）。
4. 2.2秒後：曲名が画面上に出る（曲ごとの字体と動き）。曲名の読み上げ（作った人の声）。
5. 曲は最後まで流れる（途中で次へ行かない）。もう一度タップで閉じる。
- 「NOW PLAYING」などの文字は出さない。曲名は作品の上に出す。

### データで必要なもの
- 曲ごと：音、ジャケットの絵、曲名、曲名の読み上げ音声（作った人の声、無ければ無し）、**歌詞と時間**（[秒, 行] の並び）。
- 歌詞の時間は、曲づくりの時に取れるなら取る。取れない曲は歌詞なしで流す。

## 3. 右上▶（今日の曲を全部聴く）
1. 自分が家からおどり出て、眺めが「自分の島の桟橋から海を見る」景色に切り替わる（夜、花火が上がる）。右下に自分の後ろ姿。
2. 船が1隻ずつ左から来て手前で止まり、2章と同じくディスク・曲名・歌詞・曲（最後まで）。
3. 曲が終わると船は右へ去り、次の船が来る。全部終わると「🏝 今日の曲、全部聴いたね！」。
4. ■ または画面タップで止まる。

## 4. プロフィール（水星）
- 背景：浜辺。その人の曲のレコードがスタンドに立って並ぶ（横にスクロール）。
- レコードをタップ：その曲が2章と同じく流れる（ディスク・曲名・歌詞）。
- 上の列にダチ、下に持ち主の大きなアイコン（01の3-5）。

## 5. 受け取りの確かめ方
- 船の数と段、ドラッグ、タップでディスク・歌詞・曲名・最後まで流れる、▶で桟橋から1隻ずつ、プロフィールのレコード。
- 自分の船と、推した知らない人の船が、それぞれの姿で出ること。
- 決定：M-R276〜M-R279、M-R285〜M-R288（水星）、M-R303（ドラッグ）、M-R309〜M-R310（作った人の見せ方）。
