# 台本の書き方の約束（物語担当チャット向け）

物語の台本（`docs/story-rewrite/wip/Pxx/cxx.md`）は、**そのまま自動で画面に組み込まれます**（`apps/web/lib/story/parse.ts`）。
今の書き方をほぼそのまま正式な約束にしたものです。この約束どおりなら、セリフを直して push するだけで画面に反映されます。

取り込むと、直すところの一覧が `docs/story-import/report.md`（開発ブランチ `claude/solar-system-home-planets-ew766y`）に出ます。
**❌ は動かなくなるので必ず直す**、⚠️ は確認して、意図どおりならそのままで構いません。

## 1. 場面のかたち

```
### D01-S002｜何でもない顔の、巨大な門        ← 場面ID｜題名（IDは一意。D01-S002 / L2-MERCURY-S001 の形）
**sceneID／…**：…（メタ情報。画面には出ない）
**本文**                                     ← ここから下が画面に出る
…本文…
**選択ごとの行き先／更新フラグ・保存イベント／保留・終了・再開点**：…   ← フラグ f_… と RESUME@場面ID をここに
**この場面だけの…**：…（画面には出ない）
**設計注（本文に混ぜない）**：…（画面には出ない）
```

- 場面の順番＝物語の順番。パート（P01…）とファイル（c01.md…）の番号順に読みます。
- `**本文**` の見出しがない場面は空になります（❌）。

## 2. 本文の1行の書き方

| 書き方 | 画面での扱い |
|---|---|
| `KIMORIN「待ってたケン。」` | セリフ（タップで次へ）。`／` は改行 |
| `KIMORIN（小声で）「…」` ／ `KIMORIN〔腕を組む〕「…」` | 言い方・しぐさつきのセリフ |
| `〔扉が開く〕KIMORIN「…」〔腕を組む〕「…」` | 1行にしぐさとセリフを混ぜてよい（2つ目の「」も同じ人） |
| `（ナレーション）宛名はない。` | ナレーション |
| `〔演出の説明〕` | 演出メモ（確認用のプレビューで表示。本番は絵・動画・効果で表す） |
| `〔動画 5〕` | 用意済みの動画（番号は今の動画番号） |
| `〔一枚絵：…〕` ／ `〔到着の一枚絵：…〕` | **新しく描く一枚絵**。中身がそのまま絵の注文になる（下の 5.） |
| `〔背景 mercury-island〕` | 用意済みの背景 |
| `〔札〕呼び鈴　なし` ／ `〔招待状〕`＋次の行から本文 | 紙・札・手紙のカード（次の空行・次の記号行まで） |
| `〔画面：…〕` `〔制作：…〕` `〔入力：声／文字／選択／パス〕` `〔ボタン：…〕` `〔確認画面：…〕` `〔完了画面：…〕` | **アプリの機能を呼ぶ場所**（下の 4.） |
| `（架空の入力例）…` | 書き手用の例。画面には出ない |
| `→D01-S009` ／ `→終了` | 次の場面へ／ここで終わる |
| `〔合流〕` | 選択肢の枝がここで合流 |

## 3. 選択肢と枝

```
［選択肢：霧に向かって汽笛を鳴らす→horn ／ 海図の霜を溶かす→breath ／ 今日はここまで→stop］
  （horn）〔ぼおおお〕バティ「最後の島、お留守？」
  （breath）〔はー〕フリージー「急いで解かすと、味が抜ける。」
  （stop）フリージー「海は、待つ。」→終了
  〔合流〕
```

- 行き先は **枝の名前（半角英数字）** か **場面ID**。日本語の行き先（`→通常の地図` など）は読めないので、枝の名前にする（⚠️）。
- 枝は `（名前）` で始まる行から、**次の枝・〔合流〕・場面の終わり**まで。字下げは任意。
- 1つの場面の中で、**違う選択肢に同じ枝の名前を使わない**（`hold` を2回使うときは `hold2` に）。
- 枝の中に選択肢を入れてもよい（その枝の名前は外の選択肢と別にする）。
- 行き先が1つもない選択肢＝どれを選んでも同じ続き（OK）。一部だけ行き先がないのは ⚠️。

**ある時だけ出す行**は、行の頭に1つだけ書く：

```
（nosongのとき）〔フリージーが汽笛の紐を引く〕
（mana_low）バティ「マナが少ないから、今日は一枚だけね。」
（パス）バティ「じゃあ、シールの言葉のままで。」
```

- `（xxxのとき）` の xxx は、前に出た枝の名前（その枝を選んだ人だけに出る）か、`mana_ok` / `mana_low` などの状態。
- **行の途中に（条件）を書かない**（読めない ⚠️）。条件ごとに行を分ける。

## 4. アプリの機能を呼ぶ場所

`〔画面：…〕` `〔制作：…〕` などは、その場所で機能の画面が開きます。まだない機能は、プレビューでは「ここで○○の画面」の仮の画面になり、そのまま先へ進めます。

- 頭に **機能の名前** を書く：`〔制作：曲づくり｜…〕` `〔画面：声の登録｜…〕` `〔画面：myツリー｜…〕` のように、`｜` の前が機能の名前。
- 今あるおもな機能：声の登録／曲づくり（水星）／MV（火星）／ころりん（土星）／絵のキャラづくり（ぷにぷに）／ネオの姿／バティの誕生・名前／月88円の登録。
- まだない機能（myツリー・myアイランド・myスタジオ・シール・ワカル壁・称号・アルバムなど）も同じ書き方で。名前をそろえてくれれば、あとで本物の画面に差し替えます。
- 数値で人をはかる表示・画面に「AI」の文字は出さない（いつもの決まり）。

## 5. 一枚絵の書き方（絵の注文になる）

`〔一枚絵：…〕` の中身を、Seedream 5.0 Pro への注文としてそのまま使います。

- **見えるものだけ**を具体的に：場所、時間・光、誰がどこにいて何をしているか、構図（引き／寄り）。
- 気持ちや比喩（「〜みたいな顔をしている」）は絵にしにくいので、見た目に言い換える。
- 登場人物は登録名で（KIMORIN・バティ・フリージー…）。バティや本人の姿は人によって違うので、一枚絵には描かない（立ち絵で重ねる）。
- 絵の中に文字を入れない（札・看板の文字はカードで出す）。

## 6. 話す人

- 登録済み：KIMORIN・OBOLON・MONBAN・バティ・たこ焼きブラザー・たこ焼きシスター・大根カイザー・フリージー・ヒポキン・ロングG・ハットG・ボスG・うんちピンポンくん・小箱（`apps/web/lib/story/cast.ts`）。
- `{neo}` `{bati}` も話者にできる。
- 新しい人物はそのまま書いてよい（レポートの「まだ登録されていない話者」に出て、立ち絵を用意する一覧になる）。**同じ人物の呼び方はそろえる**（「オートン」「オートンたち」「左のオートン」は別人として数えられる）。

## 7. 差し込み文字

`{name}`（名前）・`{inviter}`（招待した人）・`{neo}`（ネオの名前）・`{bati}`（バティの名前）・`{food}`（好きな食べ物）・`{age}`。これ以外を使うときは知らせてください。
