# 惑星ホーム 本番への引き継ぎ 06：空から探す（知らない人の作品に出会う）

物語セッション → 開発セッション。データは 01 の2章（タグ・公開範囲・大陸・お気に入り・ブルーナ・見た記録・通報）で入っている。ここは画面。試作は `design/home/template.html`（`expOpen` `drawSky` `openSearch` `startSwap` `tripGo` `expLand` `spawnStrangers` `spawnFlutter` `expShow` `autoStart` `SKYV`）。決定は M-R295〜M-R312、M-R316。

## 1. 入り方・戻り方
- ホームで**2本指でつまむ**（指の間が0.72倍以下）→ 空へ上がる。初めての時だけ「✌️ 2本の指でつまむと、空から探せるよ」。
- 空で2本指を広げる（1.35倍以上）→ ホームへ戻る。大陸に降りている時につまむ → 空へ戻る。
- PC はトラックパッドのピンチ（ctrl＋ホイール）でも同じ。
- 上がる時、ホームの絵は縮めない（黒い縁が出る）。少し寄って薄れる。空の絵の大きなぼかしは使わない（カクつく）。空の絵は惑星を開いた時に先に読み込んでおく。
- 空にいる間は、ホームのダチ・コロリンは隠す（上に重ならないように）。

## 2. じぶんの空
- 惑星ごとの「空」の絵の上に、手前に**じぶんの島**（タップでホームへ）、周りに**お気に入りの大陸5つ**（位置は固定の5枠：[.25,.2,.37] [.76,.23,.37] [.5,.37,.32] [.21,.55,.42] [.8,.57,.42]、じぶんの島 [.5,.85,.56]）。空き枠は「＋ さがす」。
- 惑星ごとの見え方：水星＝海に浮かぶ島、木星＝森の中の広場、土星＝輪の上のレコード広場（ほかの5惑星は 05 の世界に合わせて決める。海王星は深海のドーム）。
- 上の帯：← ／〔🔍 大陸をさがす〕／〔✈ 旅〕。

## 3. さがす
- 〔🔍〕で検索の幕：入力欄、タグのチップ（ユーザーに見せるのは検索のチップだけ）、結果の一覧（島の絵・名前・☆・〔降りる〕）。結果は一致の点数順、同点はランダム、人気順にしない。
- ☆：空き枠があれば入る。いっぱいなら「「◯◯」をどの島と入れかえる？」になり、新しい島を枠へ**ドラッグ**（またはタップ）で入れかえ。もう一度 ☆ で外す。

## 4. 旅（M-R312）
- 〔✈ 旅〕：雲の中を飛ぶ演出（約1秒）のあと、大陸が6つ浮かぶ「旅の空」（[.25,.2,.37] [.76,.23,.37] [.5,.39,.33] [.21,.57,.42] [.79,.6,.42] [.5,.8,.5]、じぶんの島は出さない、上に「✈ 旅の空」）。
- 連打できる。毎回まだ見ていない大陸を先に選ぶ。
- 旅の空から ← でじぶんの空へ。初回だけ「✈ ← でじぶんの空にもどれるよ」。

## 5. 大陸に降りる
- 島をタップ → その島へズームして降りる。降りた景色の上に大陸の名前（長い名前は画面の46%の幅に収まる大きさ）。
- 知らない人の作品が、その惑星の乗り物で浮かぶ（最大7）。水星は船が左右に航行、木星は小さなアートを持った蝶、土星は跳ねるコロリン。ドラッグで動かせる。
- タップ → 作品が開く（その惑星の開き方）。下に**作った人の姿（乗り物ごと）と名前だけ**、その下に丸い ☆（ブルーナに保存）と ♡（推す）、右下に〔⋯〕（表示しない・通報）。タグは出さない（M-R310）。
- ♡ で推した人は、以後その惑星のホームにも来る。

## 6. 大陸で▶（M-R296・M-R301）
- 右上の▶ → その島に上陸し、「島のふち（桟橋・広場の端・森のふち）から見る」景色に切り替わる。右下に自分の後ろ姿。
- 作品が1つずつ来て（水星＝船が左から、木星＝蝶が上から、土星＝コロリンが上から跳ねて）、開いて、終わると去る。止めるまでずっと続く（区切りで聞かない）。順番はランダム。
- 開いている間も ☆・♡・⋯ はそのまま押せる。⋯ で非表示・通報すると、その人は消えて次へ。
- ■ または画面タップで止めると、元の景色に戻る。

## 7. 大陸ごとの絵（3枚）
- 空から見た島（白背景を抜いた絵）、降りた景色、ふちから見た景色。試作の絵は design/mv-art/out/ の `isl-<惑星>-<key>.jpg` `exp-<惑星>-<key>.jpg` `exp-<惑星>-<key>-pier.jpg`、空の背景は `exp-<惑星>-sea.jpg`。水星・木星・土星の分（各32枚）はそのまま使ってよい。

## 8. 確かめ方
- ピンチで上がる・戻る、じぶんの空、検索、☆と入れかえ、旅の連打、降りる、作品を開く（作った人の姿と名前、☆♡⋯）、推した人がホームに来る、大陸の▶、非表示・通報、ホームのダチが空に重ならない。
