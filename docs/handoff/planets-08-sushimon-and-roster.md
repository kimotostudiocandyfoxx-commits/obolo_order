## 3. スシモン7体の作品（全員、8惑星ぶん）
中身は design/home/sushi/sushi.json（サーぽんは template.html の `SAPON`）。音と動画は design/home/sapon/ と design/home/sushi/<key>/、絵は design/mv-art/out/sapon/・out/su/<key>/。
- 土星：その食べ物の豆知識のひとこと（本人の声）。
- 木星：海や畑のアート1枚＋題（例「お父さんだポン。」）。題を本人の声で読む。
- 水星：本人の曲（ジャンルはキャラごと。「名前」をくり返す短い曲）＋ジャケット。曲名を本人の声で読む。歌詞（くり返しの言葉）が出る。
- 火星：木星のアートが3秒でつなぎ目なくくり返す動画（mv.mp4）＋水星の曲。曲が終わるまでループ。
- 金星：豆知識ラジオ（40〜60秒）。後ろで本人の曲を声のじゃまにならない音量で、区切りに効果音。
- 天王星：グッズ1つの絵。タップと同時に、本人の声でタイトルとひとこと。
- 冥王星：子ども向け6ページの絵本。片ページが正方形、文字は絵のじゃまにならない下の帯。右端からめくる。本人の声で題と中身を読み上げ、読み終わると次へ。右下に読む速さ〔ゆっくり〕〔ふつう〕〔はやい〕（0.8・1・1.3倍、声の高さは変えない、覚えておく）。最後まで読んだら（最後で〔›〕を押しても）本が閉じて飛んでいき、ホームに戻る。
- 海王星：すぐ遊べる簡単なゲーム。タップの瞬間に本人の声でゲーム名。サーぽん＝タップした所がぷるぷる（WebGL）、ガリみ♡＝花びらがふわっ、えびすけ＝うしろにジャンプ、ウニまる＝くるくる回る、いかチョロ＝スミ、しゃりお＝お米がパラパラ、かにぶぅ＝タップした所へ横歩き。
- 声（Fish Audio。実在の人や既存キャラの名前の声は使わない）：サーぽん＝活発なマスコットキャラ、ガリみ♡＝アニメ声の少女、えびすけ＝元気な男の子、ウニまる＝子供の声、いかチョロ＝元気な男の子の声、しゃりお＝子供ドクター、かにぶぅ＝元気なこども。ID は sushi.json の voice。
- 声は、タップの瞬間に鳴らす（少し遅らせるとスマホで鳴らない）。
- 曲は試作の仮の曲（手元で作ったもの）。本番は音楽の仕組みで作り直してよい（くり返す言葉とジャンルはそのまま）。
