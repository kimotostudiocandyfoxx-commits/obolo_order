# 惑星ホーム 本番への引き継ぎ 04：土星（声のコロリン）

物語セッション → 開発セッション。土星は**共通の型の例外**：ダチは浮かばず、レコードの床の上で跳ねる。試作は `design/home/template.html`（`setupRoll` `makeBall` `startSim3D` `pop` `play` `openProfS` `pileStart`）。

## 1. ホーム（奥行き版、M-R307・M-R308）
- 背景：パステルの虹の空、手前に色とりどりの小石、真ん中に大きなレコード（右奥にトーンアーム）。空に土星の玉は出さない（輪だけ）。
- コロリン（声の投稿の玉）は**8体まで**。それ以上は順番待ちで、割れた分だけ上から落ちてくる。
- 床はレコードを斜めから見た楕円。コロリンは床の上の位置（gx, gz）と高さ（h）を持つ：
  - 画面の位置：x = 中心x + gx×横半径、y = 中心y + gz×縦半径×0.86 − h×大きさ。
  - 大きさ：奥（gz=−1）0.58倍 → 手前（gz=+1）1.18倍。奥のコロリンは手前のコロリンの後ろに隠れる（重なり順を gz で決める）。
  - ときどき（約1〜2.5秒ごと）ぴょんと跳ねて床の上を移動する（上向きの速さ 330〜530、横は 0.28〜0.49/秒。外側に寄りすぎたら内側へ）。着地でつぶれて戻る（ばね）。跳ねている間は床に影。
  - 床の上でぶつかったら押し合う（手前ほど大きいので、画面の大きさで距離を測る）。
- タップ：割れてちびキャラが出て、ひと言と声（その人の声）。泡は「ひと言」が上、「by 名前」が下の小さな字。
- ドラッグ：持ち上げて好きな所へ。離すと投げた向きに床に沿って飛ぶ。
- 名前はボールの中・顔の下に小さく（自分のボールには出さない）。グラサンは丸7割・その他3割。
- レコード（トーンアーム）をタップ：自分のプロフィール。
- 2本指でつまむと空へ（06の文書。土星の空は輪の上のレコード広場、M-R316）。

## 2. 右上▶（M-R287〜M-R290、M-R304）
1. 自分が空から落ちてきてレコードに着地し、眺めが「巨大なレコードの寄り」に切り替わる（ミラーボール・針なし）。右下に自分の後ろ姿（左半分だけ見える位置）。
2. コロリンがレコードの溝に沿って奥から手前へ流れ、溝の途中で割れて喋る（泡はコロリンの上）。割れた後も溝に沿って流れ続ける。同時に3〜4体。
3. **最初のコロリンが喋るまで約2.3秒**：最初の3体は溝の途中から流し始める。以降は2.6秒ごと。
4. 全部終わると「🎉 今日のコロリン、全部聞いたね！」。■ で止まる。
- 溝の楕円（試作の PATH）：中心 x=1.02・y=0.455、半径 x=0.8・y=0.32、角度 262°→72°、152°で割れる、1体10.5秒。

## 3. プロフィール（土星、M-R304）
- 奥行きなしの**2D舞台**：真横から見た石の地面（水平）、左右にスピーカー、背景はぼかしたクラブ。
- その人の過去のコロリンが上から降って積もる（自分なら18、ダチは10〜13）。一番新しいコロリンに「NEW」。
- タップで割れて喋る、ドラッグで投げられる。

## 4. 画面にないもの
- 〔器〕〔広場〕〔つぶやく〕は無い（M-R314）。声を吹きこむのは月。

## 5. 確かめ方
- 奥へ行くと小さく・手前で大きく、隠れる順、跳ねて移動、影、タップで割れて声、ドラッグで投げる、▶で最初の声まで約2.3秒、プロフィールの2D舞台。
