## 仕上げのときに直してほしいこと（多い順）

1. **1行に条件をまぜない（約180か所）**：`（パス）バティ「…」` や `（mana_low）MONBAN「…」` が行の途中にあると読めません。条件は**行の頭に1つ**、条件ごとに行を分けてください。
2. **機能を呼ぶ場所に名前をつける（315か所のうち約250か所が名前なし）**：`〔画面：myツリー｜…〕` `〔制作：曲づくり｜…〕` のように、`｜` の前に機能の名前を。同じ機能は同じ名前に。
3. **選択肢の行き先は枝の名前（半角英数字）か場面ID に**：`→通常の地図` `→掟の表示` `→この選択` などの日本語の行き先は、枝の名前にしてください（`（map）…` を書いて `→map`）。
4. **同じ人物の呼び方をそろえる**：「オートン」「オートンたち」「左のオートン」「鞄のオートン」、「ゴリラ」「ゴリラA」などは別人として数えられ、それぞれ立ち絵が要ることになります。立ち絵が同じでよい人は同じ名前に（言い方の違いは `オートン（左の）「…」` のように（）で）。
5. **一枚絵（43枚）は見えるものだけを具体的に**：Seedream 5.0 Pro で、今の物語の絵と同じ画風（暗い宇宙・金色の光・縦長）で描きます。文字・看板の文字・音（「ザンッ」など）は絵に入れません。`{neo}` の島など人によって違うものは、一般的な姿で描きます。

## 追加（2026-10-13）：絵・声・効果音を作るための書き足し

台本が届いたら、開発チャットで UI を順に組み、足りない絵・声・効果音も作っていきます。そのために、次の3つを台本と一緒に用意してください。

### A. 人物表（`docs/story-rewrite/cast.md`）

台本に出てくる**話す人・映る人ぜんぶ**について、1人1ブロック。デザインがすでにある人は「デザイン：あり」だけでよい（絵はクライアントから届きます）。ない人は、見た目と声を書いてください（これがそのまま絵と声の注文になります）。

```
## エビ
- デザイン：なし
- 見た目：手のひらサイズの赤いエビ。大きな黒い目、長いひげ。青いスカーフを首に巻いている。二本足で立つ。
- 性格：せっかち、よくしゃべる
- 声：高め、早口、元気。語尾に「〜っス」
- 同じ姿でよい呼び方：エビたち、小エビ
```

- 見た目は**目に見えるものだけ**（形・大きさ・色・服・持ち物・目立つ特徴）。
- 声は 年齢の感じ・高さ・速さ・話し方のくせ・口癖。
- 群れ（エビたち）や「A・B」で呼ぶ人は、姿が同じなら1ブロックにまとめて「同じ姿でよい呼び方」に。

### B. 場所表（`docs/story-rewrite/places.md`）

場面の背景になる場所ごとに1ブロック。すでに絵がある場所は「絵：あり」だけでよい。

```
## mercury-beach
- 絵：なし
- 見た目：水星の小さな島の浜辺。白い砂、ガラスのように透ける波、空に大きな惑星が二つ。
- 時間・光：夕方、金色の光
- 出てくる場面：L2-MERCURY-S001〜S004
```

- 台本の中では `〔背景 mercury-beach〕` のように、この名前（半角英数字とハイフン）で呼ぶ。

### C. 効果音・BGM・声の言い方（台本の中に書く）

| 書き方 | 意味 |
|---|---|
| `〔SE：扉がきしんで開く〕` | 効果音（中身がそのまま音の注文になる。何の音か具体的に） |
| `〔BGM：静かな夜の海〕` ／ `〔BGM止め〕` | BGM を変える／止める（同じ名前は同じ曲） |
| `エビ（ひそひそ声で）「…」` | セリフの言い方（今と同じ）。声を作るときの演技の指示になる |

- 擬音を `〔ぼおおお〕` のように書いている所は、音を鳴らしたいなら `〔SE：汽笛が低く長く鳴る〕` に。
