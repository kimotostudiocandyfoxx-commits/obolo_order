# 水星の設計（2026-10-05 クライアント決定・第2版）

水星は **音楽の惑星**。木星（蝶）・土星（ころりん）と同じく、**タイムラインに友達の作品が流れてくる** 形にした。
（第1版の「ジャンルごとの島を選んで聴く」はやめた。spec.md §2.5 の「スワイプで次々に聴く」「3段階の Stars」は残す）

## 海（タイムライン）＝ 海図
- 友達・フォロワーが **公開した曲が船になって**、海を **88時間** 渡る
- 船の上には吹き出し（島をつくった／新曲をアップした／今これを聴いてる／★3をつけた など）
- **船をタップ → その人が88時間以内に作った曲が再生**。複数あれば横スワイプで次の曲。星3段階
- 上に 全部／フォロー／ダチ、「今 N人が航海中」
- 下に **海図／作曲／島**

## 島（プロフィール）
- **ユーザー一人ひとりに島** がある（自分の島、友達の島）
- 島の名前（〇〇 ISLAND）、「島を飾る」、島の住人・発見した島・出した曲
- **発表していないデモ曲は、島の土の中に埋まっている**（自分の島だけ見える）
- 公開した曲から順に **船になって** 友達・フォロワーの海へ出航
- **88時間後に島へ戻り、島のレコードとして飾られる**
- **★1／★2／★3 の宝箱**：星をつけた曲がたまる（3段階 Stars のプレイリスト）

## 作曲（✏️ 仮組み：クライアントのデザインができるまで）
- **パートナーに話しかけると、曲を作ってくれる**チャット
  - バティができるまで（ORDER になって2回目の月の神殿で作るまで）は **KIMORIN** が作る
  - バティができたら **バティ** が作る
- 話す（🎙 声で入力。iPad の Safari なら聞き取れる）→ 文字で直してもよい → 「送る」
- 曲の感じを選ぶ（ポップ／ロック／ヒップホップ／バラード／EDM／おまかせ）→ 作曲中… → 曲のカード（タイトル・歌詞4行・レコード・▶で試聴）
- **「島の土に埋める（デモ）」** → 自分の島の土の中へ。そこから出航させると船になる
- いまの曲づくりは仮：タイトルと歌詞は話した言葉から決まった型で作り、音はシンセ。本物は AI（歌詞）＋音楽生成（spec §7）につなぐ

## 実装（デモ）
`apps/web/components/mercury/MercuryWorld.tsx`（/mercury と6日目のチュートリアルで共通）
- 海の絵：デザイン画からタブと下のボタンを切り取ったもの（`mercury-sea.jpg`）。船8隻は同じ絵から吹き出しごと切り出して（`ship-*.webp`）、元の位置で波にゆれるように重ねている。タブで表示しない船は、海の色でぼかして隠す
- 自分の船：まだ絵がないので、OBOLO NEO を乗せた簡単な船を描いている
- 島の絵：デザイン画の島（`mercury-island.jpg`）を全員の島に共通で使用。宝箱も同じ絵から切り出し
- 自分のデモ曲：作曲画面ができるまで、デザイン画の3曲（ラーメン・フリースタイル／遅刻ダッシュ8:29／ほかほか日だまり）が土の中に埋まっている
- 曲・住民はサンプル、音はアプリ内のシンセ。自分の島・星はこの端末に保存

## 作曲のしくみ（クライアント決定 2026-10-06）
1. **会話**：パートナー（バティ、いなければ KIMORIN）と話す。`POST /compose/chat`（Gemini。テーマと気持ちが分かったらジャンルを聞く）。
2. **曲の設計図**：ジャンルを選ぶと `POST /compose/design`。AI が曲名・歌詞（各行ひらがな付き）・コード進行（ローマ数字）・テンポ・キー・伴奏用の英語プロンプトを書き、
   `packages/ai/src/song.ts` がひらがなをモーラ（拍）に分け、コードと声域に合うメロディ（1拍1音、1行2小節）を作る。メロディを AI に任せないのは、必ず歌える形にするため。
3. **伴奏**：曲カードの「🎹 伴奏をつくる」→ `POST /compose/instrumental` → GPU サービス `gpu/music`（Cloud Run + NVIDIA L4、非公開・API だけが呼べる）。
   設計図のコードとメロディを簡単なシンセ音にした「ガイド」を MusicGen-Melody に聞かせるので、伴奏が設計図のテンポ・キー・コードに沿う（あとで乗せる歌とずれない）。
   1回最大30秒、AAC で Bunny に保存。GPU が眠っていると起動に1〜2分（その間は「もう一度押してね」）。
   ⚠️ MusicGen のモデルは非商用ライセンス → 有料公開前に差し替え（P-MER-5）。
4. **歌**（これから）：設計図の音符（ひらがな＋音程＋長さ）を DiffSinger に渡して歌声を作り、伴奏と合わせて1曲にする → Bunny に保存。
5. **自分の声で歌う／土星の読み上げ**（これから）：短い登録音声から声を真似る技術を重ねる。

モデルは `GEMINI_MODEL`（既定は `gemini-flash-lite-latest`＝Google の最新 Flash-Lite、使えなければ `gemini-2.5-flash-lite`。全惑星のバティとの会話で共通）。キーは土星や月と同じ `obolo-gemini-api-key`。
