# 水星の設計（2026-10-05 クライアントのデザイン）

水星は **音楽の惑星**。spec.md §2.5 の「スワイプで次々に聴く」「3段階の Stars」はそのままに、入り口を **海図と島** にした。

## 海図
- 海に **ジャンルごとの島** が浮かぶ：HIPHOP王国／クラシック草原／ポップタウン／ロック山脈／EDM大陸／トラディショナル諸島／みんなの島
- 島をタップ → 島のカード（住民・収録曲数）→ **「この島を航海する」**
- 上に「島・曲・船をさがす」、右下に「＋ 島をつくる」
- 下に **海図／作曲／船**（船＝プロフィール）

## 聴く画面
- 真ん中にレコード（丸い絵）、左右に前後の曲が少し見える
- **横にスワイプで次の曲・前の曲**
- 曲名・アーティスト・再生バー・時間、**星3つ**（3段階）
- 上に 全部／フォロー／ダチ

## 実装（デモ）
`apps/web/components/mercury/MercuryWorld.tsx`（/mercury と6日目のチュートリアルで共通）
- 海図の絵：デザイン画から検索バーと下のボタンを切り取ったもの（`mercury-map.jpg`）。絵に描かれた島カードと「島をつくる」の上に、動く本物を重ねている
- レコードの絵：デザイン画の3曲（ほかほか日だまり／遅刻ダッシュ8:29／ラーメン・フリースタイル）を切り出し。ほかの曲は絵文字のレコード
- 音はアプリ内のシンセで鳴らしている（本物の曲はまだない）

## まだのこと
- 作曲の画面、船（プロフィール）の画面 → クライアントのデザインが次に届く
- 島をつくる、検索
- 絵に描かれたポップタウンの光る輪は消せないので残っている（UIなしの海図の絵があると直せる）
