# 火星の設計（2026-10-05 クライアントのデザイン）

火星は **映像の惑星**。木星（蝶）・土星（ころりん）・水星（船）と同じく、タイムラインに友達の作品がとんでくる形。

## 星図（タイムライン）
- 友達・フォロワーが公開した映像が **UFO＋映像カード** になって **88時間** とんでくる
- UFO をタップ → その人の88時間以内の映像を再生
- 上に 全部／フォロー／ダチ、「今 N人がライブ中」
- 下に **星図／撮影／スタジオ**

## スタジオ（プロフィール）
- ユーザー一人ひとりにスタジオ。〇〇 STUDIO、フォロワー・作品数、フォロー／スタジオを飾る
- 公開した映像は、88時間とんだあとスタジオに並ぶ（大きい1枠＋6枠）
- まだ公開していない映像は **ロッカー** にしまってある（自分のスタジオだけ）→「公開する」で UFO になる

## 見た目は2パターン（✅ ユーザーが選ぶ）
- **街中**（未来都市・スタジオは宇宙船の中）と **郊外**（赤い峡谷）
- 「スタジオを飾る」で選ぶと、星図とスタジオの両方が切り替わる

## 撮影（✏️ 仮組み）
- 作曲と同じく **パートナーに話しかけると映像にしてくれる** チャット（バティができるまでは KIMORIN、できたらバティ）
- 話す（🎙）→ 種類を選ぶ（MV／映画／番組／おまかせ）→ 撮影中… → 映像カード（タイトル・シーン3つ・▶試写）→「ロッカーにしまう（未公開）」
- いまの映像づくりは仮：タイトルとシーンは話した言葉から決まった型で作り、絵は絵文字、音はシンセ

## 実装（デモ）
`apps/web/components/mars/MarsWorld.tsx`（/mars と7日目のチュートリアルで共通）
- 星図の絵：デザイン画2枚（郊外・街中）からタブと下のボタンを切り取ったもの。UFO＋カード8つは同じ絵から切り出し、元の位置でふわふわ浮かせている
- スタジオの絵：デザイン画2枚。描かれたタイトル・ボタン・映像カードの上に、本物を重ねている
- 再生：本物の映像はまだないので、サムネイルがゆっくり動き、シーンの字幕と BGM が流れる「仮の再生」
- 自分のロッカーには、スタジオのデザイン画の映像3本（月影の旅人／狐の夜明け／Neon Fox）を入れてある
