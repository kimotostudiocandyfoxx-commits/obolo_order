# 物語の演出（ショット・動き・字幕・背景プレート）

M-R251 の見直し（2026-11-23）で入れた「ドラマのように見せる」仕組みのまとめです。物語担当が台本に書き足せる項目と、
何も書かないときに自動で選ばれるルールを書きます。

## 1. 2つの見せ方（ステージ）と、字幕／吹き出し

切り替えは **`apps/web/lib/onboarding/stage.ts` の1か所** です。

| ステージ | どこで | 見せ方 |
|---|---|---|
| `cinema` | 1〜2日目（場面IDが `D01-`〜`D03-`） | 話している人だけを大きく寄せる（1画面に1人）。話し手が変わるたびにカメラが切り替わって寄る。物語の吹き出し（明朝・暗いガラスに金の線）。1日目は一人称のまま |
| `row` | 3日目（`D04-`）から、4〜8日目、会員後の m1〜m3 | 横並びの会話（前列3人まで＝話し手・聞き手・あなた、ほかは後列）＋カメラ（下の「ショット」）＋**字幕** |

- 場面ごとに変えるとき：`SCENE_STAGE = { 'D04-S005': 'cinema' }` のように足す。
- 字幕か吹き出しか：`linesOf()`。`row` は字幕、`cinema` は吹き出し。場面ごとに `SCENE_LINES` で変えられる。
- 確認ページでは `?subs=1` で1〜2日目も字幕に、`?subs=0` で3日目以降も吹き出しにできる。
- バティ・ダチ・月・工房のチャットは今まで通り吹き出し（「吹き出し＝チャット、字幕＝物語」）。

## 2. 字幕（row）

- 画面の下から3分の1。答えのボタンや入力欄が出ているときは、その上に上がる。顔にはかからない（顔は列の上の方）。
- 2行まで・中央・大きめの明朝。箱は無し、下から暗くなるグラデーションの上に影つきの白い字。
- 上に小さく話し手の名前（その人の色）。あなたの台詞は {neo}（無ければ「あなた」）。
- 吹き出しの種類は文字の見え方になる：
  - 叫び（`！！`、ドン！の吹き出し）… 大きく飛び込んで小さく揺れる
  - `！！` を含む … 太字
  - ひそひそ（小声）… 小さく、細く、字間を少し空ける
  - 「……」で始まる／終わる … ゆっくり浮かぶ、少し暗い
  - `**太字**`・`^^大きく^^`・`[[金:…]]` などの印は今まで通り
- 文字は声に合わせて出る。長い台詞は区切って出る。タップで次へ。下になぞると、過去の台詞が字幕の一覧で出る。
- 部品：`apps/web/components/story/Subtitle.tsx`。

## 3. ショット（row のカメラ）

台詞1つごとに「ショット」が1つ決まります（`apps/web/lib/talk/direction.ts`）。

| ショット | 見え方 | 数字（`CAMERA`） |
|---|---|---|
| `wide` | 列ぜんぶ | 等倍、0.7秒で移る |
| `two` | 話し手と聞き手の2人が入る大きさ | 最大1.12倍（2人が画面幅の9割に入る大きさまで） |
| `mcu` | 話し手の顔に寄る | 1.3倍 |
| `reaction` | 聞き手の顔へ切り替える | 1.26倍、切り替え（0秒） |
| `push` | 話し手へゆっくり押し込む | 1.12倍から1.36倍へ5.2秒 |
| `punch` | 話し手へ一瞬で寄って小さく揺れる | 1.42倍、0.17秒＋揺れ0.36秒 |
| `q3` | 斜め（3/4）：話し手を少し斜めから。話し手は向いている側と反対の 42% の位置、舞台（背景も）が 7度回る | 1.24倍、切り替え。3/4 の絵が無ければ正面の絵を 16度回す |
| `side` | 横から：2人が向かい合う（左の人は右向き、右の人は左向き）。ほかの人は画面から外れる | 1.16倍、2人は幅の 34% と 66%。横向きの絵が無ければ正面の絵（右の人は左右反転） |
| `ots` | 肩越し：話し手は奥の左（0.72倍）でこちら向き、聞き手は手前の右（1.55倍）で後ろ姿、腰のあたりで切れて、少しぼけて暗い。返事をすると左右が入れ替わる | 等倍、切り替え。聞き手の後ろ姿の絵が無ければ使わない |

カメラは、顔のある点を中心に拡大し、その点を画面の中央へ7割寄せます。顔の高さは変えないので、字幕の位置はぶれません。
同じショットの間は、7秒かけて3.5%だけさらに寄る（ゆっくりした漂い）。背景プレートがあるときは、列と同じだけ動きます。

### 自動で選ぶルール

1. 場面の最初の台詞 → `wide`
2. 叫び（`！！`、ドン！の吹き出し）→ `punch`（後列の人も少し反応）
3. 「……」・ひそひそ → `push`
4. 問い（`？` で終わる）→ 話している間は `mcu`、言い終わったら聞き手の `reaction`。話し手は前に乗り出す
5. 喜び（`！` で笑顔）→ `two`、話し手が跳ねる
6. 驚き（`！？`）→ `mcu`、話し手が一歩下がる（後列も反応）
7. それ以外 → 話し手が変わったら `mcu`、同じ人が続けたら `two`
8. あなたの台詞 → `two`（あなたと答える相手）
9. 2人のやりとり（同じ2人が交互に話している）か「……」の台詞のとき、4〜5行に1回くらい、斜めのカット（`side` → `q3` → `ots` の順）。
   4行以内に2回は使わない。叫びのときは使わない。**180度の規則**：列で左にいる人は、これらのカットでも左のまま。
10. 同じショットは3回続けない（3回目は `two`、`two` が続いたら `wide`）
11. 話し手が変わったら**切り替え**（カットで0秒）、同じ人が続けたら**移動**（上の秒数）

聞き手は、話している人の方へ少し向いてうなずく（「聞いている」動き）。後列の人は静かに立ち、強い台詞のときだけ小さく反応する。

### 台本に書き足せる項目（say の行）

```ts
{ t: 'say', who: 'MONBAN', text: '……', shot: 'reaction:KIMORIN' }
{ t: 'say', who: 'KIMORIN', text: '……', move: 'enter-left' }
{ t: 'say', who: 'OBOLON', text: '……', move: 'exit-right:MONBAN' }
```

- `shot`: `wide` / `two` / `two:相手` / `mcu` / `reaction` / `reaction:誰` / `push` / `punch` / `q3` / `q3:誰` / `side` / `side:相手` /
  `ots:A>B`（A が話し、B の肩越し。B の後ろ姿の絵が要る）
- `move`: `enter-left` / `enter-right`（その人が列に入るとき、どちらから歩いてくるか）、`exit-left` / `exit-right`（出ていく方向）、
  `turn`（その台詞の間だけ左右反転して相手の方を向く）、`lean`（乗り出す）、`hop`（跳ねる）、`step-back`（一歩下がる）。
  `:誰` を付けると、話し手以外の人の動きになる。
- 何も書かなければ上の自動ルール。「誰」は台本の話し手名（`KIMORIN`、`MONBAN`、`たこ焼きブラザー` …、あなたは `me`）。

### 登場と退場

- 列に新しく入った人は、近い側（左半分なら左、右半分なら右）から0.7秒で歩いて入る。
- 列から外れた人は、近い側へ0.6秒で歩いて出る。`move` の `enter-*` / `exit-*` で向きを指定できる。

### 動きをへらす設定（prefers-reduced-motion）

寄りは1.06倍まで、移動は0.4秒以上のゆっくりした切り替え、漂い・揺れ・登場の歩きは無し。

## 4. cinema（1〜2日目）のカメラ

`apps/web/lib/story/motion.ts` の `MOTION.cinema` で調整します。

- 話している人だけが出る（ほかの人は0.11秒で消える）。顔が画面の上から33%の所に来るように置き、最大2.5倍まで寄る
  （小さく丸いキャラ＝OBOLON・ピンポンくんは、それぞれの上限×1.35まで。{bati}などの自分の絵は1.7倍まで）。
- 話し手が変わると、立っていた側から9%横・0.78倍の所から、0.56秒で一気に寄る（カメラが新しい話し手へ振れる）。
- 話している間は、6.5秒かけて4.5%さらに寄り、少し上へ漂う（行き来をくり返す）。
- 台詞の読みは row と同じ（`lineKind`）：叫びはさらに1.1倍寄って0.36秒揺れる、「……」は5.2秒かけて10%寄る。
- 止め絵に描き込まれた人が話すときは、今まで通り止め絵の口が動く（寄りは無し）。

## 5. 背景プレート（row）

`apps/web/lib/onboarding/plates.ts`。

- `PLATES['s/止め絵'] = { image: 's/plate-…jpg', floorY, horizonY }`：その止め絵の場所の、row 用の背景（場所ごとに1枚。
  月の神殿の朝はどの日も同じプレート）。`SCENE_PLATE['場面ID']` で場面ごとに別のプレート（または無し＝`null`）にできる。
  `floorY` = 足が立つ床の高さ（絵の高さに対する 0〜1、上から）。画面では列の地面の線に合わせて置かれ、カメラと一緒に動くので、
  どのショットでも足が床に乗る。`horizonY` = 目の高さ（立った人の胸のあたり）。
- 対象：3日目以降の row の46場面で使う場所 22か所（`scripts/story-images/m-r251/plates.json`）。
- プレートはくっきり。寄り（1.2倍より上）のときだけ少しぼける。
- `STILL_CLEAN['s/止め絵'] = 's/止め絵-empty'`：列にも立っている人が描き込まれた止め絵の、人を消した版。row ではこちらがくっきり出る。
  まだ無い止め絵は今まで通りぼかす（`media.ts` の `STILL_CAST`）。
- 作り方（Seedream の編集・外側への描き足し）：`scripts/story-images/m-r251/`。

### 390×844 での列の寸法（プレートを作るときの目安）

- 列の地面（前列の足）：画面の上から約 760px（下の答えの欄が 84px のとき）。答えのボタンが出ると、その分上がる。
- 前列の背の高さ：約 330px（列の高さ 388px × 0.86）。描かれた住人は、その 0.84 倍前後。
- 後列：前列の 80%（約 265px）、地面は前列より約 27px 上。少し暗い。
- 目の高さ（立った人の胸）：地面から約 200px 上 ＝ 画面の上から約 560px。
- 寄り：`mcu` で顔を中心に1.3倍、`punch` で1.42倍、`push` で最大1.36倍。プレートはその分も含めて、画面の高さの約2倍、幅にも余裕を持たせる。
- 字幕は下の3分の1（地面のあたり）に出るので、プレートの下の方は落ち着いた暗めの床にする。

## 6. 別の向きの絵（views）

`apps/web/lib/story/views.json`（向きの絵を作る作業が書く）：キャラごとに `back`（後ろ姿）・`side`（横向き、右向き）・`q3`（3/4）の絵と、
足の位置・頭の箱。キーは絵の名前（`kimorin-sun`、`monban` …）か話し手名（`KIMORIN` …）。無い絵は代わりを使う（上の表）。
