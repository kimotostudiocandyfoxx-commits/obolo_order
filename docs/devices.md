# 将来のデバイスと画面の考え方（2026-10-05 クライアントと決定）

## 2つのデバイス（将来）
| デバイス | 形 | 役割 | 入力 |
|---|---|---|---|
| 大画面 | **正方形**。家の壁に投影する | 見るところ（舞台） | **触れない**（✅） |
| 手元 | **丸い**、持ち運べる小さな画面 | 操作するところ（リモコン） | **基本は声**（✅）。聞き間違いの訂正で文字を打つこともある |

→ 大画面は触れないので、**すべての操作を丸いリモコンだけでできる**ように作る。

## 丸いリモコンの操作（✏️ Claude の提案。クライアント確認待ち）
| 操作 | 意味 |
|---|---|
| **まわす**（ふちを指でなぞる／将来は物理ダイヤル） | 大画面の中で選ぶものを動かす（次の蝶、次の投稿、選択肢、スクロール）。1目盛りごとに軽い振動 |
| **まん中をタップ** | 決定・ひらく |
| **まん中を長押し** | 話す（押している間だけ聞く） |
| **下へはらう** | もどる |
| **ふちの8つの場所** | よく使う行き先（例：探す／たまご／木）。8はOBOLOの数字 |

- 選んでいるものは、大画面ではっきり光らせる（触れない画面なので「今どこか」が一番大事）
- 話した言葉は大画面に文字で出す。間違った言葉はリモコンでタップ →「言い直す」（第一候補）か「文字で直す」（小さなキーボード）
- 丸い画面で文字やボタンを置けるのは、円の内側およそ7割
