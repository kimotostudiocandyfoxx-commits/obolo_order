## 木星は「命が宿る星」
日常（見た風景、今日食べたご飯）を残し、思い出にしていく星。

## 木（自分のプロフィール）
| 部分 | 役割 | 公開 |
|---|---|---|
| 根っこ | 自分だけのデータフォルダ。撮った写真はまず全部ここに保存される | 非公開 |
| 枝 | フォルダ分け（旅・食べ物など、好きに作れる） | — |
| 葉っぱ | 投稿一覧。88時間飛び終えた蝶がここに戻ってくる | 公開 |

## 写真は木星、動画は火星（✅ 2026-10-07 クライアント決定）
- 木星にしまえるのは **写真だけ**。動画を保存する機能は木星にはない
- 動画は **すべて火星の「裏スタジオ」** に保存する（`docs/mars.md`）
- 以前に木星の根っこへ入れた動画は、移行（0014）で火星の裏スタジオへ移した

## 投稿の流れ
1. 写真を撮る → 自動で **根っこ** に保存
2. **卵のボタン** → 根っこのデータフォルダが開く
3. 写真を選び、文字を入れたり加工したりして、**丸い形の投稿** をつくる
4. **投稿ボタン** → 投稿が **蝶** になる

## 蝶と空（タイムライン）
- 蝶は **88時間**、フォローしてくれている人のタイムライン（**空**）を飛び続ける（ストーリーのような仕組み）
- 蝶をタップすると投稿が見られる
- 88時間以内に複数投稿していれば、その投稿が全部見られる
- 88時間たつと、自分の木の **葉っぱ** に戻る

## 空の見え方（✅ 2026-10-05 クライアント指定）
- 空に出る蝶は **最大8体**。ふわふわ浮いている
- 見終わった蝶は画面から **フェードアウト** し、その場所に **別の蝶が入ってくる**
- ~~動画も投稿できる。長さは8秒まで~~ → 動画は火星へ（2026-10-07）

## 実装（2026-10-07 サーバー接続）
`apps/web/components/jupiter/PatapataWorld.tsx`（/jupiter は `live`＝サーバー、5日目のチュートリアルは端末だけ）、`apps/api/src/jupiter/`
- 根っこ：`POST /media/photo` → `POST /jupiter/roots`（写真だけ。自分だけ見える）。動画を入れようとすると「火星の裏スタジオへ」と案内。整理（消す）もできる
- 投稿：`POST /jupiter/posts`（根っこから1つ、ひとこと・加工・枝0〜3）。88時間は空を飛び、そのあと木の葉っぱになる
- 空：`GET /jupiter/sky?tab=all|following|friends`（タブは全惑星共通のみんな／フォロー／ダチ）。1人1匹、中に88時間以内の投稿が全部
- 木：`GET /jupiter/trees/:id`（葉・実＝☆・トモダチ＝相互フォロー、枝の名前）。札をタップで枝の名前を変える（`PUT /jupiter/branches`）
- フォローは土星と同じ（全体で1つのフォロー）。☆は `POST /jupiter/posts/:id/star`
- 探す：`GET /jupiter/users?q=`
- 蝶の絵：モックの切り出し（サンプル住人）／🦋 蝶を描いてもらう（Gemini、`POST /me/butterfly/candidates`）／土星のキャラ＋羽
- みんなの空は、本物の蝶が少ないうちはサンプル住人で埋める（✏️ 仮）
