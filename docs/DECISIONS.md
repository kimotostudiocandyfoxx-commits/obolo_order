# 決定事項ノート

全部のチャットが、作業の前にここを読む。決まったことは、決めたチャットがここに書き足す（日付と、誰が決めたか）。
迷ったら、ここに書いてあることを優先する。ここにないことは、利用者に聞く。

## 進め方
- 利用者は一人で開発している（iPad mini）。返事はいつも日本語
- 台詞を勝手に変えない。台詞を変えるのは物語チャット。ただし、利用者が直接指示した台詞の直しは、そのとおりにする（2026-10）
- 動画は、先に文字でプランを出し、利用者が直してから作る（2026-10-20）
- Seedanceの動画は、作ったら必ずコマ送りで確認し、不自然なら作り直す。効果音・BGMは、制作チャットの判断で足したり変えたりしてよい（2026-10-20）
- 秘密の鍵は、チャットに貼らない。GCPのSecret Managerに、Cloud Shellの `read -rsp` で入れる。GitHubのVariablesには秘密でないものだけを入れる

## 画面のきまり
- 人を数字で測る表示を出さない（計測は裏側だけ）
- 「AI」と画面に出さない
- 子どもにも安心な内容にする
- 文字はすべて明朝体（Shippori Mincho）（2026-10-20）
- 本番画面はチャット形式が軸。15〜20歳が「なにこれ！スゲェ！」となる質。没入感を下げるものは置かない（2026-10-19）
- 「ORDERになる」と言う
- 土星までは文字だけで進む
- 動画は720p以下、1本1MB以下。月88円のプランなので、費用に気をつける

## 物語の決まり（UIに入っているもの）
- 一番最初の招待者は「木元 駿之介」。招待者が分からないときの見本もこれ（2026-10-22）
- 招待者の名前の声が作れないときは「なるほど…。招待されたのか…。」だけを声にする（2026-10-22）
- 1日目：「おい待て」のあとの、MONBANが振り返る動画はなし（2026-10-22）
- 2日目の門：切符が紙飛行機になって本部へ → 門に近づくと閉まる → MONBAN「来たか…切符は持ってきたか？」→ 切符を見せる → 「地球の神殿に行け…地下にロケット場がある」→ 門が開く → くぐる途中でKIMORIN「待ちなさい。」→ 以降は門の内側から入口を見た景色（2026-10-22）
- 地球の神殿は、1日目と同じ天球儀の大広間（2026-10-22）
- ドラゴンのオチは、水盤に80本の腕が映る形（2026-10-22）
