### DJ（第1段階：音声エンジン＋仮の画面）— `/preview/dj`
`apps/web/lib/dj/`（エンジン）、`apps/web/components/dj/`（仮の画面）。
- 2デッキ。曲は**自分の保存した曲**（BPM が分かっている）／デモ曲／端末の音声ファイル
- 再生・一時停止、CUE（CDJ と同じ動き）、ホットキュー4つ（長押しで消す）
- テンポ ±16%、キーロック ON/OFF（Signalsmith Stretch：テンポを変えても音程そのまま）
- 3バンド EQ（−26dB〜+6dB）＋フィルター（左＝ローパス／右＝ハイパス）、チャンネルフェーダー、クロスフェーダー（等パワー）
- ループとビートジャンプ（2026-10-12）：LOOP で直前の拍から「いまの長さ」のループ、もう一度で解除。½／×2 で長さ（1/4〜32拍、ループ中ならその場で伸び縮み）。◀◀ ▶▶ は「JUMP ○」に出ている拍数だけ前後に飛ぶ（ループの長さとは別。JUMP をタップして 1/2・1・2・4・8・16・32 から選ぶ。ループ中はループごと動く）。ループの外へ飛ぶ（ホットキュー・CUE）とループは外れる。波形にループの範囲を緑で表示
- エフェクト：FILTER／ECHO（拍に合わせた付点8分）／REVERB／FLANGER／SWEEP（2小節で動くフィルター）。ミキサー各列のいちばん下が FX つまみで、長押しで種類を選び（ダブルタップはほかのつまみと同じく 0 に戻す）、回すとその効果が動く（フィルターも FX の一つ。2026-10-12）
- BPM：自分の曲は作曲時の BPM、ファイルは自動検出（web-audio-beat-detector）。SYNC＝相手のテンポに合わせ、両方再生中なら拍の位置もそろえる
- ジョグ：真ん中を触る＝スクラッチ（止まっている時は頭出し）、ふち＝ピッチベンド
- 横画面・マルチタッチ（つまみごとに指を追う）・iOS Safari（最初のタップで音を開始、`audioSession = playback` でマナーモードでも鳴る）

技術の決めごと（相談された案からの変更点）：
- **別の Vite アプリにしない**：アプリはすでに Next.js の PWA。同じアプリの中に入れて、ログイン・自分の曲・MV をそのまま使う。
- **Tone.js は使わない**：エフェクトは Web Audio の部品で書ける（4つで約200行）。重さが減り、AudioContext が1つで済み、iOS で鳴らない問題の原因が減る。
- **Signalsmith Stretch は public/vendor から読み込む**：このライブラリは自分のソースから AudioWorklet を作るため、ビルドでまとめると壊れる（実際に起動しなかった）。パッケージのファイルをそのまま `public/vendor/` に置いて読む（版を上げる時はコピーも更新）。
- **BPM 検出は「端末のファイル」の時だけが本番**：自分の曲は作曲時の BPM が正確なので、SYNC がずれない。
- ライセンス：Signalsmith Stretch（MIT）、web-audio-beat-detector（MIT）。GPL/AGPL は使っていない。

### 見た目（2026-10-12 クライアントの参考画像）
`apps/web/components/dj/DjConsole.tsx`。**丸が3つ横につながった形**（左デッキ・ミキサー・右デッキ）、暗い木目のボディに金の縁、オレンジと青の光。
- デッキの丸：真ん中に光る渦のプラッター（ジョグ）。周りの輪に ♪LOAD・ホットキュー1〜4・ループ（½・LOOP・×2）・ビートジャンプ（JUMP 拍数・◀◀ ▶▶）・SYNC、外側にテンポとその下に KEY、下に光る CUE（オレンジ）と再生（青）
- ミキサーの丸：上に2本の波形（曲名と BPM つき）、左右に EQ（HI・MID・LOW）とフィルター、チャンネルフェーダー、下にクロスフェーダー
- **VJ**：火星で MV をつけた曲は、そのデッキの**ターンテーブルに MV が流れる**（曲と同じ位置・同じ速さで進み、止めると止まる）。**真ん中の丸いビジョン**では、2つの MV をクロスフェーダーとチャンネルフェーダーに合わせて混ぜて映す（低音で少しズームする）。MV がない曲は、音から作る光の模様。保存した曲の一覧に、その曲の最新の MV（`mvUrl`）が付くようにした
- ボタンの細かい配置・フェーダーの位置はクライアントがまだ決めていない（仮）。全部、丸の直径から大きさを決めているので、どの横向きスマホでも同じ形に収まる

### これから（第2段階以降の案）
- **VJ**：火星の MV がある曲は、デッキの映像を流し、クロスフェーダーで映像も切り替える
- クライアントのデザインを反映（画像待ち）
- 録音して保存（自分の DJ ミックス）。**公開は自分の曲だけで作ったミックスに限る**（端末のファイルは他人の曲のことがあるため、公開しない）
- 曲の拍の位置（ビートグリッド）を作曲時に保存すれば、SYNC と波形の拍線がもっと正確になる
