### テスターの入口（できた）

本番（本物の API・保存・通知）のまま、決めた人だけが「全部ひらく」「日を飛ばす」「最初から」を使える入口。
許可リストはサーバーの設定だけにあり、アプリの画面からは変えられない。リポジトリにメールは書かない。

#### つけ方（依頼者がやること）
1. GitHub のリポジトリ → **Settings → Secrets and variables → Actions → Variables** タブ → **New repository variable**。
   - Name：`TESTER_EMAILS`
   - Value：ログインに使うメール（何人でも。カンマ区切り。大文字・小文字は区別しない）。例 `me@example.com, friend@example.com`

2. **Actions → Deploy API → Run workflow**（ブランチ `claude/solar-system-home-planets-ew766y`）で API を作り直す。変数を変えた時は毎回これが必要（変数だけでは本番に入らない）。

4. 止めたい時は、変数からメールを消して（空にして）もう一度 Deploy API。
