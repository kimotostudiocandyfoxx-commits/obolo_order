# ローンチ（11/26）の準備

物語のセッションから届いた順番（M-R256）：新機能を止める → 作業途中のものを片づける → Claude への切りかえ → ログインのコードをメールで送る → 本番に出す版の固定。そのあとすぐ土星（M-R257、11/28 より前に本番へ）。

## 1. 本番に出す版の固定（できた）
- 本番（Vercel の Web と Cloud Run の API）は、**最後のコミットに `[release]` と書いた push の時だけ**作り直される。
- 出し方：`scripts/release.sh "中身"`。`RELEASE.md` に版（R1, R2 …）を1行足して push する。
- それ以外の push は、本番に出ない（Web は Vercel の「Ignored Build Step」＝`apps/web/scripts/vercel-ignore.sh`、API は `deploy-api.yml` の条件）。
- 急ぎで API だけ出す時：GitHub の Actions → Deploy API → Run workflow（手で動かすと固定に関係なく出る）。
- 固定をやめる時：GitHub の変数と Vercel の環境変数に `RELEASE_GATE=off`。

## 2. 新機能を止める・作業途中のものを片づける
- ローンチまでは、物語の画面の直し（3日目以降のカメラと字幕、背景）だけを仕上げて R1 に入れる。ほかの新しい機能は入れない。
- 土星（M-R257）は R1 の後に作り、R2 として 11/28 より前に出す。

## 3. Claude への切りかえ（利用者がすること）
1. Google Cloud → Secret Manager に `obolo-anthropic-api-key` を作り、Anthropic の API キーを入れる。
2. GitHub → Settings → Secrets and variables → Actions → Variables に `CLAUDE_BATI` = `true`。
3. Actions → Deploy API → Run workflow。
- これでバティの会話が Claude（Haiku 5.5）になる。鍵がない間は今のまま Gemini。
- **ローンチは Gemini で行く（利用者決定・2026-11-24）。** 海外から Google Cloud のコンソールに入れないため、日本に戻った時（1か月後くらい）に切りかえる。

## 4. ログインのコードをメールで送る（利用者がすること）
1. Resend（resend.com）でアカウントを作り、送り元のドメインを確かめる（DNS に数行足す）。
2. Resend の API キーを、GitHub → Settings → Secrets and variables → Actions → **Secrets** に `RESEND_API_KEY` として入れる（Google Cloud のコンソールが使えなくてもできる。日本に戻ったら Secret Manager の `obolo-resend-api-key` に移してもよい）。
3. GitHub の Variables に `EMAIL_FROM` = `OBOLO ORDER <no-reply@確かめたドメイン>`（カンマは入れない）。
4. Actions → Deploy API → Run workflow。
- これで、ログインのコードと招待状がメールで届き、画面にコードは出なくなる（`EMAIL_FROM` がある時は `AUTH_DEMO_SHOW_CODE` が自動で false）。
- メールを送れなかった時は、ログインの画面にエラーが出る。最初に自分のメールで試すこと。

## 5. 招待制（M-R256）
- 今のまま招待制。入った人は、1人30日に3通まで招待状を出せる（M-R256）（`invites.service.ts` の `INVITES_PER_MONTH`）。招待状はメールで届くので、4 が済んでいることが前提。
- 広告用の数に限りのある招待コード（招待者 MIKIE⭐︎DRILL）と「招待状を待つ」受付は、ローンチの後に作る。

## 6. 支払い（エクリプス 月¥88）をローンチから本番どおり取る（利用者決定・2026-11-24）
Google Cloud のコンソールなしで、GitHub と Stripe の画面だけでできる。
1. Stripe でアカウントを作り、本人確認と銀行口座を登録する（審査に数日かかることがある）。
2. Stripe →「開発者」→「API キー」：シークレットキー（sk_live_…）を GitHub の **Secrets** に `STRIPE_SECRET_KEY`、公開可能キー（pk_live_…）を **Variables** に `STRIPE_PUBLISHABLE_KEY`。
3. Stripe →「開発者」→「Webhook」→ エンドポイントを追加：URL `https://obolo-api-679428005842.asia-northeast1.run.app/billing/webhook`、イベント `checkout.session.completed` `customer.subscription.updated` `customer.subscription.deleted`。表示された whsec_… を GitHub の **Secrets** に `STRIPE_WEBHOOK_SECRET`。
4. Stripe →「設定」→「Billing」→「カスタマーポータル」を有効にする（解約と支払い方法の変更をオン）。
5. Actions → Deploy API → Run workflow。
6. `/tokushoho`（特定商取引法に基づく表記）の「（記入してください）」を埋める（販売事業者・運営責任者・連絡先）。
- 自分のカードで一度払い、設定の〔支払い方法の変更・解約〕から解約できるところまで確かめる。
