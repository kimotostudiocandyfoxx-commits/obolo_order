# 地球の銀行：会員の口座・デビット・手数料収入の調査メモ

作成日：2026-10-13（社内用。GMOあおぞら・弁護士への相談前の叩き台。公式ページ本文は開けず、検索の抜粋で判断）

【OBOLO：「会員が自分の銀行口座を作れる機能」と手数料収入（経営者向けの答えの材料）】
注意：GMOあおぞらの公式ページは本文を開けませんでした。内容はすべて検索結果の抜粋から判断しています。確かめられなかった数字や条件には「要確認」と書きました。

■ 先に結論
・GMOあおぞらには、OBOLOのアプリから会員が「OBOLO支店」のような専用支店に自分の口座を作り、OBOLOデザインのデビットカードを持てる仕組みがあります（BaaS byGMOあおぞら）。ただし口座は会員とGMOあおぞら銀行の契約です。OBOLOが自分の銀行を持つのではなく、OBOLOは窓口になります。
・デビットや引き落としの手数料が、OBOLOに自動で入ってくる仕組みはありません。むしろOBOLOが銀行に利用料を払う側になるのが基本です。手数料を分けてもらえるかは個別の交渉と契約しだいで、GMOあおぞらの条件は公開されておらず分かりません。
・アプリの中で口座を作るよう勧めるには、国の許可か登録が要る可能性が高いです。会員の多くは15〜17歳でもあります。最初は今のStripe払いと、本人の口座への振込から始め、段階を分けて進めるのが安全です。

━━━━━━━━
1. GMOあおぞらで「会員が自分の口座を作れる」はできるか
━━━━━━━━
【できる（確認済み）】
・GMOあおぞらネット銀行は「BaaS byGMOあおぞら」を提携企業に提供しています（2023年9月15日に旧名「かんたん組込型金融サービス」から改名）。銀行API、専用支店、専用カードを部品として組み込めます。
・実例：Habittoのアプリでは、会員がGMOあおぞらの「ハビト支店」に普通預金口座を作り、専用デザインのVISAデビット付きキャッシュカードを使えます。
【できあがる形】
・「GMOあおぞら銀行のOBOLO支店」の口座と、OBOLOデザインのデビットカードです（支店名は銀行の審査あり・要確認）。「OBOLOのオリジナル銀行」とは違います。預金を預かるのは銀行で、Habittoも自社ではお金を預かれないと説明しています。
・提携が終わっても、口座は銀行側に残ります。例として、ドコモSMTBネット銀行はV NEOBANKの提携を2027年3月28日で終えると発表しました。口座番号はそのままで、支店名が変わります。
【条件】
・GMOあおぞらとのBaaS契約が要ります。費用は初期費用・月額・従量の組み合わせで、見積もり制です（検索抜粋による。金額は不明）。
・許可か登録が要る可能性が高いです（6で説明）。実例として、ラクスルバンクはGMOあおぞらを所属銀行とする銀行代理業の許可を2025年10月29日に受け、11月27日に開業しました。Habittoは2023年3月に、口座開設に関わる「預金等媒介業務」の登録をしています。
・「1支店で約90万口座」「個人と法人で別契約」「VisaとMastercardを選べる」などの細かい条件は要確認です。
【代わりの方法】
・GMOあおぞらの通常の口座開設画面へ案内するだけにする方法があります。ただ、どこからが「勧誘」になるかの境目は微妙です。金融庁は2026年7月30日に、この境目をはっきりさせる監督指針の改正案を出しました（最終版は要確認）。
・他の銀行の組込型サービスもあります。みんなの銀行（BaaSのパートナーは36社）と、ドコモSMTBネット銀行のNEOBANKです。

━━━━━━━━
2. 提携企業（OBOLO）に手数料収入は入るか
━━━━━━━━
【結論】自動では入りません。「ただ口座が作れるだけ」が出発点で、収入があるかは交渉しだいです。
【GMOあおぞらの場合】
・デビット手数料を分けるか、その割合、口座開設1件ごとの紹介料は、どれも公開されていません（確認済み）。分けてもらえるかどうか自体も分かりません。
・OBOLOは利用料を払う側です。「公式FAQに手数料収入が書かれている」という話は確認できなかったので、根拠にしないでください。
【他行の例：ドコモSMTBネット銀行のNEOBANK（旧・住信SBIネット銀行）】
・提携企業が、口座の数に応じた月額の定額料金を銀行に払います。お金の流れは「提携企業から銀行へ」です。
・取引の手数料は「提携先と分けた後の残り」が銀行の取り分、と銀行の資料にあります。分け前は契約で決まるもので、割合は公開されていません。
・「1口座あたり月約120円」という数字は確認できなかったので、要確認です。
・一般に、銀行代理業者は銀行から代理業の手数料を受け取ります。ただし条件は契約で決まります。
【混同しやすい点】
・Habittoの「デビット利用の0.8%キャッシュバック」は、会員への還元です。会社の収入ではありません。
・米国では手数料を分ける例がありますが、日本に当てはまる根拠にはなりません。

━━━━━━━━
3. 買い物の支払いを「口座からの引き落とし」でも選べるようにする方法
━━━━━━━━
・A（一番かんたん）：OBOLO支店のデビットカードで、今のStripeのカード払いをそのまま使います。デビットは使うとすぐ口座から引かれるので、実質「OBOLO支店の口座から引き落とし」になります。Stripeに月額88円で登録済みのカードとして使え、「Stripeから引くのが一番スムーズ」というお考えとも合います。ただし15歳未満はデビットを作れません（5を参照）。
・B：アプリから会員の口座へ直接、代金を引き落とす方法です。GMOあおぞらのBaaSにこの用途のAPIがあるかは、確認できず不明です。国内では、みんなの銀行のAPIを使い、pixivのBOOTHで口座から直接払える「ピクシブかんたん決済」（2023年7月開始）があります。
・C：一般的な口座振替です。代行会社を使う場合の目安は、初期0〜3万円・月3,000円前後で、1件ごとの手数料は見積もりが必要です。月額課金向けで、その場の買い物には向きません。
・Stripeには日本の「銀行振込」があります（三井住友銀行と協力、手数料1.5%）。一方、Stripeで日本の口座振替ができるかは要確認です。いずれにしても、Stripe払いとGMOの口座からの直接引き落としは別の仕組みです。

━━━━━━━━
4. 売上残高でそのまま買い物させる場合の注意
━━━━━━━━
・第1段階の「地球の銀行」の残高は、実際にはOBOLOの法人口座にあるお金です。それを長く預かって買い物に使わせると、資金移動業の登録や前払式支払手段の規制に当たる可能性があります。
・メルカリは2019年2月に、売上金の管理を資金移動業者のメルペイへ移しました。売上金をポイントに替えると前払式支払手段の扱いになり、未使用の残高が1,000万円を超えると、半分以上を供託する義務があります。
・2026年6月1日の法改正で、国境を越える収納代行は為替取引に当たると明文化されました。国内の売上金を支払いに回す場合の扱いは不明で、弁護士への確認が必要です。
・安全なのは、売上は本人の口座（どの銀行でも、OBOLO支店でも）へ振り込み、買い物は別にカードやデビットで払ってもらう形です。
・名前についての補足（今回の調査の範囲外で、要確認）：銀行法では、銀行でない者が名称に「銀行」と分かる文字を使うことを制限しています。「地球の銀行」という機能名が問題ないか、弁護士に確認してください。

━━━━━━━━
5. 未成年
━━━━━━━━
・GMOあおぞらの個人口座は、15歳以上なら本人が申し込めます。15歳未満は親が代理で申し込み、デビット付きカードは作れません。これは公式の商品概要（2022年10月17日時点）で確認しました。最新版は要確認です。
・中学3年生（15歳）が対象になるか、BaaSの専用支店で未成年が口座を作るときの条件、親の同意が要るかは、どれも分からず要確認です。
・他の銀行では「15歳以上（中学生を除く）」が多く（例：三菱UFJ銀行）、楽天銀行は16歳以上です。NEOBANKとみんなの銀行は15歳以上です。
・本人確認：2027年4月1日から、本人確認書類の画像を送るだけの方式が廃止されます。マイナンバーカードの読み取りが中心になるので、口座開設の流れはマイナンバーカードを前提に作る必要があります。
・18歳以上は成年なので、親の同意は要りません。15〜17歳への勧め方には特に配慮が要ります。

━━━━━━━━
6. 必要な許可と期間
━━━━━━━━
・銀行免許は要りません。ただし「免許が要らない」ことと「許可が要らない」ことは別です。
・第1段階（会社の法人口座とバーチャル口座、自社口座からの振込）：会員の口座は操作しないので、電子決済等代行業の登録は不要の可能性が高いです（要確認）。ただし4の、残高を預かる問題は別に確認が要ります。
・第2段階（OBOLO支店で会員の口座を作る）：次のどちらかが要る可能性が高いです。
 - 銀行代理業：内閣総理大臣の許可（窓口は財務局）。審査では、財産の基盤、実務経験者がいるかなどの業務をこなす力、社会的な信用、他の事業との兼業が見られます。
 - 金融サービス仲介業（預金等媒介業務）：登録制。保証金の供託が要り、利用者のお金を預かることは禁止です。
・アプリから会員の口座へ振込などの指示を出すなら、電子決済等代行業（登録制）も関わります。
・期間：公的な標準の期間は見つかりませんでした。「最短6か月」という話も確認できず要確認です。準備・審査・開発を合わせて、少なくとも数か月から1年単位で見ておくのが無難です（推測）。

━━━━━━━━
7. おすすめの段階的な進め方
━━━━━━━━
・段階0（今すぐ）：月額88円も商品代も、Stripeのカード払いで受けます。デビットカードもこれで使えます。
・段階1：「地球の銀行」は、バーチャル口座で売上を表示し、本人の口座（どの銀行でも可）へ振り込む形にします。アプリ内で残高を買い物に使う機能はまだ入れません。名前も確認します。
・段階2：GMOあおぞらにBaaSを相談し、見積もりと手数料を分けてもらえるかを聞きます。弁護士とは、許可が要るかを決めます。許可なしで始めるなら、GMOの口座開設画面への案内だけにします。
・段階3：OBOLO支店とOBOLOデザインのデビットカードを始めます。売上をOBOLO支店へ振り込み、Stripeでデビット払いできるようにします。口座から直接払うAPIがあれば追加します。
・並行して、みんなの銀行（pixivの例あり）やドコモSMTBのNEOBANKとも条件を比べます。
