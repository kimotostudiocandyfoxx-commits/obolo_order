# 第13ラウンドの決定事項（利用者決定 2026-10-13・最優先）

## X1. 海王星＝まずは「遊ぶ側」（二周目）
- 二周目の海王星は**遊ぶ側だけ**：会社（結社）が用意したゲームを何本か、好きに遊ぶ。会員がゲームを作る・売る・買う描写はしない。ゲームのマナ課金の描写もしない。
- 既存の場面（嵐の遊び場、キモリンの帰り道 等）は活かす。もしキモリンや主人公が「ゲームを作る」描写があれば、「遊ぶ」「遊び方を見つける」に置き換える。

## X2. 三周目PLAYER＝「自分のキャラが主人公になる」ゲーム（称号の条件は不変）
- PLAYERの称号条件（作品世界の実行可能なゲーム1本：開始→操作→変化→終わりを本人が試遊確認）は変えない。
- 作り方を**ゲームの型（テンプレ）にはめ込む**形にする：結社が用意した型（走る／パズル／リズム／すごろく 等、3〜4種）から1つ選び、これまで作った自分のキャラ（シール）・曲・アニメの場面・my場所を素材としてはめ込む。開始・変化・終わりの場面と題を本人が決める。一から作る（プログラムを書く・大量に生成する）描写はしない。
- 既存の素材を使う限りマナはほとんど使わない（新しい絵を作るときだけ使用の確認、数値なし）。
- 既存の場面の芯（遊ぶ係のキモリン、試遊、「作った人には見えないところ」、看板を一枚、題をつける、授与）は活かす。

## X3. 一から作る機能（物語の外）
- 物語を終えた人のうち、作りたい人が手を挙げられる（〔画面〕の一行でよい）。最初は少人数に招待が届き、道具が育つにつれて広げる（半年は最初の招待の目安。物語では日数を約束しない）。
- 招待は特別編と同じく**物語の外で一通だけ**届く短い場面（EX-NEPTUNE-S001）。差出人は既存の住人（海王星／PLAYERの住人）。売り買い・お金・マナの数字の話はしない。

## X4. 三周目の水星（WEAVER）＝島は「みんな」から行く、行った島だけ物語が流れる
- 全部のジャンルの島（大陸）を必須で回る作りをやめる。WEAVERの必須の流れは：**自分の曲をつくる／ダチの曲を聴く／〔みんな〕のバナー**の3つの使い方を知る→自分のフルアルバム（8曲）を作る→授与。
- 〔みんな〕（三周目で開く：R10 T3）の中に、ジャンルごとの島が並ぶ。**行ったことのない島に初めて行くと、その島の物語が最初に流れる**（寿司モンの事件と、その島の曲作りの技法：フック／引き算／フロウ／フレージング／ダイナミクス／ビルドと解放／音色の受け渡し）。行かない限り流れない。行く順番は自由、行く数も自由（0でも称号は取れる）。島ではそのジャンルのみんなの曲も聴ける。
- 島の物語どうしが順番や「前の島」に依存しないように直す（寿司モンが仲間になっていく積み重ね・前の島の小道具の持ち越し等は、行った島だけで成り立つ形か、動的な言及に）。
- フリージーの船（海賊の航海）は「行きたい島へ送ってくれる船」として残す。固定の航路順はなくす。
- **必須の山は島の外に置く**：キモリンのフィーチャリング（U1・密航の一晩）は母港（自分の島）の夜に移す（R&Bの夜島の物語は任意の島の物語として残す）。フリージーの寄り道島（冷蔵庫の奥の最初の曲の解凍）はフリージー自身の話なので、ジャンルの島ではなく必須の流れに残す。
- 八曲目を織り上げる場面・授与・振り返りは、行った島・聴いた曲だけを動的に言及する（行っていない島を「足りない」と言わない）。
- 他章（星休め・MOVER以降・太陽終章）で「八つの島をすべて巡った」前提の言及があれば動的に直す。
