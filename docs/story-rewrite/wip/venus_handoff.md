# 金星の引き継ぎメモ（物語側 → アプリ開発側）

2026-10-12　物語の改稿（bible_structure_v6・第8ラウンドの決定）で、金星の役割が変わりました。アプリ開発のチャットに「金星がこう変わった」と伝えるためのメモです。画面の作り方の指示ではなく、物語で決めたことの共有です。

---

## 1. 金星は「作ったものを鳴らして遊ぶ」ステージの星になった
- 以前の金星は「ネオの見た目を磨くアトリエ」でした。これをやめて、**DJとVJを練習して遊ぶ星**にしました。
- 水星で作った**自分の曲**と、火星で作った**自分のMV**を、ステージで流し、つなぎ、盛り上げます。
- 金星は「作る星」ではなく「遊ぶ星」です。何も新しく作らずに、自分の作品に愛着が湧く場所にします。

## 2. 二周目の新しい順番
**地球（出発）→ 月 → 土星 → 木星 → 水星 → 火星 → 金星 → 天王星 → 海王星 → 地球（帰還）**
- 月と太陽は拠点なので、惑星の数には入れません。
- 火星をクリアすると金星が開きます。火星の最後に、ヒポキンが「その映像、次の星で、鳴らしてみろ」と言って、金星へつなぎます。

## 3. 物語での流れ（二周目の金星）
1. **到着**：星ぜんたいが巨大なターンテーブルになった、霧とネオンの星。ゴリラ3人組は顔なじみです。**楽屋はありません**（着替えは月で済ませてきた、という扱い）。
2. **DJのチュートリアル**（ボスG）：自分の曲を選ぶ → 2曲をつなぐ → 盛り上げる／止める。キモリンが「盛り上げるのは、これやろ！」と赤いボタン（止める）を押して、星ぜんたいが止まる、という失敗から覚えます。
3. **VJのチュートリアル**（ハットG）：自分のMVを曲に合わせて流す → 切り替える。映像がない人は「あかり」だけで照らせます。
4. **くらべ鏡**（中盤の山場）：ステージを囲む鏡が「いちばん盛り上がりそうな曲」「みんながやっている回し方」を並べ続け、観客のオートンが「ステキ」「ワカル」と連呼します。主人公は「自分が鳴らしたい曲」を選んで回し、鏡が静かになります。
5. **キモリンが先に回す**：「漆黒の黙示録ミックス」。言った通り全部漆黒で重い曲になり、本人が踊れない、という笑いです。
6. **本人のステージ**：DJとVJを自分のために回します。見せる相手は「誰もいない夜／ここにいるみんなにだけ／誰にも見せない」から選べます。拍手や数のかわりに、ミラーボールが一回転するなどの小さな反応だけが返ってきます。
7. 金星クリア → 天王星へ。クリアの条件は「ステージの場面を終えること」です。一曲も回さなくてもクリアできます。

## 4. ゴリラ3人組の役割（性格・口調はまだ仮）
- **ボスG**：ステージの主で、DJの師匠格。首に大きなヘッドホン。短く言い切ります。
- **ハットG**：照明とVJの担当。帽子のふちに電球が並んでいて、照明卓とつながっています。乾いた真顔で一言。
- **ロングG**：音響とフロアの担当。床まで届く銀色の長い髪が低音で浮き、音量の目盛りになります。静かにぼそっと話します。

## 5. 守るルール
- **自分の曲・自分のMVだけ**を使います。ほかの人の作品をコピーしたり持ちこんだりはしません。曲がない人は「練習用の拍（曲ではない、ただの拍）」で操作だけ試せます。
- **観客数・再生数・点数・順位は出しません。**
- **プレイではマナを使いません**（生成ではないため）。画面には「力は使いません」と出します。
- **録画・公開は別の操作**にします（任意）。ステージで回しただけでは、どこにも残らず、誰にも届きません。
- **結社モード**（音を出してよい場所）を守ります。

## 6. プロフィールの着せ替えは月へ移った
- 見た目を変える機能（色・髪・服・帽子・目元・趣味の持ち物・国や文化っぽい服・翼などの空想パーツ・プロフィール用の丸の切り取り）は、**二周目の最初に寄る月**へ移しました。3日目にネオを作った月の水盤で、姿を「磨く」場面です。
- 試す → 戻す ができます。絵を描く（生成する）のは確定する時だけで、その前に使用の確認をします（数字は出しません）。
- **プロフィールの姿は、ほかの会員から見えます**（利用者の決定）。保存する直前に「この姿が、あなたのプロフィールとして表示されます」と一行で確認します。作品（つぶやき・シール・曲・MV）が「まず本人だけに保存・公開は別操作」なのとは、扱いが別です。
- 今のデモの月はバティとのチャット画面だけなので、月に姿をアレンジする入口が必要です。

## 7. ショップは天王星
- 今のデモでは**金星がショップ**になっています（★で売り買い、売れた数・売上の表示、値段、〔店に並べる〕など。VenusWorld・VenusTutorial）。物語では、これを**天王星**に置きます。
- **売れた数・売上の表示は「数で人をはからない」決まりに反する**ので、物語では出しません。デモの見直しが必要です（ゴリラ3人の「作って、売って、集める」の台詞も、物語では使いません）。
- 天王星は**結社の商店街**です。住人たちが自分の作品のグッズを並べ、二周目の主人公とキモリンは**お客さん**として訪れます（キモリンのバイトという設定はなくなりました）。注文は任意・別料金・15歳以下は保護者の承認が必要です。自分の店を開けるのは、三周目のRECORDERとHOLDERのあとです。
- ※物語の本文の天王星は、まだ古い形（キモリンが店番のバイト）のままで、作り直しを待っています。

## 8. 三周目の任意のライブ
- 三周目のMOVERの授与のあと（アルバム8曲とMV3本がそろったあと）、金星で**自分のセットリストのライブ**ができる短い寄り道があります。
- 曲順（アルバム順／並べ替え／一曲だけ）と見せる相手（誰もいない夜／三人だけ／ヘッドホンだけ）を選びます。録画・公開・数字はありません。**称号の条件にはしません。**

## 9. まだ決まっていないこと
- **DJ・VJの操作画面**：デモにはまだありません。物語では仮に、DJ＝〔レコードを選ぶ〕〔つなぐ〕〔もり上げる〕〔止める〕、VJ＝〔映像を選ぶ〕〔流す〕〔切り替える〕〔あかり〕と呼んでいますが、実装を約束するものではありません。
- **曲のつなぎ方の細部**：「一気に／ゆっくり／止めてから」の3通りで書きましたが、本当の操作（つまみ・速さ合わせなど）は未定です。
- **VJの切り替え方**：「拍ごと／サビだけ／流しっぱなし」で書きましたが、実際の操作は未定です。
- 曲が一つだけ・曲がない人、映像がない人のステージが画面上でちゃんと成り立つか。
- 星ぜんたいが曲の速さで回る演出や、オートンがミラーボールになる演出が、88分の時間の中で実際に作れるか。
- ステージで遊んだ時間を、一日88分の中に数えるかどうか（物語ではそう仮定しています）。
- 録画・公開の画面をどこに置くか（物語では、ステージの場面の外の別操作としています）。
