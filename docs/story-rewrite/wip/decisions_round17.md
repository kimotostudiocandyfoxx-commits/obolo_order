# 第17ラウンドの決定事項（利用者決定 2026-10-13・最優先）｜ナレーションと分かりやすさ

## N1. ナレーションをやめ、RPGのテロップにする（全編）
- OBOLOは「RPGとアニメを混ぜた」ソフト。RPGにもアニメにも、語り手のナレーションは基本出てこない。
- 「（ナレーション）」の地の文（小説のような語り：「急かす光り方ではない」「ずっと前からここにあったような顔をしている」等）は**全廃**する。
- 代わりに、RPGで自然な**短いテロップ**だけを使う：書式〔テロップ：……〕。**声に出さない（読み上げない）。文字だけ。**
  - 使ってよい場面：場所に着いた（〔テロップ：土星の神殿に着いた〕）、物を手に入れた（〔テロップ：招待状を手に入れた〕）、日・時間が変わった（〔テロップ：2日目〕〔テロップ：その夜〕）、人物が仲間・ダチになった、場所が開いた、など事実の短い知らせ。
  - 一文で、15字前後まで。感想・比喩・心の中の説明は書かない。
  - 入れすぎない：1場面に多くても1〜2個。台詞と絵で分かることにはテロップを付けない。
- 元のナレーションが伝えていた情報は、①絵（〔　〕の演出。アニメの絵として見せるもの。文字では出ない）、②人物の台詞、③短いテロップ、のどれかに移す。必要のない語りは消す。
- 〔　〕の演出（ト書き）も、小説的な比喩や心情の説明ではなく、**アニメの絵コンテとして描ける具体的な絵・動き・音**で書く（例：×「急かす光り方ではない」→○〔封筒が、ゆっくり点滅している〕）。
- 〔画面：……〕（操作の案内・システムの表示）は今までどおり。テロップと区別する。

## N2. 15歳に伝わる言葉で（全編）
- 世界観を守るための遠回しな言い回しより、**15歳が遊び方と住人の言っている意味をすぐ理解できること**を優先する。
- 住人の台詞：言いたいことが一度で分かるように。謎めいた言い方をする時も、直後の台詞か画面で意味が分かるようにする（MONBANの「…」の話し方や、住人の口調・キャラはそのまま。言っている中身を分かりやすく）。
- 遊び方の説明（チュートリアル）：何をすればいいか、どのボタンを押すか、押すと何が起きるかが、台詞か〔画面〕ではっきり分かるように。比喩だけで説明しない。
- 難しい漢字の言葉・大人の言い回し・古風な言葉は、やさしい言葉に（固定の原文、謎の題、称号名、核心二行は変えない）。
- 笑いは、15歳がその場で分かるものに（説明が要る笑い、元ネタを知らないと分からない笑いは直す）。
- 「深い」場面（謎の答え、太陽の終章など）は、分かりやすくした上で余韻を残す。説明しすぎない。

## N3. 変えないもの
- 話の筋・場面構成・選択肢・フラグ・sceneID、固定原文（核心二行と直後の無言、謎の題、称号の条件、利用者の固定台詞）、第16稿のKIMORINの話し方、各住人の口調。

## N0. 物語の主題（最優先・利用者決定）
- 物語は**「このソフトの使い方を、分かりやすく、簡潔に、でも面白く理解してもらうため」のもの**。まずこれを主題にし、肉付けはそのあとから足す。
- 優先順位：①遊び方・使い方が分かる ②面白い（笑える・ワクワク）③世界観・謎・深さ（①②を邪魔しない範囲で）。
- 使い方の学びから脱線している長いくだりは、短くするか削る。

## N4. オートンとオート化を全廃（利用者決定）
- オートン（反射の返事から生まれる灰色の箱の生き物）と「オート化」という異変を、物語から**すべて削る**。名前・出現・眠って置き物になる小ネタ・命名・ランニングギャグを含む。
- 三つの大ビート（二周目土星のワカル壁とシスターの命名、金星のステージの「くらべ鏡」、帰還の掲示板）は削る。その場面は、その星の遊び方を楽しく覚える流れに作り直すか、短くまとめる（例：金星はゴリラ3人組がDJ・VJを教え、キモリンが先に回し、本人が自分の曲で回す、で十分）。
- 一周目のオートン系の存在（火星の「オススメ、デス」しか言わない小箱、KIMORINが持ち歩く「漆黒の小箱」、8日目の「犯人にされた小箱」等）も削るか、使い方に関わる短い小ネタに置き換える。
- 住人の困りごとがオートンのせいだった場面は、その星の機能を使うきっかけになる、分かりやすい困りごとに置き換える（または困りごと自体をなくして、遊び方の場面にする）。
- 8日目のMONBANの「なぜお金がかかるか」の一言は、オートン・小箱に頼らない言い方にする（例：「……ここには、勝手に流れてくる広告もない…。知らない誰かの『おすすめ』も、流れてこない…。あるのは、誰かが自分の言葉で作ったものだけだ…。灯りは、会費でともしている…。」）。
- 謎（八つの謎）・称号・核心二行はオートンに依存していないので、そのまま。

## N5. 使い方の学びから外れた長いくだりも削る（利用者決定）
- 物語は「このソフトを長く遊んでもらうためのもの」でしかない。物語が主役になりすぎない。
- 各場面に問う：①この場面で、遊び方・機能が分かる／実際に触るか？ ②笑える・ワクワクする山か？ ③次を遊びたくなる引き（謎・称号・続き）か？ ④誰かの選択・同意・保留が本当に止まれるために必要か？ どれにも当たらない場面・段落・やりとりは削る。当たる場面も、同じことを繰り返す台詞・長い前置き・余談は短くする。
- 残す山（短くはしてよい）：MONBANとの出会いと招待、バティ誕生、キモリン登場と「……うんち、です。」、各星の遊び方のチュートリアルと最初の作品、8日目の決断（エクリプス）、二周目の出発（ダチ）、各星のmy場所の完成、キモリンのフィーチャリング、各称号の授与（一言で）、三周目の森・島・劇場の最初の一つ、太陽終章（星の誕生→核心二行→無言→終幕確認）、特別編。
- 謎は「各星で一つ、短く手がかり→答えは一言」程度に。謎の解説の長い台詞は削る。
- 目安：全体の文字数をおおむね半分以下に。1場面は短く（台詞のやりとりは、使い方が伝わり、オチが一つあれば十分）。
- 場面ごと削る時は、sceneIDを欠番にしてよい（その場面への行き先・フラグ・RESUMEを付け替える）。他パートからの参照は点検で直す。
- 削った場面・大きく短くした場面は、パートごとに一覧（sceneIDと一行の理由）をメタの "cutLog" に残す（あとで肉付けするときの材料）。

## N6. 自由回答（語りかけ）の仕組みは入れない（利用者決定）
- 物語の進行中にユーザーへ質問を重ねる設計はしない（疲れさせない）。遊ぶこと自体（つぶやき・シール・曲・MV）が自由な表現なので、物語は「分かりやすく簡潔に楽しく使い方を伝える」に徹する。
- 既存の選択肢・作品づくりの入力はそのまま（増やさない）。見るだけの長い場面はN5で削って、受け身になりすぎないようにする。
