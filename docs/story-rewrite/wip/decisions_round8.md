## B. 総点検の質問への編集長判断（推奨案で決定）
1. **謎8の前振り**：バティが全体で3〜4回だけ「遠く」を探す（きっかけはキモリンの聞きかじり「コスモスって、遠い星の名前らしいケン」等）。毎回外れるだけで、答えの方向は示さない。置き場所の目安：D04かD05のどこか／二周目水星（L2-MERCURY-S007付近）／三周目WEAVER（L3-WEAVER-S011付近）／PLAYERのあと（L3-PLAYER-S007付近）。太陽終章の固定原文バティ「遠くの星で、／見つけると思ってた……。」がひっくり返す相手を作る。「コスモス」の語は伝承どおりの扱い（称号・画面名にしない）。
2. **太陽終章の目的の会話**：2行に絞る（「隣の者も、、、自分の世界の、主人公だ。」相当／「見る日も、休む日も、、、人は、人だ。」相当）。残りは光の玉と線の絵で見せる。「お前も」と先に言わない。
3. **最後の台詞の順番**：MONBANとバティを先にして、OBOLON「今日はその続きを生きてこい。」を本当の最後の台詞にする（文言は変えない）。その後は選択（今日はここまで／見返す）と画面の閉じる演出だけ。
4. **太陽終章のキモリン**：今の出番は例外として残すが、核心後（L3-SUN-S010）は短くする（3択をなくし、譜面を置いて去る）。
5. **三周目SHAPER・PLAYERのキモリン**：**（利用者決定で更新：bible_kimorin K12）キモリンはバイトではない。SHAPERではキモリンも自分の作品のグッズを売る自分の店を持つ“隣の店主”として対等に描く**（主人公の旅に付いて回る形にしない）。二周目の天王星は結社の商店街で、キモリンと主人公はお客さん。PLAYERは1場面に減らす。
6. **ピンポンボタンの決め所**：太陽の日食後（L3-SUN-S004）だけを本番にする。電池をランプへ移す前振り（S002）は残す。HOLDERの「触れて押さない」など他の同じ意味の場面は削る。
7. **一周目・火星（7日目）の小箱**：一匹に絞る。暗闇の光る目の群れは、黒い画面に映りこんだ一匹の目にする。
8. **長い区間を縮める**：三周目の森・島・劇場めぐりは、場所の数を保ったまま5か所程度を半分の長さの「通りすがり」にし、型を崩す回を作る（P11・P12）。二周目の金星はv6でDJ/VJに作り直すので別扱い。
9. **原本の言葉3か所を一語ずつ直す**：「君から」→「ここから」（L2-REST-S018、謎6の答えを口で言わない）／8日目「太陽と」→「地球と」（D08-S010、流れをつなぐ）／開発者の言葉の「朧を」→「この宇宙を」、「作りました」→「作っています」（L2-REST-S016、謎1より先に「朧」をアプリ名として出さない）。

## D. 総点検で残った弱点（このラウンドで直す）
1. 救世主ノート（謎5の線）が8日目からHOLDERまで約120場面途切れている → 二周目と三周目に1〜2回、ノートがちらりと出る（キモリンが正の字を書き足す等）。
2. カイザーの最初の絵を何度も植えて「P12で回収」としたのに、HOLDERに出てこない → 回収場所を決めて回収する（三周目RECORDERの森（夜の大樹）か、HOLDERの謎5の隣の場所）。二重回収にしない。
3. 笑いの型のくり返し（ブッブー約17回、静かなピンポン約10回、「よっ、ブラザー！」約17回、モテ期約7回、漆黒約45回、P04以外の「ケン」の多さ、P11のフリージーの冷蔵庫ネタ） → 全編で間引く：「よっ、ブラザー！」は8回以下、モテ期は3回以下、漆黒は20回以下、静かなピンポンは5回以下、「ケン」はキモリンの台詞の半分以下を目安。
4. 一周目の日の終わりが同じ形（MONBAN→便り） → 2〜3日は形を変える。D04の日の終わりも。
5. キモリンが先に作る順番が土星・木星・火星で3回同じ → 1か所は主人公が先、または同時にする。
6. HOLDERの謎5の直後に、バティの説明と「君」が入る → 削る。
7. 星休めの短編の上映後に、キモリンがテーマを自分で解説する → 削る。謎6後の「オレの時は伸びんかった」が主人公を選ばれし者に見せる → キモリンの線も伸びる（または伸び方が違うだけ）に変える。
8. P11の冒頭で三周目の冒険が始まるまでが遅い → 短くする。SHAPERは事件の規模が小さく平ら → 一つ大きめの見せ場（観覧車の見送り等）を効かせる。
9. 太陽終章のS003に小さな場面が詰まりすぎ → 絞る。
10. 申し送りの残り（P06 c02の古い設計注、P12 MOVER-S003の旧台詞の参照、P11 RECORDER-S005の蝶の成長の一行）。
11. 巻頭・付録の古い要約、場面数の数え直し。
