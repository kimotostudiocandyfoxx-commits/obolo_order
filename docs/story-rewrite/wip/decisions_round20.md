# 第20ラウンドの決定事項（利用者決定 2026-11-21・最優先）｜作る・しまう・見せるの組み直し

MVを3本作ってみた利用者の気づきから、作る場所・作品の行き先・星の役割を組み直した。
UI・設計の正本は開発ブランチの `docs/工房とブルーナ_設計.md`。ここには物語にかかわる決定をまとめる。
これまでの決定と食い違うところは、この第20ラウンドを優先する。

## M-R185 作るのは月の工房・しまうのはブルーナ・見せるのは星
- **作る場所は一か所：月の工房**（月の神殿の中にある、{bati}の工房）。曲・アート・MV・小説・絵本・グッズ・声は、すべてここで{bati}と話して作る。
- **作品はブルーナにしまう**（自分だけの作品集）。
- **公開＝ブルーナから星へ投影する**（2日目の「Bluenaで投影する」をそのまま公開の動きにする）。投影された作品は、星ごとの姿（船・UFO・蝶・コロリン・灯りなど）になって出ていく。
- 決まりの一言：**作るのは月、しまうのはブルーナ、見せるのは星。**「自分だけの場所（月の工房・ブルーナ）」と「みんなが見る場所（星）」をはっきり分ける。
- **物語での扱い**：各星の住人は、これまでどおりその星の作品について教える（大根カイザーはアート、フリージー／MIKIE⭐︎は曲、ヒポキンは映像…）。ただし「作る」その時は、**ブルーナの門が開き、正方形のスクリーンの向こうの月の工房で{bati}と作る**。できあがるとブルーナにしまわれ、〔公開する〕でその星へ投影される。住人の台詞は「ここで作れる」ではなく「君の作品は、ここで生きる」に寄せる。
- 星ごとにあった「自分だけの保存場所」（水星の島の土の中・火星の裏スタジオ・木星の根っこ）は、**ブルーナの中のフォルダ**になる。見た目はその星のまま（土の中に埋まったレコード、裏スタジオの棚、根っこ）。
- 各星の「my場所」（myアイランド・myスタジオ・myアトリエ・my図書館など）は、**公開した作品を飾る所** として残す。

## M-R186 {bati}の居場所
- **{bati}の家は月。ブルーナの門が開いている間だけ、門を通って隣に来てくれる。**
- 旅の間：ブルーナの光から現れて隣にいて、住人の話に反応する。
- 作る時：{bati}「工房に行こう」→ ブルーナの正方形のスクリーンが月の工房への入口になる。
- 一日の88分が終わると門が閉まり、{bati}は月へ帰る（今の MONBAN の台詞のまま）。マナが少ない時は、門を通って出てくる力が弱まる、として見せる。
- ✏️ 案（運営の確認待ち）：Obolo Order になる前の{bati}はブルーナの光でできた仮の姿で、隣にいられる時間が短い。Obolo Order になると本当の姿になり、隣にいられる時間・一緒に作れる量が増える。

## M-R187 ブルーナのフォルダと、他の人の作品をしまう
- ブルーナは、星のアイコンが並ぶ作品集。**アイコンの下に字は付けず、右下の記号で種類を表す**（音の波＝声、正方形の額＝アート、音符＝曲、再生の三角＝映像、放送の電波＝ラジオ、宝石＝グッズ、開いた本＝本、ゲームの札＝ゲーム）。
- 星で気に入った他の人の作品は **〔ブルーナにしまう〕** で保存できる（まずは水星の曲）。しまった作品は写しではなく、元へのつながり。作った人が消す・非公開にすると「今は聴けません」。誰が何人しまったかは出さない（数字を出さない決まりのまま）。

## M-R188 冥王星＝物語の星（M-R156 の「天王星＝物語の星」「冥王星は足さない」を取り消す）
- **冥王星を足す（星は9つ）。** 小説・絵本・一冊の本は冥王星に飾る。
- 世界観：太陽からいちばん遠い、暗くて冷たい星。「星の仲間から外された、忘れられた星」に、物語がしまわれる。my図書館は **氷の書庫**（物語が氷の結晶の中に眠っている）。公開した物語は、暗い冥王星の空に **灯り** としてともる。
- これまで天王星にあった物語の場面（二周目 L2-URANUS の「書く→絵本→my図書館」、三周目 L3-SHAPER の WRITER）は、**場所を冥王星に移す**。中身・流れ・{neo}の顔のフクロウが本を運ぶこと・称号 WRITER はそのまま。場面ID・フラグ名もそのまま（名前の中の URANUS は、場所の意味ではなく古い呼び名として扱う）。
- 冥王星は一周目は「扉だけ見える星」、二周目のはじめに錠が開く（今の天王星と同じ扱い）。
- 住人：**今の物語の場面ごと、たこ焼きブラザー（バイカ）を冥王星へ移す**（新しい人物を増やさないための初期案。✏️ 利用者の確認待ち）。

## M-R189 天王星＝グッズの星（M-R156 の「グッズの機能はなくす」・M-R158 の「obolo商店は火星」を取り消す）
- **天王星はグッズの星。** obolo商店は火星から天王星へ移す（天空のアトリエの町の店）。
- 売るもの：OBOLO公式のグッズ（KIMORIN⭐︎・MIKIE⭐︎・コロリンなど）、**ユーザーが月の工房で作ったグッズ**、冥王星の小説・絵本を実物の本にする注文。
- グッズを作る機能を戻す（作る場所が月の工房に一本化され、「部品で my場所を飾る」と重ならなくなったため）。
- 火星は映像だけの星になる（上映館・七つの劇場・物語の大映画館はそのまま）。
- **二周目の天王星の場面は、第21稿より前の「天空のアトリエ・obolo商店」の場面を土台に戻す**（コミット c683cd70 の `P09/c01.md` など。`git show c683cd70:docs/story-rewrite/wip/P09/c01.md`）。ただし「作る」は月の工房に読み替え、天王星は作ったグッズを並べる・売る・買う所にする。obolo商店の店の人も、火星から天王星へ移る。
- ✏️ 確認待ち：三周目にグッズの称号（旧 SHAPER）を戻すか（今の称号は Obolo Order・RECORDER・WEAVER・MOVER・HOLDER・WRITER・PLAYER の7つ）。

## M-R190 金星＝ラジオの星（金星の DJ の決定 2026-10-12 を組み直す）
- **金星はラジオ・ポッドキャストの星。DJ は番組の中の機能の一つ。** だから番組のために DJ を練習する。
- **放送ブースは金星に置く**（ラジオは作ると見せるがその場で同時に起きるので、「作るのは月」の例外）。
- **ブルーナを DJ 機材に差し込む**と、ブルーナの中の曲（自分の曲・しまった他の人の曲）がデッキに読み込まれる（DJ の USB と同じ）。
- 番組で流せるのは **このプラットフォームで生まれた曲**（公開する時に「ラジオ・DJで使われてOK」が最初からオン。オフにできる）。流れている間は曲名と作った人を出す。既存の曲は DJ の練習（自分だけ）にだけ使える。
- 番組は **声だけ**。サムネと簡単なループ画像を回せる。収録の番組と、声だけの生配信。聴く人はリクエストと短いコメントができる。
- 一周目の7日目（D07V・かんたんDJ）は、「ラジオの練習としての DJ」に寄せる。三周目・太陽終章の「{neo}のDJ」は、ラジオの番組の中の DJ としてそのまま使える。

## M-R192 台詞の直し方（この第20ラウンドの進め方）
