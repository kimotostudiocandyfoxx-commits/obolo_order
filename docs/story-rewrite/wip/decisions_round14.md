# 第14ラウンドの決定事項（利用者決定 2026-10-13・最優先）

## Y1. 三周目の森・島・劇場は「最初の1つは本人が選んで必ず体験、あとは自由」（X4の更新・三星共通）
- 対象：木星の七つの森（RECORDER）、水星のジャンルの島（WEAVER）、火星の七つの劇場（MOVER）。
- 各星の初回のチュートリアルの最後に、住人が「どこか一つ、行ってみるか」と聞き、**本人が好きな1つを選ぶ**→その場所の物語が流れ、技法を一つ知る（必須はこの1つだけ。選ぶのは本人）。
  - 木星：カイザー（森の住人）がジャケットの絵のタッチの森を一つ選ばせる。
  - 水星：フリージーが〔みんな〕の島を一つ選ばせる（X4のチュートリアルの最後）。
  - 火星：ヒポキンがMVの撮り方の劇場を一つ選ばせる。
- 残りは〔みんな〕（木星・火星でも、その星の「みんな」や地図の中）に見えていて、行ったことのない場所は少しシルエット。初めて行くと物語が流れる。行かない限り流れない。順番・数は自由。
- 「あと○つ」「○/7」などの数や進み具合は出さない。行った数で評価しない。称号の条件は不変（選んだ1つ以外に行かなくても取れる）。
- 場所どうしの物語が順番・前の場所に依存しないようにする。各章の締め・授与・振り返りは行った場所だけを動的に言及。
- 章の必須の山（住人自身の話、キモリンの出番、授与）は場所の外か、どの場所を選んでも成り立つ形に置く。
