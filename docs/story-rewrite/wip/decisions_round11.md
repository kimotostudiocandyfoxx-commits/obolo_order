# 第11ラウンドの決定事項（利用者決定 2026-10-12・最優先）

## U1. デュエットの流れ（decisions_round10 T1 の更新）
- 三周目の水星（WEAVERの海賊の航海の中）で、**フリージーがコラボ（フィーチャリング）の機能を説明する**（住人のチュートリアル。短く、実際に触りながら）。
- それを聞いたキモリン（その夜だけ船に密航している＝三周目のこの章の1回の出番）が飛び出してくる：「フィーチャリングってこと？　え？　じゃあ早速フィーチャリングしてみたいケン！」と主人公を誘う。恥ずかしさの理由づけは不要（キモリンは堂々としている）。
- デュエットは T1 のとおり（キモリンの二番＋主人公の一番、声は登録と同意がある時だけ・なければバティの声、断れる、まず本人だけに保存、アルバムに入れるかは本人が選ぶ）。
- **デュエットが終わった後、キモリン「オレの声は、いつでも使っていいけんね！」→ 以後、主人公はいつでもキモリンとデュエットできる機能が開放される**（〔画面：キモリンとのフィーチャリングが、いつでも使えるようになりました〕）。使うかどうかは自由。称号の条件にしない。生成は毎回、使用の確認（数値なし）。
- キモリンの「……これは、また今度ケン」（未完成の意味）の回収は、このデュエットで一番が完成すること。

## U2. キモリン「オレは人生で失敗したことが一度もない！」（全編のランニングギャグ）
- **序盤（1日目、遅刻して登場したあたり）で、キモリンが「オレは、人生で失敗したことが一度もないケン！」と言い切る**。
- 以後、明らかに失敗に見える場面（3日目のブラタゴンのドア通れない、二周目のブラタゴン島の離れ目、巨大すぎるスタジオ、漆黒の黙示録ミックスで踊れない、ころりんが長すぎる、など）で、**無理やりな自己解釈で「成功」にする**：例「……ギリギリ成功ケン」「ドア通れんってことは、それだけデカいってことやけん、成功やね」「目が離れとるけん、広く見渡せる。成功ケン」「踊れんってことは、聴き入るってことやけん、成功」。
- **大事なのは“失敗作のいい部分を本当に見つけ出す”こと**（ただの言い張りで終わらせず、本当にいい所を一つ見つける）。これがキモリンの「失敗を恐れない」役割。ピンポンボタン（何でも正しく聞こえさせるニセ魔法）とは違い、こちらは本物の“いい所探し”。
- 言い回しは毎回変える（同じ決め台詞の機械的な反復にしない）。全編で6〜8回程度。主人公の作品には使わない（主人公の作品を失敗扱いしない）。うんちピンポンくんが、言い張りが苦しい時だけ「ブッブー♪」、本当にいい所を見つけた時は静かに「ピンポン♪」（G2の回数内）。
- 説教にしない。オチの解説をしない。終盤に「失敗してもいいんだ」と教訓を言わせない（キモリンは最後まで「失敗したことがない」と言い張ってよい）。
