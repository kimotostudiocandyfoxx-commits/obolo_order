## 1. 全編の芯

### 1-1. 物語の一文
友達の招待状で秘密結社に招かれた主人公が、同じ日に招待された同期のKIMORINと、返事がロボみたいになってしまった星々の住人に会いに宇宙をめぐる。住人が〈間〉をとって〈自分の返事〉を取り戻すのを見届けるうちに、主人公自身も「自分の声は、下手でも自分のもの」と知る。やがてお題を離れて自分から作るようになり、遠くに探していたコスモスの意味に気づいて、日常へ帰っていく。

世界を救う義務から始めない。主人公を選ばれた英雄にしない。救世主説はKIMORINの早とちりで、しかも自分のことだと思っている。

### 1-2. 三つの旅の役割と、主人公の目的の変化
三つの旅の役割は、利用者と相談して次のように決めました（bible_structure_v4。付録A-1 #13）。
- **一周目＝使い方を知る旅**（言葉→シール→曲→映像を、一つずつ初めて作る）。
- **二周目＝自分の姿と場所を仕上げる旅＋少しだけ使い方を学ぶ**。テンポよく短く進み、各星で「自分の場所が完成する」瞬間が山場になる（myころりん・myツリー・myアイランド・プロフィールの姿・myスタジオ）。同じ星で、KIMORINの場所も毎回ちがう形で崩れながらできあがる。木星の森・水星の島・火星の劇場は、遠くに見えるだけでまだ閉じている。
- **三周目＝いろんなやり方を学ぶ旅**。二周目に閉じていた森・島・劇場が開き、冒険しながら技法や見せ方を知って、それを自分の企画に使う（使わなくてもよい）。二周目に作った木・島・スタジオが拠点になる。

### 1-3. 危機：オート化とオートン
- **オート**：人は圧倒されると（声が多すぎる、比べられる、同じ答えを求められる）、考える前に反射で決まり文句の返事をしてしまう。これを結社では「オート」と呼ぶ。**感情は消えていない**。感じてはいるのに、返事だけがロボのように出る。感情が消えた人間は描かない。
- **オートン**：圧倒された人の口から飛び出す、灰色の角丸の小箱（横長のスリットの目、アンテナが一本）。「ピッ」と鳴り、その人の“逃げの口癖”をカタカナで言う（「ワカル」「タイシタコト、ナイ」「ステキ」など）。悪役ではなく、圧倒されている状態を形にしたもの。
- **弱点は“間”と予想外**：沈黙、「えっと」、変な返事、くだらない返事に弱く、「……エラー、ジャナイ、ヨ……？」と固まる。住人が自分で間をとって自分の返事を出すと、丸くなって淡く光り、眠る（置き物・ランプ・肩の上の相棒になる）。倒さない。完全には消えない。便利なときもある。
- **軸は“作るか作らないか”ではない**。選んでいるのが誰か、が軸。たくさん作っていても正解っぽい曲を自動で量産すればオートになりうるし、見るだけの人でも「これが好き」と選べば自分の返事になる。「アーティストの対義語はロボット」とは書かない。ロボ＝悪、技術＝悪にも読ませない。
- **名前の揺れ**：一周目は誰も名前を知らない（KIMORIN「宇宙人」→「漆黒の小箱」、ブラザー「ピッピ」など）。8日目にOBOLONが「名前は、まだ、ない。」と言う。二周目の土星でシスターが「オートン」と名づける。
- **三つの大ビート**（各地の日常の場面では繰り返さない）：
  1. 二周目の入口・土星＝**声の量**：「ワカル壁」（L2-SATURN-S001〜S002）。「一つ聞く／今日は聞かない」を選ぶ。
  2. 二周目の中盤・金星＝**比較**：「くらべ鏡」（L2-VENUS-S002）。試して戻す／背を向ける／今日は見ない。
  3. 二周目の帰還・地球＝**同じ答えへの圧力**：掲示板がすべて同じ一枚になる（L2-RETURN-S001〜S003）。原因は、KIMORINがサプライズで配った「見本」。住人は「送るとそろう」と気づき、一人ずつ自分の返事を手で持って帰ってくる。主人公はそれを見届ける。
- 一周目は局所的な兆しだけ（各星に一か所、「ピッ」と小箱の影）。黒幕・最終ボス・滅亡期限・作品で全部治る展開・採点で救う展開は置かない。
- **出番は軽く**（bible_mysteries_v5 M3）：本格的に出すのは上の三つの大ビートと、一周目の小さな兆し（便りの「ワカル」「ピッ」、各星の小箱一匹）だけ。ほかの場面では背景の小ネタ（眠って置き物・ランプ・ボタンになったオートンが光っている等）にとどめ、各星・各章で多くて1回。出現→「ステキ」→眠る、の小芝居は新しく足さない。「オートとは何か」「考える前に返事が出る」を住人が説明する台詞は置かず、行動と一言で見せる（命名のシスターの説明は一行だけ）。上の「オート」の説明は編集用の定義で、台詞にはしない。

### 1-4. 言霊（この物語の魔法）
- 主人公が言霊を唱える（つぶやき・気持ち・空想）→ バティがそれを「スペル」に編み直し、魔法陣を描いて唱える → シール・曲・映像になる。
- **声でなくてもいい**：文字で打っても、選択肢を選んでも言霊になる。マイクを使えない人、使いたくない人を置いていかない。
- **魔法を習う旅にしない**：呪文の習得、レベル、正解の呪文は作らない。「おなかすいた」でも立派な言霊。材料はいつも本人の言葉。画面にも台詞にも「AI」という語は出さない。
- 生成中の演出は実際の処理状態に合わせる。「唱え終わった＝完成」と偽らない。マナ（太陽の力）の数値は出さない。
- 段階：語の初出＝D04-S005（最初のつぶやき）／初めてのスペル＝D05-S007（シール）／曲＝D06-S006／映像＝D07-S005／太陽でもう一度、最初の言霊が見える（L3-SUN-S006）。
- KIMORINのピンポンボタンは**ニセ魔法**（何を言っても正しく聞こえる）。本物の言霊との対比が笑いになる。説明の台詞では言わない。

### 1-5. KIMORINの役割
- **案内人ではない。同じ日に招待された同期のネオ**。D01-S007で、不穏な神殿の沈黙の中へ、遅刻して、発明品を抱えて、間違った扉（裏口の小さな扉）から転がりこんでくる。空気を壊して和ませるが、伝承と「朧とは、、、、」の場面では黙る。
- お調子者で、失敗ばかり。怖いもの知らず。目立ちたがりで、少しナルシストの自称「天才発明家」（発明はいつもくだらない）。中二病（何でも漆黒・封印・禁断にしたがる）。一人称は「オレ」、語尾は「ケン」「やけん」。愛されキャラで、ただの罵倒役にはしない。
- 役目：**ユーザーが聞きにくいことを先に聞く**（1場面2問まで。体の動き・物で聞く）／**先に作って失敗する**（ただし毎回同じ形にしない。8つの型を回す）／救世主説を自分に向ける。
- 道のり：一周目は住人の誰も彼を知らない →（D08）先に払わず、先に決めず、「家の人と相談してくる」と一度帰る。本人がpayを選んだあとにだけ遅れて合流する → 二周目は顔なじみになっている、木星・水星・火星で自分の場所を先に作って毎回ちがう形で崩れる（ピンポンボタンを埋めた木／漆黒のはずがパステルの島／山のように大きすぎるスタジオ）、金星で片翼を残す、天王星の結社公式の店でバイト、海王星の自作ゲーム「キモリンの帰り道」→ 星休めは自分の映画館と短編「なんの味だったっけ？」→ 三周目は別の道（店のバイト・一番から始まる曲）で、各章に多くても一度、ちょっと顔を出す（本部で自分の名札、海賊船に一晩だけ密航、劇場の客席に変装、など）→ 太陽ではボタンが鳴らず、誰もそれに触れない。
- **“二番だけ”の曲**：作りかけて手で隠し、「……これは、また今度ケン」と言う。理由は説明しない。
- 相棒は**うんちピンポンくん**（1-8）。発明で問題を解決しない。アプリや専用機の開発者にしない。

### 1-6. はじめて棚
- 土星の神殿にある棚。住人たちの「見られたくない最初の作品」（形は人それぞれ）が、来た順にほこりを払われて並んでいる。「へたくそ」ではなく「はじめて」として置かれている。
- 流れ：D04-S003で布をかけた棚が背景に映る → L2-SATURN-S009で紹介 → L3-RECORDER-S019で、本人が自分の最初の作品を置ける（任意・非公開・いつでも下ろせる。`f_first_shelf`）→ 置いた人には、L3-SUN-S006で一瞬だけ映る。
- **新しい機能ではない**。既存の保存作品を自分だけに表示する形で代わりがきく（付録C）。NPCは読まないし、評価もしない。

### 1-7. 笑いの設計の要点
- 笑いは添え物ではなく中心に置く。**事件そのものが面白い**（人物の欲→変な行動→事態の拡大→意外な着地）。「一同爆笑」とだけ書いて済ませない。オチのあとで解説しない。
- 型①〜⑩を章ごとに入れ替える（①厳格すぎる手続きの空回り ②大げさな準備と小さな目的の落差 ③妙に本気のくだらない争い ④勘違いの連鎖 ⑤ドタバタ追いかけっこ ⑥真顔の変な対策 ⑦予想外の返事でオートンがバグる ⑧見栄の崩壊・自己矛盾 ⑨乾いた一言 ⑩規模の落差）。同じ型を続けない。
- ファンタジーの“あるある”を今ふうにずらす：オートン＝同じ台詞しか言わないRPGの村人／来ないボス戦／選ばれし者フラグの早とちり／非公開保存＝セーブポイント。実在の作品のパロディ、流行語、ダジャレには頼らない（世界中の読者と翻訳を考えて）。
- テンポ：1場面に「事件1つ＋選択1つ＋変化1つ」。笑い→静けさ→次への引き、の三拍。各日・各星は未解決の1点で閉じる。
- **回数の上限**：うんちピンポンくんの「ブッブー♪」は1日・1星につき1回まで（2回目は鳴らない／鳴りかけて止める／あくび／本当にいいときの静かな「ピンポン♪」に変える）。ピンポンボタンは1日・1星につき2回まで。MONBANが影から一言ツッコむのは1場面に1回まで。反復と指摘された型は3回以内にして、毎回形を変える。
- 笑いの標的にしないもの：本人の作品・容姿・家庭の事情・声が出せないこと・作らない選択。核心二行の前後は絶対に茶化さない。

## 3. 読み方の注

### 3-1. 場面書式の欄
各場面は次の順で書いてあります。
- **見出し**：`### 〈sceneID〉｜〈場面題〉`
- **sceneID／原本見出し・短いアンカー／既存素材参照**：原本のどの場面にあたるか（短い見出しと引用）。〔動画N〕〔背景…〕などの既存素材の番号は振り直さずに残しています。
- **旅・日・星／開始条件／本人の目的／NPCの望み／緊張や食い違い**：その場面が始まる条件と、本人と住人がそれぞれ何を望み、どこで食い違うか。
- **本文**：短い情景と行動 → 話者別の実際の台詞 → 本人の選択 → 目に見える変化。台詞は `話者名「台詞」`、ナレーションは（ナレーション）。選択肢は `［選択肢：〜→行き先］` の形で、各選択肢の反応を書いています。
- **選択ごとの行き先／更新フラグ・保存イベント／保留・終了・再開点**：分岐の合流先、内部フラグ、保存の操作。保留や拒否で止まった場合の再開点は `RESUME@sceneID`。
- **この場面だけの発見・笑い・関係変化／次を見たい理由／謎の状態**：その場面で動くもの。
- **設計注（本文に混ぜない）**：制作側へのメモ。台詞ではありません。
- 各パートの冒頭には「このパートの芯／笑いの仕掛け／次への接続」を置いています。

### 3-2. 記号と表記
- **〔　〕**：演出・画面の指示（カメラ、効果音、〔画面：…〕のUI表示、〔入力：声／文字／選択／パス〕など）。台詞ではありません。
- **〈　〉**：動的な部分（本人の入力や保存作品が入るところ）。`{name}` `{neo}` `{bati}` `{food}` `{inviter}` `{choice1}` は変数です。D03でネオに名前をつけて以降、呼び名は{neo}になります。
- **（架空の入力例）**：自由入力に対する応答の例。実際の利用者の言葉や経験ではなく、書き手が想定した例です。内容がわからない入力には、あいまいに褒めず、短い確認か選択肢を返します。
- **入力の代替**：声を使う場面にはすべて、文字・選択・パスの道があります。マイクは本人が操作したときだけ始まります。
- **フラグ名**（`f_…`、`mana_low`／`mana_ok` など）：新しい稿を設計するための内部名で、既存コードのキーと同じとは限りません。一覧は付録C-2。
- **`mana_low`／`mana_ok`**：バティの眠気・疲れ・透ける予兆は実際の残量に連動します。本文で二つの経路を書き分けているのは、一周目5〜8日目の該当場面と8日目だけです。内部の88マナは画面にも台詞にも出しません。

### 3-3. 〔制作：標準フロー（付録C-1）〕の意味
- 本文の制作場面は、原則として次の1〜2行にまとめてあります。
  `〔制作：標準フロー（付録C-1）。材料＝〈前の作品／新しい言霊〉／この場の焦点＝〈技法・画風・見せ方など1つ〉／生成前に使用の確認（数値なし）／保存は本人だけ・公開は別操作〕`
- 標準フローの中身は付録C-1にまとめています。言霊の入力（声／文字／選択）→ 焦点の選択 → 下書きの確認 → 生成前の使用確認（数値なし）→ バティのスペルと魔法陣（実際の状態に連動し、完成と偽らない）→ 待ち・失敗・完成の台詞 → 試聴・確認 → 本人だけに保存 → 公開は別の操作。
- 本文で物語として書いているのは、その場で本人が選ぶ**焦点ひとつ**と、魔法が世界に起こす目に見える変化と、人物の反応だけです。失敗の台詞は、各星で最大1回だけ本文に出します。
- 〔制作：原本画面「…」〕と書いてあるところは、標準フローではなく原本の専用画面（ネオ作りなど）を使います。
- 保存・送信・公開・継続展示・決済は、どれも台詞だけでは実行されません。宛先と内容を確かめる別の明示操作が必要です。

### 3-4. 固定原文
次の台詞は原本どおり一字一句そのままで、本文でも改変していません。1日目の伝承（MONBAN「結社には、言い伝えがある…。」「『コスモスを見つけよ。／そこに、お前の宝がある』…。」）、「朧とは、、、、」、1日目と8日目の「わかりやすく、言う。」、8日目の「結社の仲間は、全員、／表現者、なんだ。」、太陽終章の想起・核心二行（本文 L3-SUN-S007 にのみ掲載。巻頭では引用しない）、最後の言葉「今日はその続きを生きてこい。」。「／」は原本での改行位置です。核心二行はL3-SUN-S007にだけ出てきます。直後には説明・相棒の返事・自動送りを挟まず、本人がタップするまで待ちます。
