# 第15ラウンドの決定事項（利用者決定 2026-10-13・最優先）

## Z1. おぼろ商店への申請は三周目SHAPERから（W1の更新）
- 二周目の天王星：グッズを作ってアトリエに飾るまで。おぼろ商店は「いつか自分のものも並べられる場所」として眺めるだけ（申請はまだできない。〔画面〕で一言「申請は、旅の先で開きます」程度。日数・条件の数字は出さない）。
- 三周目SHAPER：グッズの作り方を最初から教え直さない（「覚えているか」の一行程度）。**自分のアニメの世界をグッズにする**体験を前に出す（物語の場面・主役の全身・小物などを見本に）。アトリエを自分の作品の展示室にする。**ここで初めておぼろ商店に申請できるようになる**（申請は任意、称号の条件にしない）。キモリンの「オレもいつか、おぼろ商店に並べるケン」の回収もここ。
- 星休め（P10）の天王星は「申請はまだ」のまま。

## Z2. 三周目で同じ星に着いた時の一言
- 三周目に、二周目にも行った星（木星・水星・火星・天王星・海王星、任意の金星ライブ）に着いた時、その星の住人が**二周目との違いが分かる一言**を言う（例：海王星「前は遊びに来たな。今度は、お前のが遊ばれる番だ」）。説明台詞にせず短く、住人の口調で。既に同じ働きの台詞があれば足さない。

## Z3. 8日目のエクリプスの決断（D08-S002〜S003、S006）に3つ足す
1. **なぜお金がかかるか**：MONBANの一言で、7日間に見たもの（オートン、火星の「オススメ、デス」の小箱）と結びつける。例：MONBAN「……ここには、勝手に流れてくる広告も、オススメの小箱もない…。あるのは、誰かが自分の言葉で作ったものだけだ…。灯りは、会費でともしている…。」。他のSNSの名前・比較・「AI」の語は出さない。説教にしない。既存の〔画面：月額88円。広告は入りません。人だけが入れる場所を続けるための会費です。無料の席はありません〕と重複しないように整える。
2. **何がもらえるか**：MONBAN「入れば、月が巡るたびに、お前のジェムにマナが湧く…。」＋ジェムの中に小さな泉が光る絵（数字は出さない。88マナを画面に出さない決まり）。
3. **旅の続き**：決める前に、星図の上で、まだ行っていない星（金星・天王星・海王星）とその先の太陽がうっすら光る。KIMORIN「……まだ、半分も来とらんケン。」の一言。
- 急がせる言葉・損をさせる言い方は入れない。「入らなくても消えない」等の既存の誠実な部分はそのまま。
- 支払いの最終確認の〔画面〕（D08-S006）に、**値段・毎月の更新日・自動で続くこと・やめ方**を並べる（特定商取引法の最終確認画面。文言は運営で最終確認、と設計注に）。
