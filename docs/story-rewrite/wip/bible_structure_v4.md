# バイブル追補 第4版｜二周目と三周目の構成変更（最優先・利用者決定）

利用者（制作者）と相談して確定。bible_kimorin.md と同格の最優先。他の資料（指示書§7「二周目：土星8広場、木星7画風＋仕上げ、水星8ジャンル・各1技法、金星4場面、火星7見せ方＋完成」を含む）と矛盾したら、この文書を優先する。付録Aの判断ログに「利用者決定による構成変更」と記録する。

## S1. 三つの旅の役割（ざっくり）
- **一周目＝使い方を知る旅**（変更なし）。
- **二周目＝自分の姿と場所を仕上げる旅＋少しだけ使い方を学ぶ**。テンポよく短く。各星で「自分の場所が完成する」のが山場。
- **三周目＝いろんなやり方を学ぶ旅**。二周目には行けなかった森・島・劇場が開き、冒険しながら技法を知り、それを自分の企画に使う。

## S3. 三周目の新構成（称号の順番・条件は変えない）
| 章 | 称号の条件（変更なし） | 三周目で開く冒険 |
|---|---|---|
| RECORDER | 異なる完成曲3曲のミニアルバム（曲順・ジャケット・名前・企画を本人確認） | 曲は水星のmyアイランドで3曲。**ジャケット作りのために、木星の七つの森が開く**（ポップ／水彩／鉛筆／切り絵／漫画（バトル漫画風）／ピクセル／やわらかい3Dトゥーン＋仕上げ）。森ごとに世界の画風がまるごと変わる冒険。分身カイザー、褒めオート、根っこの奥の最初の絵など、現行P06の森の場面を三周目向けに移植。最後にジャケットを選ぶ（森で作った絵でも、既存の作品の絵でもよい） |
| WEAVER | 異なる完成曲8曲のフルアルバム（先の3曲を含めてよい） | **水星の八つの島の航路が開く＝海賊の航海**。寿司モン7体＋フリージー、各1技法（フック／引き算／フロウ／フレージング／ダイナミクス／ビルドと解放／音色の受け渡し／ハーモニーの色）。島ごとに1曲を作ってアルバムに足していける。現行P07の島の場面を移植。冷蔵庫の奥の最初の曲の解凍もこの章 |
| MOVER | 8曲から異なる3曲を選び、各1本の完成MV（同方式3本可） | **火星の七つの劇場が開く**（ことばの大ビジョン＝リリック／シールの画廊＝イラストMV／ネオのライブステージ＝パフォーマンス／光のドーム＝抽象／思い出の回廊＝モンタージュ／笑いの小劇場＝コミカル短編／静かなミニシアター＝静かな短編）。劇場を巡って見せ方を知り、3曲の見せ方を選ぶ。現行P08火星の場面を移植 |
| HOLDER | 自主企画アニメ（1話可・4話は提案） | **物語の大映画館**（現行P08の「君の上映室」）が、自主企画アニメの舞台として開く |
| SHAPER・PLAYER | 変更なし | 変更なし |

- **重要（隠れた条件の禁止）**：森・島・劇場を全部巡ることは称号の条件にしない。冒険としては順に案内するが、飛ばして直接制作に進んでも称号は取れる（「全技法使用を隠れた条件にしない」原本の決まり）。巡った場所の数・技法の数で評価しない。
- 各場所の制作は global_fixes.md G1 どおり〔制作：標準フロー（付録C-1）〕1〜2行。物語は冒険・人物・世界の変化に使う。
- **三周目のキモリンは別の道**（bible_kimorin K1）。森・島・劇場の冒険の同行者は、バティと各星の住人（カイザー、寿司モン、フリージー、ヒポキン）。キモリンは**各章で多くても1回、ちょっと顔を出す**程度（例：海賊船に一晩だけ密航してくる、劇場の客席に変装して座っている、など）。現行の移植元でキモリンが担っていた笑いは、住人・バティ・ピンポンくん（キモリンが来た時だけ）に振り分ける。
- 三周目は自分の企画が主役。森・島・劇場の住人の事件（寿司モンの困りごとなど）は「本人の企画づくりの途中で出会う出来事」として描き、お題として作品を要求しない。本人は自分の企画の曲・絵・映像を作りながら、その場の技法を“使ってみる／使わない”を選べる。
- 二周目で作ったmyツリー・myアイランド・myスタジオは、三周目の拠点として使われる（森から帰る場所＝木、島めぐりの母港＝自分の島、劇場めぐりの後に編集する場所＝スタジオ）。
