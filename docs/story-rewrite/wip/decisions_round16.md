# 第16ラウンドの決定事項（利用者決定 2026-10-13・最優先）｜KIMORINの人物像の作り直し

## K-R1. 見た目（本文の描写をこれに合わせる）
- 深い赤のビロードのフード付きローブ（銀の縁取り・幾何学の刺繍）、胸に青い宝石の留め具と青い房飾り。
- 顔は白い面（狐のような耳、目を閉じた笑みの切れ目、額に青い紋、頬に青い渦、面の端に小さく「秘」の字）。目の切れ目が青く光ることがある。素顔は見えない。
- 背中に、白・黒・朱の羽のような尾がたくさん扇のように広がる。手足は白い肉球の手袋とブーツ（青い肉球）。
- 時々、丸いサングラスをかける（気取りたい時の小道具。自分では最高にかっこいいと思っている）。
- 旧描写（リュック、鼻、ほこりを払う、頭からこける、扉に挟まる等の子どもっぽいドタバタ）は、この姿で成り立つ動きに直す（羽の尾が枠につかえる、ローブの裾を踏まれる等は可。ただし本人は優雅さを崩さない）。

## K-R2. 話し方（いちばん大事）
- **普段は丁寧語で静か、優雅**（フリーザの丁寧さ、涅マユリの発明家気質を参考。ただし残酷さ・悪役らしさ・見下しは入れない）。一人称は「私（わたし）」。語尾例：「〜ですよ」「〜でしょう？」「おや」「……ふむ」「当然です」。声を張らない。
- **テンションが上がった時だけ、素の方言（「〜ケン」「オレ」）が漏れる**：自分の発明、ブラタゴン、褒められた時、音楽・フィーチャリング、心が動いた時。漏れた直後に咳払いして丁寧語に戻る（「……失礼。取り乱しました」等。毎回同じ言い方にしない）。
- 漏れは多用しない（1日・1星につき多くても1〜2回。山場で効くように）。
- 利用者が書いた固定の台詞は「漏れ」として残す：「フィーチャリングってこと？　え？　じゃあ早速フィーチャリングしてみたいケン！」「オレの声は、いつでも使っていいけんね！」、特別編の動機の台詞「目の前が宝物やって、気づいたケン。…」（手紙の前半は丁寧語、ここで方言に崩れる）。
- 口ぐせ（U2）は丁寧語で：初出の例「……私の人生に、失敗という頁は、ありませんので。」。以後の“無理やり成功”も丁寧語で淡々と（例「通れない。つまり、それだけ大きいということです。成功ですね」）。いい所探しの役割はそのまま。
- 「中二病」は叫ぶ型から**優雅に大げさな名前をつける型**へ（「漆黒の黙示録ミックス」「封印されし黒虎竜の聖杯」等は淡々と言う）。
- ナルシスト・自称天才発明家・見栄・評価を欲しがる、は残す（静かに言う。例「ええ、天才ですから」）。

## K-R3. 笑いの作り方
- 体を張ったドタバタより、**本人は優雅なのに状況だけが崩れていく**笑い、**真顔の一言**、**丁寧語からの方言の漏れ**を中心に。
- 1日目、OBOLONに好きな食べ物を聞かれて、真顔で静かに「……うんち、です。」→うんちピンポンくん誕生（そのまま）。
- うんちピンポンくん（ブッブー♪／ピンポン♪）、ピンポンボタンはそのまま（G2の回数）。優雅なキモリンとかわいい相棒の落差を生かす。
- 温かさ（デュエット、帰還、太陽で画面のガラスにそっと触れる、特別編の手紙）は残す。主人公を見下さない。仲間で同期。

## K-R4. 正体
- 同じ日に招待された同期のネオ、という設定は不変。**素顔・年齢は最後まで出さない・言わない**（面を外す場面を作らない。誰かが年齢を聞いても、はぐらかす）。
