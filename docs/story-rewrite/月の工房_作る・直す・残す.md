# 月の工房：作る・直す・残す（決定 M-R253・2026-11-22）

> 月はこのソフトでいちばん大事な所。作るのは全部{bati}との同じチャットの中（M-R210）、できた物は自動でBluenaへ（M-R211）。その上に、次の5つを足す。

## 1. やり直しは「同じ作品の中」に重ねる
- カード1枚＝作品1つ。「もう少し明るく」などのやり直しは、新しいカードにせず、同じカードの中に重なる。
- カードを左右にめくると、1つ目・2つ目・3つ目…を見比べられる。カードの下に小さな点（いくつ目か）。
- 最後に見ていたものが、その作品の顔になる（Bluenaの一覧・星へ飛ばす時に使われる）。
- Bluenaには作品が1つだけ入り、中に試した分が全部残る。あとで前のものに戻せる。要らない試しは、作品の中で消せる。
- 新しく別の物を作りたい時は、言葉で「新しく作って」。{bati}が新しいカードを出す。

## 2. 指でさして直す
- カードの上の直したい所を指でさしてから、言葉（文字・声）で頼む。
  - 絵：さした所に小さな光の輪。「ここ、もっと青く」。
  - 曲：波の形をなぞった所だけ色が変わる。「ここのサビ、もっと盛り上げて」。
  - 映像：場面のコマを選ぶ。「この場面、夜にして」。
  - コロリン・ラジオ：文字（聞き取った文字）の一部を選ぶ。
- 画面は変えない。さすのも、カードの上だけ。

## 3. 前の作品を、次の作品の材料にする
- 作れる物が増える朝、{bati}が前の日までの作品を材料に持ちかける（使うかどうかはユーザーが選ぶ）。
  - 5日目（曲）：「3日目のコロリン、歌詞にしてみる？」
  - 6日目（映像）：「4日目の絵と、昨日の曲で、映像にしよう」
  - 7日目（ラジオ）：「今まで作った曲を流して、しゃべってみる？」
- Bluenaから作品をチャットへ引っぱってきても、材料になる。
- 材料にした作品は、新しい作品のカードに小さく並ぶ（押すとその作品へ）。8日間でつながった「自分だけの1本」になるように。

## 4. 時間のかかる物は「〇分後に戻ってきてね」（利用者の案）
- 作り始める時に、できあがるまでの時間を計算して、{bati}が先に伝える。
  - 例：{bati}「この曲は、だいたい4分かかるよ。4分後に戻ってきてね。そのあいだ、土星でも見てくる？」
- ユーザーは、そのあいだ別のトーク（ダチ・過去のトーク）や、別の星に行っていてよい。待っている感じを出さない。
- カードはすぐに出て、残りの時間（「あと3分」）と、少しずつ埋まっていく様子が見える。
- できたら知らせる：アプリの中ならどの画面でも上に小さな知らせ（{bati}のコロリンと「できたよ！」）、アプリの外なら通知。押すとそのカードへ。
- 時間の出し方：作る物の種類・長さ・今の混み具合から見積もる。言った時間より早くできるのはよいが、遅れそうな時は{bati}が先に言う（「ごめん、あと1分だけ」）。
- すぐできる物（コロリン・短い直しなど、だいたい30秒以内）は、時間を言わずにその場で待つ。
- うまく作れなかった時は、エラーの文を出さず、{bati}が自分の言葉で謝って、作り直しを始める（その時も時間を言い直す）。

## 5. 星から帰ってきた反応を、{bati}が伝える
- 飛ばした作品が88時間たって自分の場所に帰る時、{bati}が報告する。
  - 例：「ミキエが★つけてたよ」「知らない人が3回聞いてた」
  - 数字は「何回」くらいまで。順位や比べる言い方はしない。
- 15歳未満の人には、ダチからの反応だけを伝える（M-R213）。
- Bluenaで作品を押すと、それを作った時の会話の場所へ飛べる（左のバナーの過去のトークと同じ場所）。
