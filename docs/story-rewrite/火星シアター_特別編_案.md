# 火星シアター 特別編（案・2026-11-21・決定 M-R203）

## 決まり
- **火星シアター**：火星の町の奥にある、金色の幕の古い映画館。**Obolo Order（会員）だけが入れる。**
  - 旅の6日目（火星）の夜、切符の星図に、錠のかかった幕の絵が出る（D07-S007）。
  - 会員になった瞬間に〔通信：火星シアターの扉が、開いた〕（SYS-S002・D08-S006）。
- **かかるもの**
  1. YouTube のショートアニメ（ミキエが世界中で人を誘いまくる、1話完結のギャグ）を、いつでも見返せる棚。
  2. **会員だけの特別編**：ミキエの側の物語。コスモスの言い伝え、oboloフェス、「obolo とは何か」の匂わせ。季節ごとに1話ずつ足す。
- **人物の立場**
  - **ミキエ**：結社の人（運営側）ではなく、**いちばん熱心な会員**。この宇宙が好きすぎて、誰彼かまわず誘ってしまう人。お金の話は一切しない。
  - **MONBAN**：言い伝えを一言だけ告げる役。説明役にはしない。若いころのミキエを知っている（2日目、KIMORINの母の話で目が細くなる所の答え）。
  - **OBOLON**：「oboloとは、、、」と言いかけて、MONBANに「おい待て、そこまでだ。」で止められる（ソフトと同じお決まり）。
  - **KIMORIN**：子どものころの姿で、ときどき出てくる（ソフトで初めて会った人へのご褒美）。
- **長さ**：1話3〜5分。笑いは残し、最後に少しだけ深くする。
- **気をつけること**：誘う理由は「一緒に作ると楽しいから」「灯りが増えるから」。友だちを招待しても、マナやお金のお返しは出さない（マルチ商法に見えないように）。

## 第1話「ミキエの招待状」
- **あらすじ**：若いころのミキエ。毎日、手の中の画面に流れてくる他人の暮らし（ナガレ）を、ぼんやり眺めている。ある夜、金色の招待状が届く。本部の門で、若いMONBANに会う。
- **見せ場**：
  - 若いミキエが、門の前でMONBANを質問攻めにして、MONBANが押し負ける（今のミキエの強引さは、このころから）。
  - 月の工房で、ミキエが初めて作ったもの（へたくそな歌）が、小さな灯りになって星に飛んでいく。
- **決め台詞**：MONBAN「……『コスモスを見つけよ。／そこに、お前の宝がある』…。」
- **終わり**：ミキエ「コスモス？　……花？　星？　人の名前？」〔つづく〕

## 第2話「コスモスを探して」
- **あらすじ**：ミキエが、コスモスを探して星をめぐる。土星で花のコスモスを見つけて「これだ！」、木星の蝶に「これか！」。全部ちがう。
- **見せ場**：
  - 探しているうちに、ミキエは行く先々で、作ったものを人に見せて、また作っている。
  - 家に帰ると、小さなKIMORINが、ミキエの歌に合わせて、ガラクタで変な楽器を発明している。
- **決め台詞**：OBOLON「コスモスは、、、」　MONBAN「おい待て、そこまでだ。」
- **終わり**：ミキエ、KIMORINの楽器の音を聞いて、何かに気づきかける。〔つづく〕

## 第3話「oboloフェス」
- **あらすじ**：Obolo Order が増えると、地球のどこかに町「obolo」が生まれる。ミキエと会員たちが、その町で88日間の『oboloフェス』を開く。白い丸いドーム（プラネット）が通りに並び、真ん中にDJブース。
- **見せ場**：
  - ミキエがDJブースで、昔のへたくそな歌と、KIMORINの変な楽器の音を混ぜて回す。町の灯りが、一つずつ増えていく。
  - ミキエ「……灯りは、作る人が増えるほど、増えるのね。」
- **決め台詞**：ミキエ「よし。もっと、誘いましょう。世界中の人を。」
- **終わり**：ミキエが、制服を着て、どこかの高校の門をくぐる（YouTube のアニメの1話目につながる）。

## このあと（季節ごとに足す案）
- ミサコや、ほかの会員の話。
- 「コスモスは、、、お前だ。」の答えは、急がず、いつか大事な話で出す。
- 「obolo とは何か」は、町「obolo」の話で少しずつ匂わせる。

## 作り方
- MV と同じ流れ（止め絵 → 動画 → 声 → 効果音）。若いミキエ、今のミキエ、小さなKIMORIN、若いMONBANの参照画像を先に固める。
- YouTube のアニメと、絵の雰囲気をそろえる。
