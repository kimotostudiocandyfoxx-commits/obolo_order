# 土星：自分のレコード（決定 M-R257・2026-11-23）

> 土星は「神殿」「器」「広場」をやめ、**土星の大地に、ユーザーの数だけ巨大なレコードが並ぶ星**にする。台本は D04-S003・D04-S005・D04-S005c・D04-S007（P02/c02.md・c03.md）。前の `画面設計/saturn.md` の神殿・器・広場の部分は、これで置きかえる。

## 1. 世界の決まり
- 土星の大地には、見わたすかぎり巨大なレコードが地面に埋まるように並ぶ。**一人に一枚、自分のレコード**（ふちに名札）。
- レコードの横に針が立ち、**針の先にマイク**がついている。
- **再生ボタン**を押すと、いつでもレコードが回り出す。針の下（マイクの前）に来たコロリンが、サングラスを落として、その人の声で歌う（＝土星のサイファー）。
- たこ焼き兄妹のレコードは、金ぴかのふちに赤い提灯、たこ焼きの形のマイク（「趣味悪い」）。

## 2. 何が自分のレコードに乗るか
| コロリン | 乗り方 | いる時間 |
|---|---|---|
| 自分のコロリン | 月の工房やBluenaから〔土星へ飛ばす〕と、空から自分のレコードに降ってくる | **ずっと**（Bluenaの中の同じ物。外せばレコードから消える） |
| ダチのコロリン | ダチが飛ばすと、自分のレコードに降ってくる | **88時間**（そのあと、その人のレコードへ帰っていく） |
| 推しのコロリン | 推した人が飛ばすと、自分のレコードに降ってくる | **88時間** |
- **推し**：ダチは自動で入る。ほかの星（木星の森・水星の海など）で見かけた知らない人の作品から〔推す〕で推せる（M-R213 の「推しはダチだけ」を広げる）。推しはいつでも外せる。
- **15歳未満**：降ってくるのは、自分とダチのコロリンだけ。知らない人を推すボタンは出さない。
- 知らない人から勝手に降ってくることはない。降ってきたコロリンには、長押しで〔このコロリンを外す〕〔通報〕。

## 3. 画面（土星の「自分のレコード」）
- **入口**：Bluenaの土星（コロリンの棚）／ロケットで土星へ／コロリンのカードの〔土星で聞く〕。
- **見た目**：斜め上から見た巨大なレコード（画面の幅いっぱい）。背景は土星の空と輪、遠くに他の人のレコードがいくつも見える（ほんのり回っているものもある）。右上に針とマイク。ふちに名札『{neo}』。
- **コロリンの並び**：溝に沿ってコロリンが乗る。新しい順に外側から。ふちの色で区別：自分＝金、ダチ＝白、推し＝ピンク。88時間以内に降ってきたばかりの物は、小さくきらめく（数は出さない）。
- **再生ボタン**（レコードのふち、いちばん押しやすい所）：押すとレコードが回り出し、針が下りる。針の下に来た順にコロリンが歌う（声の長さに合わせてレコードの回る速さを自動で変える）。もう一度押すと止まる。
- **タップ**：コロリンをタップすると、そのコロリンが針の下へ来て、すぐ歌う（再生中でも止まっていても）。
- **降ってくる演出**：前に開いてから新しく降ってきたコロリンがあれば、開いた時に空から、ひゅう、ぽとん、と落ちてくる（最大5つ。それ以上は「＋」でまとめて落ちる）。
- **飛ばした時**：月の工房やBluenaで〔土星へ飛ばす〕を押すと、コロリンが空へ飛んでいく短い演出のあと、「{neo}のレコードと、ダチ・推してくれている人のレコードに降ったよ」と{bati}が一言。
- **歌の字幕**：歌っている間、レコードの上に、その人の名前と、吹き込まれた言葉（聞き取った文字）を小さく出す。
- **88時間たったダチ・推しのコロリン**：レコードからふわっと浮いて、空へ帰っていく（その人のレコードへ）。

## 4. 前の決まりとの関係
- M-R208 の表の土星の行：「88時間のあいだ：巨大なDJレコードの上でサイファー／88時間のあと：自分のレコードにしまわれる」→「**飛ばすと、自分のレコードと、ダチ・推してくれている人のレコードに降る。自分のレコードにはずっと、ほかの人のレコードには88時間乗って歌う**」に読みかえる。
- M-R213 の「星の広い場所（88時間のあいだ）に知らない人の作品も並ぶ」は、木星・水星・火星・金星のまま。土星だけは、知らない人の作品は降ってこない（推した人を除く）。
- 背景の新しい絵：`saturn-records`（大地のレコードの群れ・輪の空）、たこ焼き兄妹のレコード（寄り）、自分のレコード（斜め上から・人がいない絵）。M-R255 の「キャラの大きさに合わせた背景」で作る。
