## 0. ひとことで

- 三周目の目的を一つにします。**oboloフェスで、自分のDJセットを回すこと。そして、フェスの町に自分のテントを立てること。**
- 称号（RECORDER〜PLAYER）は残します。ただし目的にはしません。「準備が一つできた」というしるしにします。称号の名前が見えるのは、テントの看板の小さな文字だけです。
- 準備が進むと、自分のテントの中に物が増えていきます。数字は出しません。
- 準備はどの順番で進めてもかまいません。全部そろっていなくても、物語の中のフェス（太陽の終章）に行けます。物語の中のフェスでは、全員がブースに立てます（おまかせもあります）。
- 現実のフェスは、物語が終わったあとの別の話です。準備ができた人が申し込みます。DJの時間割とテントの数は運営が決めます。枠より多く申し込みが来たら、外れた人には「また来年」と伝えます。来る人は1日入場88円のチケットを買います。

今の台本には、この形の芽がもうあります。

- 招待状の裏の「持ちもの」（L3-RECORDER-S001）
- ヒポキンの「……oboloフェスの、前夜祭には、ちょうどいい。」（L3-MOVER-S003）
- 金星のセットリスト（L3-MOVER-S016）
- ブラザーの「このテントは、いつか、どこかの野原に、ぜんぶ集まるらしいZE。」（L2-URANUS-S001）
- 天王星の「{neo}の丸いテントのアトリエ」（L2-URANUS-S003）と、となりのKIMORINのアトリエ（L3-SHAPER-S002）
- 太陽の終章の{neo}のDJ（L3-SUN-S005b）と、星がテントの上に止まる場面（L3-SUN-S010）

なので、作り直しは少なくてすみます。主に変えるのは**章の入口、授与の場面、つなぎの台詞**です。寄り道の場面（森・島・劇場）は、どれも削りません。

## 3. テントの育ち方

### 3-1. 準備ごとに増えるもの

決まりは三つです。

- **テントの大きさは変えません。** 中に置く物が増えるだけです（L3-SUN-S010の「大きさは、まわりと同じ」を守るため）。
- 増えるのは、置いた本人の作品そのものです。
- まだ用意していない場所には、白い布をかけた台が置いてあります。布は催促しません。

| 準備（称号） | テントに出るもの | 見え方 |
|---|---|---|
| はじめ | 今のアトリエ（飾ったグッズはそのまま）、白い布の台、名前だけの看板 | 布の下は空っぽ |
| セットの芯（RECORDER） | 入口の横に小さなレコード棚 | 三曲のジャケットの顔が並ぶ |
| セットぜんぶ（WEAVER） | 棚が奥まで広がる。入口に試聴の台 | 前を通ると、テントから曲がかすかに聞こえる |
| 町の大きな画面の映像（MOVER） | 屋根の上に小さな映写機 | 光の筋が、遠くの空へ伸びる |
| テントで流す物語（HOLDER） | テントの奥に幕と、小さな客席 | 幕に、自分のアニメの最初の一コマ |
| テントの店（SHAPER） | 入口のカウンター | グッズの見本が並ぶ。obolo商店に申請した人は、カウンターから自分の棚へ行ける |
| テントの遊び（PLAYER） | テントの横に、点滅する遊びの灯り | 灯りに触れると、自分のゲームが始まる |

看板には、名前の下に得意の名前が小さく一つずつ増えます（例：『{neo}』の下に小さく『RECORDER・WEAVER』）。**称号の名前を文字で見せるのは、ここだけにします。**

今と同じく、テントを見に来られるのはダチだけです（L2-URANUS-S003の決まりのまま）。ダチのテントを訪ねることもできます。見に来た数はどこにも出ません。

### 3-2. 授与の場面の新しい形（L3-TENT-S002）

今の授与は「MONBANの宣言 → 星の階段の短い映画 → OBOLON」の流れです。真ん中の短い映画をテントの映像に替えます。

> MONBAN「……届いたぞ…。水星の海から…。」（届いた場所の一言は、どの授与も今のまま）
> MONBAN「……テントの布を、一枚、外しておいた…。」
> 〔短い映像（停止・スキップあり）：天王星の野原。{neo}のテント。白い布が一枚、ふわりと外れて、レコード棚が出る〕
> 〔看板に、小さく一行増える〕
> 〔テロップ：持ちもの「セットの芯になる曲」に灯りがともった〕
> （スキップした場合）〔画面：テントにレコード棚が出ました〕

- MONBANの「お前は…『レコーダー』だ…。」を声だけ残すかどうかは、7の質問1で決めてください。
- OBOLONの一言（「、、、録る者、か。」「、、、織り手、か。」など）は残します。
- 星の階段は本部に残します（太陽の終章の「星の階段・おわり」に使うため）。段は灯りますが、段に称号の文字は刻みません。決まった順に上る階段ではなくなるので、「〇段目」と言う台詞と〔画面〕は外します。

### 3-3. テントを見られる場所

- **三周目のあいだ**：天王星の野原のアトリエが、そのまま自分のテントです。宇宙の地図からいつでも見に行けます。向かいはブラザーのアトリエです。KIMORINのアトリエ（ブラタゴンバイク）がとなりに越してくるのは、今と同じくSHAPERの章（L3-SHAPER-S001の手紙、S002）からです。

- **物語のあと**：宇宙の地図の天王星の野原が「フェスの町」に変わります。

今の設計注には「{neo}のテント、ブラタゴンの旗、門の文字『oboloフェス　88日間』、地球のoboloの灯りは、L3-SUN-S010まで見せない」という決まりがあります。ただ、天王星の「{neo}の丸いテントのアトリエ」は二周目のL2-URANUS-S003ですでに見せています。そこでこの案では、決まりを次のように読みかえます。

- 天王星にあるあいだは「アトリエ」として見せてよい。
- **フェスの町に並んだ姿、門の文字『oboloフェス　88日間』、地球のoboloの灯りは、今までどおりS010まで見せない。**

### 3-4. 太陽の終章のDJ（L3-SUN-S005b）とのつながり

## 4. 順番の自由と、残りの見せ方

### 4-1. 三本の道

称号の条件は変えません。そのため、前の準備が要るものがあります。道は三本です。

| 道 | 順番 | 理由 |
|---|---|---|
| 曲の道 | セットの芯 → セットぜんぶ → 町の大きな画面の映像 | MVは八曲の中から三曲を選ぶため |
| 物語の道 | テントで流す物語 → テントの店 | グッズは自分のアニメから作るため |
| 遊びの道 | テントの遊び | 今までの作品をはめこむだけなので、いつでも作れる |

- 三周目はRECORDERから始まります。招待状を受け取るとすぐ水星に着く、今の流れのままです。
- RECORDERのあとは、三本の道を好きな順に進めます。
- 本部の招待状の裏から、欄を押すとその章の入口へ行けます。
- まだ選べない欄は薄く光り、「セットぜんぶのあとで」のように一言だけ出ます。

### 4-2. 残りを数字なしで見せる

使うのは三つだけです。

1. **招待状の裏**：灯りのともった欄と、まだ暗い欄。「あと〇つ」「〇/6」は出しません。
2. **テントの中**：白い布のかかった台。
3. **看板**：得意の名前が増えていく。

### 4-3. 全部そろわなくてもフェスへ

- **太陽への門は、RECORDERを済ませたら開きます**（案）。自分の曲が一つでもあると、ブースに立ったときに気持ちいいからです。今の門の開始条件は「PLAYERを済ませたこと」なので、そこを直します。
- 門が開いたら、次に本部へ来たときに一回だけ短く知らせます（新しい場面 L3-SUN-S000）。

> MONBAN「……太陽への門が…開いている…。」
> MONBAN「……持ちものは…途中でも、いい…。行く日は、お前が、決めろ…。」
> MONBAN「……門は、開けておく…。」

**門が早く開くことに合わせて直すところ**

| 場所 | 直し方 |
|---|---|
| L3-SUN-S001 の「八枚の札。五つはほどけ」 | 謎5が開いていないと合わない。そこで、HOLDERをしていない人には、門の前でL3-HOLDER-S008を短く流す。流すのは星図から札5が開くまで。最後の「映し板のアニメの一コマ」「こつ」の三行は流さない（SHAPERの章への前振りなので）。謎が開く順 2→1→4→3→5→6→7→8 は崩れない |
| 札6・札7・札8の前触れ | 今はSHAPER-S003（札6のふちが光る）とPLAYER-S007（札7のひび、八つ目の題の光）にある。済ませていない人には、門の前で札がかすかに光る一行を足す |
| L3-PLAYER-S007 の「最後の道は、、、太陽の神殿で、話そう。」 | まだ物語を終えていない人にだけ出す |
| L3-SUN-S003 の OBOLON「音を、残し。物語を、持ち。／形を与え、遊べる世界を、作った。」 | 用意したものだけを言うように分ける（例：RECORDERだけの人は「音を、、、残した。」）。続く「、、、どれも、DJの、得意だ。」はそのまま |
| 旅の完了記録 | 今の「完成した記録と、本人の終幕確認」のままでよい。完成した記録は、その時点で作ったものになる |
| 物語のあと | 残りの準備は、物語を終えたあともいつでもできる。テントも育ち続ける |

## 5. 物語のあとの、現実のフェス

### 5-1. 流れ

```
物語を終え、準備ができる
  ↓
案内ページに〔申し込む〕が出る（申し込み期間だけ）
  ↓
申し込む（DJの枠／テントの枠／両方。来られる日を選ぶ）
  ↓
運営が、DJの時間割とテントの数を決めておく
  ↓
枠より多ければ、くじ（または先着。7の質問2）
  ↓
当たり → 金色の封筒（日と時間）→ 出る・出ないを本人が返事
外れ   → 白い封筒「また来年」。準備はそのまま残る
```

### 5-2. 細かい決まり（案）

| 項目 | 案 |
|---|---|
| 申し込める人 | 物語を終えた人のうち、準備ができた人（目安は7の質問3）。準備が要るのは出る人だけで、遊びに来る人には何も求めない |
| 運営が決めること | フェスの日にち、日ごとのDJの時間割と人数、テントの数、申し込み期間、くじの日（管理画面で） |
| 選び方 | うまい下手や数字（聴かれた数など）では選ばない。前の年に外れた人を少し優先するかどうかは、運営が決めてよい |
| 出さないもの | 申し込んだ人の数、倍率、何番目か。アプリのどこにも出さない |
| 当たった人が出られないとき | 返事の期限を過ぎたら、静かに次の人へ回す。回ってきた人には、あとから金色の封筒が届く |
| ステージでの姿 | 顔を出さなくてもよい。ネオの姿（フードと金ぶちの丸いサングラス）のままでもよい（今のEX-KIMORIN-S001の決まりのまま） |
| 年齢 | 18歳未満の申し込みは家の人の同意を取る。15歳以下は家の人と一緒（今の決まりのまま）。15歳以下が出られるかどうかは7の質問4 |
| エージェントとのちがい | エージェント（EX-SCOUT）は申し込む道がない。フェスは本人が申し込む。この二つは混ぜない |

**直す必要がある決まり**：今のバイブルには「来場を、称号・旅の完了記録・特別編の条件にしない」とあります。遊びに来る人については、この決まりをそのまま守ります。**出る人（DJ・テント）にだけ「準備ができた人が申し込む」という条件を付ける**、と決め直す必要があります。

### 5-3. 来る人のチケット

- **1日入場88円**です。行く日を選んで買います（M-R88のまま）。
- 15歳以下の分は家の人が買います。
- 外れた人も、チケットを買えば遊びに来られます。
- 出る人とテントの人のチケット代は運営が決めます（案：本人は要らない。一緒に来る家の人は買う）。

## 6. 88日ごとに「町に、また灯りがともる」（入れなくてもよい案）

### 中身

- 物語のあと、アプリの中のフェスの町（天王星の野原）で、88日ごとに新しい会期が始まります。
- 町はずっとあります。会期ごとに変わるのは、ブースの順番表と町の飾りです。
- 会期ごとに、ブースで新しいセットを回せます（S005bと同じ回し方。数も点数もなし）。
- テントに新しく置いたものが、町の通りに並びます。
- 呼び名は「シーズン」ではなく「町に、また灯りがともる」にします。

### よいところと気になるところ

| よいところ | 気になるところ |
|---|---|
| 物語のあとも、作り続ける理由になる | 「88日ごとに来ないと損」と感じると、ナガレと同じ「追われる気持ち」になりかねない |
| 現実のフェスで「また来年」になった人が、待つあいだも楽しめる | 運営が会期ごとに飾りなどを用意する手間がかかる |
| フリージーの「フルアルバムは、季節だ。」と自然につながる | 「88日間ひらく」フェスが88日ごとに始まると、いつも開いているのと同じに見える。見せ方の工夫が要る |
| テントが育ち続けるので、続ける楽しみがある | ごほうび・連続記録・逃すと消えるものを置くと、今までの決まりとぶつかる |

### 入れるなら（案）

- 知らせるのは、バティの一言を一回だけにします。
- 逃しても何も消えません。ごほうびも置きません。
- ダチのテントは見えますが、数は出しません。

## 7. 決めてほしいこと（6つ）

1. **授与の場面**：MONBANの「お前は…『レコーダー』だ…。」を声だけ残しますか。それとも看板の一行だけにしますか。星の階段の短い映画を、テントの映像に替えてよいですか。
2. **枠より多いときの決め方**：くじにしますか。それとも先に申し込んだ順（先着）にしますか。
3. **「準備ができた」の目安**：現実のフェスに申し込める目安は、DJの枠は「セットぜんぶ（WEAVER）まで」、テントの枠は「物語・店・遊びのどれか一つ以上」でよいですか。それとも六つ全部そろってからにしますか。
4. **15歳以下の出演**：現実のフェスで、15歳以下の人もDJやテントに申し込めますか（家の人と一緒が条件）。
5. **太陽への門が開くとき**：RECORDERを済ませたら、でよいですか。ほかの案は「招待状を受け取ったらすぐ」「持ちものが三つ以上そろったら」です。
6. **88日ごとの会期**：入れますか。入れる場合、現実のフェスは「年に一回」のままでよいですか。
