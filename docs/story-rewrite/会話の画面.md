# 会話の画面「隣に並ぶトーク」（決定 M-R232・2026-11-22・利用者のイメージ図から）

{bati}との会話、ダチとのメッセージ、グループトーク、すべてこの形にする（向かい合う形のチャットは使わない）。

## 1. 形
- 話している人たちが、画面の下半分に**隣に並んで**立つ（全身）。自分はいつも右、相手は左。同じ方を向いて、並んで話している感じ。
- 背景は、いる場所（2日目は月、星にいる時はその星）。
- 吹き出しは、2人の頭の上に**2枚まで**。**新しい吹き出しが下**（話した人の頭のすぐ上・しっぽがその人に向く）、ひとつ前が上。
- 3枚目が来ると、いちばん上の吹き出しが小さくなって、輪のてっぺん（12時）に入り、**丸**になる。言葉が上へのぼって、2人のまわりを回る星になるイメージ。
- 丸の輪は**時計回り**に進む（12時がいちばん新しく、時計回りに古くなる）。丸は8個まで。それより前は、左のバナー（過去のチャット）で読む。
- 丸には、話した人の顔（小さく）と、最初の数文字を入れる。色は話した人ごと（{bati}・ダチごとに色、自分は青）。押すと、その発言が吹き出しで開く。
- 輪はゆっくり回って見える（動きを減らす設定の時は止める）。

## 2. 長い返事・カード
- 長い返事は、吹き出しが下へ伸びて、指でスクロールできる。
- 画像・曲・映像・コロリンなどのカードは、吹き出しの中に小さく出し、押すと大きく開く（再生・やり直し・星へ飛ばす）。Bluenaへは自動でしまわれる（M-R211）。

## 3. スマホの縦画面
- 2人は画面の下半分。丸の輪は2人の上に半円で並べる。
- 下のまん中にマイクのボタン。文字で答える時だけキーボード（キーボードが出たら、2人は胸から上にして上へよける）。
- 左のバナー＝過去のチャット・会話の一覧、右のバナー＝Bluena（M-R211）はそのまま。

## 4. ダチとのメッセージ
- ダチとの会話も同じ形。自分（右）とダチ（左）が並ぶ。ダチの姿は、そのダチが作った自分の姿。
- 声のメッセージは、吹き出しの中に再生のボタン（話している間、話した人の口が動く）。

## 5. グループトーク
- 3人以上の時は、全員が横一列に並ぶ（自分は右はし）。5人までは全身、6人をこえたら胸から上で2列にする。
- 話した人が、少し前に出て光る。吹き出しのしっぽは、その人に向く。
- 輪の丸は、話した人の顔と色で見分ける。
- グループの名前と人数は、いちばん上に小さく。
