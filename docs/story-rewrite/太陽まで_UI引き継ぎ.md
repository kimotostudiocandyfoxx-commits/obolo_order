## 1. お願いしたいこと（いちばん大事）

1. **太陽行きロケット（D08-S006）までのUIを本番の形で作り、通しで動くか確かめてください。** 台本・場面のつながり・フラグ・再開点は §8 と §5 にあります。
2. **一周目で開く機能は、15歳がすぐ分かるように、分かりやすく簡潔に、その星の住人の言葉で説明してください。** 一周目に何が開くかは §2 の表のとおりです。二周目・三周目の機能は一周目では説明しません（閉じているものは「二周目から」と一言だけ）。
3. **説明する順番と、説明の言葉（住人のセリフ・〔画面〕の案内文）は、UIと一緒にそちらで作ってください。こちら（物語側）からはお任せします。** 実際の画面を見ながら作る方が、分かりやすくなるためです。
   - 対象の場面：木星 D05-S005〜S008、水星 D06-S005〜S007、火星 D07-S004〜S006（本文に「仮：UIが決まってから作り直す」の印があります。今の台詞は下書きなので、自由に作り直してかまいません）。土星のコロリン（D04-S005）は利用者の台本で決まっていますが、ボタン名や〔画面〕の言葉はUIに合わせて調整してかまいません。
   - 住人の口調：たこ焼きブラザー＝語尾「ZE」、たこ焼きシスター＝「〜ワ／〜のよ」、大根カイザー＝語尾「ダ」・一人称「俺」、フリージー＝さっぱりした兄貴分、ヒポキン＝映画監督（メガホン、「カット」）。KIMORIN⭐︎はふだん丁寧語で「私」、興奮した時だけ方言（「〜やん」「〜ケン」）。一周目はOBOLO ORDERを「お金目当ての組織」だと疑っています。
   - 毎日の型（3〜6日目）：ロケットの中でKIMORIN⭐︎がBluenaを光らせて外れ推理→MONBANが次の住人の名前を言う→着く→住人「誰だ？」→「ネオです」→「遊びに来たのか。遊び方を教えてやる」→**遊ぶ画面（ここをそちらで作る）**→その日の終わりに謎の書の札に文字・切符にスタンプ。
4. **仮の場面以外の台詞は、利用者が決めた台本です。** 変えたい所があれば、変える前にこちら（利用者）に相談してください。
5. 作ってみて分からない所・台本と合わない所は、遠慮なく利用者に聞いてください。

## 3. 間違えそうな所・気になる所（事前のお知らせ）

### 3-1. 一周目を組む時にとくに注意
- 【場面IDと日にちがずれている】M-R10で月を2日目にしたので、場面IDの数字は「何日目」と一致しない（D03＝2日目・月、D04＝3日目・土星、D05＝4日目・木星、D06＝5日目・水星、D07＝6日目・火星、D08＝7日目・エクリプス）。decisions_round19のM-R5・M-R6・M-R7・M-R9の本文にも古い日付（『3日目の月』『8日目のエクリプス』など）がそのまま残っているので、M-R10で読み替えること。M-R9のボタン名『もちろん待てない』も古く、今は全日『明日まで待てない』
- 【一周目は全部『自分だけ』】T3では一周目に〔みんな／フォロー／ダチ〕のタブ、ほかの会員の作品、フォロー、公開・届ける操作を出さない。アプリは全惑星に3つのタブを最初から出し（P-UI-1・P-PLANETS-1）、〔🦋 投稿する〕〔🚢 出航させる〕・ひろば（P-SAT-13）も最初から使える。周回ごとに機能を開け閉めする仕組みが要る（一周目＝自分だけ、二周目＝ダチ＝KIMORINだけ、帰還L2-RETURN-S008から＝みんな・フォロー・探す）
- 【一周目の土星の〔画面〕に『広場』という言葉が出る】D04-S006の〔画面：広場のコロリンをタップすると、声が聞けます〕は住人のリングのこと。同じ日にD04-S005で『広場に飛ばせるのは二周目から』と言うので、利用者が混乱しやすい。説明文を作る時は『土星の空のリング』など別の言い方にした方が安全
- 【土星の言葉が周回でそろっていない】一周目＝コロリン／〔🎙〕／〔自分の部屋に飛ばす〕（旧〔ゆらす〕〔声をおとす〕のチュートリアルは削除済み）。二周目＝玉／〔ゆらす〕〔声をおとす〕〔おまかせ〕／思い出メモ／〔myころりん〕。アプリ＝ころりんぱ／myころりん／〔🎙 土星におとす〕。一周目の『自分の部屋』と二周目の『思い出メモ／myころりん』が同じ保存場所かどうか、ボタン名をどちらに寄せるかが決まっていない

## 5. 台本の読み方
