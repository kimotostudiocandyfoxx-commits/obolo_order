# バティの調味料（決定 M-R220・M-R221・2026-11-22）

{bati}が「ずっと覚えておくユーザーの情報」は、{bati}に振りかける**調味料**。ふだんの会話（左のバナーの過去のチャット）とは別にしまう。最近のチャットは{bati}がそのまま読めるので、ここには、ずっと必要なことだけを入れる。
「かけすぎると、しょっぱくなる」ので、多すぎない量が自然に伝わる。2体目・3体目にも同じように振る。

## 1. 調味料は三つだけ（M-R221）
| 調味料 | 中身 | いつ振るか |
|---|---|---|
| 塩（ひとつまみ） | 呼ばれたい名前 | 2日目の誕生の直後（OBOLON「まずは、、、塩を、ひとつまみ。お前を、なんと呼べばいい？」） |
| マヨ | 返事の長さ：短め／ふつう／しっかり（選ぶだけ） | 2日目、塩のすぐあと |
| 隠し味 | 本人が「これ、覚えておいて」と頼んだこと（例：「金曜が曲の締め切り」） | 会話の中で、本人が頼んだ時だけ |

- 塩とマヨは共通の味（どの{bati}にもかかる）。隠し味はその子だけの味。
- 隠し味は1体に5振りまで（1振り30字くらい）。超えそうになると{bati}が「しょっぱくなっちゃう〜！　どれか、洗い流す？」。
- {bati}から「振りかけていい？」とは聞かない。毎日の質問もしない（M-R220 の六つの小瓶・毎日のおすすめはやめた）。
- {bati}のカードで「味見」（かかっている物を見る）と「洗い流す」（消す）。塩とマヨは、カードからいつでも変えられる。

## 2. マヨで変えられるのは長さだけ（性格は変わらない）
- マヨは返事の長さと詳しさだけ。話し方の調子（敬語・ギャル語・関西弁など）は、生まれた時の性格のまま。
- 「ギャルみたいに話して」などと頼まれたら、その場の遊びとして一回だけ乗って、もとに戻る。例：バティ「ギャルのまね、やってみる！　……{neo}っち、マジ神じゃん！　……やっぱり、ボクはボクがいいや！」
- ずっと違う話し方の子と話したい人は、2体目・3体目でその子に会う。

## 3. かけない物（{bati}がうまく逃げる）
- 住所・電話番号・メール・学校や会社の名前・パスワードや暗証番号・お金や口座のこと・ほかの人の個人のこと・体や病気の細かいこと。
- {bati}の言い方（性格に合わせて変える）：「それは……かけたら、おなか壊しちゃうから、やめとくね」。
- サーバーでも弾く。15歳未満の人には、とくに強く守る。

## 4. 相方の役目（2体目・3体目から）
- 名前のあとに{bati}が聞く：「ボクは、{neo}の、なんの相方になる？」〔なんでも〕〔遊び〕〔仕事・勉強〕〔作ること〕。役目で話の向きが変わる。1体目は〔なんでも〕から。あとで変えられる。
