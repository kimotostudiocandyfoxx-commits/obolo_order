# バティの調味料（決定 M-R220・2026-11-22。M-R219 の「手帳」を置きかえ）

{bati}が「ずっと覚えておくユーザーの情報」は、**調味料**として{bati}に振りかける。ふだんの会話（左のバナーの過去のチャット）とは別にしまう。
「かけすぎると、しょっぱくなる」ので、多すぎない量が自然に伝わる。この宇宙では、調味料＝その子の「味」（その子らしさ）。音や言葉から生まれた2体目・3体目にも、同じように振る。

## 1. 調味料と、振りかける情報
| 調味料 | 振りかける情報 | 例 |
|---|---|---|
| 塩（ひとつまみ） | 呼ばれたい名前 | 「ネオって呼んで」 |
| 砂糖 | 好きなこと・ハマっていること | 「最近はK-POP」 |
| こしょう | 苦手なこと | 「朝が弱い」 |
| しょうゆ | 今がんばっていること・作りたいもの | 「曲を作れるようになりたい」 |
| マヨ | 話し方の好み | 「短めがいい」「ツッコミ多めで」 |
| わさび（ツンとくる） | 話してほしくないこと | 「テストの話はしないで」 |

- 共通の味（どの{bati}にもかかる）：塩・わさび。その子だけの味：砂糖・こしょう・しょうゆ・マヨ（2体目・3体目は役目に合わせて振る）。
- **量**：小瓶1本に3振りまで、1体に全部で16振りまで。1振りは短い一文（30字くらい）。
  - 超えそうになると{bati}が：「しょっぱくなっちゃう〜！」「これ以上かけたら、ボク、味がわかんなくなっちゃう。どれか、洗い流す？」
  - 同じような話が重なったら：「それ、もう、かかってるよ！」
- **味見**：{bati}のカードで「味見」すると、かかっている調味料と中身が見える（小瓶の絵が並ぶ）。「洗い流す」で一振りずつ消せる。全部洗い流すこともできる。

## 2. かけない物（{bati}がうまく逃げる）
- 住所・電話番号・メール・学校や会社の名前・パスワードや暗証番号・お金や口座のこと・ほかの人の名前と個人のこと・体や病気の細かいこと。
- {bati}の言い方（性格に合わせて変える）：「それは……かけたら、おなか壊しちゃうから、やめとくね」「それは、ボクの味じゃないかも！」
- サーバーでも弾く。15歳未満の人には、とくに強く守る。

## 3. 振りかけ方
- **はじめて（2日目・D03-S005）**：生まれた直後、まだ食べ物そっくりの{bati}に。OBOLON「、、、生まれたては、まだ、味がない。」「、、、お前の味を、少しだけ、振れ。」→「まずは、、、塩を、ひとつまみ。お前を、なんと呼べばいい？」→ バティ「しょっぱっ！　……でも、覚えた！」→ OBOLON「、、、かけすぎると、しょっぱくなる。少しずつで、いい。」
- **2日目のチャット（D03-S008）**：小瓶六つをチャットの中に出す。バティ「ねえ、{neo}。調味料、もうちょっとだけ、かけてもいいよ！　かけすぎは、だめだけど！」
- **毎日一つ**：その日はじめて話した時、{bati}が一つすすめる（答えなくていい）。例：「今日は、しょうゆ、ちょっとだけかけてみる？　{neo}が今がんばってること、教えて！」
- **会話の中で**：大事そうな話が出たら「それ、ボクに振りかけていい？」。いいと言われた時だけ振る。振った時は、小瓶が傾いて、さらさらと落ちる。

## 4. 相方の役目（2体目・3体目から）
- 名前のあとに{bati}が聞く：「ボクは、{neo}の、なんの相方になる？」〔なんでも〕〔遊び〕〔仕事・勉強〕〔作ること〕。
- 役目で、すすめる調味料と話の向きが変わる（仕事の子は、しょうゆ多め・要点を短く、など）。1体目は〔なんでも〕から。あとで変えられる。
- チャットの相方を入れかえれば、プライベート用・仕事用を切りかえられる。
