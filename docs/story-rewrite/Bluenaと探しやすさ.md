# Bluenaの画面と、探しやすさ（決定 M-R236・2026-11-22）

## 1. 円形と、縦・タイルの使い分け（決まりは一つ）
- **少ない物から選ぶ時は、円形に回す**：Bluenaの惑星、{bati}（3体）、会話の輪（8個まで）。
- **たくさんある物を探す時は、縦かタイルで流す**：作品の一覧、過去のトーク、ダチの一覧。
- 覚え方：「選ぶ時は回す、探す時は流す」。

## 2. Bluena（右のバナー）
- 開くと、まん中に**月**（自分の姿・{bati}の見た目）、まわりを**8つの惑星**が回る（土星＝コロリン、木星＝アート、水星＝曲、火星＝映像、金星＝ラジオ、天王星＝グッズ、冥王星＝物語、海王星＝ゲーム）。指でなぞると回る。
- まだ作れない惑星は暗い（作れるようになった日に、明かりがともる）。文字は出さず、惑星の絵と記号だけ。
- 惑星を押すと、その惑星の景色の上に、作品が**タイル**で並ぶ（木星なら森の上にアート、水星なら海の上に曲）。新しい順。

## 3. 過去のトーク（左のバナー）
- 会話の一覧（{bati}・ダチ・グループ・結社からの知らせ）は縦に並ぶ。
- 一つの会話の過去の話は、**星をつないだ細い道（星の道）**に沿って、日付ごとに縦に並ぶ（新しいほど上）。

## 4. お気に入り（★）と、しるし（♠♦♥♣）
二つを分ける。
- **★（お気に入り）**：作品のカードの右上、会話の吹き出し・コロリンの右上に、小さな★。押すたびに ★ → ★★ → ★★★ → なし、とまわる（たいていの人は★1つだけ使う。もっと分けたい人は3つまで）。
- **しるし（♠♦♥♣）**：仕事・プライベートなどで分けたい人のための、4つのしるし。名前は自分でつけられる（例：♠＝仕事、♥＝プライベート。つけなくてもよい）。
  - つけ方：カード・吹き出し・コロリンを**長押し**すると、小さな輪が開いて ♠♦♥♣ が並ぶ（ここでも★を変えられる）。1つの作品に、しるしは1つ。
  - しるしの名前は、Bluenaの右上の小さな歯車から変える。
- **探し方**：Bluenaの惑星の中・過去のトークの上に、細い帯で ［★］［♠］［♦］［♥］［♣］ が並ぶ（使っているしるしだけ出る）。押すと、それがついた物だけになる。もう一度押すと戻る。
- {bati}にも頼める：「★がついた曲、見せて」「♠の画像、出して」と言うと、チャットの中にカードで出す。
- 初めて作品が5つたまった時に、{bati}が一度だけ教える：「気に入ったのには、★をつけておくと、あとで見つけやすいよ！　長押しすると、しるしもつけられるよ！」
