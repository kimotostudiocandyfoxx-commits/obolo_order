# Bluenaの画面と、探しやすさ（決定 M-R236・2026-11-22）

## 1. 円形と、縦・タイルの使い分け（決まりは一つ）
- **少ない物から選ぶ時は、円形に回す**：Bluenaの惑星、{bati}（3体）、会話の輪（8個まで）。
- **たくさんある物を探す時は、縦かタイルで流す**：作品の一覧、過去のトーク、ダチの一覧。
- 覚え方：「選ぶ時は回す、探す時は流す」。

## 2. Bluena（右のバナー）（M-R237 で更新）
- 開くと、まん中に**月**（自分の姿・{bati}の見た目）、まわりを**8つの惑星**が回る（土星＝コロリン、木星＝アート、水星＝曲、火星＝映像、金星＝ラジオ、天王星＝グッズ、冥王星＝物語、海王星＝ゲーム）。指でなぞると回る。まだ作れない惑星は暗い。文字は出さず、惑星の絵と記号だけ。〔すべて〕は月の横に小さく。
- 惑星を押す（または〔すべて〕）と、**渦＋縦のリスト**になる（利用者のイメージ図）：
  - 上に**渦**（銀河のような渦巻き）。丸は作品で、色と小さな記号で惑星が分かる（色だけに頼らない）。外側の大きい丸ほど新しく、まん中ほど古い。
  - 渦の外の端から、下へ**縦のリスト**が続く。1行＝左に丸（惑星の色と記号・作品の小さな絵）、右に題名・日付・★・しるし。新しい順。
  - 渦は**時間の地図**：渦を指でなぞると、リストがその時期へ飛ぶ。リストをスクロールすると、渦の上で「今見ている所」が光って、一緒に回る。
  - リストを下へスクロールし始めたら、渦は小さく縮んで上のすみへ寄る（リストを広く見せる）。いちばん上に戻すと、渦がまた開く。
  - 渦に出す丸は30個くらいまで。古い作品は、日ごとに1つの丸にまとめる。
  - リストの上に、絞りこみの細い帯（［★］［♠］［♦］［♥］［♣］と惑星。使っているものだけ）と、小さな検索窓（題名・歌詞・言葉で探す）。

## 3. 過去のトーク（左のバナー）（M-R237 で更新）
- 会話の一覧（{bati}・ダチ・グループ・結社からの知らせ）は、相手の数が少ないうちは**円形**（選ぶ時は回す）。
- 一つの会話の過去の話は、Bluenaと同じ**渦＋縦のリスト**：渦の丸は、その日の会話（話した人のコロリンの色）、リストの1行は、日付と、その日の最初の言葉・★・しるし。渦は時間の地図で、なぞるとその日へ飛ぶ。リストを押すと、その日の会話が隣に並ぶトークの形で開く。
- 上に、絞りこみの帯（★・しるし）と小さな検索窓（言葉で探す）。

## 4. お気に入り（★）と、しるし（♠♦♥♣）
二つを分ける。
- **★（お気に入り）**：作品のカードの右上、会話の吹き出し・コロリンの右上に、小さな★。押すたびに ★ → ★★ → ★★★ → なし、とまわる（たいていの人は★1つだけ使う。もっと分けたい人は3つまで）。
- **しるし（♠♦♥♣）**：仕事・プライベートなどで分けたい人のための、4つのしるし。名前は自分でつけられる（例：♠＝仕事、♥＝プライベート。つけなくてもよい）。
  - つけ方：カード・吹き出し・コロリンを**長押し**すると、小さな輪が開いて ♠♦♥♣ が並ぶ（ここでも★を変えられる）。1つの作品に、しるしは1つ。
  - しるしの名前は、Bluenaの右上の小さな歯車から変える。
- **探し方**：Bluenaのリスト・過去のトークのリストの上に、細い帯で ［★］［♠］［♦］［♥］［♣］ が並ぶ（使っているしるしだけ出る）。押すと、それがついた物だけになる。もう一度押すと戻る。
- {bati}にも頼める：「★がついた曲、見せて」「♠の画像、出して」と言うと、チャットの中にカードで出す。
- 初めて作品が5つたまった時に、{bati}が一度だけ教える：「気に入ったのには、★をつけておくと、あとで見つけやすいよ！　長押しすると、しるしもつけられるよ！」
