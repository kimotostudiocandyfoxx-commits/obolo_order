# 組み直し案：二周目（Obolo Order になってから）

作成：2026-10-27。第21稿（M-R124・M-R125）で、一周目に「作る・自分の場所・届ける・かんたんDJ」が全部入った。そのため、いまの二周目の「同じ星で、届ける・my場所を覚える」場面は、一周目と重なる。二周目を、Obolo Order になった人だけの旅として組み直す案です。**まだ決定ではありません。**

---

## 1. 考え方
- 二周目は、エクリプスを受けた人（Obolo Order）だけが進む。
- 芯は三つ。
  1. **新しい星**：天王星（グッズ・アトリエ・obolo商店）、海王星（ゲーム）。
  2. **仲間を増やす・つながる**：招待状で友だちを招く、〔名前で探す〕（18歳以上）、地球の連絡室（メール。電話は準備中）。
  3. **前の星の「奥」**：一周目の星に戻ると、一周目では見せなかった深い使い方が一つずつ開く。いまの星休め（L2-REST）にある「深い使い方」の場面を、ここへ前倒しする。
- MIKIE⭐︎の紹介（水星）とMV（火星）、カイザーの二つ目の姿（木星）は、二周目の見せ場として残す。
