## 1. ひとことで

**水星は、自分の言葉（と木星のジャケット）から曲を作り、船にして海に出す星。**
船は、押した時だけ鳴る。

## 5. 画面ごとの中身

画面は正方形。どの画面も「上の帯（タブ）／真ん中（絵）／下の帯（ボタン3つ）」の三段です。

### M-1 海図（🗺️ 海図）

```
┌──────────────────────────┐
│ 〔みんな〕〔推し〕  ← 周回で変わる│
│   ⛵        ⛵             │ ← 船は最大8隻。波にゆれる
│       ⛵  @名前  ⛵         │    帆にジャケット、名札は「@名前」
│  ⛵           ⛵   ⛵       │
│ 〔🗺️ 海図〕〔♫+ 作曲〕〔🏝️ myアイランド〕│
└──────────────────────────┘
```

| ボタン・もの | 押すと |
|---|---|
| 船 | タップすると M-2（その人が88時間以内に出した曲）。タップするまで音は出ない |
| 聴き終えた船 | 沖へ去り、ほかにあれば別の船が入る（下へ流れない） |
| 〔推し〕（一周目の5日目から。土星でダチができたあと） | ダチの船（一周目・二周目・星休め）。三周目からは推した人の船も。ダチの船には小さな名札の印 |

- 船の上の吹き出しは「曲名」だけ（「今これを聴いてる」「★3をつけた」などは出さない）。残り時間も出さない。
- ふだん曲を探すのは、この海図の船だけ。スワイプで次々に流れる形や「今N人が航海中」は作らない。
- 一周目の案内（D06-S007）は、一行ずつ出す（台本どおり）：
  1. 「〔🚢 出航させる〕を押すと、曲が船になって、ダチの海を88時間めぐり、このあと作るmyアイランドの桟橋に戻ります（届くのはダチだけ。いまのダチは、{inviter}とKIMORIN⭐︎です）」

- 二周目（L2-MERCURY-S002）は出航と作曲の案内を出さない（一周目で覚えた）。出すのは〔曲を置く〕の二行だけ（M-6）。

### M-3 作曲（♫+ 作曲）

{bati}と話して作る。手順は一画面に一つ、光った所を押せば進む（二周目以降は物語の案内なしで同じ画面）。
流れ：入力→曲の感じ→歌詞の下書き（本人が確かめて〔✏️ 手直しする〕）→マナの確認→♪作曲中…（台本 D06-S006 と同じ順）。

| 手順 | 画面に出す一行 | ボタン |
|---|---|---|
| ① 材料 | 「どこから作る？」 | 〔ジャケットを選ぶ〕〔新しく作る〕〔今はここで止める〕（一周目。二周目からは〔今日は作らない〕）（一周目は全員が木星でジャケットを作っているので、〔ジャケットを選ぶ〕はいつも出る） |
| ①' ジャケットを選ぶ | 「このジャケットの曲を作ります」 | 根っこのジャケットが並ぶ。選べるのは1枚（M-R91） |
| ② 入力（一回だけ） | 新しく作る人：「今日あったことを話してみよう」／ジャケットを選んだ人：「そのときの気持ちを、足してもいい」 | 〔🎙 話して入力〕〔⌨ 打つ〕〔えらぶ〕〔パス〕→〔送る〕（〔えらぶ〕は候補3つ） |
| ③ 曲の感じ | 「どんな感じの曲にする？」 | 〔ポップ〕〔ロック〕〔ヒップホップ〕〔バラード〕〔EDM〕〔おまかせ〕 |
| ④ 歌詞の下書き（本人が確かめる） | 歌詞の下書きが出る。直したい所があれば〔✏️ 手直しする〕 | 〔✏️ 手直しする〕〔♪ 作曲する〕（押すと⑤の確認へ。まだマナは使わない） |
| ⑤ マナの確認 | 「作曲に、マナを使います。いいですか？」 | 〔使う〕〔やめる〕（数字なし） |
| ⑥ 作曲中 | 「♪ 作曲中…」 | 〔閉じる〕（閉じても続く） |
| ⑦ 曲のカード | タイトル・歌詞・レコード | 先に出すのは〔▶〕〔🔒 土の中にしまう〕の2つだけ |
| ⑧ しまったあと | 「曲を、あなただけの〔⛏ 土の中の曲〕にしまいました。誰にも送られていません」 | 〔🚢 出航させる〕〔もう一回つくる〕〔閉じる〕 |

- 言葉を入れるのは②の一回だけ（D06-S006 で二回入れていたのを一回にまとめた。アプリの「話す→送る→曲の感じ」と同じ）。
- ②の〔パス〕：録音はしない。新しく作る人は〔画面：言葉がなくても大丈夫。いまいる場所（氷の島と冷蔵庫）から、歌詞を考えます〕。ジャケットを選んだ人は「いまある言葉だけで、歌詞にします」。本人の言っていない言葉は足さない。
- 決定（M-R116(1)）：まわりの音は使わない。マイクは、本人が〔🎙 話して入力〕を押した時だけ動く。〔パス〕でマイクは開かない。
- 失敗した時：歌詞は残す。「もう1回唱えてもいい？」。
- 一周目は曲ができたあとに〔テロップ：−2マナ〕（数は仮）。
- 一周目は全員がここで一曲作り、⑦で〔🔒 土の中にしまう〕まで進む（M-R125。作らずに先へは進まない。閉じても下書きは残り、次は同じ所から）。
- ⑦の曲のカードには〔▶〕〔🔒 土の中にしまう〕の2つだけが並ぶ（台本 D06-S006）。自動では保存しない。〔🚢 出航させる〕〔もう一回つくる〕は⑧（しまったあと）で出す。聴いたあとに一行「聴いたら〔🔒 土の中にしまう〕を押します（自動ではしまいません）」（D06-S007）。
- ⑦では、光る印が〔▶〕のあとすぐ〔🔒 土の中にしまう〕に移る（作ったらすぐしまう。自動ではしまわない）。押さずに閉じた時は、次に〔♫+ 作曲〕を開くと、この曲のカードから（RESUME@D06-S007 と同じ）。
- 〔🚢 出航させる〕：一周目から押せる（M-5）。
- しまった時：「曲を、あなただけの〔⛏ 土の中の曲〕にしまいました。誰にも送られていません」。一周目は続けて「しまった曲は、このあと作る〔🏝️ myアイランド〕の土の中から、いつでも聴けます」（D06-S007）。
- 作った曲は、元のジャケットとつながっている（保存データで曲→ジャケットを指す。7日目の上映で一本の線になる）。
- 🎙 は声入力の印。ほかの用途に使わない。
- 三周目から増えるもの：〔思い出を見返す〕（今までの言葉・ジャケット・曲・映像が日付順。選ぶと材料になる）、〔一緒に歌う声〕（M-11）、島で覚えた技（フック・引き算など。使っても使わなくてもいい）、〔制作メモ〕（使った技と日付。自分だけ）。
