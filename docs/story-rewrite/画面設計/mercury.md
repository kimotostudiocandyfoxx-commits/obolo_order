## 3. 三つの星（木星・水星・火星）で共通の決まり

| 決まり | 中身 |
|---|---|

| 模様替え | 〔🏝️ 島を飾る〕 |
| 並べる操作 | 指で引きずらない。押した順に 1・2・3 と番号がつく（もう一度押すと外れる） |

## 5. 画面ごとの中身

画面は正方形。どの画面も「上の帯（タブ）／真ん中（絵）／下の帯（ボタン3つ）」の三段です。

### M-1 海図（🗺️ 海図）

```
┌──────────────────────────┐
│ 〔ダチ〕〔みんな〕〔フォロー〕  ← 周回で変わる│
│   ⛵        ⛵             │ ← 船は最大8隻。波にゆれる
│       ⛵  @名前  ⛵         │    帆にジャケット、名札は「@名前」
│  ⛵           ⛵   ⛵       │
│ 〔🗺️ 海図〕〔♫+ 作曲〕〔🏝️ myアイランド〕│
└──────────────────────────┘
```

| ボタン・もの | 押すと |
|---|---|
| 船 | M-2（その人が88時間以内に出した曲）。押すまで音は出ない |
| 聴き終えた船 | 沖へ去り、ほかにあれば別の船が入る（下へ流れない） |
| 〔ダチ〕〔みんな〕〔フォロー〕 | 海に出す船の範囲を変える |

- 一周目の海図：物語の「{neo}の最初の一隻」だけが沖へ出ていく（「港の船は、お話の中の船です。曲は送られません」D06-S007）。
- 船の上の吹き出しは「曲名」だけ（「今これを聴いてる」「★3をつけた」などは出さない）。

### M-3 作曲（♫+ 作曲）

{bati}と話して作る。手順は一画面に一つ、光った所を押せば進む（二周目以降は物語の案内なしで同じ画面）。

| 手順 | 画面に出す一行 | ボタン |
|---|---|---|
| ① 材料 | 「どこから作る？」 | 〔ジャケットを選ぶ〕〔新しく作る〕〔今日は作らない〕（ジャケットがない人には〔ジャケットを選ぶ〕を出さない） |
| ①' ジャケットを選ぶ | 「このジャケットの曲を作ります」 | 根っこのジャケットが並ぶ。選べるのは1枚（M-R91） |
| ② 話す | 「今日あったことを話してみよう」 | 〔🎙 話して入力〕〔⌨ 打つ〕〔えらぶ〕〔パス〕→〔送る〕 |
| ③ 足す（任意） | 「そのときの気持ちを、足してもいい」 | 〔🎙〕〔⌨〕〔えらぶ〕〔パス〕 |
| ④ 曲の感じ | 「どんな感じの曲にする？」 | 〔ポップ〕〔ロック〕〔ヒップホップ〕〔バラード〕〔EDM〕〔おまかせ〕 |
| ⑤ 歌詞の下書き | 歌詞が出る | 〔✏️ 手直しする〕〔♪ 作曲する〕 |
| ⑥ 確認 | 「マナを使います。いいですか？」 | 〔使う〕〔やめる〕（数字なし） |
| ⑦ 作曲中 | 「♪ 作曲中…」 | 〔閉じる〕（閉じても続く） |
| ⑧ 曲のカード | タイトル・歌詞・レコード | 〔▶〕〔🔒 土の中にしまう〕〔🚢 出航させる〕〔もう一回つくる〕 |

- ②の〔パス〕：いま聞こえる音を種にする（「いま聞こえる音を、種にします」）。本人の言っていない言葉は足さない。
- ③の〔パス〕：「いまある言葉だけで、歌詞にします」。
- 失敗した時：歌詞は残す。「もう1回唱えてもいい？」。
- 一周目は曲ができたあとに〔テロップ：−2マナ〕（数は仮）。
- 〔🚢 出航させる〕：一周目は薄い色で押せない。「二周目からひらきます」。
- しまった時：「曲を、あなただけの〔⛏ 土の中の曲〕にしまいました。誰にも送られていません」。
- 作った曲は、元のジャケットとつながっている（保存データで曲→ジャケットを指す。7日目の上映で一本の線になる）。
- 🎙 は声入力の印。ほかの用途に使わない。
- 三周目から増えるもの：〔思い出を見返す〕（今までの言葉・ジャケット・曲・映像が日付順。選ぶと材料になる）、〔一緒に歌う声〕（M-11）、島で覚えた技（フック・引き算など。使っても使わなくてもいい）、〔制作メモ〕（使った技と日付。自分だけ）。

### M-7 島をつくる・島を飾る

| 部品 | 候補 |
|---|---|
| 形 | 〔丸い丘〕〔三日月〕〔ふたこぶ〕 |
| 浜 | 〔白い砂〕〔貝がら〕〔黒い石〕〔小さな桟橋〕 |
| 灯り | 〔灯台〕〔ランタンの木〕〔光る岩〕〔灯りなし〕 |
| 名前 | 〔🎙〕〔⌨〕〔つけない〕 |

- ボタン：最初は〔この島にする〕、二回目からは〔飾る〕。選ばなければおまかせ。
- 形・浜・灯りは別々の部品を重ねて見せる。浮き上がる動き（五線の輪・せり上がり・滝）は共通の一本。
- 生成ではないのでマナは使わない。
- 星休め（L2-REST-S006）：テーマの島を新しく作る（「雨の日の曲だけ」など）。曲を置く・ダチの曲を並べる（作った人が消すと聴けなくなる）。

- 自分が〔★ しおり〕をつけた曲が新しい順に並ぶ。自分だけ。

### M-9 アルバム棚・曲順・完成確認（三周目）

| 場面 | 画面 | ボタン |
|---|---|---|
| アルバムの種（RECORDER-S001） | 「アルバムの種（選ばなくても始められる）」 | 〔ひとつの出来事を残す〕〔いろんな気持ちを集める〕〔空想の世界を作る〕〔まだ決めない〕〔思い出を見返す〕 |
| 棚 | RECORDERは3枠、WEAVERで8枠に広がる | 枠を押す→曲を入れる・外す |
| 曲順 | 「流したい順に押すと、1・2・3と番号がつきます」 | レコードを押す（もう一度で外れる）／〔通しで聴く〕 |
| ジャケット | 木星の夜の大樹で決めたもの／森のジャケット／持っている絵 | 〔ジャケットを選ぶ〕〔新しく作る〕（作る前にマナの確認） |
| 名前 | 仮の名前（冷蔵庫のテープ『〈月日〉の三曲』） | 〔🎙〕〔⌨〕〔仮のまま〕 |
| 完成確認 | 曲・曲順・ジャケット・名前・日付 | 〔このアルバムで完成〕〔もう少し直す〕〔今日はここまで〕 |

- 完成確認は、足りない所（同じ曲が二度・未完成の曲）がある時は押せず、足りない所だけ出す。
- 保存は自分だけ。公開はしない（届けるのは別の操作）。
- WEAVER の曲順は「フェスで回す順番のもとになります（あとで並べ替えられます）」と一行。

### M-10 〔みんな〕の海（三周目・確認待ち）

台本（L3-WEAVER-S002〜S010）の今の形：

- 海図の上のタブ〔みんな〕を押すと、ジャンルの島が七つ：〔ポップ〕〔アコースティック〕〔ヒップホップ〕〔R&B〕〔ロック〕〔EDM〕〔クラシック〕。
- 行ったことのない島は少しシルエット。最初の島だけ必ず一つ選ぶ。初めての島では短い物語と、技が一つ。
- 島では、そのジャンルのみんなの曲が聴ける（押した時だけ。並びは新しい順かランダム）。

| 島 | 技（一つだけ選ぶ） |
|---|---|
| ポップ | フック（何度も戻る短いひとこと） |
| アコースティック | 引き算〔声と楽器ひとつ〕〔声だけ〕〔楽器だけ〕 |
| ヒップホップ | フロウ（言葉の間をタップして区切り、強く言う所を一つ） |
| R&B | フレージング〔短く〕〔伸ばす〕〔前に間を置く〕 |
| ロック | 強弱（楽器の数と弾き方で。試聴の音量は一定） |
| EDM | ビルドと解放〔すぐ〕〔高まってから〕〔いったん静かにしてから〕〔開かずに終わる〕 |
| クラシック | 受け渡し〔丸い音→弓の音〕〔声→楽器〕〔楽器だけで一周〕 |

- どの島も最後に〔技を使って一曲作る〕〔技は使わずに作る〕〔今日は作らない〕。
- アプリの `docs/mercury.md` は「ジャンルごとの島を選んで聴く」をやめている。どちらにするかは利用者の確認待ち（M-Q1）。

### M-11 フィーチャリング（一緒に歌う声・三周目）

| 手順 | ボタン |
|---|---|

## 7. 出さないもの

- 数：「今N人が航海中」、フォロワー、曲の数、聴かれた数、★の数、Loops、Stars、順位、人気の並び。

- 勝手な連続再生、下へ流し続ける一覧（スワイプで次々に聴く形はやめる）。
- 続けた日数・ごほうび・呼び戻す通知。
- 「AI」の文字。
- 「ヘッドホンで先に聴く」（スマホは音の出口が一つ。金星と同じ）。

## 10. 台本との小さな食い違い（台本係へ）
