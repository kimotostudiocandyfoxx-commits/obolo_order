# 水星 画面設計（UIチーム向け）

- 版：第20稿（ループ見直し R3）・2026-10-26

- もとにしたもの：今の台本（parts/P03・P07・P10・P11）、利用者の決定 M-R1〜M-R111、レビューの申し送り
- 渡す先：アプリ（ブランチ `claude/solar-system-home-planets-ew766y`）を作るUIチーム
- 優先順位：物語にかかわる画面の決まりは、この文書を `docs/mercury.md` より先に見てください。食い違いは「9. アプリの今と違う所」にまとめました。曲を作る仕組み（`docs/mercury.md`「作曲のしくみ」）はそのまま使えます。

## 1. ひとことで

**水星は、自分の言葉（と木星のジャケット）から曲を作り、船にして海に出す星。**
船は、押した時だけ鳴る。

## 5. 画面ごとの中身

画面は正方形。どの画面も「上の帯（タブ）／真ん中（絵）／下の帯（ボタン3つ）」の三段です。

### M-1 海図（🗺️ 海図）

```
┌──────────────────────────┐
│ 〔みんな〕〔推し〕  ← 周回で変わる│
│   ⛵        ⛵             │ ← 船は最大8隻。波にゆれる
│       ⛵  @名前  ⛵         │    帆にジャケット、名札は「@名前」
│  ⛵           ⛵   ⛵       │
│ 〔🗺️ 海図〕〔♫+ 作曲〕〔🏝️ myアイランド〕│
└──────────────────────────┘
```

| ボタン・もの | 押すと |
|---|---|
| 船 | M-2（その人が88時間以内に出した曲）。押すまで音は出ない |
| 聴き終えた船 | 沖へ去り、ほかにあれば別の船が入る（下へ流れない） |
| 〔推し〕（二周目から） | ダチの船（二周目・星休め）。三周目からは推した人の船も。ダチの船には小さな名札の印 |
| 〔みんな〕（三周目から） | みんなの海。〔みんなへ〕で出航した船が来る。中に〔技の島めぐり〕の入口（M-10。授業の場面だけ） |

- 一周目の海図：物語の「{neo}の最初の一隻」だけが沖へ出ていく（「港の船は、お話の中の船です。曲は送られません」D06-S007）。
- 船の上の吹き出しは「曲名」だけ（「今これを聴いてる」「★3をつけた」などは出さない）。残り時間も出さない。
- ふだん曲を探すのは、この海図の船だけ。スワイプで次々に流れる形や「今N人が航海中」は作らない。

### M-3 作曲（♫+ 作曲）

{bati}と話して作る。手順は一画面に一つ、光った所を押せば進む（二周目以降は物語の案内なしで同じ画面）。

| 手順 | 画面に出す一行 | ボタン |
|---|---|---|
| ① 材料 | 「どこから作る？」 | 〔ジャケットを選ぶ〕〔新しく作る〕〔今日は作らない〕（ジャケットがない人には〔ジャケットを選ぶ〕を出さない） |
| ①' ジャケットを選ぶ | 「このジャケットの曲を作ります」 | 根っこのジャケットが並ぶ。選べるのは1枚（M-R91） |
| ② 話す（一回だけ） | 新しく作る人：「今日あったことを話してみよう」／ジャケットを選んだ人：「そのときの気持ちを、足してもいい」 | 〔🎙 話して入力〕〔⌨ 打つ〕〔えらぶ〕（候補3つ）〔パス〕→〔送る〕 |
| ③ 曲の感じ | 「どんな感じの曲にする？」 | 〔ポップ〕〔ロック〕〔ヒップホップ〕〔バラード〕〔EDM〕〔おまかせ〕 |
| ④ 歌詞の下書き | 歌詞が出る | 〔✏️ 手直しする〕〔♪ 作曲する〕 |
| ⑤ 確認 | 「マナを使います。いいですか？」 | 〔使う〕〔やめる〕（数字なし） |
| ⑥ 作曲中 | 「♪ 作曲中…」 | 〔閉じる〕（閉じても続く） |
| ⑦ 曲のカード | タイトル・歌詞・レコード | 〔▶〕〔🔒 土の中にしまう〕〔🚢 出航させる〕〔もう一回つくる〕 |

- 言葉を入れるのは②の一回だけ（D06-S006 で二回入れていたのを一回にまとめた。アプリの「話す→送る→曲の感じ」と同じ）。
- ②の〔パス〕：新しく作る人は、いま聞こえる音を種にする（「いま聞こえる音を、種にします」）。ジャケットを選んだ人は「いまある言葉だけで、歌詞にします」。本人の言っていない言葉は足さない。
- 失敗した時：歌詞は残す。「もう1回唱えてもいい？」。
- 一周目は曲ができたあとに〔テロップ：−2マナ〕（数は仮）。
- ⑦の曲のカードには〔▶〕〔🔒 土の中にしまう〕が並ぶ（台本 D06-S006）。聴いたあとに一行「聴いたら〔🔒 土の中にしまう〕を押します（自動ではしまいません）」（D06-S007）。
- ⑦では、光る印が〔▶〕のあとすぐ〔🔒 土の中にしまう〕に移る（作ったらすぐしまう。自動ではしまわない）。押さずに閉じた時は、次に〔♫+ 作曲〕を開くと、この曲のカードから（RESUME@D06-S007 と同じ）。
- 〔🚢 出航させる〕：一周目は薄い色で押せない。「二周目からひらきます」。
- しまった時：「曲を、あなただけの〔⛏ 土の中の曲〕にしまいました。誰にも送られていません」。一周目は続けて「しまった曲は、右の〔🏝️ myアイランド〕の空き地の土の中から、いつでも聴けます」（D06-S007）。
- 作った曲は、元のジャケットとつながっている（保存データで曲→ジャケットを指す。7日目の上映で一本の線になる）。
- 🎙 は声入力の印。ほかの用途に使わない。
- 三周目から増えるもの：〔思い出を見返す〕（今までの言葉・ジャケット・曲・映像が日付順。選ぶと材料になる）、〔一緒に歌う声〕（M-11）、島で覚えた技（フック・引き算など。使っても使わなくてもいい）、〔制作メモ〕（使った技と日付。自分だけ）。
