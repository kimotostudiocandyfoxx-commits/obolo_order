## 5. 画面ごとの中身

画面は正方形。どの画面も「上の帯（タブ）／真ん中（絵）／下の帯（ボタン3つ）」の三段です。見た目は「郊外（赤い峡谷）」と「街中（未来都市）」の2つで、〔🎬 スタジオを飾る〕で選ぶと星図とスタジオの両方が変わる。

### X-1 星図（✨ 星図）

```
┌──────────────────────────┐
│ 〔みんな〕〔推し〕  ← 周回で変わる│
│   🛸▭      🛸▭           │ ← UFOが映像カードをぶら下げて
│       🛸▭  @名前   🛸▭    │    最大8機、ふわふわ浮く
│  🛸▭          🛸▭         │
│ 〔✨ 星図〕〔🎥 撮影〕〔🎬 myスタジオ〕│
└──────────────────────────┘
```

| ボタン・もの | 押すと |
|---|---|
| UFO | X-2（その人が88時間以内に公開した映像）。押すまで動かない |
| 見終えたUFO | 去っていき、ほかにあれば別の一機が入る（下へ流れない） |
| 〔推し〕（二周目から） | ダチのUFO（二周目・星休め）。三周目からは推した人のUFOも。ダチのUFOには小さな名札の印 |
| 〔みんな〕（三周目から） | みんなの星図。〔みんなへ〕で公開された映像がとぶ |

- 一周目の星図：タブなし。UFOはとんでいない。「ダチが公開した映像は、二周目からここをとびます」（提案）。
- ダチは自動で〔推し〕に入る。ダチのまま〔推し〕から外してもよい（相手には知らせない）。
- 名札は「@名前」だけ。残り時間（「◯h」）は出さない。
- 二周目のはじめの案内：「ダチが公開した映像は、UFOになって88時間、この空をとびます」（L2-MARS-S001）。

|---|---|

| 〔次の映像 ›〕〔‹ 前の映像〕 | 同じ人の88時間以内の別の映像（押した時だけ） |

| 〔⋯〕（ダチでない人・三周目） | 〔推す〕（その人の作品が〔推し〕に入る）／〔推すのをやめる〕、〔通報する〕〔ブロック〕。数は出さない |
| 〔⋯〕（ダチ） | 〔推しから外す〕／〔推しにもどす〕（「外しても、相手には知らせません。ダチのままです」）、〔通報する〕〔ブロック〕 |

### X-3 撮影（🎥 撮影）

手順は **話す→種類→曲（MVのとき）→シーン3つ** の順（アプリと同じ。M-R108）。一周目は〔MV〕だけ光らせる。一画面に一つ、光った所を押せば進む（D07-S004・L3-MOVER-S012・L3-HOLDER-S004）。

| 手順 | 画面に出す一行 | ボタン |
|---|---|---|
| ① 話す | 「撮りたい場面を話してみよう」 | 〔🎙 話して入力〕〔⌨ 打つ〕〔えらぶ〕（候補）〔おまかせ〕 |
| ② 種類 | 「何を撮る？」 | 〔MV〕〔映画〕〔番組〕〔おまかせ〕 |
| ③ 曲（MVのとき） | 「どの曲に映像をつける？」 | 〔きのうの曲〕（一周目）／しまった曲が並ぶ（1ページ8曲）／〔曲なしで、場面だけ作る〕（音はあとで） |
| ④ シーン3つ | 「三つのシーンに分けました」 | 〔🎬 シーン1〕〔シーン2〕〔シーン3〕。シーン2と3には絵、シーン1だけ白い |
| ④' シーン1 | 「最初のシーンは、自分で決めよう」 | 候補3つ（例：〔曲の景色から〕〔自分が歩いてくる〕〔真っ暗から〕）。ほかのシーンも〔直す〕で変えられる |
| ⑤ 確認 | 「マナを使います。いいですか？」 | 〔使う〕〔やめる〕（数字なし） |
| ⑥ 撮影中 | 「🎬 撮影中…」 | 〔閉じる〕（閉じても続く） |
| ⑦ 映像カード | 題・種類・「未公開」・真ん中に〔▶〕 | 〔▶〕〔🔒 裏スタジオにしまう〕〔🛸 公開する〕〔もう一回つくる〕 |

- 一周目のチュートリアルでは〔MV〕だけを光らせる（ほかも見える）。
- ①の〔おまかせ〕：「曲の景色から三つ考えました。ちがったら直せます」。
- 曲をしまっていない人：③は〔曲なしで、場面だけ作る〕だけ（「音は、あとでいい」）。
- 前に作ったMVがある曲は、それを使ってもよい（新しく作らないのでマナは使わない）。
- 一周目はMVができたあとに〔テロップ：−8マナ〕（数は仮）。
- ⑦では〔▶〕をいちばん大きく。「最初に見るのは、作った者だ」。見なくても、しまう・閉じてあとで決めるは選べる。
- 〔🛸 公開する〕：一周目は薄い色で押せない。「二周目からひらきます」。
- しまった時：「🔒 裏スタジオにしまいました。あなただけが見られます」。
- カメラも端末の写真も使わない。話した言葉から作る。
- 🎙 は声入力の印。ほかの用途に使わない。
- 三周目の劇場で覚えた見せ方（X-10）は、ここでも選べる（④の前に〔見せ方〕が一つ増える）。

### X-5 公開の確認（二周目から）

| ボタン | 押すと |
|---|---|
| 〔ダチへ〕 | ダチの星図へ＝ダチの〔推し〕に入る（二周目はこれだけ） |
| 〔みんなへ〕 | みんなの星図へ＝〔みんな〕と、あなたを推している人の〔推し〕に入る（三周目から） |
| 〔🛸 公開する〕 | とばす。直前に一行「88時間、星図をとんで、あなたのスタジオに並びます」（スタジオを建てる前の二周目は「このあと建てるmyスタジオに並びます」） |
| 〔やめる〕 | 戻る（映像は裏スタジオに残る） |

- 届けるのは本人が押した時だけ。どちらも選ばないと〔🛸 公開する〕は押せない。
- ダチを一人ずつ選ぶかどうかは、まだ決まっていない（jupiter.md J-Q1）。決まるまでは〔ダチへ〕でダチ全員へ。

### X-7 スタジオを建てる・飾る

| ボタン | 押すと |
|---|---|
| 〔郊外の赤い峡谷〕 | その見た目にする |

- 最初の一回は、カチンコを押すと建つ（L2-MARS-S003「鳴らせ。」）。

### X-8 上映館（星休めから）

| ボタン | 押すと |
|---|---|
| 〔一本目を置く〕 | 自分の映像か、ダチが公開した映像から一本選ぶ |
| 〔並べる順を決める〕 | 押した順に 1・2・3 と番号（もう一度で外れる） |
| 〔ダチに見せる〕 | 見せる相手を選ぶ（ダチだけ）。上映館を見せても、映像の公開の代わりにはならない |

- テーマを決められる（〔笑える映像だけ〕〔眠る前に見たい映像〕〔自分の作った映像だけ〕〔まだ決めない〕／🎙／⌨）。
- 作品がなくても、場所だけ先に作ってよい。
- 作った人が非公開・削除にした映像は、ここでも見られなくなる。
