## 3. 三つの星（木星・水星・火星）で共通の決まり

| 決まり | 中身 |
|---|---|
| 下のボタンは3つ | 左＝流れ〔✨ 星図〕／真ん中＝作る〔🎥 撮影〕／右＝my場所〔🎬 myスタジオ〕。木星・水星も同じ位置 |
| 一周目のmy場所 | 右を押すと「空き地（二周目で作れます）」。空き地に〔🔒 裏スタジオ〕の扉だけある（提案。10. を参照） |
| 上のタブ | 一周目＝なし／二周目＝〔ダチ〕だけ／三周目＝〔ダチ〕〔みんな〕〔フォロー〕 |
| 届けるボタン | 火星は〔🛸 公開する〕（一周目から同じ名前）。一周目は薄い色で押せず、下に「二周目からひらきます」 |
| 自分だけにしまう | 〔🔒 裏スタジオにしまう〕 |
| 模様替え | 〔🎬 スタジオを飾る〕 |
| 並べる操作 | 指で引きずらない。押した順に 1・2・3 と番号がつく（撮影予定・上映館の順番・話をつなぐ） |
| 数を出さない | 「今N人がライブ中」・フォロワー・作品数・観客の数・点数・Loops・Stars・順位。並びは「新しい順」と「ランダム」だけ |
| 勝手に流さない | UFOは押した時だけ再生。一本終わっても次の人の映像を勝手に流さない |
| 88時間 | 公開した映像はUFOになって88時間ダチの星図をとび、myスタジオに並ぶ |
| マナ | 画面でも「マナ」。作る前の確認に数字は出さない |
| 一周目のマナ | MVができた時だけ〔テロップ：−8マナ〕（数は仮。UIチャットが決める。M-R75）。二周目からは出さない |
| マナジェムが光らない時 | 「マナジェムが、光らなくなった。今は、魔法は唱えられない」だけ。買う画面へは誘わない。話した言葉・シーンは残す |
| 1日88分 | カウントダウンは出さない。撮影中・保存の途中では止めない。閉じても撮影（生成）は続き、その間は88分に数えない |
| アプリの外への通知 | 出さない（できあがりは、次に開いた時に光る印だけ） |
| 作らない日 | 〔今日は撮らない〕がいつもある |
| 住人の作品 | 印つき・少なめ・チュートリアル中は出さない・太陽の終章のあとは出さない（M-R45・M-R47）。住人はふざけない（M-R106） |
| ほかの人の作品 | 〔⋯〕から〔通報する〕〔ブロック〕 |

## 5. 画面ごとの中身

画面は正方形。どの画面も「上の帯（タブ）／真ん中（絵）／下の帯（ボタン3つ）」の三段です。見た目は「郊外（赤い峡谷）」と「街中（未来都市）」の2つで、〔🎬 スタジオを飾る〕で選ぶと星図とスタジオの両方が変わる。

### X-1 星図（✨ 星図）

```
┌──────────────────────────┐
│ 〔ダチ〕〔みんな〕〔フォロー〕  ← 周回で変わる│
│   🛸▭      🛸▭           │ ← UFOが映像カードをぶら下げて
│       🛸▭  @名前   🛸▭    │    最大8機、ふわふわ浮く
│  🛸▭          🛸▭         │
│ 〔✨ 星図〕〔🎥 撮影〕〔🎬 myスタジオ〕│
└──────────────────────────┘
```

| ボタン・もの | 押すと |
|---|---|
| UFO | X-2（その人が88時間以内に公開した映像）。押すまで動かない |
| 見終えたUFO | 去っていき、ほかにあれば別の一機が入る（下へ流れない） |
| 〔ダチ〕〔みんな〕〔フォロー〕 | とばすUFOの範囲を変える |

- 一周目の星図：UFOはとんでいない。「ダチが公開した映像は、二周目からここをとびます」（提案）。
- 二周目のはじめの案内：「ダチが公開した映像は、UFOになって88時間、この空をとびます」（L2-MARS-S001）。

### X-2 映像を見る

| ボタン | 押すと |
|---|---|
| 〔▶〕／〔⏸〕 | 再生・止める（勝手に始まらない） |
| 〔次の映像 ›〕〔‹ 前の映像〕 | 同じ人の88時間以内の別の映像（押した時だけ） |
| 〔🎬 この人のスタジオへ〕 | その人の myスタジオ（見るだけ） |
| 〔⋯〕 | 〔通報する〕〔ブロック〕（自分の映像なら〔公開をやめる〕） |
| 〔閉じる〕 | 星図へ |

- 作った人が非公開・削除にしたら、ここでも見られなくなる。

### X-3 撮影（🎥 撮影）

手順は **種類→曲（MVのとき）→話す→シーン3つ** の順（D07-S004・L3-MOVER-S012・L3-HOLDER-S004）。一画面に一つ、光った所を押せば進む。

| 手順 | 画面に出す一行 | ボタン |
|---|---|---|
| ① 種類 | 「何を撮る？」 | 〔MV〕〔映画〕〔番組〕〔おまかせ〕 |
| ② 曲（MVのとき） | 「どの曲に映像をつける？」 | 〔きのうの曲〕（一周目）／しまった曲が並ぶ（1ページ8曲）／〔曲なしで作る〕（音はあとで） |
| ③ 話す | 「撮りたい場面を話してみよう」 | 〔🎙 話して入力〕〔⌨ 打つ〕〔えらぶ〕（候補）〔おまかせ〕 |
| ④ シーン3つ | 「三つのシーンに分けました」 | 〔🎬 シーン1〕〔シーン2〕〔シーン3〕。シーン2と3には絵、シーン1だけ白い |
| ④' シーン1 | 「最初のシーンは、自分で決めよう」 | 候補3つ（例：〔曲の景色から〕〔自分が歩いてくる〕〔真っ暗から〕）。ほかのシーンも〔直す〕で変えられる |
| ⑤ 確認 | 「マナを使います。いいですか？」 | 〔使う〕〔やめる〕（数字なし） |
| ⑥ 撮影中 | 「🎬 撮影中…」 | 〔閉じる〕（閉じても続く） |
| ⑦ 映像カード | 題・種類・「未公開」・真ん中に〔▶〕 | 〔▶〕〔🔒 裏スタジオにしまう〕〔🛸 公開する〕〔もう一回つくる〕 |

- 一周目のチュートリアルでは〔MV〕だけを光らせる（ほかも見える）。
- ③の〔おまかせ〕：「曲の景色から三つ考えました。ちがったら直せます」。
- 曲をしまっていない人：②は〔曲なしで作る〕だけ（「音は、あとでいい」）。
- 前に作ったMVがある曲は、それを使ってもよい（新しく作らないのでマナは使わない）。
- 一周目はMVができたあとに〔テロップ：−8マナ〕（数は仮）。
- ⑦では〔▶〕をいちばん大きく。「最初に見るのは、作った者だ」。見なくても、しまう・閉じてあとで決めるは選べる。
- 〔🛸 公開する〕：一周目は薄い色で押せない。「二周目からひらきます」。
- しまった時：「🔒 裏スタジオにしまいました。あなただけが見られます」。
- カメラも端末の写真も使わない。話した言葉から作る。
- 🎙 は声入力の印。ほかの用途に使わない。
- 三周目の劇場で覚えた見せ方（X-10）は、ここでも選べる（④の前に〔見せ方〕が一つ増える）。

### X-7 スタジオを建てる・飾る

| ボタン | 押すと |
|---|---|
| 〔郊外の赤い峡谷〕 | その見た目にする |
| 〔街中の宇宙船〕 | その見た目にする |

### X-8 上映館（星休めから）

| ボタン | 押すと |
|---|---|
| 〔一本目を置く〕 | 自分の映像か、ダチが公開した映像から一本選ぶ |
| 〔並べる順を決める〕 | 押した順に 1・2・3 と番号（もう一度で外れる） |
| 〔ダチに見せる〕 | 見せる相手を選ぶ（ダチだけ）。上映館を見せても、映像の公開の代わりにはならない |

- テーマを決められる（〔笑える映像だけ〕〔眠る前に見たい映像〕〔自分の作った映像だけ〕〔まだ決めない〕／🎙／⌨）。
- 作品がなくても、場所だけ先に作ってよい。
- 作った人が非公開・削除にした映像は、ここでも見られなくなる。

### X-9 スケジュールボード（三周目・MOVER）

```
┌──────────────────────────┐
│ 撮影予定  [1][2][3]           │ ← 選んだ曲に番号
│ ───────────────          │
│ ◉ ◉ ◉ ◉  アルバムの8曲      │ ← レコードの形の磁石
│ ◉ ◉ ◉ ◉                     │
│ 〔えらぶ〕   〔今日はここまで〕    │
└──────────────────────────┘
```

- 磁石を押す＝頭だけ試聴。〔えらぶ〕で上の段「撮影予定」に入る（押した順に1・2・3）。同じ曲は二度選べない。入れかえは何度でも。
- 前に作ったMVがある曲は、それを使える（マナは使わない）。
- 3曲以外にも、あとからMVを付けられる。

### X-10 劇場マップ・劇場（三周目・MOVER）

- 七つの劇場：『ことばの大ビジョン』『ジャケットの画廊』『ネオのライブステージ』『光のドーム』『思い出の回廊』『笑いの小劇場』『静かなミニシアター』。
- 最初の一つは自分で選んで必ず入る。あとは自由。行った劇場は窓に灯り（「あと○つ」は出さない）。

| 劇場 | 見せ方 | 選ぶこと（一つ） |
|---|---|---|
| ことばの大ビジョン | リリックMV | 〔歌詞から一行選ぶ〕〔曲名だけ出す〕〔自分で一言足す〕〔言葉は出さない〕 |
| ジャケットの画廊 | イラストMV（一枚の絵を動かす。早くできる） | 〔一か所に、ゆっくり寄る〕〔全体から、少しずつ引く〕〔動かさない〕 |
| ネオのライブステージ | パフォーマンスMV | 主役を選んでから〔寄って〕〔引いて〕〔主役についていって〕 |
| 光のドーム | 抽象MV（色と形だけ） | 形と色を選んでから〔拍に合わせる〕〔歌声に合わせる〕〔音が消えた時だけ動く〕 |
| 思い出の回廊 | モンタージュMV（今ある自分の作品だけ） | 〔旅の順に並べる〕〔自分で好きな順に並べる〕（扉を押した順に番号） |
| 笑いの小劇場 | コミカル短編（勘違いから始まる） | 切り替え〔すぐ〕〔一拍おく〕〔長めにおく〕（タップした所で切り替わる） |
| 静かなミニシアター | 静かな短編（せりふなし） | 〔手を振りかけて、やめる〕〔何かを、そっと渡す〕〔何もしない〕〔動きを文字で書く〕 |

- どの劇場も最後に〔この見せ方で一本撮る〕〔撮らずにマップへ〕〔今日はここまで〕。撮ったMVは自分だけに保存（公開しない）。
- 撮らなかった曲は、自分の撮影所（X-3 を使う）でいつでも撮れる。

### X-11 上映（三周目・MOVER）

- 「あなたたちだけの上映です。公開ではありません。観客の数や点数は出ません」。
- 〔⏸〕〔もう一度見る〕はいつでも。行ったことのある劇場で上映してもよい。

### X-12 話をつなぐ・全編確認（三周目・HOLDER）

| 場面 | ボタン |
|---|---|
| 話数 | 〔起・承・転・結（4話）〕〔1話にまとめる〕〔自分で決める〕 |
| 一話を撮る | X-3 を〔映画〕で→映像カード→〔つなぐ〕で前の話の後ろへ（1・2・3…と番号）→〔🔒 裏スタジオにしまう〕 |
| 前の作品を使う | ジャケット・曲・MVなど持っているものは、場面として使える（作り直さない） |
| 全編確認 | 題（〔🎙〕〔⌨〕〔無題のまま〕）／ジャケット／曲（場面ごと・曲なしも可）／声（自分の声＝使いたい人だけ／{bati}が選ぶ声／字幕だけ） |
| 完成 | 〔これで完成にする〕〔直したい所がある〕〔今日はここまで〕 |

## 10. 台本との食い違い（台本係へ）

- **一周目の myスタジオ**：D07-S004 で KIMORIN が〔🎬 myスタジオ〕を押すと「枠は空っぽ。つくった映像は、ここに並びます」、D07-S005 で「myスタジオに、一本だけ並ぶ」とある。共通の決まり（一周目のmy場所は「空き地（二周目で作れます）」）と、二周目の決まり（myスタジオに並ぶのは公開してとび終えた映像。しまった映像は裏スタジオ）と食い違う。
  - 案：一周目は「空き地」に〔🔒 裏スタジオ〕の扉だけ。KIMORINの笑い（「私のスタジオ、がらがらですね」→「がらがらでは、なくなりましたね」）は、空き地と裏スタジオの一本で作り直す。本文の手直しは台本係へ。
- L2-REST-S008 の〔順番を入れかえる〕は、この設計では〔並べる順を決める〕（押した順に番号）にした。
- L2-MARS-S002 の設計注の「上映館は〔一本目を置く〕〔順番を入れかえる〕」も同じ。
