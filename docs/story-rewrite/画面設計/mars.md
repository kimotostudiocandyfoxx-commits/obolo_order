# 火星 画面設計（UIチーム向け）

- 版：第20稿（ループ見直し R5）・2026-10-26
- R5で変えたこと：①話すの『言葉を入れない』ボタンを〔パス〕にし、②種類の〔おまかせ〕と名前を分けた。〔🛸 公開する〕のすぐ下に、行き先の一行をいつも出す（二周目は「届くのはダチだけ」。「公開」を全体公開と読ませない）。実在の人の注意は入力のすぐあとに出す、と書き直した。〔みんなへ〕の初回の注意と18歳未満のはじめの行き先〔ダチへ〕を足した（M-R116(4)）。5b-2 にMIKIE⭐︎の右足のドリルを足し（M-R116(5)）、二つのMVの題を利用者の歌詞（docs/story-rewrite/歌詞_MIKIE_MISAKO.md）に合わせた。88分の割りこみ（SYS-S001）は撮影・保存・支払いが終わるまで待つ、を共通の決まりに足した。7. にスタジオのフォロワー数を足した。
- R4で変えたこと：撮影の入力（話す）のすぐ下に毎回「本当にいる人の顔や名前、ほかの人の作品のキャラクターは、映像にしません」、〔ほかのキャラ〕・コミカル短編の主役・アニメの主役と登場人物の入力欄に「空想の人物だけです。実在の人の名前や顔は使えません」（M-R113(3)）。アニメは〔映画〕で撮る、の一言。MIKIE⭐︎とダチになっても連絡はできない（M-R113(2)）を2. と共通の決まりに書いた。新しく「5b. 物語の映像」を足し、二周目のMIKIE⭐︎のMV（右足のドリルで庭を掘ってトマトを植える。約40秒）と三周目のMIKIE⭐︎とMISAKO⭐︎のMV（MISAKO⭐︎がキレてハードスタイル）の作り方を書いた（M-R112・M-R113）。（ ）の中の注記は画面に出さない、と書き方に足した
- R3で変えたこと：見た目を選ぶと星図の景色も変わることを X-7 に書いた。上映館を見せるのと作品を届けるのは別に確かめる、とした（X-8）。一周目の大スクリーン（D07-S006）に「お話の中だけ」の〔画面〕を一行出すと書いた。届ける操作を『〔🛸 公開する〕→行き先〔ダチへ〕を確かめる』にそろえた（X-5）。上映館を①置く②並べる③〔ダチに見せる〕の三手順の表にし、台本 L2-REST-S008 の反映ずみを記した。撮影の画面の文とボタンを台本 D07-S004 にそろえた。二周目に星を出る時の選択とロケット、物語の人物の絵（KIMORINのサングラス・MIKIE⭐︎の見た目 M-R111(2)）を足した
- R2で変えたこと：撮る順をアプリと同じ「話す→種類」に（M-R108）。上のタブを〔みんな〕〔推し〕の2つに（M-R109）。一周目のmyスタジオは空き地と〔🔒 裏スタジオ〕の扉だけ、二周目の見た目は2つのボタンだけ（台本に反映済み）。〔推す〕〔推しから外す〕、届け先〔ダチへ〕〔みんなへ〕を書いた
- もとにしたもの：今の台本（parts/P04・P08・P10・P12・P14）、利用者の決定 M-R1〜M-R116、レビューの申し送り
- 渡す先：アプリ（ブランチ `claude/solar-system-home-planets-ew766y`）を作るUIチーム
- 優先順位：物語にかかわる画面の決まりは、この文書を `docs/mars.md` より先に見てください。食い違いは「9. アプリの今と違う所」にまとめました。
- 書き方：〔 〕はボタンの文字（このとおりに出す）。「 」は画面に出す一行の文。表の中の（ ）は、UIチームへの注記です。「（数字なし）」なども含めて、画面には出しません。

## 5. 画面ごとの中身

画面は正方形。どの画面も「上の帯（タブ）／真ん中（絵）／下の帯（ボタン3つ）」の三段です。見た目は「郊外（赤い峡谷）」と「街中（未来都市）」の2つで、〔🎬 スタジオを飾る〕で選ぶと星図とスタジオの両方が変わる。

### X-1 星図（✨ 星図）

```
┌──────────────────────────┐
│ 〔みんな〕〔推し〕  ← 周回で変わる│
│   🛸▭      🛸▭           │ ← UFOが映像カードをぶら下げて
│       🛸▭  @名前   🛸▭    │    最大8機、ふわふわ浮く
│  🛸▭          🛸▭         │
│ 〔✨ 星図〕〔🎥 撮影〕〔🎬 myスタジオ〕│
└──────────────────────────┘
```

| ボタン・もの | 押すと |
|---|---|
| UFO | タップすると X-2（その人が88時間以内に公開した映像）。タップするまで動かない |
| 見終えたUFO | 去っていき、ほかにあれば別の一機が入る（下へ流れない） |
| 〔推し〕（二周目から） | ダチのUFO（二周目・星休め）。三周目からは推した人のUFOも。ダチのUFOには小さな名札の印 |
| 〔みんな〕（三周目から） | みんなの星図。〔みんなへ〕で公開された映像がとぶ |

- 一周目の星図：タブなし。UFOはとんでいない。「ダチが公開した映像は、二周目からここをとびます」（提案）。
- ダチは自動で〔推し〕に入る。ダチのまま〔推し〕から外してもよい（相手には知らせない）。
- 名札は「@名前」だけ。残り時間（「◯h」）は出さない。
- 二周目のはじめの案内：「ダチが公開した映像は、UFOになって88時間、この空をとびます」（L2-MARS-S001）。
