- 版：第20稿（ループ見直し R1）・2026-10-26
- もとにしたもの：今の台本（parts/P02・P05・P10・P11・P14）、利用者の決定 M-R1〜M-R106（とくに M-R33・M-R74・M-R85・M-R106）、レビューの申し送り、アプリの `KororinWorld.tsx`・`PlazaMap.tsx`・`docs/spec.md` 2.3
- 渡す先：アプリ（ブランチ `claude/solar-system-home-planets-ew766y`）を作るUIチーム
- あつかう範囲：土星の全部。ただし3日目（D04-S003〜S007）は確定稿なので、そこは「一周目でどう見えるか」だけ書き、二周目からの〔ダチの部屋〕〔ダチに届ける〕〔招待状〕〔名前で探す〕、三周目の広場とはじめて棚をくわしく書く。

## 1. ひとことで

**土星は、つぶやきを声にする星。** 石に言葉を吹きこむと、しゃべるたこ焼き「コロリン」になる（声はキーを2上げた自分の声）。
場所は、自分の部屋（一周目）→ダチの部屋（二周目）→広場（三周目）と広がる。

## 5. 画面ごとの中身

画面は正方形。上の帯（タブ）／真ん中（絵）／下の帯（ボタン3つ）の三段。

### S-1 土星の空（リング）

```
┌──────────────────────────┐
│ 〔ダチ〕〔みんな〕〔フォロー〕 ← 周回で変わる│
│        ＿＿＿＿＿＿＿＿            │
│     ●  ●   ●  ●   ●  ← 輪の上を  │
│       コロリンが ころころ舞う        │
│        ￣￣￣￣￣￣￣￣            │
│ 〔🪐 空〕〔🎙 つぶやく〕〔🏠 自分の部屋〕│
└──────────────────────────┘
```

| もの・ボタン | 押すと |
|---|---|
| 舞っているコロリン | そのコロリンが喋る（キーを2上げた声）。名札「@名前」が出る |
| 〔🎙 つぶやく〕 | S-2 |
| 〔🏠 自分の部屋〕 | S-3 |
| 上のタブ | 二周目から。S-4／S-8／S-11 |

- 一周目：住人のコロリンが輪になって舞う（D04-S006）。「空を舞う住人たちのコロリンをタップすると、声が聞けます」。
- 一度に舞うのは8つまで。聞き終えたコロリンはふっと降り、ほかにあれば入れかわる（下へ流れない）。
- 全部聞いたら一行：「いまの声は、ぜんぶ聞いたよ」（アプリの今の文。「新しい声を待ってね」は待たせる言い方なので外す）。

### S-2 つぶやく（石に吹きこむ）

```
┌──────────────────────────┐
│ つぶやく                    〔閉じる〕│
│         ◯ 丸い土星の石              │
│     〔🎙〕（大きく）     ⌨（すみ）     │
│ 〔お題から〕                         │
│  → {bati}がタッチ → コロリン ●      │
│ 〔▶ 聞く〕〔自分の部屋に飛ばす〕       │
│ 〔ダチに届ける〕（一周目は薄い色）      │
└──────────────────────────┘
```

| ボタン | 押すと |
|---|---|
| 〔🎙〕 | 押して話す→もう一度押すと止まる。止まると{bati}が石にタッチしてコロリンになる |
| ⌨ | 文字で入れる（声を出せない時）。コロリンはバティの声で喋る |
| 〔お題から〕 | お題の札が3枚出る（今したいこと／最近驚いたこと／やりたいこと）。押すと例が入る |
| 〔▶ 聞く〕 | できたコロリンが喋る |
| 〔自分の部屋に飛ばす〕 | コロリンが自分の部屋へ転がっていく→S-3（誰にも送られない） |
| 〔ダチに届ける〕 | S-5（二周目から） |
| 〔閉じる〕 | 作らずに戻る |

- 一周目の一行：「人に届けられるのは、二周目の旅から」「コロリンは、あなたの部屋に、日付と時刻つきで残ります。誰にも送られません」（D04-S005）。
- 吹きこみ直す時は〔🎙〕をもう一度押す（前の声は消える）。
- 一周目は作るたびに〔テロップ：−1マナ〕（数は仮。UIチャットが決める）。
- 声で作った最初の一回だけ「いまの普通の声を、少し高くして、{bati}の声にもする？」〔する〕〔今のままでいい〕（D04-S005）。

### S-3 自分の部屋

```
┌──────────────────────────┐
│ 🏠 {neo}の部屋（あなただけ）  〔閉じる〕│
│  ─ 10月24日 ─                     │
│   ● 14:02   ● 21:30              │ ← コロリンが日付と時刻つきで並ぶ
│  ─ 10月25日 ─                     │    （1ページ8つまで）
│   ● 08:15                         │
│ 〔‹ 前の日〕            〔次の日 ›〕  │
└──────────────────────────┘
```

| ボタン | 押すと |
|---|---|
| コロリン | 喋る |
| コロリンの〔⋯〕 | 〔ダチに届ける〕（二周目から）〔消す〕 |
| 〔‹ 前の日〕〔次の日 ›〕 | ページをめくる（勝手に読み込み続けない） |

- 自分だけ。メモ代わり・日記代わりに使える（D04-S005 のブラザーの説明）。
- 届けたコロリンも、ここにずっと残る。届けたものに小さな🪐の印（88時間めぐっている間だけ）。

### S-4 ダチの部屋（二周目から）

- 上のタブ〔ダチ〕を押すと出る。上の帯に「ダチの部屋」。
- ダチが届けたコロリンが、輪の上を転がって届いている。まだ聞いていないものは少し光る（数は出さない）。
- コロリンをタップ→喋る。名札「ダチ　@名前」。
- 〔⋯〕：〔🚩 通報する〕〔🚫 ブロックする〕。
- 届いたコロリンは88時間で輪から降りて見えなくなる。残り時間は出さない。
- 右上〔👥 ダチ〕→S-6。
- 返事（💬）・引用（🔁）は出さない（台本で教えていない。§10 問い4）。

### S-5 届け先を選ぶ（二周目から）

| 順 | 画面 | ボタン |
|---|---|---|
| 1 | ダチの名札が並ぶ。押した順に✓（もう一度押すと外れる） | 〔ぜんぶのダチ〕〔届ける〕〔やめる〕 |
| 2 | 届けた演出：コロリンが輪の上をダチの部屋のほうへ転がる | 一行「88時間、輪をめぐって、自分の部屋に戻ります」 |

- 三周目も、ここで選べるのはダチだけ。広場に置く時は S-9 の中から（S-9 参照）。

### S-6 ダチの一覧

- 名札が並ぶ。並びはダチになった順（新しい順）。
- 最初は『ダチ　KIMORIN⭐︎』『ダチ　{inviter}』（L2-SATURN-S004）。
- 下に〔✉ 招待状〕〔🔍 名前で探す〕→S-7。
- 数・「あと〇人」は出さない。

### S-7 〔招待状〕〔名前で探す〕

地球の連絡室の机と**同じ画面**（`earth.md` E-7）。土星から使える。
- ダチになれるのは「〔招待状〕を送った人（マナジェムを添えます）」と「〔名前で探す〕で見つけて、おたがいに承認した人」（L2-SATURN-S004 の〔画面〕）。
- 知らない人から申しこみが来た時：「承認しなくてもかまいません。断っても、相手には知らせません」（**確認待ち**。§10 問い2）。

### S-8 広場の地図（三周目から）

```
┌──────────────────────────┐
│ 〔ダチ〕〔みんな〕〔フォロー〕          │
│   ◇ねこ好き   ◇夜ふかし部            │ ← 輪にそって広場が浮かぶ
│        ◇大阪      ◇わたしだけ        │
│ 〔ひろばをさがす〕  〔＋ ひろばをつくる〕 │
│ 〔🪐 空〕〔🎙 つぶやく〕〔🏠 自分の部屋〕│
└──────────────────────────┘
```

| ボタン | 押すと |
|---|---|
| 広場 | S-9 |
| 〔ひろばをさがす〕 | 名前で探す。ない時は「〈言葉〉の広場は、まだありません」〔＋「〈言葉〉」をつくる〕 |
| 〔＋ ひろばをつくる〕 | S-10 |

- 並びは新しい順とランダムだけ。人数・参加者の数・にぎわいの順は出さない。
- 静かな広場に住人を足して、にぎやかに見せることはしない。

### S-9 広場の中（三周目から）

- その広場に置かれたコロリンが、輪の上を舞う（一度に8つまで。聞き終えると入れかわる）。
- 〔🎙 この広場でつぶやく〕：S-2 と同じ手順で作り、この広場に置く。
- 入れる人の決まりが上に一行（『入れる人：わたしだけ』『入れる人：承認した人』『入れる人：Obolo Orderのみんな』）。
- 〔⋯〕：〔🚩 通報する〕〔🚫 ブロックする〕。
- 「参加中」「参加する」の切りかえは出さない（人数の代わりになるため。§10 問い3）。

### S-10 広場をつくる（三周目から）

| 順 | 画面 | ボタン |
|---|---|---|
| 1 | 名前を言うか打つ（〔🎙〕／⌨） | 〔次へ〕〔やめる〕 |
| 2 | ひろばのしるしを選ぶ（絵の札が並ぶ） | 〔次へ〕〔もどる〕 |
| 3 | 入れる人を選ぶ：〔わたしだけ〕〔承認した人〕〔Obolo Orderのみんな〕 | 〔このひろばをつくる〕〔もどる〕 |

- 一行：「最初は自分だけでもいい。誰かを迎えるのは、あとで決められます」（L2-REST-S004 から移した言葉）。
- 同じ名前の広場があれば、そこへ案内する。

### S-11 フォローの輪（三周目から）

- フォローしている人のコロリンが輪の上を舞う（一度に8つまで）。
- フォローしても数はどこにも出ない（L3-RECORDER-S001）。
- フォローする・やめるは、名札を押して〔フォローする〕〔フォローをやめる〕。

### S-12 はじめて棚（三周目・任意）

- 土星の神殿の低い棚。シスターが布を上げる（L3-RECORDER-S019）。
- 〔三日目の最初の言葉を置く〕（3日目に言葉を残した人だけ）〔ほかの「はじめて」を置く〕〔見るだけ〕〔置かない〕。
- 一行：「はじめて棚に置く（置かなくてもいい）。{neo}だけが見られる。誰にも送られず、公開もされない。いつでも下ろせる」。
- 最初の言葉は、置いても文面を出さない（光の玉のまま。太陽の終章で使う）。
- 初めて訪れた時だけ、シスターの声のフィーチャリングが使えるようになった〔画面〕（水星の作曲で使う）。

## 7. 出さないもの

| 出さないもの | かわり・理由 |
|---|---|
| ☆・いいね・返事の数・聞いた数 | どの周回もなし（M-R74） |
| 部屋のコロリンの数・ダチの数 | 並んでいるだけ |
| 広場の人数・参加者の数・にぎわい順 | 並びは新しい順とランダムだけ |
| 「のこり〇時間」 | 88時間で静かに降りる。数えない |
| 住人を足してにぎやかに見せる | しない |
| マナの数字（二周目から） | 出さない |
| 「AI」という言葉 | 使わない（「{bati}がコロリンにする」） |
| 外への通知 | 出さない。届いたコロリンは、次に開いた時に少し光るだけ |

| アプリの今 | この文書（台本） | 直してほしいこと |

## 10. 決まっていないこと（確認待ち）

1. **3日目の住人の笑い（ブラザーのくしゃみのコロリン）**（利用者の確認待ち・確定稿の本文）：M-R106 で「住人はふざけない」と決まった。D04-S006 のコロリン「……へっくしゅん！」とブラザー「……俺のだZE。押すボタンを、間違えたZE。」は住人の笑いにあたる。D04-S007 のKIMORIN「……あれは、ブラザーのくしゃみです。」でも受けている。7日目の声の高さのヒント（D08-S009）は、今回すでにKIMORIN自身のコロリンの声で受ける形に直っているので、くしゃみがなくても話はつながる。3日目は確定稿なので、残すか削るか（削るならD04-S006・S007の二か所）を利用者が決める。UIへの影響：住人のコロリンの見本の音声が一つ変わるだけ。
2. **知らない人からのダチの申しこみ**（利用者の確認待ち）：「承認しなくてもかまいません。断っても、相手には知らせません」を画面に出すか。おすすめは出す。
3. **広場の〔参加する〕**：参加の印をなくすと、どの広場に自分がいたか分からない。おすすめ：自分がつぶやいた広場だけ、地図で少し明るくする（人数は出さない）。
4. **返事・引用**：二周目は出さない。三周目に声の返事（〔🎙 声でかえす〕）を足すかは、台本で教える場面がないので利用者が決める。
5. **三周目の広場を教える場面**：L2-REST-S004 の予告から移したシスターの作り方の三つ（〔＋ ひろばをつくる〕→名前→〔ひろばのしるし〕〔このひろばをつくる〕）の受け皿の場面が、台本にまだない。今は S-10 の画面の一行だけで教える。場面を足すかは利用者が決める（新しい場面にあたる）。
6. **〔自分の部屋に飛ばす〕の言葉**：ほかの星は「自分だけにしまう」を『🔒 ◯◯にしまう』でそろえた。土星だけ3日目の確定稿の〔自分の部屋に飛ばす〕のまま。そろえるなら〔🔒 自分の部屋にしまう〕だが、3日目の〔画面〕を変えることになるので利用者が決める。おすすめは今のまま（土星は「飛ばす・転がる」の絵が合うため）。

## 11. 台本係への申し送り

- L2-SATURN-S001・L2-REST-S004 の〔ダチの部屋〕は、上のタブ〔ダチ〕を押すと出る画面の名前。〔画面〕の文は「上の〔ダチ〕を押すと、ダチの部屋」と読める形にするとよい（言葉の直しなので自動でよい）。
- L2-SATURN-S004 の send の枝「〔🎙〕でバティに話しかける→バティがコロリンにする」は、3日目の「石に声を吹きこむ→{bati}がタッチ」と同じ手順に読めるようにそろえるとよい。
