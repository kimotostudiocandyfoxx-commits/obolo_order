## 1. ひとことで

**土星は、つぶやきを声にする星。** 石に言葉を吹きこむと、しゃべるたこ焼き「コロリン」になる（声はキーを2上げた自分の声）。
場所は、自分の部屋（一周目）→上の〔推し〕＝ダチのコロリンが届く場所（二周目）→広場（三周目）と広がる。

## 5. 画面ごとの中身

画面は正方形。上の帯（タブ）／真ん中（絵）／下の帯（ボタン3つ）の三段。

### S-1 土星の空（リング）

```
┌──────────────────────────┐
│ 〔みんな〕〔推し〕 ← 周回で変わる      │
│        ＿＿＿＿＿＿＿＿            │
│     ●  ●   ●  ●   ●  ← 輪の上を  │
│       コロリンが ころころ舞う        │
│        ￣￣￣￣￣￣￣￣            │
│ 〔🪐 空〕〔🎙 つぶやく〕〔🏠 自分の部屋〕│
└──────────────────────────┘
```

| もの・ボタン | 押すと |
|---|---|
| 舞っているコロリン | そのコロリンが喋る（キーを2上げた声）。名札「@名前」が出る |
| 〔🎙 つぶやく〕 | S-2 |
| 〔🏠 自分の部屋〕 | S-3 |
| 上のタブ | 二周目から。〔推し〕＝S-4／〔みんな〕＝S-8（三周目） |

- 一周目：住人のコロリンが輪になって舞う（D04-S006）。「空を舞う住人たちのコロリンをタップすると、声が聞けます」。
- 一度に舞うのは8つまで。聞き終えたコロリンはふっと降り、ほかにあれば入れかわる（下へ流れない）。
- 全部聞いたら一行：「いまの声は、ぜんぶ聞いたよ」（アプリの今の文。「新しい声を待ってね」は待たせる言い方なので外す）。

| ボタン | 押すと |
|---|---|

| ⌨ | 文字で入れる（声を出せない時）。コロリンはバティの声で喋る |
| 〔お題から〕 | お題の札が3枚出る（今したいこと／最近驚いたこと／やりたいこと）。押すと例が入る |
| 〔▶ 聞く〕 | できたコロリンが喋る |

| 〔閉じる〕 | 作らずに戻る |

- 一周目の一行：「人に届けられるのは、二周目の旅から」「コロリンは、あなたの部屋に、日付と時刻つきで残ります。誰にも送られません」（D04-S005）。
- 吹きこみ直す時は〔🎙〕をもう一度押す（前の声は消える）。
- 一周目は作るたびに〔テロップ：−1マナ〕（数は仮。UIチャットが決める）。
- 声で作った最初の一回だけ「いまの普通の声を、少し高くして、{bati}の声にもする？」〔する〕〔今のままでいい〕（D04-S005）。

| ボタン | 押すと |
|---|---|
| コロリン | 喋る |
| コロリンの〔⋯〕 | 〔届ける〕（二周目から）〔消す〕 |
| 〔‹ 前の日〕〔次の日 ›〕 | ページをめくる（勝手に読み込み続けない） |

### S-4 推し（上のタブ〔推し〕。二周目はダチのコロリンだけ）

- 上のタブ〔推し〕を押すと出る。土星では〔推し〕＝ダチのコロリンが届く場所。
- 二周目：中身はダチのコロリンだけ。ダチになると自動で〔推し〕に入る。
- 三周目は推した人のコロリンも同じ輪に舞う（一度に8つまで、聞き終えると入れかわる）。ダチのコロリンには小さな名札の印。
- ダチが届けたコロリンが、輪の上を転がって届いている。まだ聞いていないものは少し光る（数は出さない）。
- コロリンをタップ→喋る。名札「ダチ　@名前」（推した人は「@名前」だけ）。
- 推す・やめるは、名札を押して〔推す〕〔推すのをやめる〕（三周目から・ダチでない人）。推しても数はどこにも出ない（L3-RECORDER-S001）。
- ダチのコロリンの〔⋯〕：〔推しから外す〕〔🚩 通報する〕〔🚫 ブロックする〕。外しても相手には知らせない（ダチのまま。M-R109）。
- 推した人のコロリンの〔⋯〕：〔推すのをやめる〕〔🚩 通報する〕〔🚫 ブロックする〕。
- 届いたコロリンは88時間で輪から降りて見えなくなる。残り時間は出さない。
- 88時間舞ったコロリンは、届けた人の自分の部屋に戻る（台本 L2-SATURN-S001 の〔画面〕）。
- 右上〔👥 ダチ〕→S-6。
- 返事（💬）・引用（🔁）は出さない（台本で教えていない。§10 問い3）。

### S-5 届け先を選ぶ（二周目から）

〔届ける〕を押すと出る。押すと行き先を選ぶ（二周目は〔ダチへ〕、三周目からは〔ダチへ〕〔みんなへ〕）。ほかの星（木星・水星・火星・金星）の届け先と同じ形。

| 順 | 画面 | ボタン |
|---|---|---|
| 1 | 届け先を選ぶ | 〔ダチへ〕（二周目はこれだけ）　〔みんなへ〕（三周目から）　〔やめる〕 |
| 2 | 届けた演出：コロリンが輪の上をダチのほうへ転がる | 一行「88時間、輪をめぐって、自分の部屋に戻ります」 |

- 〔ダチへ〕＝ダチの〔推し〕の輪に舞う。今はダチ全員へ。ダチを一人ずつ選べるようにするかは、まだ決まっていない（`jupiter.md` J-Q1。木星・水星・火星・金星と一緒に決める）。選べるようにする場合は、1と2のあいだに、ダチの名札が並ぶ画面（押した名札が光る）を足す。
- 〔みんなへ〕は、三周目のはじめ（L3-RECORDER-S001）の〔画面〕で名前を一度教えてから出す（それまでは、ボタンそのものを出さない）。
- 年齢に関係なく、初めて〔みんなへ〕を選んだ時に一度だけ〔画面：〔みんなへ〕にすると、Obolo Orderのだれでも見たり聞いたりできます。本名・学校・住所・顔がわかるものは入れないでね〕を出す。18歳未満の人は、行き先のはじめの選択を〔ダチへ〕にしておく（自分で選べば〔みんなへ〕も使える）（M-R116(4)。木星・水星・火星・金星・海王星も同じ）。
- 〔みんなへ〕（三周目から）＝置く広場を選ぶ（入れる人が『Obolo Orderのみんな』の広場だけが並ぶ）→その広場の輪と、{neo}を推している人の〔推し〕の輪に舞う（案。§10 問い6）。
- 入れる人をしぼった広場（『わたしだけ』『承認した人』）に置く時は、S-9 の〔🎙 この広場でつぶやく〕から。〔推し〕には入らない。
- 推した数・推された数・届いた人の数は出さない。

### S-6 ダチの一覧

- 名札が並ぶ。並びはダチになった順（新しい順）。
- 最初は『ダチ　KIMORIN⭐︎』『ダチ　{inviter}』（L2-SATURN-S004）。火星（L2-MARS-S001）で選んだ人は『ダチ　MIKIE⭐︎』、三周目の桟橋（L3-WEAVER-S006）で選んだ人は『ダチ　MISAKO⭐︎』も並ぶ。
- **物語の仲間**（KIMORIN⭐︎・MIKIE⭐︎・MISAKO⭐︎）：ダチにはなれる（18歳未満も例外としてなれる）が、連絡はできない（M-R113(2)）。名札の並びの下に、地球の連絡室と同じ一行「物語の仲間の名札には、連絡できません」。名札の〔⋯〕は〔推しから外す〕だけ（通報・ブロックは出さない）。
- 下に〔✉ 招待状〕〔🔍 名前で探す〕→S-7。18歳未満の人には〔🔍 名前で探す〕を灰色で出し、押すと一行「ダチになれるのは、〔招待状〕でつながった人と、物語の仲間（KIMORIN⭐︎たち）です。〔名前で探す〕は18歳から使えます」（L2-SATURN-S004・L2-REST-S004 の18歳未満の〔画面〕と同じ文。地球 E-2 も灰色＋押すと一行）。
- 名札の〔⋯〕：〔推しから外す〕（外したダチは〔推しにもどす〕）、〔🚩 通報する〕〔🚫 ブロックする〕。一行「外しても、相手には知らせません。ダチのままです」（M-R109）。外したダチのコロリンは〔推し〕に出ないが、ダチのつながり（連絡室・プラネット訪問）はそのまま。
- 数・「あと〇人」は出さない。

### S-7 〔招待状〕〔名前で探す〕

## 10. 問いと決定（1・4・7・9は決定・解決。ほかは確認待ち）

1. **3日目の住人の笑い（ブラザーのくしゃみのコロリン）**：決まった（M-R107）。くしゃみは削除。D04-S006 で落ちてくるのはシスターのコロリン「……今日の夕焼け、きれいだったワ。」、D04-S007 はKIMORINの「……見つけました。あれが、コスモスです。」→点が消える→「……今日のところは、逃がしてあげましょう。」。UIの住人のコロリンの見本の音声を、この一つに差しかえる。番号はほかの文書から引くため、そのままにする。
2. **広場の〔参加する〕**：参加の印をなくすと、どの広場に自分がいたか分からない。おすすめ：自分がつぶやいた広場だけ、地図で少し明るくする（人数は出さない）。
3. **返事・引用**：二周目は出さない。三周目に声の返事（〔🎙 声でかえす〕）を足すかは、台本で教える場面がないので利用者が決める。
4. **三周目の広場を教える場面**（解決）：新しい場面は足さない。L3-RECORDER-S001の〔みんな〕の一行で、〔＋ ひろばをつくる〕と広場をのぞけることを教える（「土星の〔みんな〕では、ほかの人の広場をのぞいたり、〔＋ ひろばをつくる〕で自分の広場を作ったりできます」）。作り方の三つ（名前→〔ひろばのしるし〕→〔このひろばをつくる〕）は S-10 の画面の流れで見せる。
5. **〔自分の部屋に飛ばす〕の言葉**：ほかの星は「自分だけにしまう」を『🔒 ◯◯にしまう』でそろえた。土星だけ3日目の確定稿の〔自分の部屋に飛ばす〕のまま。そろえるなら〔🔒 自分の部屋にしまう〕だが、3日目の〔画面〕を変えることになるので利用者が決める。おすすめは今のまま（土星は「飛ばす・転がる」の絵が合うため）。
6. **三周目の〔みんなへ〕の行き先**（UIチームと決める）：土星の〔みんな〕は広場の地図なので、〔みんなへ〕は「みんなが入れる広場を一つ選んで置く」案にした（S-5）。広場を選ばずに、推している人の〔推し〕にだけ届ける形もありうる。どちらでも数は出さない。
7. **三周目のボタンの文字**（解決・R4）：台本も二周目からボタンを〔届ける〕にした（L2-SATURN-S001・S004・L2-REST-S004）。ボタンの文字に届け先を入れず、押すと行き先を選ぶ（二周目は〔ダチへ〕、三周目からは〔ダチへ〕〔みんなへ〕）。ほかの星の〔🦋 投稿する〕〔🚢 出航させる〕と同じ形なので、周回が変わっても食い違わない。
8. **ダチを一人ずつ選ぶか**：まだ決まっていない（`jupiter.md` J-Q1）。決まるまでは〔ダチへ〕でダチ全員へ。
9. **〔みんなへ〕と18歳未満**：決定（M-R116(4)）：S-5 の行のとおり。年齢に関係なく、初めて〔みんなへ〕を選んだ時に一度だけ注意の〔画面〕を出す。18歳未満の人は行き先のはじめの選択を〔ダチへ〕にしておき、自分で選べば〔みんなへ〕も使える。広場の人数・置いた人の数は出さない。

## 11. 台本係への申し送り

- 〔ダチの部屋〕は上の〔推し〕に言い直した（L2-SATURN-S001・S004・S010・L2-REST-S004）。
- 反映ずみ（R3：石に声を吹きこむ→{bati}が石にタッチ、行き先〔ダチへ〕を確かめる）。L2-SATURN-S004 の send の枝の「〔🎙〕でバティに話しかける」と「届け先のダチを選ぶ」は、3日目と同じ手順・S-5 の〔ダチへ〕にそろった。
- 反映ずみ（R4）：届けるボタンは台本・UIとも〔届ける〕（押すと行き先を選ぶ）。L2-SATURN-S004・L2-REST-S004 の18歳未満の〔画面〕は M-R113(2) の文になり、UIの S-7 も同じ一行「ダチになれるのは、〔招待状〕でつながった人と、物語の仲間（KIMORIN⭐︎たち）です。〔名前で探す〕は18歳から使えます」で出す。
- 反映ずみ（R4 検証）：L2-REST-S004 の dachi の枝のト書き「（18歳未満の人には〔名前で探す〕は出ない）」は「（18歳未満の人には〔名前で探す〕は灰色で、押すと上の一行）」に直した。もとの申し送り：UI は地球の連絡室（L2-RETURN-S008「虫めがねは、机に置いたまま」）と同じく「灰色で出し、押すと一行」にそろえた。ト書きを「（18歳未満の人には〔名前で探す〕は灰色）」に直すと食い違わない。
