## 1. ひとことで

**自分の作品をグッズの見本にして、自分の白いプラネット（アトリエ）に飾る星。** まん中のobolo商店では、品物を見て、欲しい時だけ買えます。物語のあとは、この野原がoboloフェスの町になります。

- 金星・天王星・海王星では、下の三つのボタン（流れ／作る／my場所）は出しません。星のトップ（U-1）が目次です。行き先をタップすると、バイカで動きます（M-R77の自由に移動。**案。§7の問い1**）。

### U-3 刷り台

正方形の画面。手順は四つ。今の手順だけが光ります。

| 手順 | 画面 | ボタン（文字どおり） |
|---|---|---|
| ① 形を選ぶ | 形のボタンが並ぶ。準備中の形は薄い色で、見るだけ | 〔Tシャツ〕〔マグカップ〕〔アクリルスタンド〕〔ステッカー〕〔缶バッジ〕〔トート〕〔おまかせ〕 |
| ② 絵を選ぶ | 二周目：自分のジャケットが並ぶ（8枚ずつ。〔新しい順〕〔ランダム〕）。三周目SHAPER：自分のアニメの札（場面・主役・小物） | 〔新しく描く〕（任意。下の注） |
| ③ 見本を出す | 刷り台の上に、選んだ絵の選んだ形 | 〔ハンドルを回す〕 |
| ④ 見本を見る | 光の見本が浮かぶ | 〔並べて表示〕〔自分のアトリエに飾る〕〔飾らずに閉じる〕 |

- 〔おまかせ〕はバティが形を選ぶ。
- 〔ハンドルを回す〕はタップです。指で回す操作はしません（ぎ、ぎ、と回る動きだけ見せる）。
- 今あるジャケットや作品を使うなら、お金もマナもかかりません。
- 〔新しく描く〕を押した時だけマナを使います。作る前に「マナを使います。作りますか？」と確認する。数字は出しません。入力は声／文字／選択／パス（バティにおまかせ）。
- 〔自分のアトリエに飾る〕：見本が自分のプラネットへ飛んでいき、小窓に灯りがつく。一行：「{neo}のアトリエに飾りました。注文はしていません」。
- 〔飾らずに閉じる〕：一行：「保存はしていません。〔つくる〕は、いつでも使えます」。
- 見本だけでは、注文も支払いもしません。これを④の下に小さく出しておく。
- **三周目SHAPER**：④のあとに〔完成として保存する〕が加わる（確認画面：札／形／大きさ／〔完成として保存する〕〔戻る〕）。作りかけは〔🔒 作業台にしまう〕で自分だけに残せる（**ボタン名は案**）。

### U-5 ダチのアトリエ

- 上の名札をタップすると、そのダチのプラネットの中が見られる。
- 見られるのは飾ってある見本だけ。〔もどる〕。
- 見た記録・足あとは相手に出しません。数も出しません。
- ダチでない人のプラネットは、二周目も三周目も見られません（L3-PLANET-S001「見に来られるのはダチだけ」）。

### U-8 買う画面（物語の外の手続き）

- 〔購入〕を押した時だけ開く。物語の画面とは見た目を分ける。
- 見せるもの：商品代・送料・合計・届け先の地域・届くまでの目安。
- 一行：「月額88円（毎月のマナの代金）とは別の料金です。売り買いに、マナは使いません」。
- 住所はこの手続きの中だけで入力する。準備中の品は注文できない。
- 15歳以下の承認などは、仕様の手続きどおり（この文書では決めない）。
- 物語の台詞やボタンだけでは注文しません。本人が確定する。

## 5. 出さないもの

| 出さないもの | かわり・理由 |
|---|---|
| 売れた数・売上・★・順位・人気順 | 数で人をはからない。並びは新しい順とランダムだけ |
| 見に来た数・足あと | 「見に来た数は、どこにも出ません」の一行 |
| マナの数字 | 一周目のテロップだけ（M-R75）。ここでは「マナを使います」の確認だけ |
| 申請の通過率・待ち順 | 結果は「並んだ」か「ここを直せば出せます」だけ |
| 取り分の額（本人以外に） | 本人だけ |
| 「限定」「残りわずか」「期限」 | 買うことをせかさない |
| 88分のカウントダウン | 出さない。買う・申請・生成・保存の途中では止めない |
| フェスの残り日数・申し込み数・倍率 | 出さない |
| 「AI」という言葉 | 使わない |

## 7. まだ決まっていないこと（問い）

1. **下の三つのボタン**：天王星では出さず、野原の見下ろし図を目次にする案でよいか（金星・海王星と同じ）。
2. **obolo商店に並ぶ範囲**：三周目に申請して並んだ会員のグッズは、二周目の人にも見えるか。〔みんな〕〔フォロー〕〔ダチ〕の切りかえを出すか。おすすめ：品物はだれにでも見える店なので、切りかえは出さず、〔新しい順〕〔ランダム〕だけ。
3. **形の〔おまかせ〕の書き方**：台本で〔おまかせ！〕（二周目）と〔おまかせ〕（三周目）がゆれている。画面は〔おまかせ〕にそろえる案。台本係にそろえてもらう。
4. **作者が自分の売れた数を見られるか**：取り分の額は本人だけに見える。数そのものを本人に見せるかは、お金にかかわるので利用者が決める。
5. **収入を出す場所の名前**：地球の銀行／お財布のどちらにするか（利用者の確認待ち）。
6. **申請の結果の知らせ方**：知らせの通知は出さない決まりなので、次にアプリを開いた時、いつもの丸に紙飛行機が戻っている形でよいか。
7. **〔新しく描く〕の回数**：月の水盤（4枚→言い直し1回→選ぶ）と同じにするか（月の問いと一緒に利用者が決める）。
8. **作りかけのしまい場所のボタン名**：『🔒 ◯◯にしまう』の形にそろえる。〔🔒 作業台にしまう〕でよいか。
9. **88分を過ぎた時**：刷り台の生成・保存、買う画面・申請の途中では止めない。終わってから「今日はここまで」を出す（共通の決まりどおり）。
