## 1. ひとことで

**二周目は、結社が用意したゲームで遊ぶ星。三周目は、結社の型に自分の作品をはめこんで、遊べるゲームを1本作る星。**

### 共通の決まり（三つの星で同じ）

- 金星・天王星・海王星では、下の三つのボタン（流れ／作る／my場所）は出しません。星のトップ（N-1）が目次です。島をタップすると、光の橋を渡ってそこへ行きます（**案。§7の問い1**）。
- 左上は〔← 宇宙の地図〕、右上は〔今日はここまで〕。
- 指で引きずる操作はしません。全部タップです。
- 数はどこにも出しません（§5）。点滅は1秒に2回まで。

### N-0 星図の海王星（一周目）

- 錠の印と『Obolo Orderのみ』。タップすると一行：「Obolo Orderになると、ひらきます」。

### N-1 海王星の島々（トップ）

正方形の画面。深い青の嵐の上に、平たい浮き島。島と島は光の橋でつながる。

| 島 | ゲーム | 出る時期 |
|---|---|---|
| 模型の町の島 | 『キモリンの帰り道』 | 二周目から |
| すごろくの盤の島 | 『星すごろく』 | 二周目から |
| 生け垣の迷路の島 | 『生け垣ラビリンス』 | 二周目から |
| 何もない白い島（模型の町の隣） | 自分の作業台と遊び場 | 三周目・PLAYERの入口から |

- 島をタップ→N-2。
- 自分の白い島をタップ→N-5（作りかけ）またはN-12（完成後）。
- 二周目の最初だけ、いちばん手前の橋のたもとに結社の札『おかえり。今日から、結社が用意したゲームで、遊べる。』。

### N-2 島の札

| 項目 | 中身 |
|---|---|
| 書くこと | 題・用意した人（例：『題　キモリンの帰り道　用意した人　結社』） |
| ボタン | 〔あそぶ〕〔もどる〕 |

- 評価・★・遊んだ数・値段は書きません。
- 二周目の最初（L2-NEPTUNE-S002）だけ、〔となりで見る〕も出す（KIMORINが動かし、分かれ道は本人が選ぶ）。

### N-3 ゲームの画面

| 場所 | 中身 |
|---|---|
| 上 | 一行の目当て（例：「じいちゃんに、土産話を届けよう」） |
| 中 | ゲームの絵。進める道が光っている |
| 下 | 〔おまかせで進む〕〔やめる〕 |

| 操作 | 動き |
|---|---|
| 光っている道をタップ | そこへ進む |
| 分かれ道 | 立て札が出る（例：『←坂の道』『川の道→』『まっすぐ：たこ焼き屋の前』）。タップで選ぶ |
| 〔おまかせで進む〕 | バティが道を選んで進む。押すと〔自分で進む〕に変わり、いつでも自分の操作に戻せる |
| 〔やめる〕 | 島にもどる。次は分かれ道から続ける（§7の問い2） |

- 最初に一行：「光っている道をタップすると進みます。迷ったら〔おまかせで進む〕。時間の制限・点数・勝ち負けはありません」。
- 時間制限・点数・勝ち負け・残り回数・ライフは出しません。失敗で前の章に戻すこともしません。
- 選んだ道で、終わりの話が変わる（『キモリンの帰り道』は、じいちゃんに話す土産話が三通り）。

### N-4 おわり

- 「おわり」と、選んだ道で変わった最後の場面。
- ボタン：〔もう一回〕〔島にもどる〕。
- 点数・クリアの記録・「◯回目」は出しません。

### N-5 作業台（三周目）

正方形の画面。白い島の真ん中の作業台。

| 場所 | 中身 |
|---|---|
| 上 | 型の木の箱が四つ（いま使える型だけ） |
| 中 | 自分の作品が手のひらの大きさで集まっている（ジャケット・レコード・MV・アニメの場面・グッズの見本・my場所の模型。持っているものだけ） |
| 下 | ボタン3つ |

| 型の箱（文字どおり） | 押すと |
|---|---|
| 〔走る〕〔パズル〕〔リズム〕〔すごろく〕 | 型が島の地面に写る。型はあとで選び直せる |
| 〔決められない〕 | バティが一つすすめる（選ばなくてもよい） |

| ボタン（文字どおり） | 押すと |
|---|---|
| 〔はめこむ〕 | N-6 |
| 〔始め・変わり目・終わり〕 | N-7 |
| 〔ためしに遊ぶ〕 | N-8 |

- 三つは、左から順に光る（はめる→決める→ためす）。どれから押してもよい。
- 一行：「中に入れるのは、これまでの{neo}の作品です」。アニメがある人だけに：「アニメ全部をゲームにしなくてかまいません」。
- 下書きは自動で自分だけに保存。〔今日はここまで〕で閉じても残る。

### N-6 〔はめこむ〕

| 枠 | 選ぶもの |
|---|---|
| キャラ | ジャケットから1枚（絵の中の顔が、型の人形に写る） |
| 舞台 | アニメの場面か、my場所（アニメがない人はmy場所から） |
| 曲 | これまでの自分の曲 |
| なかま | バティを入れるか（〔なかま役に入れる〕〔入れない〕）。入れる時は、台詞を一つだけ決める |

- 選び方：作品をタップ／声（本人がマイクをタップして始める）／文字／〔おまかせ〕（バティが選ぶ）。
- バティが下書き→本人が確かめて直す→自分だけに保存。録った声そのものは残さない。
- これまでの作品を選ぶだけで、一から作らない。
- 一行：「なかまの枠は空けてもかまいません」。

### N-7 〔始め・変わり目・終わり〕

| 枠 | 決めること |
|---|---|
| 始め | 始まりの場面を、作品から選ぶ |
| 変わり目 | 遊ぶ人が何をすると、何が変わるかを1つ（例：光る石を三つ拾うと、森がツリーに変わり、曲が二番に入る） |
| 終わり | 終わりの場面を、作品から選ぶ |

- 新しい絵を1枚作るのは任意。作る前に「マナを使います。作りますか？」と確認する。数字は出さない。
- 作品をはめこむだけなら、ほとんどマナを使わない。
- 入力は声／文字／選択／〔おまかせ〕。

### N-8 〔ためしに遊ぶ〕と確認表

- 始まりから自分で遊ぶ。遊びながら、本人が確認表に印をつける。

| 確認表（6つ） |
|---|
| □ 始まりから始められる |
| □ 何をすればいいか分かる |
| □ 押すと応える |
| □ 変わり目が起きる |
| □ 終わりまで行ける |
| □ 途中でやめて、続きから遊べる |

- 埋まらない項目は、その場面へ戻って直せる。
- 「合格」「何点」は出さない。本人が印をつけるだけ。
- 印が6つそろうと、N-10へ進むボタン〔題をつける〕が光る。

### N-9 直す所を選ぶ

詰まる所があった時に出す（L3-PLAYER-S005）。

| ボタン（文字どおり） | 押すと |
|---|---|
| 〔看板を足す〕 | 看板の文を、声か文字で書く（例：「高い所の光る石は、二回押すと届くよ」）。〔KIMORINに頼む〕も選べる |
| 〔変わり目を光らせる・音を足す〕 | 変わり目の所を光らせる・音を鳴らす |
| 〔押せる範囲を広げる〕 | 押せる所を広くする |
| 〔このまま〕 | 何も変えない |

- 一行：「確認してから反映します。勝手に作り直すことはありません」。
- 反映の前に、かならず本人の確認画面〔反映する〕〔もどる〕。

### N-10 題をつけて完成

| 順 | 画面 | ボタン |
|---|---|---|
| 1 | 題と遊び方を入れる（声／文字／バティの案から選ぶ。仮の題でもよい） | 〔これで完成にする〕〔直したい所がある〕〔今日はここまで〕 |
| 2 | 確認：題／遊び方／型／はめた作品（キャラ・舞台・曲）／始まり・変わり目・終わり | 〔完成として保存する〕〔戻る〕 |
| 3 | 「完成として保存しました。{neo}だけに保存。公開していません」 | 〔見せる相手を選ぶ〕〔あとで〕 |

- 完成のあと、バティがゲームの中に入って最後まで遊ぶ短い演出（止める・飛ばす・字幕あり）。飛ばした時は一行：「{bati}が〈題〉を最後まで遊びました」。

### N-11 見せる相手を選ぶ（三周目・別の画面）

- 〔みんな〕〔フォロー〕〔ダチ〕〔自分だけ〕から選ぶ。
- 押すまでは、だれにも見えない。
- 遊ばれた数・評価・コメントの数は出さない。
- どこで遊ばれるかは§7の問い3。

### N-12 自分の遊び場の棚

- 白い島の端の小さな棚。〈題〉の札『{neo}の遊び場（{neo}だけ）』。
- ボタン：〔あそぶ〕〔直す〕〔見せる相手を選ぶ〕。
- 授与（L3-PLAYER-S007）のあと、天王星の自分のプラネットの横に遊びの灯りが出る。灯りに触れると、このゲームが始まる（灯りの点滅は1秒に2回まで）。

### N-13 海王星からの板（物語のあと）

EX-NEPTUNE-S001。いつもの丸に、木の板が一回だけ届く。

| ボタン（文字どおり） | 押すと |
|---|---|
| 〔手を挙げる〕 | 「名簿に名前を書きます。招待は書いた順に届き、届く日は決まっていません。名前はいつでも消せます」→板の欄に名前 |
| 〔今はいい〕 | 板は手紙入れの横に残る。あとから手を挙げられる |
| 〔あとで決める〕 | 板は手紙入れの横に残る。「もう一度お知らせすることはありません」 |

- 名簿の順番の数字は、本人にも見せない。
- 再通知・バッジ・赤い点は出さない。

## 5. 出さないもの

| 出さないもの | 理由・かわり |
|---|---|
| 時間制限・残り時間 | 急がせない |
| 点数・勝ち負け・ランク・ライフ・残り回数 | 遊ぶ人が自分のペースで進む |
| 遊んだ数・遊ばれた数・評価・★・コメント数 | 数で人をはからない |
| 値段・「開発者に92%」などのお金の表示 | 結社のゲームはお金と関係ない |
| ゲームの一覧を下へずっと続ける表示 | 島をタップした時だけ出す |
| 名簿の順番の数字 | 本人にも見せない |
| マナの数字 | 一周目のテロップだけ（M-R75）。ここでは確認だけ |
| 88分のカウントダウン | 出さない。生成・保存の途中では止めない |
| 「AI」という言葉 | 使わない |

## 7. まだ決まっていないこと（問い）

1. **下の三つのボタン**：海王星では出さず、島の見下ろし図を目次にする案でよいか（金星・天王星と同じ）。
2. **ゲームを途中でやめた時**：台本でゆれている（L2-NEPTUNE-S002は「分かれ道から」、L2-REST-S013は「次は最初から」）。おすすめ：分かれ道から続ける。台本係にそろえてもらう。
3. **完成したゲームを「みんな／フォロー」に見せた時、どこで遊ばれるか**：天王星のプラネットはダチしか訪ねられない。おすすめ：海王星の島々に「見せてもらったゲーム」の島を一つ置き、タップした時だけ8本ずつ（新しい順／ランダム）出す。
4. **自分のゲームの〔おまかせで進む〕**：型で作ったゲームにも、いつも出すか。おすすめ：出す（操作が難しい人のため）。
5. **〔リズム〕の型**：点数も勝ち負けもない中で、どう遊ぶか。おすすめ：拍に合わせて押すと光と音が返る。外しても止まらず、先へ進む。
6. **『星すごろく』『生け垣ラビリンス』の中身**：台本にない。光った道をタップ・時間制限なし・点数なしの決まりで、UIチームが作ってよいか。
7. **88分を過ぎた時**：ゲームの途中なら、次の分かれ道で止めて続きから。下書き・生成・保存の途中では止めない。
