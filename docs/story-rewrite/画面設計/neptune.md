### 共通の決まり（三つの星で同じ）

- 金星・天王星・海王星では、下の三つのボタン（流れ／作る／my場所）は出しません。星のトップ（N-1）が目次です。島をタップすると、光の橋を渡ってそこへ行きます（**案。§7の問い1**）。
- 左上は〔← 宇宙の地図〕、右上は〔今日はここまで〕。
- 指で引きずる操作はしません。全部タップです。
- 上のタブ〔みんな〕〔推し〕は、ほかの人のゲームを見る画面（N-14）にだけ出します。一周目＝なし／二周目＝〔推し〕だけ（中身はダチのゲームだけ）／三周目＝〔みんな〕〔推し〕（〔推す〕を押した人のゲームも〔推し〕に入る）。〔推し〕の中のダチのゲームには、小さな名札の印（M-R109）。
- ゲームは押した時だけ出ます。一度に見えるのは8本まで。見終えると入れかわります。
- 数はどこにも出しません（§5）。点滅は1秒に2回まで。
- **届ける操作の形（どの星も同じ）**：作る → 届けるボタンを押す → 行き先を確かめる。行き先は二周目＝〔ダチへ〕だけ、三周目から〔ダチへ〕〔みんなへ〕。海王星でゲームを作るのは三周目だけなので、作る→〔見せる相手を選ぶ〕→行き先〔みんなへ〕〔ダチへ〕〔自分だけ〕を確かめる、の形になる（N-11）。〔ダチへ〕はダチ全員へ（一人ずつ選ぶかはJ-Q1で未定）。〔みんなへ〕の名前は、三周目のはじめ（L3-RECORDER-S001）の〔画面〕で一度だけ教える。
- **星を出る時（二周目）**：住人の「次は、〇〇だ。」→テロップ「〇〇が開いた」→〔画面〕このあとも自由にできます→選択［〇〇へ向かう／今日はここまで］（海王星からは［地球へ帰る／今日はここまで］）。〔向かう〕でロケットが星を離れる短い動き（タップで飛ばせる）。〔今日はここまで〕は、次に開くとこの選択から。地球の出発と同じ形です。
- **KIMORINの絵**：月から先のKIMORINは、いつも丸いサングラスをかけている。目の切れ目が光る絵は、サングラスが鼻先までずり落ちるか、額に押し上げてからだけ（サングラスの上から光らせない：M-R84）。光が引いたら、かけ直す。MIKIE⭐︎・MISAKO⭐︎も同じ丸いサングラス（M-R111(2)）。
- **MIKIE⭐︎とMISAKO⭐︎（M-R112・M-R113。くわしくは index.md 2.4）**：海王星の台本に二人の出番はない。絵を描く時は index.md 2.4 の設定どおり（MIKIE⭐︎＝金色のガトリングの右手・銀色のフックの左手・ふだん見えないドリルの右足、バティは猫のみーちゃん。MISAKO⭐︎＝白い光の衣・後光・浮かぶ水晶。腕・足のことは誰も触れない）。二人は住人ではなくネオの家族なので、住人の「ふざけない」決まりの外。
- **物語の仲間**：KIMORIN⭐︎・MIKIE⭐︎・MISAKO⭐︎はダチになれる（18歳未満も例外としてなれる）が、連絡はできない（M-R113(2)）。海王星の画面には、物語の仲間への連絡のボタンは出さない。

### N-1 海王星の島々（トップ）

正方形の画面。深い青の嵐の上に、平たい浮き島。島と島は光の橋でつながる。

| 島 | ゲーム | 出る時期 |
|---|---|---|
| 模型の町の島 | 『キモリンの帰り道』 | 二周目から |
| すごろくの盤の島 | 『星すごろく』 | 二周目から |
| 生け垣の迷路の島 | 『生け垣ラビリンス』 | 二周目から |
| 何もない白い島（模型の町の隣） | 自分の作業台と遊び場 | 三周目・PLAYERの入口から |
| とどいたゲームの島（案） | ダチや推している人が見せてくれたゲーム（N-14） | 見せてもらったゲームが一本でも届いた時から（§7の問い3） |

- 島をタップ→N-2。
- 自分の白い島をタップ→N-5（作りかけ）またはN-12（完成後）。
- 二周目の最初だけ、いちばん手前の橋のたもとに結社の札『おかえり。今日から、結社が用意したゲームで、遊べる。』。

### N-2 島の札

| 項目 | 中身 |
|---|---|
| 書くこと | 題・用意した人（例：『題　キモリンの帰り道　用意した人　結社』） |
| ボタン | 〔あそぶ〕〔もどる〕 |

- 評価・★・遊んだ数・値段は書きません。
- 初めて海王星の札を開いた時だけ、上に一行（台本 L2-NEPTUNE-S002）：「島ごとに、結社が用意したゲームが一つずつ。〔あそぶ〕を押すと始まります。時間の制限・点数・勝ち負けはなく、評価や遊んだ数も出ません」。進み方（光る道・〔おまかせで進む〕）は、ここではまだ言わない。
- 二周目の最初（L2-NEPTUNE-S002）だけ、〔となりで見る〕も出す（KIMORINが動かし、分かれ道は本人が選ぶ）。

### N-3 ゲームの画面

| 場所 | 中身 |
|---|---|
| 上 | 一行の目当て（例：「じいちゃんに、土産話を届けよう」） |
| 中 | ゲームの絵。進める道が光っている |
| 下 | 〔おまかせで進む〕〔やめる〕 |

| 操作 | 動き |
|---|---|
| 光っている道をタップ | そこへ進む |
| 分かれ道 | 立て札が出る（例：『←坂の道』『川の道→』『まっすぐ：たこ焼き屋の前』）。タップで選ぶ |
| 〔おまかせで進む〕 | バティが道を選んで進む。押すと〔自分で進む〕に変わり、いつでも自分の操作に戻せる |
| 〔やめる〕 | 島にもどる。次は分かれ道から続ける（§7の問い2） |

- 進み方の案内は、遊ぶ前にまとめて出さず、**初めての分かれ道に来た時に**一行だけ出す（台本 L2-NEPTUNE-S002）：「光っている道をタップすると進みます。迷ったら〔おまかせで進む〕（バティが道を選びます。いつでも自分の操作に戻せます）」。このとき光るのは、分かれ道の立て札と〔おまかせで進む〕だけ。二回目からは出さない。
- 時間制限・点数・勝ち負け・残り回数・ライフは出しません。失敗で前の章に戻すこともしません。
- 選んだ道で、終わりの話が変わる（『キモリンの帰り道』は、じいちゃんに話す土産話が三通り）。

### N-4 おわり

- 「おわり」と、選んだ道で変わった最後の場面。
- ボタン：〔もう一回〕〔島にもどる〕。
- 点数・クリアの記録・「◯回目」は出しません。

### N-5 作業台（三周目）

正方形の画面。白い島の真ん中の作業台。

| 場所 | 中身 |
|---|---|
| 上 | 型の木の箱が四つ（いま使える型だけ） |
| 中 | 自分の作品が手のひらの大きさで集まっている（ジャケット・レコード・MV・アニメの場面・グッズの見本・my場所の模型。持っているものだけ） |
| 下 | ボタン3つ |

| 型の箱（文字どおり） | 押すと |
|---|---|
| 〔走る〕〔パズル〕〔リズム〕〔すごろく〕 | 型が島の地面に写る。型はあとで選び直せる |
| 〔決められない〕 | バティが一つすすめる（選ばなくてもよい） |

| ボタン（文字どおり） | 押すと |
|---|---|
| 〔はめこむ〕 | N-6 |
| 〔始め・変わり目・終わり〕 | N-7 |
| 〔ためしに遊ぶ〕 | N-8 |

- 三つは、左から順に光る（はめる→決める→ためす）。どれから押してもよい。
- 一行：「中に入れるのは、これまでの{neo}の作品です」。アニメがある人だけに：「アニメ全部をゲームにしなくてかまいません」。
- 下書きは自動で自分だけに保存。〔今日はここまで〕で閉じても残る。

### N-6 〔はめこむ〕

枠は**三つ**です（台本 L3-PLAYER-S003 の〔画面〕。画面の札の名前は〔キャラ〕〔舞台〕〔曲〕。〔舞台〕＝遊ぶ場所）。上から一つずつ光り、一つ選ぶと次が光ります。

| 枠 | 選ぶもの |
|---|---|
| 〔キャラ〕 | ジャケットの絵から1枚（四角いジャケットが開いて、絵の中の顔が型の人形に写る）。アニメがある人は〈主役〉も選べる（アニメの一コマから抜け出して人形に重なる）。〔おまかせ〕の時、アニメがある人は〈主役〉、ない人はジャケットの絵の子 |
| 〔舞台〕 | アニメの場面か、my場所（アニメがない人はmy場所から） |
| 〔曲〕 | これまでの自分の曲 |

三つがうまったあとに、別の小さな画面で一つだけ聞きます（枠ではなく、選ばなくてもよい）：

| 聞くこと | ボタン（文字どおり） |
|---|---|
| バティを、なかま役に入れるか（台本：バティ「ボクは、主役の友達として入ってみたいな。／君は、どうする？」） | 〔なかま役に入れる〕〔入れない〕。入れる時は、台詞を一つだけ決める（声／文字／選択／バティにおまかせ） |

- 選び方：作品をタップ／声（本人がマイクをタップして始める）／文字／〔おまかせ〕（バティが選ぶ）。
- バティが下書き→本人が確かめて直す→自分だけに保存。録った声そのものは残さない。
- これまでの作品を選ぶだけで、一から作らない。
- 一行：「なかまは、入れなくてもかまいません」。

### N-7 〔始め・変わり目・終わり〕

| 枠 | 決めること |
|---|---|
| 始め | 始まりの場面を、作品から選ぶ |
| 変わり目 | 遊ぶ人が何をすると、何が変わるかを1つ（例：光る石を三つ拾うと、森がツリーに変わり、曲が二番に入る） |
| 終わり | 終わりの場面を、作品から選ぶ |

- 新しい絵を1枚作るのは任意。作る前に「マナを使います。作りますか？」と確認する。数字は出さない。
- 作品をはめこむだけなら、ほとんどマナを使わない。
- 入力は声／文字／選択／〔おまかせ〕。

### N-8 〔ためしに遊ぶ〕と確認表

- 始まりから自分で遊ぶ。遊びながら、本人が確認表に印をつける。

| 確認表（6つ） |
|---|
| □ 始まりから始められる |
| □ 何をすればいいか分かる |
| □ 押すと応える |
| □ 変わり目が起きる |
| □ 終わりまで行ける |
| □ 途中でやめて、続きから遊べる |

- 埋まらない項目は、その場面へ戻って直せる。
- 「合格」「何点」は出さない。本人が印をつけるだけ。
- 印が6つそろうと、N-10へ進むボタン〔題をつける〕が光る。

### N-9 直す所を選ぶ

詰まる所があった時に出す（L3-PLAYER-S005）。

| ボタン（文字どおり） | 押すと |
|---|---|
| 〔看板を足す〕 | 看板の文を、声か文字で書く（例：「高い所の光る石は、二回押すと届くよ」）。〔KIMORINに頼む〕も選べる |
| 〔変わり目を光らせる・音を足す〕 | 変わり目の所を光らせる・音を鳴らす |
| 〔押せる範囲を広げる〕 | 押せる所を広くする |
| 〔このまま〕 | 何も変えない |

- 一行：「確認してから反映します。勝手に作り直すことはありません」。
- 反映の前に、かならず本人の確認画面〔反映する〕〔もどる〕。

## 7. まだ決まっていないこと（問い）

3. **見せてもらったゲームを、どこで遊ぶか**：天王星のプラネットの遊びの灯りはダチしか訪ねられない。おすすめ：海王星の島々に「とどいたゲームの島」を一つ置き（N-14）、見せてもらったゲームが一本でも届いた時から出す。タップした時だけ8本ずつ（新しい順／ランダム）。あわせて、ほかの作品と同じく「88時間ほかの人の島をめぐり、そのあと自分の遊び場の棚に戻る」決まりを当てはめるかも決める（おすすめ：当てはめる。プラネットの遊びの灯りは、本人が〔ダチに見せる〕をオンにしている間、ダチ向けに灯り続ける）。

5. **〔リズム〕の型**：点数も勝ち負けもない中で、どう遊ぶか。おすすめ：拍に合わせて押すと光と音が返る。外しても止まらず、先へ進む。
