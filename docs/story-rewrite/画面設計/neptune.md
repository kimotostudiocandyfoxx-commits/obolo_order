### 共通の決まり

- 海王星は作る星ではないので、下の三つのボタンは出さない。N-1 の一枚の絵が目次（index 2.1。絵はUIチームが決める）。
- 左上は〔← 宇宙の地図〕、右上は〔今日はここまで〕。指で引きずる操作はしない。全部タップ。
- 遊ぶのにマナは使わない。点数・順位・人と比べる数は出さない（§5）。点滅は1秒に2回まで。急な点滅・急な音量の上昇はしない。
- **星を出る時（二周目）**：KIMORIN「次は、地球ですね。」→［地球へ帰る／今日はここまで］→ロケット（L2-NEPTUNE-S003）。
- **KIMORINの絵**：いつも丸いサングラス。目が光るのは、サングラスが鼻先までずり落ちるか額に押し上げてから（M-R84）。

| 場所 | 中身 |
|---|---|
| まん中 | ひときわ大きな巻き貝の館。入口のまわりだけネオンがしっかり灯る。看板『ナガレを越えて』 |
| まわり | 灯りの入っていない館（ネオンがゆっくり光ったり消えたり）。タップしても入れない。一行：「この館には、まだ灯りが入っていません」 |

### N-4 ステージ

| マス | 使う{neo}の作品 | 操作 |
|---|---|---|
| 土星 | コロリン（サングラスを目に落として、本人の声のまま歌う。M-R152） | コロリンをタップすると歌い、石の言葉が一文字ずつほどける |

- 作品がない時は、結社が用意した絵・曲で進める（だれでもクリアできる）。

### N-5 クリア

- 「クリア」だけを出す。点数・時間・回数・「◯回目」は出さない。
- 金星のクリアのあと：嵐が晴れて、フェスの町の舞台（夜の森に六角形のドームの灯り）。〔テロップ：『ナガレを越えて』を、最後までクリアした〕。地図のマスが一つずつ灯り、そのステージの{neo}の作品の小さな絵が出る。
- **PLAYERの条件**：『ナガレを越えて』を最後までクリア（`f_l3_player_clear`＝true。L3-PLAYER-S006）。授与は本部（L3-PLAYER-S007。`f_l3_player_done`）。

## 5. 出さないもの

| 出さないもの | 理由・かわり |
|---|---|
| 点数・順位・ランキング・時間・ライフ・残り回数 | 結果は「クリア」だけ（M-R160・M-R161） |
| 遊んだ数・遊ばれた数・評価・★ | 数で人をはからない |
| くじ（ガチャ）・景品のための課金・毎日のごほうび | 入れない（M-R161） |
| マナやお金で買えるものを賭けること | しない（大人どうしでも。M-R161・M-R162） |
| 実在のゲーム・店の名前 | 使わない |
| マナの数字 | 遊ぶのにマナは使わない |
| 88分のカウントダウン | 出さない。ステージの途中なら、そのステージが終わってから止める |
| 「AI」という言葉 | 使わない |

## 第20稿までの記録

第20稿までの海王星は「嵐の上の浮き島で結社のゲーム（『キモリンの帰り道』『星すごろく』『生け垣ラビリンス』）を遊び、三周目に型（走る／パズル／リズム／すごろく）に作品を〔はめこむ〕でゲームを1本作る星」でした。次の画面は**作りません**：島々と光の橋、光る道と〔おまかせで進む〕、作業台・〔はめこむ〕・〔始め・変わり目・終わり〕・〔ためしに遊ぶ〕と確認表・〔看板を足す〕・題をつけて完成・見せる相手〔みんなへ〕〔ダチへ〕〔自分だけ〕・自分の遊び場の棚・とどいたゲームの島（旧 N-1〜N-14）。M-R161 のゲームセンターの建物（手前の三台・トランプ）は M-R163・M-R164 で深海の都に置きかえた。
