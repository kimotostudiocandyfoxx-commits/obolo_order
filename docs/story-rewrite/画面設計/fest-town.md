## 1. ひとことで

**三周目の目的は一つ。「oboloフェスで自分のDJセットを回し、町に自分のプラネットを出す」こと。**
準備ができるたびに、天王星の自分のプラネットの白い布が一枚外れる。称号は、その準備ができたしるし（看板に小さく出るだけ）。

- 町obolo＝DJの町。宇宙にも地球にもある。フェスは年に一回・88日間ひらく。

## 5. 画面ごとの中身

### F-1 招待状の裏（持ちもの）

```
┌──────────────────────────┐
│ oboloフェス　持ちもの        〔閉じる〕│
│  ✦ セットの芯になる曲     （灯り）    │
│  ○ セットぜんぶの曲       （押せる）  │
│  ・ 町の大きな画面に映す映像（まだ）   │
│  ○ プラネットで流す物語    （押せる）  │
│  ・ プラネットの店に並べるもの（まだ） │
│  ○ プラネットの遊び       （押せる）  │
│         〔表を見る〕                  │
└──────────────────────────┘
```

| 欄の見た目 | 意味 | 押すと |
|---|---|---|
| ✦ 灯り | 用意できた | 「{neo}のプラネットに〈出てきたもの〉があります」〔プラネットを見に行く〕〔閉じる〕 |
| ○ ふつうの明るさ | 始められる | F-2 欄の札 |
| ・ うすい色 | まだ始められない | 一行「〈前の欄の名前〉のあとで、ひらきます」 |

- 欄がひらく順（台本どおり）：セットの芯になる曲（RECORDER）が最初。そのあと、セットぜんぶの曲（WEAVER）・プラネットで流す物語（HOLDER）・プラネットの遊び（PLAYER）がひらく。町の大きな画面に映す映像（MOVER）はWEAVERのあと。プラネットの店に並べるもの（SHAPER）はHOLDERのあと。
- 一行（三周目のはじめ）：「持ちものは、『セットの芯になる曲』から始めます。そのあとは、どれから用意してもかまいません」「全部そろっていなくても、フェスには行けます。用意ができた欄には、灯りがともります」。
- 〔表を見る〕：金色の表（町の絵・88日間・場所：宇宙のobolo）に戻る。
- 灯りは称号のフラグ（`f_l3_recorder_done`〜`f_l3_player_done`）から出す。新しいフラグは作らない。

### F-2 欄の札（章を始める）

- 欄の名前と、行き先の星の小さな絵（例：「プラネットで流す物語　→　火星」）。
- 〔始める〕〔今はやめておく〕。
- 〔始める〕で、その章の最初の場面へ（WEAVER＝L3-WEAVER-S001、MOVER＝L3-MOVER-S001、HOLDER＝L3-HOLDER-S001、SHAPER＝L3-SHAPER-S001、PLAYER＝L3-PLAYER-S001）。
- 称号の名前はここに出さない（看板の小さな一行だけ）。

### F-3 自分のプラネット（布の台）

`uranus.md` U-2（自分のアトリエの中）と同じ画面。三周目から、白い布をかけた台が増える。

| 準備 | 布が外れて出るもの | 持ちものの欄 |
|---|---|---|
| RECORDER | 入口の横の小さなレコード棚（三曲のジャケットの顔） | セットの芯になる曲 |
| WEAVER | 棚が奥まで広がる。入口に試聴の台（前を通ると曲がかすかに聞こえる） | セットぜんぶの曲 |
| MOVER | 屋根の上の小さな映写機（光の筋が空へ伸びる） | 町の大きな画面に映す映像 |
| HOLDER | 奥の幕と小さな客席（幕に自分のアニメの最初の一コマ） | プラネットで流す物語 |
| SHAPER | 入口のカウンター（グッズの見本） | プラネットの店に並べるもの |
| PLAYER | 横の、点滅する遊びの灯り（触れると自分のゲームが始まる） | プラネットの遊び |

- 入口の看板：名前『{neo}』。その下に、得意の名前が小さく一行ずつ増える（例『RECORDER』）。
- まだの台は布をかけたまま、風で少し揺れるだけ。押すと「まだ、何も置いていません」（催促の言葉は出さない）。
- プラネットの大きさは変わらない。中の物だけが増える。
- 一行：「{neo}のプラネットは、宇宙の地図の天王星から、いつでも見に行けます。見に来られるのはダチだけです。見に来た数は、どこにも出ません」（L3-PLANET-S001）。
- ダチのプラネットへは、天王星の〔ダチのアトリエ〕の札から行く（上のタブではない。`uranus.md`）。札を押すとダチの名札が並び、押した名札のプラネットへ。並びはダチになった順。数は出さない。
- ダチが来ても、知らせ・足あと・「来た人」の一覧は出さない。
- 遊びの灯りの点滅は1秒に2回まで。

### F-4 布が外れる短い映像

- 約6秒。〔❚❚〕（止める）と〔飛ばす〕がある。
- 流れ：天王星の野原→自分の白いプラネット→白い布が一枚ふわりと外れ、〈出てくるもの〉が出る→看板に〈得意の名前〉が一行増える→〔テロップ：持ちもの「〈欄の名前〉」に灯りがともった〕。
- 飛ばした時の一行：「{neo}のプラネットに、〈出てくるもの〉が出ました」。
- 授与の場面の中だけで流す（MONBANの「お前は…『〇〇』だ…。」のあと、OBOLONの前）。単独では流さない。

### F-5 太陽への門

- 本部の奥の丸い石の門。WEAVERのあとに、指一本ぶん開く。
- 初めて開いた時だけMONBANの三行（L3-SUN-S000）と一行：「太陽への門は、本部の奥から、いつでも選べます。招待状の裏の欄が全部ともっていなくても、行けます。物語を終えたあとも、残りの持ちものは、いつでも用意できます」。
- 門を押すと、太陽の章の入口（L3-SUN-S001）。行くか、まだ行かないかを選べる。

### F-6 太陽のDJブース（L3-SUN-S005b）

```
┌──────────────────────────┐
│ 🎧 DJ                              │
│  （上：ステージの画面＝MVかあかり）     │
│   ◎左の台        ◎右の台           │
│   〔印〕〔SYNC〕  ━つまみ━            │
│   〔コロリン〕〔あかり〕〔映像を選ぶ〕(小) │
│  （次に押す所だけが光る）             │
│ 〔自分で回す〕〔おまかせで回す〕〔今は回さない〕│
└──────────────────────────┘
```

- 台の操作は金星の「かんたんDJ」と同じ（`venus.md` V-2）。台2つ・つまみ1本・〔印〕〔SYNC〕〔コロリン〕〔あかり〕、控えの〔映像を選ぶ〕だけ。卓の形（アプリの横長の三つの丸か、正方形の画面か）は金星で決めたものと同じにする。
- 最初の一行：「金星で覚えた回し方で、旅で作った自分の曲・映像・コロリンの声だけを混ぜます。曲は、八曲のアルバムから選べます。観客の数や点数は出ません。回すのに、マナは使いません。おまかせの{bati}の魔法も、マナを使いません。録画も公開もされません」。
- 手順は画面に並べない。次に押す所だけ光る：台に曲をのせる→〔印〕→〔SYNC〕→つまみ→〔コロリン〕。
- MVのある曲は、台にのせると上のステージの画面に流れ、つまみで映像も一緒に切り替わる（光の案内に「映像」の歩はない）。〔映像を選ぶ〕は、別の映像に替えたい時だけの控えのボタン。MOVERの三本がない人・MVがない曲は〔あかり〕。
- 点滅は1秒に2回まで。

| ボタン | 押すと |
|---|---|
| 〔自分で回す〕 | 光った所を順に押して回す |
| 〔おまかせで回す〕 | バティ「どれを混ぜる？　三つ選んで。」→材料を三つ選ぶ（曲／映像／コロリンの声）→バティがセットを組む。押すのは、つなぐ瞬間とコロリンを落とす瞬間だけ（ボタンが光る） |
| 〔今は回さない〕 | 台だけが静かに回る。OBOLON「、、、それも、いい。」 |

- 回せる曲がない人（曲を消した人など）：練習用のリズムとあかりで、つなぐ・落とす・照らすを一回ずつ。
- 窓から届くダチの光は、ダチの名札の窓が灯るだけ（ダチの作品の中身は流さない）。
- 曲が止まったあとの静けさは飛ばせない場面につながる（L3-SUN-S006・S007）。ここでボタンや一行を足さない。
