## 5. 画面ごとの中身

### F-1 招待状の裏（持ちもの）

```
┌──────────────────────────┐
│ oboloフェス　持ちもの        〔閉じる〕│
│  ✦ セットの芯になる曲     （灯り）    │
│  ○ セットぜんぶの曲       （押せる）  │
│  ・ 町の大きな画面に映す映像（まだ）   │
│  ○ プラネットで流す物語    （押せる）  │
│  ・ プラネットの店に並べるもの（まだ） │
│  ○ プラネットの遊び       （押せる）  │
│         〔表を見る〕                  │
└──────────────────────────┘
```

| 欄の見た目 | 意味 | 押すと |
|---|---|---|
| ✦ 灯り | 用意できた | 「{neo}のプラネットに〈出てきたもの〉があります」〔プラネットを見に行く〕〔閉じる〕 |
| ○ ふつうの明るさ | 始められる | F-2 欄の札 |
| ・ うすい色 | まだ始められない | 一行「〈前の欄の名前〉のあとで、ひらきます」 |

- 欄がひらく順（台本どおり）：セットの芯になる曲（RECORDER）が最初。そのあと、セットぜんぶの曲（WEAVER）・プラネットで流す物語（HOLDER）・プラネットの遊び（PLAYER）がひらく。町の大きな画面に映す映像（MOVER）はWEAVERのあと。プラネットの店に並べるもの（WRITER）はHOLDERのあと。
- 一行（三周目のはじめ）：「持ちものは、「セットの芯になる曲」から始めます。そのあとは、開いている欄から好きな順に用意できます（「町の大きな画面に映す映像」は「セットぜんぶの曲」のあと、「プラネットの店に並べるもの」は「プラネットで流す物語」のあとに開きます）」「全部そろっていなくても、フェスには行けます。用意ができた欄には、灯りがともります」（台本 L3-RECORDER-S001）。
- 〔表を見る〕：金色の表（町の絵・88日間・場所：宇宙のobolo）に戻る。
- 灯りは称号のフラグ（`f_l3_recorder_done`〜`f_l3_player_done`）から出す。新しいフラグは作らない。

### F-2 欄の札（章を始める）

- 欄の名前と、行き先の星の小さな絵（例：「プラネットで流す物語　→　火星」）。
- 〔始める〕〔今はやめておく〕。
- 〔始める〕で、その章の最初の場面へ（WEAVER＝L3-WEAVER-S001、MOVER＝L3-MOVER-S001、HOLDER＝L3-HOLDER-S001、WRITER＝L3-SHAPER-S001、PLAYER＝L3-PLAYER-S001）。
- 称号の名前はここに出さない（看板の小さな一行だけ）。

### F-3 自分のプラネット（布の台）

`uranus.md` U-2（自分のアトリエの中）と同じ画面。三周目から、白い布をかけた台が増える。

| 準備 | 布が外れて出るもの | 持ちものの欄 |
|---|---|---|
| RECORDER | 入口の横の小さなレコード棚（三曲のジャケットの顔） | セットの芯になる曲 |
| WEAVER | 棚が奥まで広がる。入口に試聴の台（前を通ると曲がかすかに聞こえる） | セットぜんぶの曲 |
| MOVER | 屋根の上の小さな映写機（光の筋が空へ伸びる） | 町の大きな画面に映す映像 |
| HOLDER | 奥の幕と小さな客席（幕に自分のアニメの最初の一コマ） | プラネットで流す物語 |
| WRITER | 入口のカウンター（グッズの見本） | プラネットの店に並べるもの |
| PLAYER | 横の、点滅する遊びの灯り（触れると自分のゲームが始まる） | プラネットの遊び |

- 入口の看板：名前『{neo}』。その下に、得意の名前が小さく一行ずつ増える（例『RECORDER』）。
- まだの台は布をかけたまま、風で少し揺れるだけ。押すと「まだ、何も置いていません」（催促の言葉は出さない）。
- プラネットの大きさは変わらない。中の物だけが増える。
- 出てくる棚・幕・カウンター・遊びの灯りは、はじめは本人だけに見える。プラネットの中で一つずつ〔ダチに見せる〕を切りかえる（初めはオフ。M-R113(4)）。切りかえの画面は `uranus.md` U-2 と同じ（出たものを押す→大きく見える→下に〔ダチに見せる〕〔もどる〕）。
- ダチのプラネットで見えるのは、その人が見せると選んだものだけ。オフのものは、ダチからは白い布をかけた台に見える（`uranus.md` U-5b）。見せているものの数・ダチが見たかどうかは出さない。
- 一行：「{neo}のプラネットは、宇宙の地図の天王星から、いつでも見に行けます。布が外れて出てくる棚や幕は、はじめは{neo}だけに見えます。ダチに見せるかは、プラネットの中で一つずつ選べます。見に来られるのはダチだけで、見に来た数は、どこにも出ません」（L3-PLANET-S001）。
- ダチのプラネットへは、天王星の〔ダチのアトリエ〕の札から行く（上のタブではない。`uranus.md`）。札を押すとダチの名札が並び、押した名札のプラネットへ。並びはダチになった順。数は出さない。
- ダチが来ても、知らせ・足あと・「来た人」の一覧は出さない。
- 遊びの灯りの点滅は1秒に2回まで。

### F-4 布が外れる短い映像

- 約6秒。〔❚❚〕（止める）と〔飛ばす〕がある。
- 流れ：天王星の野原→自分の白いプラネット→白い布が一枚ふわりと外れ、〈出てくるもの〉が出る→看板に〈得意の名前〉が一行増える→〔テロップ：持ちもの「〈欄の名前〉」に灯りがともった〕。
- 飛ばした時の一行：「{neo}のプラネットに、〈出てくるもの〉が出ました」。
- 授与の場面の中だけで流す（MONBANの「お前は…『〇〇』だ…。」のあと、OBOLONの前）。単独では流さない。
