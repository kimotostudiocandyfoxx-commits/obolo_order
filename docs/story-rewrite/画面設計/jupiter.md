- 版：第20稿（ループ見直し R5）・2026-10-26
- R5で変えたこと：〔みんなへ〕の初回の注意と18歳未満のはじめの行き先〔ダチへ〕を足した（M-R116(4)）。ジャケットはいつも1:1の正方形、と1. に書いた。ダチのジャケット（KIMORINの『プリプリ・ボカン』も同じ形）は上の〔推し〕の空に飛んできて、タップすると〔ジャケット帳〕で開く、を J-1 に書いた（台本 L2-JUPITER-S002）。88分の割りこみ（SYS-S001）は作る・保存・支払いが終わるまで待つ、を共通の決まりに足した。

- R3で変えたこと：L2-JUPITER-S002 の申し送りを反映ずみにした。J-3 に、一周目の下のボタンと「一周目は葉が出ない（二周目から）」を書き足した。〔🔒 根っこにしまう〕は自動でしまわないこと、届ける流れ（どの星も同じ）、二周目に星を出る時の選択とロケット、物語の人物の絵（KIMORINのサングラス・MIKIE⭐︎の見た目 M-R111(2)）を足した。周回表に「葉」の行を足した
- R2で変えたこと：上のタブを〔みんな〕〔推し〕の2つに（M-R109）。〔推す〕〔推しから外す〕の場所と、届け先〔ダチへ〕〔みんなへ〕を書いた。夜の大樹の声の文を台本（L3-RECORDER-S015）にそろえた。人の木を見に行ける範囲を決まっていないことに足した
- もとにしたもの：今の台本（parts/P03・P04・P06・P10・P11）、利用者の決定 M-R1〜M-R116、レビューの申し送り
- 渡す先：アプリ（ブランチ `claude/solar-system-home-planets-ew766y`）を作るUIチーム
- 優先順位：物語にかかわる画面の決まりは、この文書を `docs/jupiter.md` より先に見てください。食い違いは「9. アプリの今と違う所」にまとめました。
- 書き方：〔 〕はボタンの文字（このとおりに出す）。「 」は画面に出す一行の文。表の中の（ ）は、UIチームへの注記です。「（数字なし）」なども含めて、画面には出しません。

## 1. ひとことで

**木星は、日々の言葉や写真を、正方形のレコードの「ジャケット」にする星。**
ジャケットはいつも1:1の正方形（丸いシールにはしない。M-R89）。
曲はまだなくていい。顔（ジャケット）を先に作り、中身（曲）は水星で作る。

## 5. 画面ごとの中身

画面は正方形。どの画面も「上の帯（タブ）／真ん中（絵）／下の帯（ボタン3つ）」の三段です。

### J-1 空（🦋 空）

```
┌──────────────────────────┐
│ 〔みんな〕〔推し〕  ← 周回で変わる│
│                          │
│  ▢  ▢     ▢             │ ← ジャケットが最大8枚、
│     ▢   ▢    ▢  ▢      │    パタパタ開け閉めしながら浮く
│        @名前 の名札      │
│                          │
│ 〔🦋 空〕〔🥚 たまご〕〔🌳 myツリー〕│
└──────────────────────────┘
```

| ボタン・もの | 押すと |
|---|---|
| 飛んでいるジャケット | J-5 ジャケット帳（その人が88時間以内に出したジャケット） |
| 見終えたジャケット | ふっと消え、ほかにあれば別の一枚が入る（下へ流れない） |
| 〔推し〕（二周目から） | ダチのジャケット（二周目・星休め）。三周目からは推した人のジャケットも。ダチのジャケットには小さな名札の印 |
| 〔みんな〕（三周目から） | みんなのジャケットを見る入口。〔みんなへ〕で飛ばされたジャケットが飛ぶ |
| 名札「@名前」 | 〔⋯〕が出る（下の J-5 と同じメニュー） |
| 〔🥚 たまご〕 | J-2 根っこ |
| 〔🌳 myツリー〕 | J-6 |

- 一周目の空：物語に出たジャケット（自分・KIMORIN・大根カイザー）だけが木のまわりを飛ぶ。「ジャケットは木のまわりを飛ぶだけで、誰にも送られていません」（D05-S008）。
- 名札は「@名前」だけ。残り時間（「◯h」）は出さない。
- ダチのジャケットは、上の〔推し〕の空にパタパタと飛んでくる。タップすると〔ジャケット帳〕（J-5）で開く。二周目の L2-JUPITER-S002 で届くKIMORINの『プリプリ・ボカン』も、同じ形（特別な演出の画面は作らない）。
- 一周目はタブを出さない。二周目は〔推し〕が一つだけ（押しても範囲は変わらないので、タブというより見出し）。
- 二周目のはじめの案内（L2-JUPITER-S002）は三つに分けて、一行ずつ出す：
  1. 「〔🥚 たまご〕→〔🔒 根っこ〕で言葉を選び、〔ジャケットをつくる〕」
  2. 「できたジャケットは、〔🦋 投稿する〕で、ダチの空に飛ばせます（届くのはダチだけ。88時間飛んだら、このあと植えるmyツリーの枝に戻ります）」
  3. 「ダチのジャケットは、上の〔推し〕の空に飛んできます。タップすると見られます」

### J-2 根っこ（🔒 根っこ）

```
┌──────────────────────────┐
│ 🔒 根っこ（あなただけ）     〔閉じる〕│
│ ─ 10月24日 ─              │
│ 「私、宇宙一の天才発明家」  [写真]  │ ← 言葉と写真が日付つきで並ぶ
│ 「たこ焼き食べたい。」      [写真]  │    （1ページ8つまで）
│ 〔‹ 前の日〕        〔次の日 ›〕   │
│ 〔整理する〕  〔📷 写真を撮る〕    │
│        〔ジャケットをつくる〕      │ ← 一つ選ぶと光る
└──────────────────────────┘
```

| ボタン | 押すと |
|---|---|
| 言葉・写真 | 選ぶ（もう一度押すと外れる） |
| 〔ジャケットをつくる〕 | J-3（選んだものが材料） |
| 〔📷 写真を撮る〕 | その場で撮って根っこに入れる |
| 〔整理する〕 | 各項目に✕が出る→押すと消える。〔おわる〕で戻る |
| 〔‹ 前の日〕〔次の日 ›〕 | ページをめくる（下へ流し続けない） |

- 中身は「土星でつぶやいた言葉（コロリンの文字）」と「撮った写真」。自分だけ。

### J-3 ジャケットをつくる

手順は一画面に一つ。光った所を押せば進む。

| 手順 | 画面 | ボタン |
|---|---|---|
| ① 言葉 | 根っこで選んだ言葉。選んでいない時は入力 | 〔🎙 話して入力〕〔⌨ 打つ〕〔えらぶ〕（候補3つ）〔パス〕 |
| ② 絵 | 正方形の白い台紙 | 〔写真を添える〕〔{bati}に描いてもらう〕〔字だけ〕（3つを同じ大きさで横に並べる。どれかを大きくしたり、先に光らせたりしない） |
| ③ ひとこと | 「ひとこと（なくてもOK）」 | 〔🎙〕〔⌨〕〔なし〕 |
| ④ 加工 | 5つから一つ | 〔そのまま〕〔あたたか〕〔セピア〕〔モノクロ〕〔ふんわり〕 |
| ⑤ できあがり | 正方形のジャケットが大きく出る | 〔🔒 根っこにしまう〕〔🦋 投稿する〕〔直す〕〔今日はやめる〕 |

- 〔パス〕：本人の言っていない言葉では作らない。見えたままの短い言葉を出し「あとで変えられます」。
- 〔写真を添える〕：その場で撮る／根っこから選ぶ。「人が写っている写真は、その人がいいと言ったものだけ使おう。人の顔を、勝手に描くことはしません」。
- マナを使うのは〔{bati}に描いてもらう〕だけ。押したあとに「マナを使います。いいですか？」〔使う〕〔やめる〕（数字なし）。〔やめる〕は②に戻る。
- 〔写真を添える〕〔字だけ〕はマナを使わない。マナの確認も出さない（D08-S002 のめやす「写真や字だけのジャケットは、マナを使いません」と同じ。M-R113(6)）。
- マナジェムが光らない時も、②の3つのボタンはそのまま出す。〔{bati}に描いてもらう〕を押した時だけ「マナジェムが、光らなくなった。今は、魔法は唱えられない」を出して②に戻す。〔写真を添える〕〔字だけ〕はいつでも選べる。言葉は残す。
- 一周目は絵ができたあとに〔テロップ：−3マナ〕（数は仮）。写真・字だけは減らない。
- 失敗した時：言葉は残す。「もう一回」「字だけにする」を出す。
- ③④は選ばなくても進める。
- 〔🦋 投稿する〕：一周目は薄い色で押せない。「二周目からひらきます」。
- 〔🔒 根っこにしまう〕は本人が押した時だけ。自動ではしまわない（D05-S006 で KIMORIN が、D05-S007 で{neo}が自分で押す）。押さずに閉じた時は、次に〔🥚 たまご〕を開くと、このできあがりの画面から（RESUME@D05-S007）。
- しまった時：「ジャケットを、あなただけの根っこにしまいました。誰にも送られていません」。
- 一周目の下のボタンは〔🦋 空〕〔🥚 たまご〕〔🌳 myツリー〕の三つ（J-3 を閉じると J-1 に戻る）。一周目の木星では葉は出ない（台本 D05-S008。カイザーが言葉で説明するだけ）。帰ってくると枝に葉が出るのは二周目から。

## 7. 出さないもの

- 数：葉・実・ダチ（トモダチ）・推した数・推された数・ジャケットの数、☆、見られた数、順位、人気の並び。
- 誰が推しているか・誰に〔推し〕から外されたか（知らせない）。
- 残り時間（「◯h」）：急がせないため、飛んでいる時間の残りは出さない（UIへの提案）。
- 続けた日数・ごほうび・「今日も来てね」の通知。
- 〔🔔〕：アプリの外へ呼び戻す通知はないので置かない（UIへの提案。必要なら「9.」で相談）。
- 「AI」の文字。
- 一周目の残りマナ（〔テロップ：−〇マナ〕だけ）。
- マナの確認の文の中の数字。UI向けの注記「（数字なし）」の文字そのもの。
- 物語の仲間（KIMORIN⭐︎・MIKIE⭐︎・MISAKO⭐︎）への連絡の入口（ダチにはなれるが連絡はできない）。
