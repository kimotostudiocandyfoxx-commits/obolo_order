## 1. ひとことで

**自分の曲と、自分の声（コロリン）と、自分の映像だけで、DJをする星。** 作る星ではなく、遊ぶ星です。

### 共通の決まり（金星・天王星・海王星で同じ）

- 金星・天王星・海王星では、下の三つのボタン（流れ／作る／my場所）は出しません。かわりに、星のトップ（V-1）が目次になります。行きたい所をタップすると、そこへ動きます（**案。§7の問い1**）。
- 左上はいつも〔← 宇宙の地図〕。右上は〔今日はここまで〕。
- 上のタブは、届いた作品を見る画面（V-7）にだけ出します。一周目＝なし／二周目＝〔推し〕だけ（中身はダチの作品だけ）／三周目＝〔みんな〕〔推し〕（〔推す〕を押した人の作品も〔推し〕に入る）。〔推し〕の中のダチの作品には、小さな名札の印をつけます（M-R109）。
- 届け先のボタンは〔ダチへ〕〔みんなへ〕（〔みんなへ〕は三周目から）。「へ」をつけて、上のタブとまぎれないようにします。
- 作品は押した時だけ流れます。一度に見えるのは8つまで。見終えると入れかわります。
- 数はどこにも出しません（§5）。推した数・推された数も出しません。
- 光の点滅は1秒に2回まで。
- **届ける操作の形（どの星も同じ）**：作る → 届けるボタンを押す → 行き先を確かめる。行き先は二周目＝〔ダチへ〕だけ、三周目から〔ダチへ〕〔みんなへ〕。〔ダチへ〕はダチ全員へ（一人ずつ選ぶかはJ-Q1で未定）。〔みんなへ〕の名前は、三周目のはじめ（L3-RECORDER-S001）の〔画面〕で一度だけ教える。
- **星を出る時（二周目）**：住人の「次は、〇〇だ。」→テロップ「〇〇が開いた」→〔画面〕このあとも自由にできます→選択［〇〇へ向かう／今日はここまで］。〔向かう〕でロケットが星を離れる短い動き（タップで飛ばせる）。〔今日はここまで〕は、次に開くとこの選択から。地球の出発と同じ形です。
- **KIMORINの絵**：月から先のKIMORINは、いつも丸いサングラスをかけている。目の切れ目が光る絵は、サングラスが鼻先までずり落ちるか、額に押し上げてからだけ（サングラスの上から光らせない：M-R84）。光が引いたら、かけ直す。MIKIE⭐︎・MISAKO⭐︎も同じ丸いサングラス（M-R111(2)）。
- **MIKIE⭐︎とMISAKO⭐︎の絵（M-R112・M-R113。くわしくは index.md 2.4）**：MIKIE⭐︎（KIMORINの母）は、肩までの黒髪に前髪、濃いピンクのふんわりしたブラウス、小さなペンダント、明るい柄のスカート、にこにこ顔。右手はひじから先が金色のガトリング（撃つのは紙吹雪と光の粒だけ。人には向けない）、左手は銀色のフック。右足はふだんスカートに隠れて見えない（ひざから下が銀色のドリル。出てくるのはMVの時だけ）。バティは猫のみーちゃん。MISAKO⭐︎（KIMORINの祖母）は、白い光の衣・うっすら後光・手の上に浮かぶ水晶・宙に浮く、優しい顔（本物の宗教の印は使わない）。腕・足・猫のことは、画面の文でも誰も触れない（それが笑い）。二人は住人ではなくネオの家族なので、住人の「ふざけない」決まりの外。金星で二人が出るのは、太陽のブースの窓（L3-SUN-S005b）だけ。
- **物語の仲間**：KIMORIN⭐︎・MIKIE⭐︎・MISAKO⭐︎はダチになれる（18歳未満も例外としてなれる）が、連絡はできない（M-R113(2)）。金星では、ダチのステージとして届く（V-7）だけで、返事や連絡のボタンは出さない。

### V-2 かんたんDJ（ブース）

**卓の形**：＿＿＿＿＿＿（**UIチームが一行で書く**。アプリの横長の「三つの丸」の卓〔`DjConsole.tsx`〕を物語でも使うか、この下の正方形のかんたん画面にするか。§7の問い2）

下は、正方形のかんたん画面にする場合の案です。たて持ちのまま使えます。

| 場所 | 中身 |
|---|---|
| いちばん上（約20%） | ステージの画面：いま流れている自分の映像（MVのある曲はそのMV）、または〔あかり〕の色 |
| 中（約40%） | 左の台・右の台。台はレコードの丸。台の横に、その曲の四角いジャケット。下に曲の名前だけ |
| 下・1段目 | 〔印〕　〔SYNC〕 |
| 下・2段目 | 真ん中のつまみ（横に1本。左端＝左の台、右端＝右の台） |
| 下・3段目 | 〔コロリン〕　〔あかり〕　〔映像を選ぶ〕（小さめ・控え） |

**ボタンはこれだけです。** EQ・FX・ホットキュー・ループ・テンポの数字は出しません。〔もり上げる〕〔止める〕も出しません。

| ボタン・つまみ | 押すと |
|---|---|
| 空いた台〔レコードを選ぶ〕 | V-3へ。選んだ曲が台にのる。左の台は、のせるとすぐ鳴る。〔印〕を押すと右の台が印の所から回りだし、音はつまみを動かすと聞こえる。MVのある曲は、のせるとMVが上のステージの画面に流れる |
| 台のジャケット | V-3へ（のせかえ） |
| 台の丸のふち | 押した所に小さな光の印が置かれる（鳴らしたい所） |
| 〔印〕 | 待っている方の台が、印の所から回りだす（音は、つまみを動かすと聞こえる）。スマホは音の出口が一つなので、先に聴く機能はない |
| 〔SYNC〕 | 待っている方の速さを、鳴っている方にそろえる。そろうと、二つの台のふちが同じ速さで光る |
| つまみ | 指でゆっくり右（左）へ。鳴っている方が消えて、もう一方が残る。これが「つなぐ」。MVのある曲どうしなら、映像も一緒に切り替わる |
| 〔コロリン〕 | 土星で作った自分のコロリンの声が、ひとつ落ちる（キーは2上げ）。文字で作ったコロリンはバティの声 |
| 〔あかり〕 | 映像のかわりに、光の色だけで照らす。押すたびに色が変わる。MVがない曲のための灯り |
| 〔映像を選ぶ〕 | **控えのボタン**。のせた曲のMVとは別の自分の映像に替えたい時だけ押す。V-4へ。光の案内では光らせない |

- つまみは「指で動かす」ただ一つの操作です。ほかはすべてタップです。指で引きずる操作は、これ以外に入れません。

#### 初めての日の案内（L2-VENUS-S002）：一つ言われたら、一つ触る

はじめに三択を出します：〔自分の曲と映像で、回してみる〕〔練習用のリズムで、操作だけ試す〕〔今はいい〕。〔今はいい〕はV-1にもどる（あとでいつでも回せる）。

回す二つを選んだ時は、次の五つを一つずつ進めます。**住人の一言 → 画面の一行 → 光った所を一つ触る → 次へ**、のくり返しです。手順を全部並べた表は出しません。光るのは、次に押す所だけです。

| 歩 | 住人の一言（台本） | 画面の一行（上に出す） | 光る所 |
|---|---|---|---|
| ① | ボスG「台は、二つ。左で鳴らしながら、右で次を待たせる。」 | 「①左右の台に、レコードをのせる」 | 左右の空いた台 |
| ② | ハットG「次の曲は、出だしに、印をつけておく。」 | 「②右のレコードの、鳴らしたい所を押して〔印〕」 | 右の台のふち → 〔印〕 |
| ③ | ロングG「……速さを、そろえろ。」 | 「③〔SYNC〕を押す（左右の拍がそろうと、光ります）」 | 〔SYNC〕 |
| ④ | ボスG「つまみを、ゆっくり右へ。…」 | 「④真ん中のつまみを、ゆっくり右へ」 | つまみ |
| ⑤ | ボスG「つなぎ目に、お前のコロリンを落としてもいい。」 | 「⑤つなぎ目で〔コロリン〕を押すと、自分のコロリンの声がひとつ落ちる」 | 〔コロリン〕 |

- ④と⑤のあいだに、ハットGの一言（映像も一緒に切り替わる）と、その一行「火星で映像をつけた曲は、台にのせると映像も流れ、つまみで一緒に切り替わります（映像がない曲は〔あかり〕で照らせます）」を出します。ここでは何も光らせません（触る所がないので、読んだら次へ）。
- 光った所を触るまで、次の歩には進みません。ちがう所を触っても何も起きず、責める言葉も出しません。
- 二回目からは、上の一行は出しません。光の案内だけです（〔⋯〕→〔案内を出す〕で、また出せる）。
- 入った時に一度だけ：「音が出ます。音を出せる場所か、イヤホンで遊んでください。回す・映すのに、マナは使いません」。
- 曲がない人：台に「練習用のリズム（曲ではありません）」がのる。操作だけ試せる。
- 曲が一つの人：同じ一枚を両方の台にのせられる。
- ブースで回したものは、どこにも残らず、誰にも届きません。

### V-4 映像を選ぶ（控え）

- 火星で作った自分の映像（裏スタジオ・myスタジオ）が並ぶ。〔新しい順〕〔ランダム〕。8本ずつ。
- いちばん上に〔曲のMVにもどす〕（MVのある曲の時だけ）。
- 映像がない人には「映像がなくても、〔あかり〕で照らせます」と一行。
- タップで上のステージの画面に流れる。V-2にもどる。

### V-5 ステージ（一曲回して、見せる）

L2-VENUS-S006の場面です。

| 場所 | 中身 |
|---|---|
| 上 | 夜の野外ステージの絵。足もとのライト |
| 中 | V-2と同じかんたんDJ（小さめ） |
| 下 | 〔▶ 一曲回す〕　〔🎤 見せる〕 |

- 最初に一行（台本どおり）：「一曲回して〔🎤 見せる〕を押すと、ダチだけが見られます（届け先はダチだけ）。押さなければ、音はあなたの手もとでだけ鳴り、どこにも送られません」。三周目からは「ダチだけが」を「届け先に選んだ人が」にする。
- 〔🎤 見せる〕は、一曲回し終わるまで薄い色。回し終わると光る。
- 曲がない人は〔🎤 見せる〕を薄い色のまま「自分の曲がないと、見せられません」と出す（練習用のリズムは誰かの作品ではないので見せられない）。
- 回し終わったあとに出すボタン：〔🎤 見せる〕〔もう一曲〕〔おわる〕。〔おわる〕を押すと、回したものはどこにも残りません。
- **〔🎤 見せる〕で何が届くかは、まだ決まっていません**（その場で流すのか、回した一曲を届けるのか。§7の問い3）。決まるまで、画面の文に「録画」「録る」という言葉は使いません。下のV-6は「回した一曲を届ける」場合の案です。

### V-6 行き先を確かめる

届ける操作は、どの星も同じ形にそろえます：**〔🎤 見せる〕→行き先〔ダチへ〕を確かめる**（台本 L2-VENUS-S006）。

| 順 | 画面 | ボタン |
|---|---|---|
| 1 | 行き先を確かめる。行き先〔ダチへ〕（二周目はこれだけ）。三周目からは〔ダチへ〕〔みんなへ〕から一つ選ぶ。**届くものを一行で書く**（下の案） | 〔🎤 届ける〕〔やめる〕 |
| 2 | 「届けました」。夜空へ光が一本のびる演出 | 〔金星にもどる〕 |

- 届けるのは本人が押した時だけ。最初から「届ける」にしておかない。
- 〔ダチへ〕はダチ全員へ。ダチを一人ずつ選べるようにするかは、まだ決まっていません（J-Q1。木星 `jupiter.md` と同じ問い）。選べるようにする場合は、1の行き先の下に、ダチの名札が並ぶ所（押した名札が光る）を入れる。
- 〔みんなへ〕で届けたものは、〔みんな〕と、本人を推している人の〔推し〕に入ります。数は出しません。
- 届くものの一行（**案。§7の問い3**）：「いま回した一曲（音と映像）が、88時間、夜空を流れます。88時間たつと、あなたの手もとに戻ります」。
- 届けたあと、相手が見たかどうかは出しません（既読なし）。

### V-7 夜空のステージ（届いたステージを見る）

| 場所 | 中身 |
|---|---|
| 上の帯 | タブ。二周目＝〔推し〕だけ／三周目＝〔みんな〕〔推し〕 |
| 真ん中 | 夜空に、届いたステージの光が一本ずつおりている。光の根もとに、回した人の名札 |
| 下 | 〔ほかの光を見る〕（8本が入れかわる） |

- 光をタップした時だけ、そのステージが流れる（題・回した人の名札だけ）。勝手には流れません（台本 L2-VENUS-S006「ダチのステージは、光をタップした時だけ流れます」）。
- 一度に見える光は8本まで。見終えると入れかわる。
- 〔推し〕の中のダチのステージには、名札に小さな名札の印。
- 名札の〔⋯〕：ダチでない人には〔推す〕／〔推すのをやめる〕（三周目から）、ダチには〔推しから外す〕（ダチのまま。相手には知らせない）、どちらにも〔🚩 通報する〕〔🚫 ブロックする〕。
- 数（届いた本数・見た人の数）は出しません。何も届いていない時：「まだ、届いたステージはありません」。
- 二周目のはじめ（L2-VENUS-S006）に、KIMORINのステージ『漆黒の黙示録ミックス』が一本届いている（名札『KIMORIN⭐︎』）。
- 物語の仲間（KIMORIN⭐︎・MIKIE⭐︎・MISAKO⭐︎）の名札の〔⋯〕に何を出すかは§7の問い11（案：〔推しから外す〕だけ）。連絡のボタンは出さない。

### V-8 セットリスト（三周目・寄り道）

L3-MOVER-S016の場面です。WEAVERのあとに開きます。任意で、何度でもできます。称号・フェスの申し込みの条件にはしません。

| 順 | 画面 | ボタン |
|---|---|---|
| 1 | 曲順 | 〔アルバムの曲順のまま〕〔自分で並べる〕 |
| 2 | 自分で並べる：八つの仕切りの棚。曲を押した順に1、2、3…と番号がつく。もう一度押すと番号が外れる。何曲でもよい | 〔これで決める〕〔はじめから〕 |
| 3 | 曲ごとの映像：番号の横に〔MV〕か〔あかり〕（MVのある曲は、はじめから〔MV〕） | 〔つぎへ〕 |
| 4 | 客席を選ぶ（台本どおりの二択） | 〔ゴリラの三人に見せる〕〔誰もいない客席で回す〕 |
| 5 | ステージ：かんたんDJで、曲の終わりに次の曲へつなぐ（次の曲に〔印〕→〔SYNC〕→真ん中のつまみを、次の曲の側へゆっくり）。次に押す所だけが光る。つなぎ目で〔コロリン〕も押せる | 〔今日はここまで〕はいつでも |
| 6 | 終わり | 〔地図へ戻る〕〔もう一度、組み直して流す〕 |

- 指で引きずって並べる操作はしません。押した順に番号がつく形です。
- 客席はどちらを選んでも、回したものはどこにも残らず、誰にも送られません。〔ゴリラの三人に見せる〕は、ステージの絵の客席にゴリラ三人が座るだけです（台本 L3-MOVER-S016 の〔画面〕の言い方は§7の問い13）。
- MVのない曲では、{bati}が照明卓の上で、曲が変わるたびに光の色を変える（点滅は1秒に2回まで）。
- 初回だけ、終わりに一行：「ボスG・ハットG・ロングGの声で、フィーチャリングできるようになりました｜使うかどうかは自由。作るたびに使用の確認」。
- 終わりに一行：「どこにも送られていません。いつでも［今日はここまで］で終われます。」

## 7. まだ決まっていないこと（問い）

1. **下の三つのボタン**：金星・天王星・海王星では出さず、星のトップを目次にする案でよいか。（おすすめ：この案。流れ／作る／my場所は木星・水星・火星の決まりなので）
2. **卓の形**：アプリの横長の「三つの丸」の卓（`DjConsole.tsx`）を物語でも使うか、この文書の正方形のかんたん画面にするか。**UIチームが決めて、V-2のいちばん上の欄に一行で書く。** どちらでも、物語の中で見せるボタンは〔印〕〔SYNC〕つまみ〔コロリン〕〔あかり〕〔映像を選ぶ〕だけにする。
3. **〔🎤 見せる〕で何が届くか（まだ決まっていない）**：その場で流すのか、回した一曲を届けるのか。おすすめは「回した一曲を88時間届け、88時間たつと自分の手もとに戻る」（ほかの作品と同じ88時間の決まり）。決まるまで、画面の文に「録画」「録る」は使わない。戻った記録を置く場所（例：V-1に〔📼 自分のステージ〕）もあわせて決める。決まったら、V-6の確認画面に一行で書く。
4. **ダチを一人ずつ選ぶか（J-Q1・まだ決まっていない）**：〔ダチへ〕はダチ全員へ、の案。一人ずつ選べるようにするかは、木星・水星・火星と一緒に決める。
5. **どのコロリンを落とすか**：コロリンが何個もある人。おすすめ：いちばん新しいもの。〔コロリン〕の横の小さな〔⋯〕で選び直せる。
6. **〔くわしい卓〕**：実アプリにある本格的な卓（横画面・EQ・ホットキューなど）を、物語の外で出すか。物語の中では出さない。
7. **〔🌠 夜空のステージ〕の名前**：台本は「ダチのステージ」と呼ぶ。三周目から推した人のステージも入るので、この名前でよいか。
8. **88分を過ぎた時**：一曲の途中なら、その曲の終わりまで鳴らしてから止める案でよいか。〔🎤 見せる〕の送信の途中では止めない。
9. **星ぜんたいが曲の速さで回る演出**：重すぎる場合は、ステージの絵の床だけ回す形でもよい。
10. **太陽の光の案内の「→映像」**：解決（R3：台本 L3-SUN-S005b から「→映像」を外した）。画面でも映像は光らせない（MVは台にのせると流れ、つまみで一緒に切り替わる）。
11. **物語の仲間の名札の〔⋯〕（V-7）**：KIMORIN⭐︎・MIKIE⭐︎・MISAKO⭐︎のステージの名札に、〔🚩 通報する〕〔🚫 ブロックする〕を出すか。おすすめ：〔推しから外す〕だけを出す（運営が用意した物語の人物なので）。
12. **〔みんなへ〕と18歳未満**（index.md 4.2 と同じ問い）：18歳未満の人が〔みんなへ〕で届けたステージを、知らない人の〔みんな〕にどこまで出すか。決まるまで、V-6の言葉は変えない。
13. **台本の「録画」（台本係へ）**：L3-MOVER-S016 と L3-SUN-S005b の〔画面〕に「録画も公開もされません」が残っている。問い3が決まるまでは、L2-REST-S007（R4）と同じく「どこにも残らず、送られません」の形にそろえるか。
