## 1. ひとことで

**自分の曲と、自分の声（コロリン）と、自分の映像だけで、DJをする星。** 作る星ではなく、遊ぶ星です。

### 共通の決まり（三つの星で同じ）

- 金星・天王星・海王星では、下の三つのボタン（流れ／作る／my場所）は出しません。かわりに、星のトップ（V-1）が目次になります。行きたい所をタップすると、そこへ動きます（**案。§7の問い1**）。
- 左上はいつも〔← 宇宙の地図〕。右上は〔今日はここまで〕。
- 数はどこにも出しません（§5）。
- 光の点滅は1秒に2回まで。

|---|---|---|

### V-2 かんたんDJ（ブース）

正方形の画面に収めます。たて持ちのまま使えます。

| 場所 | 中身 |
|---|---|
| いちばん上（約20%） | ステージの画面：いま映っている自分の映像、または〔あかり〕の色 |
| 中（約40%） | 左の台・右の台。台はレコードの丸。台の横に、その曲の四角いジャケット。下に曲の名前だけ |
| 下・1段目 | 〔印〕　〔SYNC〕 |
| 下・2段目 | 真ん中のつまみ（横に1本。左端＝左の台、右端＝右の台） |
| 下・3段目 | 〔コロリン〕　〔映像を選ぶ〕　〔あかり〕 |

**ボタンはこれだけです。** EQ・FX・ホットキュー・ループ・テンポの数字は出しません。〔もり上げる〕〔止める〕も出しません。

| ボタン・つまみ | 押すと |
|---|---|
| 空いた台〔レコードを選ぶ〕 | V-3へ。選んだ曲が台にのる |
| 台のジャケット | V-3へ（のせかえ） |
| 台の丸のふち | 押した所に小さな光の印が置かれる（鳴らしたい所） |
| 〔印〕 | 待っている方の台が、印の所から鳴る。スマホは音の出口が一つなので、先に聴く機能はない |
| 〔SYNC〕 | 待っている方の速さを、鳴っている方にそろえる。そろうと、二つの台のふちが同じ速さで光る |
| つまみ | 指でゆっくり右（左）へ。鳴っている方が消えて、もう一方が残る。これが「つなぐ」 |
| 〔コロリン〕 | 土星で作った自分のコロリンの声が、ひとつ落ちる（キーは2上げ）。文字で作ったコロリンはバティの声 |
| 〔映像を選ぶ〕 | V-4へ。選んだ映像が上のステージの画面に流れる。もう一度押すと、次の映像に切り替える |
| 〔あかり〕 | 映像のかわりに、光の色だけで照らす。押すたびに色が変わる |

- つまみは「指で動かす」ただ一つの操作です。ほかはすべてタップです。指で引きずる操作は、これ以外に入れません。
- 手順は光で案内します。**次に押す所だけが光ります**（台に曲をのせる→〔印〕→〔SYNC〕→つまみ→〔コロリン〕→〔映像を選ぶ〕）。
- 初めての日（L2-VENUS-S002）だけ、上に一行の案内を出します。出すのは**いまの一歩だけ**です（例：「②右のレコードの、鳴らしたい所を押して〔印〕」）。手順を全部並べた表は出しません。二回目からは光だけです。
- 入った時に一度だけ：「音が出ます。音を出せる場所か、イヤホンで遊んでください。回す・映すのに、マナは使いません」。
- 曲がない人：台に「練習用のリズム（曲ではありません）」がのる。操作だけ試せる。
- 曲が一つの人：同じ一枚を両方の台にのせられる。
- ブースで回したものは、どこにも残らず、誰にも届きません。

### V-3 レコードを選ぶ

| 場所 | 中身 |
|---|---|
| 上 | 並び替え：〔新しい順〕〔ランダム〕 |
| 中 | 自分の曲の四角いジャケットが並ぶ（水星の土の中の曲・出航した曲・アルバムの曲）。一度に見えるのは8枚まで。〔つぎの8枚〕で入れかわる（下へずっと続く一覧にしない） |
| 下 | 〔練習用のリズム〕（曲がない人には最初から光る） |

- タップでその台にのる。V-2にもどる。
- 並ぶのは**自分の曲と練習用のリズムだけ**。ほかの人の曲は並びません。端末の音声ファイルも、物語の中では出しません。

### V-4 映像を選ぶ

- 火星で作った自分の映像（裏スタジオ・myスタジオ）が並ぶ。〔新しい順〕〔ランダム〕。8本ずつ。
- 映像がない人には「映像がなくても、〔あかり〕で照らせます」と一行。
- タップで上のステージの画面に流れる。V-2にもどる。

### V-5 ステージ（一曲回して、見せる）

L2-VENUS-S006の場面です。

| 場所 | 中身 |
|---|---|
| 上 | 夜の野外ステージの絵。足もとのライト |
| 中 | V-2と同じかんたんDJ（小さめ） |
| 下 | 〔▶ 一曲回す〕　〔🎤 見せる〕 |

- 最初に一行：「一曲回して〔🎤 見せる〕を押すと、ダチだけが見られます。押さなければ、音はあなたの手もとでだけ鳴り、どこにも送られません」。
- 〔🎤 見せる〕は、一曲回し終わるまで薄い色。回し終わると光る。
- 曲がない人は〔🎤 見せる〕を薄い色のまま「自分の曲がないと、見せられません」と出す（練習用のリズムは誰かの作品ではないので見せられない）。
- 回し終わったあとに出すボタン：〔🎤 見せる〕〔もう一曲〕〔おわる〕。〔おわる〕を押すと、録ったものは消えます。

### V-6 見せる先を選ぶ・確認

| 順 | 画面 | ボタン |
|---|---|---|
| 1 | ダチの名札が並ぶ。タップで選ぶ（選んだ名札が光る。何人でも） | 〔つぎへ〕〔やめる〕 |
| 2 | 確認。**届くものを一行で書く**（下の案） | 〔送る〕〔もどる〕 |
| 3 | 「届けました」。夜空へ光が一本のびる演出 | 〔金星にもどる〕 |

- 届くものの一行（**案。§7の問い2**）：「いま回した一曲（音と映像）が、選んだダチに88時間届きます。88時間たつと、あなたの手もとに戻ります」。
- 二周目の届け先はダチだけ。〔みんな〕〔フォロー〕は出しません。
- 届けたあと、相手が見たかどうかは出しません（既読なし）。

### V-7 ダチのステージ

- 夜空に、ダチから届いたステージの光が、一本ずつおりている。
- 光をタップした時だけ、そのステージが流れる（題・回した人の名札だけ）。勝手には流れません。
- 一度に見える光は8本まで。見たら入れかわる。
- 数（届いた本数・見た人の数）は出しません。
- 二周目のはじめ（L2-VENUS-S006）に、KIMORINのステージ『漆黒の黙示録ミックス』が一本届いている。

### V-8 セットリスト（三周目・寄り道）

L3-MOVER-S016の場面です。WEAVERのあとに開きます。任意で、何度でもできます。称号・フェスの申し込みの条件にはしません。

| 順 | 画面 | ボタン |
|---|---|---|
| 1 | 曲順 | 〔アルバムの曲順のまま〕〔自分で並べる〕 |
| 2 | 自分で並べる：八つの仕切りの棚。曲を押した順に1、2、3…と番号がつく。もう一度押すと番号が外れる。何曲でもよい | 〔これで決める〕〔はじめから〕 |
| 3 | 曲ごとの映像：番号の横に〔MV〕か〔あかり〕 | 〔つぎへ〕 |
| 4 | 誰に見せるか（台本の三択。§7の問い6） | 三つのボタン |
| 5 | ステージ：かんたんDJで、曲の終わりに次の曲へつなぐ。光った所を押すだけ | 〔今日はここまで〕はいつでも |
| 6 | 終わり | 〔地図へ戻る〕〔もう一度、組み直して流す〕 |

- 指で引きずって並べる操作はしません。押した順に番号がつく形です。
- 初回だけ、終わりに一行：「ボスG・ハットG・ロングGの声で、フィーチャリングできるようになりました｜使うかどうかは自由。作るたびに使用の確認」。
- 録画も公開もしません。「どこにも送られていません」と一行出します。

## 5. 出さないもの

| 出さないもの | 理由・かわり |
|---|---|
| 観客の数・再生数・見た人の数・届いた本数 | 数で人をはからない。かわりに光や星の回転だけ |
| 点数・順位・「うまい」の判定 | 遊ぶ星なので、うまい下手を決めない |
| BPM・テンポの％・キーの数字 | かんたんDJには数字を出さない |
| マナの数字 | 一周目のテロップだけ（M-R75）。金星はマナを使わない |
| 〔もり上げる〕〔止める〕 | 意味が分かりにくい。台本から外した |
| 「ヘッドホンで先に聴く」・🎧の先聴き | スマホは音の出口が一つ。〔印〕を押すとそこから鳴る |
| 🎙のマーク | 声で入力する印。コロリンのボタンには使わない |
| ほかの人の曲・端末の音声ファイル | 物語の台は自分の曲と練習用のリズムだけ |
| EQ・FX・ホットキュー・ループ | 物語の中では出さない（§7の問い5） |
| 88分の残り時間のカウントダウン | 出さない。途中で止める時は、曲の切れ目まで待つ（§7の問い7） |
| 「AI」という言葉 | 使わない |

## 7. まだ決まっていないこと（問い）

1. **下の三つのボタン**：金星・天王星・海王星では出さず、星のトップを目次にする案でよいか。（おすすめ：この案。流れ／作る／my場所は木星・水星・火星の決まりなので）
2. **〔🎤 見せる〕で何が届くか**：UIで決めて、V-6の確認画面に一行で書く。おすすめは「回した一曲を録って、選んだダチに88時間届け、88時間たつと自分の手もとに戻る」（ほかの作品と同じ88時間の決まり）。戻った記録を置く場所（例：V-1に〔📼 自分のステージ〕）もあわせて決める。
3. **三周目の見せる相手**：〔🎤 見せる〕とV-7に〔みんな〕〔フォロー〕を足すか。おすすめ：共通の上のタブに合わせて三周目から足す（海王星のゲームも三周目は「みんな／フォロー／ダチ」）。
4. **どのコロリンを落とすか**：コロリンが何個もある人。おすすめ：いちばん新しいもの。〔コロリン〕の横の小さな〔⋯〕で選び直せる。
5. **〔くわしい卓〕**：実アプリにある本格的な卓（横画面・EQ・ホットキューなど）を、物語の外で出すか。物語の中では出さない。
6. **セットリストの見せる相手**：台本の三択「誰もいない夜／ここにいる三人にだけ／自分だけ」の「誰もいない夜」と「自分だけ」の違いが画面では分からない。台本係に確かめる（おすすめ：二択「ゴリラ三人にだけ／自分だけ」）。
7. **88分を過ぎた時**：一曲の途中なら、その曲の終わりまで鳴らしてから止める案でよいか。〔🎤 見せる〕の送信の途中では止めない。
8. **台本の言葉のずれ（台本係へ）**：L2-REST-S007のvjの〔流す〕〔切り替える〕と、L3-MOVER-S016の〔つなぐ〕〔流す〕は、かんたんDJのボタン（〔印〕〔SYNC〕〔コロリン〕〔映像を選ぶ〕〔あかり〕とつまみ）にない。画面はこの文書のボタンで作り、台本の言葉を合わせてもらう。
9. **星ぜんたいが曲の速さで回る演出**：重すぎる場合は、ステージの絵の床だけ回す形でもよい。
