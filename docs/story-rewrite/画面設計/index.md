## 2. どの星でも同じ決まり

### 2.1 画面の形とボタン

| 決まり | 中身 |
|---|---|
| 画面は正方形 | 上の帯（タブ）／真ん中（絵）／下の帯（ボタン）の三段 |
| 下のボタンは3つ（作る星） | 左＝流れ（🦋 空／🗺️ 海図／✨ 星図／🪐 空）、真ん中＝作る（🥚 たまご／♫+ 作曲／🎥 撮影／🎙 つぶやく）、右＝my場所（🌳 myツリー／🏝️ myアイランド／🎬 myスタジオ／🏠 自分の部屋） |
| 一周目のmy場所 | 木星・水星・火星は「空き地（二周目で作れます）」。土星だけ一周目から自分の部屋がある |
| 作る星でない所 | 地球・月・金星・天王星・海王星は、下の3ボタンを出さず、一枚の絵を目次にする（各文書の問い） |
| 上のタブ | 一周目＝なし／二周目＝〔ダチ〕／三周目＝〔ダチ〕〔みんな〕〔フォロー〕 |
| 届けるボタン | 開くまで薄い色で、下に「二周目からひらきます」（火星も〔🛸 公開する〕で同じ） |
| 自分だけにしまう | 『🔒 ◯◯にしまう』でそろえる（土星の〔自分の部屋に飛ばす〕だけ確定稿のまま。`saturn.md` 問い6） |
| 模様替え | 『◯◯を飾る』でそろえる |
| 並べる操作 | 指で引きずらない。押した順に 1・2・3 と番号がつく（曲順・撮影予定・話をつなぐ） |
| 🎙 | 声で入れる印。声の入力のボタンにだけ使う（コロリンを落とすボタンには使わない） |
| 点滅 | 1秒に2回まで |
| 安全 | ほかの人の作品・名札の〔⋯〕から〔🚩 通報する〕〔🚫 ブロックする〕。ブロックは相手に知らせない |

### 2.2 出さないもの

| 出さないもの | かわり |
|---|---|
| 人気の数（いいね・☆・フォロワー・再生・Loops・Stars・順位・人数・「今N人が航海中・ライブ中」） | どこにも出さない。フォローしても数は出ない |
| 作品・葉・実・コロリン・ダチの数 | 並んでいるだけ |
| 人気順の並び | 並びは「新しい順」と「ランダム」だけ |
| 未読の数・既読 | 未読は点だけ |
| 88分のカウントダウン・残り時間・残り日数 | 出さない。生成・保存・支払いの途中では止めない。閉じている間の生成は88分に数えない |
| マナの数字（二周目から） | 一周目だけ〔テロップ：−〇マナ〕（M-R75。数は仮でUIチャットが決める）。残りのマナは出さない。言葉は「マナ」（「力」「MANA」は使わない） |
| 「AI」という言葉 | 「{bati}の魔法」「バティに聞く」など |
| 外への引き戻す知らせ・赤い点・バッジ・連続記録・ごほうび | 置かない。手紙やフェスの知らせは、いつもの丸でバティが一回だけ |
| 下へ流し続ける画面 | 出るのは押した時だけ。見終えたものは入れかわる |

### 2.3 時間とお金

| 決まり | 中身 |
|---|---|
| 1日88分 | 毎日、その日の最初のロケットから数える。地球の本部と月の神殿は数えない（SYS-S001） |
| 88時間 | 届けたものは88時間めぐって、自分の場所に戻る。すぐには戻らない |
| 作らない日 | どの画面にも〔閉じる〕か〔今日は作らない〕。作らなくても先へ進める |
| 買う・払う | いつも物語の外の買う画面。キャラクターはすすめない |

### 2.4 人の決まり（画面の言葉にもかかわる）

| 決まり | 中身 |
|---|---|
| 住人と世界はふざけない | 住人の説明・住人の見本の作品はまじめ。笑いはKIMORIN（M-R106） |
| バティは必要な時だけ喋る | 魔法を唱える時・ユーザーに聞く時・どうしても必要な時だけ（M-R73）。説明は〔画面〕の一行で |
| 呼び名 | OBOLON は大文字。obolo は小文字。Obolo Order・Obolo Neo は頭だけ大文字。「ORDER」だけで呼ばない（M-R104）。人の白い丸い場所は「プラネット」（M-R98）。スカウトは「エージェント」（M-R96） |

## 3. 周回の流れ（画面がひらく順）

| 時 | ひらくもの |
|---|---|
| 一周目（1〜7日目） | 月（姿・名前・バティ）→土星（コロリン・自分の部屋）→木星（ジャケット）→水星（曲）→火星（MV）→地球（エクリプス）。届けるボタンは薄い色 |
| 二周目 | 月（バティに聞く・水盤）→土星（ダチの部屋・〔ダチに届ける〕・〔招待状〕〔名前で探す〕）→木星→水星→火星（my場所ができる）→金星（かんたんDJ）→天王星（アトリエ）→海王星（ゲーム）→地球（証・謎3・連絡室） |
| 星休め | 各星で自由に。土星の広場は予告だけ |
| 三周目 | 「みんな」「フォロー」が開く。金色の招待状と持ちもの六つ→RECORDERから、好きな順に章。準備ごとにプラネットの布が外れる。WEAVERのあと太陽への門 |
| 物語のあと | 天王星の野原が町obolo（フェスは年に一回88日間、ほかは町の静かな季節）。手紙（キモリン・金色・白・銀色・海王星の板）。エージェントの机（選ばれた人だけ） |
