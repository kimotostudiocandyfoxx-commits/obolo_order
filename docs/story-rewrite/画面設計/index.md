### 0.6 声が主役、文字は非常口（M-R130）

このアプリは「喋っているだけで、曲・ジャケット・映像ができる」。全部の星の入力の画面を、土星のつぶやき（D04-S005・saturn.md S-2）の形にそろえる。

```
┌──────────────────────────┐
│ 撮りたい場面を話してみよう   〔閉じる〕│
│                                  │
│      ┌────────────┐          │
│      │ 〔🎙 話してみよう〕 │（大きく）│
│      └────────────┘          │
│   例「…」（小さな字）                 │
│   〔おまかせ〕〔パス〕（小さく）  ⌨（すみ）│
└──────────────────────────┘
```

| 決まり | 中身 |
|---|---|
| まん中 | 大きなマイクのボタン〔🎙 話してみよう〕だけを主役に置く。例は小さな字で添える。マイクは押した時だけ動く |
| 〔⌨ 打つ〕〔えらぶ〕 | 主役の並びから外す。すみに小さな⌨を一つだけ（「声が出せない時だけ」）。押すと文字の入力と、前の選ぶボタン（例のボタン）が出る |
| はじめて⌨を押した時 | 一度だけ「声が出せる場所で、また来てね。ここは、声で作る宇宙です」（D03-S004。そのまま⌨で進んでもよい）。2日目以降に開いた時の小さな案内として残す（M-R131） |
| 〔おまかせ〕〔パス〕 | 残す（何も思いつかなくても作れる道）。主役の下に小さく |
| 名前 | {neo}・バティの名前は文字の入力のまま（M-R130）。島の名前・枝の札・題名など「名前」の欄は〔🎙〕で言うと字になる形を先にし、⌨でも同じ扱い |
| 住人の台詞 | 「話してみろ」「声で言ってみて」にそろえる（「打っても、選んでもいい」とは言わない）。台本は第21稿でそろえた |
| 締め出さない | 「喋らないと一歩も進めない」まではしない（話すことが難しい人・耳が聞こえにくい人のため。マイクの権限を無理に求めない：アプリストアの審査） |
| 手数 | 話す→すぐできあがる→もう一回、までの手数を減らす（「簡単・できそう・もっと作りたい」） |
