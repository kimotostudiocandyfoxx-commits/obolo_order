## 2. どの星でも同じ決まり

### 2.1 画面の形とボタン

| 決まり | 中身 |
|---|---|
| 画面は正方形 | 上の帯（タブ）／真ん中（絵）／下の帯（ボタン）の三段 |
| 下のボタンは3つ（作る星） | 左＝流れ（🦋 空／🗺️ 海図／✨ 星図／🪐 空）、真ん中＝作る（🥚 たまご／♫+ 作曲／🎥 撮影／🎙 つぶやく）、右＝my場所（🌳 myツリー／🏝️ myアイランド／🎬 myスタジオ／🏠 自分の部屋） |
| 一周目のmy場所 | 木星・水星・火星は「空き地（二周目で作れます）」。土星だけ一周目から自分の部屋がある |
| 作る星でない所 | 地球・月・金星・天王星・海王星は、下の3ボタンを出さず、一枚の絵を目次にする（各文書の問い） |
| 上のタブ | 一周目＝なし／二周目＝〔推し〕（中身はダチの作品だけ）／三周目＝〔みんな〕〔推し〕（推した人の作品も〔推し〕に入る。ダチの作品には小さな名札の印）。タブの名前は変わらず中身が広がる（M-R109） |
| 推す | 名札の〔推す〕〔推すのをやめる〕（三周目から・ダチでない人。前の〔フォローする〕）。ダチは自動で〔推し〕に入り、名札の〔⋯〕→〔推しから外す〕でダチのまま外せる（相手に知らせない）（M-R109） |
| 推すの考え方 | このアプリはDJになるソフト。ダチの曲も知らない誰かの曲も、同じ一つの作品として「推す」。ダチの作品を推すのは、ダチのアーティスト活動を応援すること（M-R109）。上のタブの名前に〔ダチ〕〔フォロー〕は使わない。タブでない所の〔ダチの曲を聴く〕〔ダチのアトリエ〕などはそのまま |
| 届け先のボタン | 〔ダチへ〕（二周目から）／〔みんなへ〕（三周目から）。「へ」をつけて、上のタブとまぎれないようにする。〔みんなへ〕で届けたものは、〔みんな〕と、本人を推している人の〔推し〕に入る。ダチを一人ずつ選ぶかは未決定（4.2 J-Q1）。決まるまでは〔ダチへ〕でダチ全員へ |
| 作品が流れる形 | 押した時だけ流れる。一度に8つまで。見終えると入れかわる。下へ流し続けない |
| ダチだけのもの | 連絡室（メール・電話）と、プラネットの中に来られるのはダチだけ。推しているだけの人は入れない。〔推し〕から外しても、ダチのつながりはそのまま |
| ダチの安全 | 知らない人の申しこみに『承認しなくてかまいません。断っても、相手には知らせません』〔承認する〕〔断る〕。〔名前で探す〕は18歳から（18歳未満は結果にも出ない。見つからない時の文は年齢に関係なく同じ）。招待状ならつながる。連絡はダチごとのランプ2つ（M-R108(3)。earth.md E-3・E-7） |
| 届けるボタン | 開くまで薄い色で、下に「二周目からひらきます」（火星も〔🛸 公開する〕で同じ） |
| 自分だけにしまう | 『🔒 ◯◯にしまう』でそろえる（土星の〔自分の部屋に飛ばす〕だけ確定稿のまま。`saturn.md` 問い5） |
| 模様替え | 『◯◯を飾る』でそろえる |
| 並べる操作 | 指で引きずらない。押した順に 1・2・3 と番号がつく（曲順・撮影予定・話をつなぐ） |
| 🎙 | 声で入れる印。声の入力のボタンにだけ使う（コロリンを落とすボタンには使わない） |
| 点滅 | 1秒に2回まで |
| 安全 | ほかの人の作品・名札の〔⋯〕から〔🚩 通報する〕〔🚫 ブロックする〕。ブロックは相手に知らせない |

### 2.2 出さないもの

| 出さないもの | かわり |
|---|---|
| 人気の数（いいね・☆・フォロワー・再生・Loops・Stars・順位・人数・「今N人が航海中・ライブ中」） | どこにも出さない。推しても数は出ない（推した数・推された数も出さない） |
| 作品・葉・実・コロリン・ダチの数 | 並んでいるだけ |
| 人気順の並び | 並びは「新しい順」と「ランダム」だけ |
| 未読の数・既読 | 未読は点だけ |
| 88分のカウントダウン・残り時間・残り日数 | 出さない。生成・保存・支払いの途中では止めない。閉じている間の生成は88分に数えない |
| マナの数字（二周目から） | 一周目だけ〔テロップ：−〇マナ〕（M-R75。数は仮でUIチャットが決める）。残りのマナは出さない。言葉は「マナ」（「力」「MANA」は使わない） |
| 「AI」という言葉 | 「{bati}の魔法」「バティに聞く」など |
| 外への引き戻す知らせ・赤い点・バッジ・連続記録・ごほうび | 置かない。手紙やフェスの知らせは、いつもの丸でバティが一回だけ。手紙の届く場所は手紙入れ一つ（『郵便受け』は使わない） |
| 「銀行」という言葉 | 収入の場所は〔お財布〕（地球のお財布。M-R108(5)） |
| 下へ流し続ける画面 | 出るのは押した時だけ。見終えたものは入れかわる |

### 2.5 星ごとの要点（R2の申し送り。くわしくは各文書）

| 星 | 要点 |
|---|---|
| 地球 | 連絡室はダチの名札とランプ2つ。〔連絡OK〕・〔連絡の許可を申しこむ〕→『許可待ち』・〔許可する〕〔今はしない〕。〔名前で探す〕は18歳から。収入は〔お財布〕。エージェントに選ぶ決め方は運営の中だけで、数・順位を出さない |

| 土星 | 二周目の〔推し〕＝ダチのコロリンが舞う場所（前のダチの部屋）。三周目は推した人のコロリンも同じ輪に（フォローの輪はなくした）。☆・返事・残り時間は出さない |
| 木星 | ジャケットは正方形。二周目は〔推し〕の空を88時間飛んで、myツリーの枝に戻る。三周目の〔みんな〕がみんなのジャケットの入口 |
| 水星 | 作ったらすぐ〔🔒 土の中にしまう〕を押す（自動ではしまわない）。船はダチの海を88時間めぐり、myアイランドの桟橋に戻る。三周目の〔技の島めぐり〕は授業の場面だけ。ふだんの曲探しは海図の船だけ |
| 火星 | 撮る順は〔🎥 撮影〕→話す→種類→曲（MVのとき）→シーン3つ→確認。一周目のmyスタジオは空き地と〔🔒 裏スタジオ〕の扉だけ |
| 金星 | 次に押す所だけ光る：台→〔印〕→〔SYNC〕→つまみ→〔コロリン〕。MVは台にのせると流れ、つまみで切り替わる。〔映像を選ぶ〕は控え。卓の形はUIチームが一行で書く |
| 天王星 | 〔つくる〕は形→絵→ハンドル→〔自分のアトリエに飾る〕を一手ずつ。ダチのアトリエの入口は〔ダチのアトリエ〕の札。obolo商店は売れた数を出さない |
| 海王星 | 見せる相手は〔みんな〕〔ダチだけ〕〔自分だけ〕。点数・時間の制限・遊んだ数は出さない |
| フェスの町 | プラネットの中はダチだけ。町のDJブースは金星と同じ操作。チケット・くじ・また来年は物語の外の案内ページだけ |

## 3. 周回の流れ（画面がひらく順）

| 時 | ひらくもの |
