# 地球 画面設計（UIチーム向け）

- 版：第20稿（ループ見直し R4）・2026-10-26
- R4で変えたこと：物語の仲間（KIMORIN⭐︎・MIKIE⭐︎・MISAKO⭐︎）はダチになれるが連絡はできない（M-R113(2)）。連絡室の名札はランプなし・選べない、「物語の仲間の名札には、連絡できません」、18歳未満の〔名前で探す〕は灰色で新しい一行。〔お財布〕に、毎月88円とobolo商店の受け取り先登録の保護者の同意（M-R113(1)）と、obolo商店の取り分も〔お財布〕に出ることを足した。
- R4（見直し2）で変えたこと：〔お財布〕を、エージェントの収入とobolo商店の取り分を一か所に出す画面にし、入口をエージェントの机だけでなく本部の広間の〔👛 お財布〕にも置いた（案。§10 問い7）。設定に〔毎月のマナ〕→〔やめる〕を書いた（台本 D08-S006 のやめ方「〔設定〕→〔毎月のマナ〕→〔やめる〕」と同じ三手）。物語の仲間の名札に MISAKO⭐︎（L3-WEAVER-S006）を足し、名札を押した時の動きを書いた。18歳未満の〔名前で探す〕を、土星（`saturn.md` S-6）と同じく灰色のボタン＋押すと一行にそろえた。
- R3で変えたこと：18歳未満のマナジェムの購入は保護者の同意（M-R111(3)）。〔名前で探す〕のボタンを〔ダチを申しこむ〕に（相手が承認するとダチ）。知らない人の申しこみを断ってよい一行を、〔名前で探す〕の最初の画面にも出す（台本 L2-RETURN-S008 の search の枝）。連絡室の名札に、火星（L2-MARS-S001）でダチになった人の『ダチ　MIKIE⭐︎』を足し、名札の顔の絵（丸いサングラス。M-R111(2)）を書いた。二周目の星と星のあいだの［〈次の星〉へ向かう／今日はここまで］を §8 に書いた。
- R2で変えたこと：M-R108(3)(5)とM-R109を反映。連絡室のランプ2つと〔連絡OK〕〔連絡の許可を申しこむ〕『許可待ち』〔許可する〕〔今はしない〕の画面を、台本 L2-RETURN-S008 の文にそろえた。〔名前で探す〕は18歳未満の人の画面ではボタンの代わりに一行。収入の場所は〔お財布〕。名札の〔⋯〕に〔推しから外す〕。§10の問い1〜3を決定にした。
- もとにしたもの：今の台本（parts/P05・P09・P10・P11・P14・EX）、利用者の決定 M-R1〜M-R113、レビューの申し送り、アプリの `docs/earth-comms.md`・`docs/spec.md` 2.1
- 渡す先：アプリ（ブランチ `claude/solar-system-home-planets-ew766y`）を作るUIチーム
- あつかう範囲：二周目からの地球（本部・連絡室・手紙入れ・エージェントの机・収入・設定）。1〜3日目の門・神殿・マナジェム・切符は確定稿のまま（この文書では変えない）。
- 書き方：〔 〕はボタンの文字（このとおりに出す）。「 」は画面に出す一行の文。

画面は正方形。上の帯（場所の名前）／真ん中（絵）／下の帯（ボタン）の三段。
地球には「流れ・作る・my場所」の下の3ボタンは出さない（作る星ではないため）。

### E-2 連絡室（交換台）

```
┌──────────────────────────┐
│ 連絡室                     〔閉じる〕│
│  ┌名札┐ ┌名札┐ ┌名札┐          │
│  │KIMORIN│ │{inviter}│ │名前│      │
│  │ ●  ● │ │ ●  ○ │ │ ○  ○ │      │ ← ランプ2つ
│  └────┘ └────┘ └────┘          │    左＝自分の許可／右＝相手の許可
│      [机：✉ 招待状　🔍 名前で探す]  │
└──────────────────────────┘
```

- 壁一面の古い交換台。灯っているのは、ダチの名札だけ。空いた差し込み口は飾り（数は読めない）。
- 名札は「ダチ　@名前」だけ。並びは、ダチになった順（新しい順）。
- 最初に並ぶ名札は『ダチ　KIMORIN⭐︎』『ダチ　{inviter}』。火星（L2-MARS-S001）でMIKIE⭐︎とダチになった人は『ダチ　MIKIE⭐︎』も並ぶ（L2-RETURN-S008）。三周目の桟橋（L3-WEAVER-S006）でMISAKO⭐︎とダチになった人は『ダチ　MISAKO⭐︎』も並ぶ。
- 名札の顔の絵：KIMORIN⭐︎は白い狐の顔に丸いサングラス（月から先はいつもかけている）。MIKIE⭐︎は肩までの黒髪に前髪、濃いピンク（マゼンタ）のブラウス、KIMORINと同じ丸いサングラス（目元のモザイクは使わない。M-R111(2)）。MISAKO⭐︎は白い光の衣とうっすら後光、丸いサングラス（本物の宗教の印は使わない）。名札は顔だけなので、MIKIE⭐︎の腕・足やMISAKO⭐︎の水晶は描かなくてよい。
- **物語の仲間（KIMORIN⭐︎・MIKIE⭐︎・MISAKO⭐︎）の名札**：並ぶが、ランプがなく、選べない（押しても E-3 は開かない）。物語の仲間の名札が並ぶ列の下に、いつも一行「物語の仲間の名札には、連絡できません」（L2-RETURN-S008）。18歳未満でも物語の仲間とはダチになれる（M-R113(2)）。〔推しから外す〕は土星のダチの一覧（`saturn.md` S-6）の〔⋯〕から。
- 18歳未満には机の〔🔍 名前で探す〕を灰色で出し、押すと一行「〔名前で探す〕は18歳から使えます。ダチになれるのは、〔招待状〕でつながった人と、物語の仲間（KIMORIN⭐︎たち）です」（L2-RETURN-S008 の search の枝。土星 S-6 も同じ形）。
- **ランプ2つ＝両方の許可**。両方点いた名札だけ、メール・電話ができる。
- 未読のメールがある名札の角に、小さな点が一つ（数は出さない）。

| もの・ボタン | 押すと |
|---|---|
| 名札 | E-3 名札のメニュー |
| 机の〔✉ 招待状〕 | E-7（招待状の下書き・贈る手続き） |
| 机の〔🔍 名前で探す〕 | E-7（名前で探して、ダチを申しこむ。相手が承認するとダチ） |
| 〔閉じる〕 | E-1 |

### E-3 名札のメニュー

名札を押すと、名札が大きくなり、ランプ2つと〔連絡OK〕が出る。

```
┌──────────────────────────┐
│ ダチ　@名前                   〔⋯〕│
│   自分 ●　　相手 ○                 │ ← ランプ2つ
│   〔連絡OK〕（自分のランプを点ける・消す）│
│   （ここに状態ごとのボタン）          │
│                          〔やめる〕│
└──────────────────────────┘
```

| ボタン | 押すと |
|---|---|
| 〔連絡OK〕 | 自分の側のランプが点く。もう一度押すと消える。消しても相手には知らせない（L2-RETURN-S008） |

| 状態 | 出す一行とボタン |
|---|---|
| ランプが両方点いている | 〔✉️ メールを書く〕〔📞 電話をかける〕（第2段階から）〔やめる〕 |
| 片方だけ／両方消えている（申しこんでいない） | 「いまは連絡できません」〔連絡の許可を申しこむ〕〔やめる〕。一行「相手も許可すると、連絡できます」 |
| 申しこんで返事待ち | 名札の横に小さな札『許可待ち』。〔やめる〕だけ（催促のボタンは出さない） |
| 相手から申しこみが来ている | 名札が小さく光る。「〈名前〉から、連絡の許可の申しこみが来ています」〔許可する〕〔今はしない〕。一行「許可しなくても、相手には知らせません」 |

- 〔連絡の許可を申しこむ〕を押すと、自分の側のランプも点く（自分は許可した、という意味）。
- 〔許可する〕を押すと、自分の側のランプが点き、両方点く。〔今はしない〕は何も変えず、相手にも知らせない。
- 申しこみの数・何日待っているかは出さない。
- 右上の〔⋯〕：〔推しから外す〕（外したダチは〔推しにもどす〕。ダチのまま。相手には知らせない：M-R109）、〔🚩 通報する〕〔🚫 ブロックする〕。ブロックすると、ダチから外れ、メールも電話もできない。相手には知らせない。〔🚫 ブロックした人〕は E-11 設定から見られる。
- 〔推し〕から外しても、連絡室の名札とランプはそのまま（連絡とプラネットはダチのつながりで決まる）。

### E-4 メール

- やりとりの一覧：名札と、最後のひとこと（一行）。新しい順。未読は点だけ。
- 一人とのやりとり：吹き出しが日付つきで並ぶ。古いものは〔前を見る〕を押した時だけ出る（勝手に読み込み続けない）。
- 声のメッセージをつけられる（〔🎙 声をつける〕。押して話す）。
- 既読・入力中・送った時刻の秒は出さない。

### E-5 メールの下書き→確認→送る

| 順 | 画面 | ボタン |
|---|---|---|
| 1 | 下書き（文字／〔🎙 声をつける〕） | 〔確かめる〕〔下書きにしまう〕〔やめる〕 |
| 2 | 宛先と中身を確かめる | 〔送る〕〔送らない〕 |
| 3 | 送った | 一行「送りました」。既読は出ません |

- 送れない言葉の時：「その言葉は送れないよ」（アプリの今の文のまま）。
- 下書きは本人だけに残る。

### E-6 電話（第2段階から）

- 第2段階（spec 2.1）までは〔📞 電話をかける〕を**出さない**。メール（声のメッセージつき）だけを見せる。
- かける：自分で〔📞 電話をかける〕を押す→「呼び出し中…」→相手が〔出る〕を押した時だけつながる。
- かかってきた：〔出る〕〔出ない〕。出なくても、相手に理由は出ない。
- 通話中：〔ミュート〕〔切る〕だけ。通話の時間は出さない（おすすめ。§10 問い4）。
- 連絡室がひらいても、誰かに勝手にかかることはない（L2-RETURN-S008）。

### E-7 招待状の机（〔招待状〕〔名前で探す〕）

土星（`saturn.md` S-7）と**同じ画面**。連絡室の机からも開ける。

**〔✉ 招待状〕**

| 順 | 画面 | ボタン |
|---|---|---|
| 1 | 招待状を書く（声／文字／選ぶ：『来てみる？』『見せたいものがある』） | 〔下書きにしまう〕〔贈る手続きへ〕〔やめる〕 |
| 2 | 宛先の確認 | 〔次へ〕〔やめる〕 |
| 3 | マナジェムの購入の確認（料金は物語の外の買う画面） | 〔購入〕〔やめる〕 |
| 4 | 招待状の中身の確認 | 〔送る〕〔やめる〕 |
| 5 | 送った | 「招待状を送りました。開くかどうかは、相手が決めます」 |

- 一行：「マナジェム（1つ88円。月額88円の毎月のマナの代金とは別）」は手順3の中だけに出す（台本 L2-RETURN-S008 のとおり）。
- どの段階でもやめられる。やめた時は「送っていません」。
- 招待された人が、参加・支払い・連絡を自動で承認することはない。
- 招待した人の数・「あと〇人」・お得の表示は出さない。
- 18歳未満のマナジェムの購入は保護者の同意が必要（物語の外の買う画面で扱う。M-R111(3)）。

**〔🔍 名前で探す〕**（18歳から）

| 順 | 画面 | ボタン |
|---|---|---|
| 1 | 名前を入れる（文字）。上に二行「18歳未満の人は、名前で探しても出てきません。招待状からは、これまでどおりダチになれます」「知らない人からダチの申しこみが来ても、承認しなくてかまいません。断っても、相手には知らせません」（L2-RETURN-S008 の search の枝） | 〔さがす〕〔やめる〕 |
| 2 | 名札が一枚、虫めがねの中で光る | 〔ダチを申しこむ〕〔やめる〕（相手が承認するとダチ） |
| 3 | 申しこんだ | 名札の枠が一つ増え、相手が受けると名前が入る |

- 見つからない時：「その名前の人は見つかりませんでした」。この文は、相手が18歳未満で出てこない時も同じにする（いるかいないかが分からないように）。

### E-8 手紙入れ（いつもの丸のすみ）

- 手紙が届く場所は、この手紙入れ一つ（『郵便受け』という言葉は使わない）。
- 届いた手紙と板が、届いた順に並ぶ：キモリンの手紙／金色の封筒／白い封筒／銀色の封筒／海王星からの板／エージェントの配信のお知らせ。

- 開くと、その手紙の場面の再開点から（EX の各場面）。
- 手紙は本人が消せる。返事の期限があるもの（金色の封筒）は、封筒の表に日付を書く。残り日数は出さない。

## 10. 問いと決定（4〜7は確認待ち）

1. **連絡の許可の切り替え**：決定（M-R108(3)）。ダチごとのランプ2つ（自分の許可・相手の許可）、〔連絡OK〕、〔連絡の許可を申しこむ〕『許可待ち』、〔許可する〕〔今はしない〕をアプリに足す（E-3）。
2. **収入を出す場所の名前**：決定（M-R108(5)）。〔お財布〕（地球のお財布）。画面に「銀行」は使わない（E-10）。
3. **知らない人からのダチの申しこみと〔名前で探す〕**：決定（M-R108(3)）。『承認しなくてかまいません。断っても、相手には知らせません』〔承認する〕〔断る〕を出す。18歳未満は〔名前で探す〕の結果に出さず、自分でも使えない。見つからない時の文は年齢に関係なく同じ。招待した・された人とはダチになれる（E-7）。
4. **電話の着信とメールの知らせ**：電話は、知らせがないと受けられない。おすすめ：着信だけは本人がオンにした時に知らせる。メールは次に開いた時の点だけ。通話の時間も出さない。（決まりの中身にかかわるので利用者が決める）
5. **エージェントの配信のマナの数**：台本は仮に500マナ。お金にかかわるので、運営が管理画面で決める（UIは数を固定しない）。
6. **E-1 の見た目**：本部の広間に置く物（掲示板・鉄の扉・招待状・エージェントの机）を一枚の絵にするか、ボタンの一覧にするか。おすすめは一枚の絵で、押せる所だけ少し光る（点滅は1秒に2回まで）。
7. **〔お財布〕の入口**（`uranus.md` 問い5 と同じ問い）：エージェントでない人も、obolo商店で売ると取り分が出る。案：本部の広間に〔👛 お財布〕を置き、エージェントの人とobolo商店に申請した人にだけ描く（E-1）。エージェントの机の〔収入を見る〕からも同じ画面へ。お金にかかわるので利用者の確認がいる。決まるまでは、この案で作ってよい。
