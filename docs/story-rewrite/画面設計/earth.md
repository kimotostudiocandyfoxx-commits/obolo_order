# 地球 画面設計（UIチーム向け）

- 版：第20稿（ループ見直し R1）・2026-10-26
- もとにしたもの：今の台本（parts/P05・P09・P10・P11・P14・EX）、利用者の決定 M-R1〜M-R106、レビューの申し送り、アプリの `docs/earth-comms.md`・`docs/spec.md` 2.1

- 書き方：〔 〕はボタンの文字（このとおりに出す）。「 」は画面に出す一行の文。

## 3. 地球の決まり（ほかの星と共通の決まりのうち、地球で大事なもの）

| 決まり | 中身 |
|---|---|
| 88分に数えない | 地球の本部と月の神殿は、1日88分に数えないし、割りこまない（SYS-S001） |
| 数を出さない | ダチの数、名札の数、メールの数、未読の数、通話の時間、招待した人の数を出さない。未読は点だけ |
| 既読なし | メールに既読の印は出さない |
| 勝手に流さない | 下へ流し続ける画面はない。手紙も連絡も、押した時だけ開く |
| 引き戻す知らせなし | 赤い点・バッジ・「〇日来ていません」は出さない。手紙が届いた時、いつもの丸でバティが一回だけ言う |
| 相手はダチだけ | メール・電話の相手はダチだけ。ダチは「招待した・された人」と「〔名前で探す〕でおたがいに承認した人」 |
| 招待者は最初からダチ | 招待してくれた人とKIMORIN⭐︎は、二周目の土星でダチになっている（L2-SATURN-S004） |
| 安全 | 名札・メール・電話の〔⋯〕から〔🚩 通報する〕〔🚫 ブロックする〕。ブロックは相手に知らせない |
| マナ | 画面でも「マナ」と書く（「力」「MANA」は使わない） |
| お金 | 買う・払うは、いつも物語の外の買う画面。キャラクターはすすめない・がっかりしない |

## 5. 画面ごとの中身

画面は正方形。上の帯（場所の名前）／真ん中（絵）／下の帯（ボタン）の三段。
地球には「流れ・作る・my場所」の下の3ボタンは出さない（作る星ではないため）。

### E-1 本部の広間

```
┌──────────────────────────┐
│ 本部                          〔⚙︎〕│
│   [掲示板]      [鉄の扉＝連絡室]   │
│        ◯ 光の柱（OBOLON）        │
│   [宇宙の地図]   [招待状（三周目）] │
│   [エージェントの机（該当者だけ）] │
│ 〔🗺 宇宙の地図〕〔今日はここまで〕 │
└──────────────────────────┘
```

| もの・ボタン | 押すと |
|---|---|
| 掲示板 | ひと巡りのカードと星めぐりの証を見る（L2-RETURN-S005。順位・称号の数は出さない） |
| 鉄の扉 | E-2 連絡室（L2-RETURN-S008より前は閉まっていて押せない。説明も出さない） |
| 〔🗺 宇宙の地図〕 | 星を選ぶ地図 |
| 招待状（三周目） | 招待状の裏の持ちもの（`fest-town.md` F-1） |
| エージェントの机 | E-9（エージェントでない人には、机そのものを描かない） |
| 〔⚙︎〕 | E-11 設定 |

### E-2 連絡室（交換台）

```
┌──────────────────────────┐
│ 連絡室                     〔閉じる〕│
│  ┌名札┐ ┌名札┐ ┌名札┐          │
│  │KIMORIN│ │{inviter}│ │名前│      │
│  │ ●  ● │ │ ●  ○ │ │ ○  ○ │      │ ← ランプ2つ
│  └────┘ └────┘ └────┘          │    左＝自分の許可／右＝相手の許可
│      [机：✉ 招待状　🔍 名前で探す]  │
└──────────────────────────┘
```

- 壁一面の古い交換台。灯っているのは、ダチの名札だけ。空いた差し込み口は飾り（数は読めない）。
- 名札は「ダチ　@名前」だけ。並びは、ダチになった順（新しい順）。
- **ランプ2つ＝両方の許可**。両方点いた名札だけ、メール・電話ができる。
- 未読のメールがある名札の角に、小さな点が一つ（数は出さない）。

| もの・ボタン | 押すと |
|---|---|
| 名札 | E-3 名札のメニュー |
| 机の〔✉ 招待状〕 | E-7（招待状の下書き・贈る手続き） |
| 机の〔🔍 名前で探す〕 | E-7（名前で探して、ダチに追加） |
| 〔閉じる〕 | E-1 |

### E-3 名札のメニュー

| 状態 | 出すボタン | 一行 |
|---|---|---|
| ランプが両方点いている | 〔✉️ メールを書く〕〔📞 電話をかける〕（第2段階から）〔やめる〕 | — |
| 自分だけ点いている | 〔やめる〕 | 「いまは連絡できません」 |
| まだ申しこんでいない | 〔連絡の許可を申しこむ〕〔やめる〕 | 「相手も許可すると、連絡できます」 |
| 申しこんで返事待ち | 〔やめる〕 | 名札の横に小さな札『許可待ち』 |

- 右上に〔⋯〕：〔🚩 通報する〕〔🚫 ブロックする〕。ブロックすると、ダチから外れ、メールも電話もできない。相手には知らせない。〔🚫 ブロックした人〕は E-11 設定から見られる。
- 〔連絡の許可を申しこむ〕を足すかどうかは**確認待ち**（§10 問い1）。足さない場合は、ダチになった時点でランプが両方点く。

### E-4 メール

- やりとりの一覧：名札と、最後のひとこと（一行）。新しい順。未読は点だけ。
- 一人とのやりとり：吹き出しが日付つきで並ぶ。古いものは〔前を見る〕を押した時だけ出る（勝手に読み込み続けない）。
- 声のメッセージをつけられる（〔🎙 声をつける〕。押して話す）。
- 既読・入力中・送った時刻の秒は出さない。

### E-5 メールの下書き→確認→送る

| 順 | 画面 | ボタン |
|---|---|---|
| 1 | 下書き（文字／〔🎙 声をつける〕） | 〔確かめる〕〔下書きにしまう〕〔やめる〕 |
| 2 | 宛先と中身を確かめる | 〔送る〕〔送らない〕 |
| 3 | 送った | 一行「送りました」。既読は出ません |

- 送れない言葉の時：「その言葉は送れないよ」（アプリの今の文のまま）。
- 下書きは本人だけに残る。

### E-6 電話（第2段階から）

- 第2段階（spec 2.1）までは〔📞 電話をかける〕を**出さない**。メール（声のメッセージつき）だけを見せる。
- かける：自分で〔📞 電話をかける〕を押す→「呼び出し中…」→相手が〔出る〕を押した時だけつながる。
- かかってきた：〔出る〕〔出ない〕。出なくても、相手に理由は出ない。
- 通話中：〔ミュート〕〔切る〕だけ。通話の時間は出さない（おすすめ。§10 問い4）。
- 連絡室がひらいても、誰かに勝手にかかることはない（L2-RETURN-S008）。

### E-7 招待状の机（〔招待状〕〔名前で探す〕）

土星（`saturn.md` S-7）と**同じ画面**。連絡室の机からも開ける。

**〔✉ 招待状〕**

| 順 | 画面 | ボタン |
|---|---|---|
| 1 | 招待状を書く（声／文字／選ぶ：『来てみる？』『見せたいものがある』） | 〔下書きにしまう〕〔贈る手続きへ〕〔やめる〕 |
| 2 | 宛先の確認 | 〔次へ〕〔やめる〕 |
| 3 | マナジェムの購入の確認（料金は物語の外の買う画面） | 〔購入〕〔やめる〕 |
| 4 | 招待状の中身の確認 | 〔送る〕〔やめる〕 |
| 5 | 送った | 「招待状を送りました。開くかどうかは、相手が決めます」 |

- 一行：「マナジェム（1つ88円。月額88円の毎月のマナの代金とは別）」は手順3の中だけに出す（台本 L2-RETURN-S008 のとおり）。
- どの段階でもやめられる。やめた時は「送っていません」。
- 招待された人が、参加・支払い・連絡を自動で承認することはない。
- 招待した人の数・「あと〇人」・お得の表示は出さない。
- 15歳以下の購入の承認は、物語の外の買う画面で扱う。

**〔🔍 名前で探す〕**

| 順 | 画面 | ボタン |
|---|---|---|
| 1 | 名前を入れる（文字） | 〔さがす〕〔やめる〕 |
| 2 | 名札が一枚、虫めがねの中で光る | 〔ダチに追加する〕〔やめる〕 |
| 3 | 申しこんだ | 名札の枠が一つ増え、相手が受けると名前が入る |

- 見つからない時：「その名前の人は見つかりませんでした」。
- 知らない人から申しこみが来た時：「承認しなくてもかまいません。断っても、相手には知らせません」と一行（**確認待ち**。§10 問い3）。

### E-8 手紙入れ（いつもの丸のすみ）

- 届いた手紙と板が、届いた順に並ぶ：キモリンの手紙／金色の封筒／白い封筒／銀色の封筒／海王星からの板。
- 届いた日、いつもの丸でバティが一回だけ言う（「キモリンから、手紙が来たよ。」など。白い封筒の時は何も言わない）。
- 赤い点・バッジ・二度目の知らせは出さない。
- 開くと、その手紙の場面の再開点から（EX の各場面）。
- 手紙は本人が消せる。返事の期限があるもの（金色の封筒）は、封筒の表に日付を書く。残り日数は出さない。

### E-9 エージェントの机（エージェントだけ）

EX-SCOUT-S002 で〔エージェントになる〕を選んだ人だけに出る。ほかの人には机ごと描かない。

```
┌──────────────────────────┐
│ エージェントの机            〔閉じる〕│
│  配信した曲                       │
│   ▢ 〈曲名〉  権利の確認中          │
│   ▢ 〈曲名〉  配信先に届きました    │
│                                  │
│ 〔配信する曲を選ぶ〕〔収入を見る〕    │
└──────────────────────────┘
```

| ボタン | 押すと |
|---|---|
| 〔配信する曲を選ぶ〕 | 自分の曲の棚（水星）から一曲選ぶ→確認「〈マナ〉を使って、〈曲名〉を配信します。よろしいですか？」〔配信する〕〔やめる〕 |
| 〔収入を見る〕 | E-10 |
| 〔閉じる〕 | E-1 |

- 状態は「権利の確認中」「配信先に届きました」「ここを直せば出せます：〈直す所〉」の三つだけ。
- **再生数・リスナー数・順位は出さない**（「アプリの中には、再生数やリスナー数は出ません」と一行）。
- 配信先に届いた時は、地球の郵便受けにお知らせが一通入るだけ（外への通知は出さない）。
- 配信のマナの数（台本は仮に500マナ）は、確認の画面だけに出す。数は運営が管理画面で決める。
- 18歳未満：配信の契約とお金の受け取りの前に「家の人の同意が必要です」〔家の人に送る〕〔今はやめる〕。
- ほかの人の声のまね・ほかの人の曲を使ったものは配信できない、と一行。

### E-10 収入（名前は確認待ち）

- 本人だけが見られる。配信で入ったお金（作者の取り分）を円で出す。
- 〔自分の口座に移す〕：本人の、すでにある口座へ移す（物語の外の手続き）。
- ほかの人には見えない。売れた数・聴かれた数は出さない。
- **場所の名前は確認待ち**：台本は「地球の銀行」（EX-SCOUT-S002）、アプリの spec v1.8 は「Wallet（お財布）」で、UIの名前に「銀行」を使わないとしている（法律の確認）。§10 問い2。

### E-11 設定

| 項目 | 中身 |
|---|---|
| プロフィール | 月の水盤で決めた姿・名前（月で変える。ここは見るだけ） |
| 声を待たずに進む | 初めはオフ。耳が聞こえにくい人・音を出せない場所のため（M-R102） |
| 🚫 ブロックした人 | 一覧と〔ブロックをやめる〕 |
| バティの設定 | 月の〔⚙︎ バティの設定〕へ（`moon.md` MO-5） |
| メール認証のアドレス | 変更（物語の外の手続き） |

- 通知の設定は、§10 問い4が決まってから置く。

## 9. アプリの今と違う所（`docs/earth-comms.md`・`Comms.tsx` との差）

| アプリの今 | この文書（台本） | 直してほしいこと |
|---|---|---|

## 10. 決まっていないこと（確認待ち）

1. **連絡の許可の切り替えを足すか**（利用者の確認待ち）：台本はランプ2つ（自分の許可・相手の許可）と〔連絡の許可を申しこむ〕『許可待ち』。アプリは「ダチなら連絡できる」。足さない場合は、ダチになった時に両方のランプが点く形にし、台本の〔画面〕の一言を台本係が直す。
2. **収入を出す場所の名前**（利用者の確認待ち・法律にかかわる）：「銀行」か「お財布」か。spec v1.8 は「銀行」をUIの名前に使わないとしている。決まったら、台本 EX-SCOUT-S002 の「地球の銀行」を台本係が直す。
3. **知らない人からのダチの申しこみ**（利用者の確認待ち）：「承認しなくてもかまいません。断っても、相手には知らせません」を画面に出すか（土星と同じ）。
4. **電話の着信とメールの知らせ**：電話は、知らせがないと受けられない。おすすめ：着信だけは本人がオンにした時に知らせる。メールは次に開いた時の点だけ。通話の時間も出さない。（決まりの中身にかかわるので利用者が決める）
5. **エージェントの配信のマナの数**：台本は仮に500マナ。お金にかかわるので、運営が管理画面で決める（UIは数を固定しない）。
6. **E-1 の見た目**：本部の広間に置く物（掲示板・鉄の扉・招待状・エージェントの机）を一枚の絵にするか、ボタンの一覧にするか。おすすめは一枚の絵で、押せる所だけ少し光る（点滅は1秒に2回まで）。
