## 5. 画面ごとの中身

画面は正方形。上の帯（場所の名前）／真ん中（絵）／下の帯（ボタン）の三段。
地球には「流れ・作る・my場所」の下の3ボタンは出さない（作る星ではないため）。

台本 D01-S000（招待信号）の前。確定稿の変更（M-R131）。電車やバスで何も知らずに開いて、あとから「声を出せる場所で」と言われるより、最初に伝える（M-R130 声が主役）。

│                                  │
│          ◉（金色の封蝋の印。        │
│            ゆっくり脈打つ）          │
│   この招待状を開く前に                │
│   □ 音が出せる場所にいる              │
│   □ 声を出せる（話しても大丈夫な）場所にいる│
│  この宇宙は、あなたの声で作ります。      │
│  電車やバスの中ではなく、家など、        │
│  ゆっくりできる場所で開いてください      │
│   生まれた年を教えてください〔年を選ぶ〕   │
│   （年齢に合わせて、守りの設定を変えるため │

### E-8 手紙入れ（いつもの丸のすみ）

- 手紙が届く場所は、この手紙入れ一つ（『郵便受け』という言葉は使わない）。
- 届いた手紙と板が、届いた順に並ぶ：キモリンの手紙／金色の封筒／白い封筒／銀色の封筒／海王星からの板／エージェントの配信の手紙（確認中・届いた・ここを直せば出せる。E-9）／〔お財布〕ができた手紙（一回だけ。E-10）。
- 届いた日、いつもの丸でバティが一回だけ言う（「キモリンから、手紙が来たよ。」など。白い封筒の時は何も言わない）。
- 赤い点・バッジ・二度目の知らせは出さない。
- 開くと、その手紙の場面の再開点から（EX の各場面）。
- 手紙は本人が消せる。返事の期限があるもの（金色の封筒）は、封筒の表に日付を書く。残り日数は出さない。

- 状態は「権利の確認中」「配信先に届きました」「ここを直せば出せます：〈直す所〉」の三つだけ。
- 物語の仲間の声でフィーチャリングした曲は配信できる（配信先の表記は「feat. 〈名前〉」）。住人・KIMORIN⭐︎の声は取り分なし。MIKIE⭐︎・MISAKO⭐︎の声を使った曲は、収益の8%を二人に渡す（M-R119。モデルのご本人の許可ずみ。どの曲・どの歌詞にも使える）。その曲の〔お財布〕の行には「MIKIE⭐︎・MISAKO⭐︎へ 8%」を一行で出す（金額だけ。再生数は出さない）。権利の確認で止まった曲のマナは戻す。直してもう一度出す時は、マナはかからない（M-R120。§10 問い11は決定）。
- **進み具合は手紙で知らせる**（手紙入れ E-8。外への通知は出さない）。手紙は三種類だけ：
  | 手紙 | いつ | 文（案） |
  |---|---|---|
  | 確認中 | 〔配信する〕を押したすぐあと | 「〈曲名〉の権利の確認を始めました。終わったら、また手紙を出します」 |

- 確認中の手紙は自分の操作のすぐあとなので、バティは何も言わない。届いた／直せば出せるの手紙は、いつもの丸でバティが一回だけ言う。
- **再生数・リスナー数・順位は出さない**（「アプリの中には、再生数やリスナー数は出ません」と一行）。
- エージェントに選ぶ決め方は運営の中だけで、画面にも手紙にも数や順位を出さない。
- （第20稿の M-R117「obolo商店の審査はスカウトの条件にしない」は、M-R158 でユーザーが商店で売らなくなったので、問いごとなくなった。）

- ほかの人の声のまね・ほかの人の曲を使ったものは配信できない、と一行。

### E-10 お財布（収入）

- 本人だけが見られる。配信の収入を、**この一か所**に出す。ユーザーは obolo商店で売らないので、商店の売上はない（M-R158）。
- **開く時**：はじめての配信（スカウト・obolo records など）の収入が入るまで隠しておき、入った時に本部の広間に〔👛 お財布〕が出る（M-R165）。エージェントになっただけでは、まだ出さない。
- 配信で入ったお金（運営の手数料8%を引いた残りが、すべて作者の取り分。M-R110）を、円で出す。
- **見せるのは2行だけ**：
  - 「見込み　¥〇〇」：まだ届いていないお金。下に小さく「配信先からのお金は、数か月おくれて届きます」。
  - 「確定　¥〇〇　〈日付〉に振り込みます」：届いて、額が決まったお金。振込日をつける。受け取り先をまだ登録していない人には、日付の代わりに「受け取り先を登録すると、振込日が決まります」〔受け取り先を登録する〕。
- 〔月ごとに見る〕を押した時だけ、月ごとの行（「〈何月〉の分　¥〇〇　見込み／確定」）が出る。EX-SCOUT-S002 の「いつの分が、いつ届くかは、〔お財布〕でいつでも確かめられます」はここで見せる。8か月ずつ、〔‹ 前〕で前を見る（下へ流し続けない）。
- ほかの人には見えない。売れた数・聴かれた数・再生数は出さない。
- **初めて開いた時だけ**（はじめての配信の収入が入った時）、手紙入れに手紙が一通届く（「地球の本部に、〔👛 お財布〕ができました。中身を見られるのは、あなただけです」。文は運営が決める）。バティは一回だけ「手紙が来たよ。」と言う。
- お金が入るたびの知らせ・赤い点は出さない（ごほうび・呼び戻しになるため）。見たい時に本人が開く。
- **場所の名前**：〔お財布〕（M-R108(5)。台本の言い方は「地球のお財布」。法律の都合で、画面に「銀行」の言葉は使わない。EX-SCOUT-S002 もそろえた）
- 一行：「ここに出るのは、あなたの取り分だけです。ほかの人には見えません」。
- 画面の形（案）：

```
┌──────────────────────────┐
│ 👛 お財布（あなただけ）      〔閉じる〕│
│  見込み  ¥〇〇                       │
│   配信先からのお金は、数か月おくれて届きます│
│  確定    ¥〇〇  〈日付〉に振り込みます  │
│ 「ここに出るのは、あなたの取り分だけです」│
│ 〔月ごとに見る〕                      │
└──────────────────────────┘
```

- 振り込みの仕組み（決まった日に自動で振り込むか、本人が押した時に移すか）と、振込日の決め方は運営が決める（§10 問い9）。画面の言葉は「振り込み」「受け取り先」で、「銀行」は使わない。
- 受け取り先の登録（〔受け取り先を登録する〕）は、物語の外の手続きの画面。**18歳未満は、その画面で保護者の同意が必要**（M-R113(1)。台詞は変えない）。
- 毎月88円の支払い（D08-S006 の入会の画面）も、18歳未満は同じく手続きの画面で保護者の同意（M-R113(1)）。お財布の画面には毎月の支払いを出さない（支払いのことは E-11〔毎月のマナ〕）。

## 10. 問いと決定（4・9は確認待ち。6はUIチームが決めてよい）

1. **連絡の許可の切り替え**：決定（M-R108(3)）。ダチごとのランプ2つ（自分の許可・相手の許可）、〔連絡OK〕、〔連絡の許可を申しこむ〕『許可待ち』、〔許可する〕〔今はしない〕をアプリに足す（E-3）。
2. **収入を出す場所の名前**：決定（M-R108(5)）。〔お財布〕（地球のお財布）。画面に「銀行」は使わない（E-10）。
3. **知らない人からのダチの申しこみと〔名前で探す〕**：決定（M-R175。M-R108(3) を置きかえ）。〔名前で探す〕と、知らない人からのダチの申しこみ（〔承認する〕〔断る〕）は、なくした。ダチになれるのは〔招待状〕でつながった人と〔🤝 ダチの招待状〕を交わした人（と物語の仲間）だけ。年齢の制限はない。知らない人とは三周目の〔推す〕だけ（E-7）。
4. **電話の着信の知らせ**（利用者が決める）：電話は、知らせがないと受けられない。おすすめ：着信だけは本人がオンにした時に知らせる。通話の時間も出さない。メールは M-R183 でなくなった（土星の器に届いた知らせは字で一回：`saturn.md` S-13）。
5. **エージェントの配信のマナの数**：決定：配信のマナの数は運営が管理画面で決める（台本の500は仮）
6. **E-1 の見た目**（UIチームが決めてよい）：本部の広間に置く物（掲示板・鉄の扉・招待状・エージェントの机）を一枚の絵にするか、ボタンの一覧にするか。おすすめは一枚の絵で、押せる所だけ少し光る（点滅は1秒に2回まで。ほかの作る星でない所と同じ：index.md 2.1）。
7. **〔お財布〕の入口**：決定（M-R165。M-R116(6) を置きかえ）。はじめての配信（スカウト・obolo records など）の収入が入るまで隠しておき、入った時に本部の広間に〔👛 お財布〕を描く。中身は配信の収入だけ。エージェントの机の〔収入を見る〕からも同じ画面へ（収入が入る前は「まだ、収入はありません」）。
8. **最初の公開で電話を使えるか**：決定（M-R118(2)）。台本はそのまま。使えるまでは〔📞 電話をかける〕を薄い色で「準備中」と出す（E-6）。
9. **振り込みの仕組み**（お金にかかわるので運営が決める）：「確定」のお金を、決まった日に自動で振り込むか、本人が押した時に移すか。どちらでも画面は「見込み」「確定（振込日つき）」の2行で、「銀行」は使わない。
10. **スカウトとobolo商店**：M-R158 でユーザーは obolo商店で売らないので、問いごとなくなった（M-R117 は第20稿の記録）。
11. **権利の確認で止まった配信のマナ**：決定（M-R120）。止まった曲のマナは戻す。直してもう一度出す時は、マナはかからない（EX-SCOUT-S002の③）。MIKIE⭐︎・MISAKO⭐︎の声入りの曲も配信できる（収益の8%を二人に。M-R119・M-R120）。
