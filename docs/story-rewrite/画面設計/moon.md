## 5. 画面ごとの中身

画面は正方形。月には「流れ・作る・my場所」の下の3ボタンは出さない。神殿の一枚の絵が目次になる。

### MO-1 月の神殿（トップ）

```
┌──────────────────────────┐
│ 月の神殿                 〔⚙︎ バティの設定〕│
│        ◯ 光の柱（OBOLON）        │
│     ◎ {bati}     ≈ 水盤 ≈       │
│                                  │
│ 〔💬 バティに聞く〕〔🪞 水盤〕          │
│ 〔バティと宇宙を、別々に使う〕（星休めから）│
└──────────────────────────┘
```

| ボタン | 押すと |
|---|---|
| 〔💬 バティに聞く〕 | MO-2 |
| 〔🪞 水盤〕 | MO-3 |
| 〔⚙︎ バティの設定〕 | MO-5 |
| 〔バティと宇宙を、別々に使う〕 | MO-6（星休めから出る。押した時だけ案内が始まる） |

- 入口ボタンの文字は〔💬 バティに聞く〕（台本 L2-MOON-S001 に反映）。「話す」「会話」の言葉は使わない。

### MO-2 バティに聞く

```
┌──────────────────────────┐
│ バティに聞く                〔閉じる〕│
│                                  │
│   {bati}：「氷と、石のかけらが、     │
│    いっぱい集まってるんだって！」    │
│                                  │
│ 「土星の輪って、何でできてるの？」    │ ← 自分の質問
│ 〔🎙〕  ⌨（すみに小さく）            │
└──────────────────────────┘
```

| ボタン | 押すと |
|---|---|
| 〔🎙〕 | 押して話す→もう一度押すと送る（声の入力の印） |
| ⌨ | 文字で聞く |
| 〔閉じる〕 | MO-1 |

- 一問一答。見えているのは、いまの質問と答えだけ。前の質問は〔前を見る〕を押した時だけ出る（下へ流し続けない）。
- バティは調べて答える役。悩み相談・恋愛相談の形にしない。答えの下に、毎回、小さく一行「バティの答えが、まちがっていることもあります。大事なことは、自分でも確かめてね」（M-R111(1)。台本 L2-MOON-S001）。体や心の悩みの質問には、調べた答えのあとに、バティが一言だけ「家の人や、信じられる大人にも話してね。」と添える（台本 L2-MOON-S001 の設計注。吹き出しの文字でも出す。医療の言葉は使わない。治せるとも言わない。悩み相談の続きには誘わない）。
- 記録を残さない設定の時は、閉じると消える。一行：「この話は、閉じると消えます」。
- 聞いた回数・残りの回数は、どの画面にも出さない。一日の上限をどう扱うか（spec の「30回まで無料、そのあと1マナ」）は確認待ち（§9 問い2）。決まるまで、上限の画面は作らない。

### MO-3 水盤（姿を試す）

2日目（D03-S003〜S005）と同じ流れ（M-R108(2)）。三つの段を、別々の画面で一つずつ見せる。

| 段 | 画面 | ボタン |
|---|---|---|
| ① 言う | 水面に今の{neo}。ふちに札が並ぶ | 〔🎙〕・⌨・ふちの札〔もっと明るく〕〔もっとクールに〕〔色を青に〕〔耳の形を変えて〕〔小物を足して〕→〔描く〕。〔今の姿のままにする〕 |
| ② 確認 | 「マナを使って、4枚の姿を描きます」 | 〔描く〕〔やめる〕 |
| ③ 選ぶ | 4枚を2×2で並べる | 〔この姿にする〕〔言い直す〕（1回だけ）〔今の姿のままにする〕〔もどる〕 |

- ② の画面に出す文は「マナを使って、4枚の姿を描きます」の一行だけ。使うマナの数は出さない（二周目から。M-R75）。「数字なし」はUI向けの注記なので、画面の文には入れない。

```
③ 選ぶ
┌──────────────────────────┐
│ 水盤                        〔もどる〕│
│   ┌────┐ ┌────┐                 │
│   │ 1  │ │ 2  │   ← 4枚（2×2）     │
│   └────┘ └────┘                 │
│   ┌────┐ ┌────┐                 │
│   │ 3  │ │ 4  │                 │
│   └────┘ └────┘                 │
│ 〔この姿にする〕 〔言い直す〕          │
│ 〔今の姿のままにする〕                 │
└──────────────────────────┘
```

| ボタン | 押すと |
|---|---|
| 〔🎙〕／⌨／ふちの札 | 変えたいところを言う（色・髪・服・持ち物・翼など。現実にない姿でもよい）。札を押すと、その言葉が入る |
| 〔描く〕 | ② 確認→〔描く〕で、言ったことの入った4枚を描く→③ |
| 4枚の1枚 | 押すと大きく見られる。選んだ1枚に印がつく |
| 〔この姿にする〕 | 選んだ1枚で MO-4（1枚選ぶまでは薄い色） |
| 〔言い直す〕 | 要望を足して（声・文字。例「もっとかっこよく」）、新しい4枚を描く（使う前に②の確認）。1回だけ。使ったあとは灰色にして一行「言い直しは、使いました」。言い直したあとは新しい4枚から選ぶ |
| 〔今の姿のままにする〕 | 姿を変えずに MO-1 |
| 〔もどる〕 | 何も変えずに MO-1（描いた絵は下書きに残る） |

- 一回に描けるのは全部で8枚まで（4枚＋言い直しの4枚）。描き直しの残り回数は数で出さない。
- 作らないもの：〔前の姿にもどす〕、「何度でも試す」、決めた一枚だけを描く形。
- 途中で閉じた時：姿は変わらない。描いた絵は下書きに残り、次に水盤を開くと ③ 選ぶ から（言い直しを使ったかどうかも、そのまま）。
- 姿の決まり：セミリアルの絵、大きめのフード、動物の耳、細い金ぶちの丸いサングラス（目は見せない。M-R94）。サングラスは外せない。
- 星休め（L2-REST-S020）では、①の上に一度だけ水盤の使い方の一行（「①変えたいところを水盤に言う…④1枚選んで〔この姿にする〕」）を出す。

### MO-4 プロフィールの確認

- 一行：「この姿が、あなたのプロフィールとして表示されます」〔この姿にする〕〔もどる〕。
- プロフィールの顔の丸（丸く切り抜いた顔）も、ここで合わせる（指で引きずらず、〔大きく〕〔小さく〕〔上へ〕〔下へ〕を押す）。
- 決めたあと一行：「姿は、あとから、いつでも変えられます」。
- 見える範囲：二周目はダチだけ。三周目からは〔みんな〕にも（L2-REST-S020 の保存の決まり）。

### MO-5 バティの設定

| 項目 | 選び方 | 一行 |
|---|---|---|
| 名前 | 文字で入れる〔この名前にする〕 | 「名前は、あとでいつでも変えられます」 |
| 元気さ | 〔おだやか〕〔ふつう〕〔元気〕の三つから選ぶ（数字・目盛りは出さない） | — |
| 話し方 | 〔ていねい〕〔ふつう〕〔くだけた〕の三つから選ぶ | — |
| 声 | 〔{neo}の声を少し高くした声〕〔はじめの声〕（土星 D04-S005 の確認の続き） | — |
| 聞いたことの記録 | 〔残す〕〔残さない〕と〔記録を消す〕 | 「消した記録は、戻せません」〔消す〕〔やめる〕 |

- 選んだ数字（元気さのレベルなど）は物語にも画面にも出さない（L2-MOON-S002 の設計注）。
- 元気さ・話し方の三つの名前は仮。UIで決めてよい（三つまで）。

### MO-6 家の宇宙と、持ち歩く相棒

- バティの一言「ボクを外に連れていって、／宇宙は家で待ってる使い方もあるんだ。」のあと、一行：「家では、壁に宇宙を開く。出かける時は、バティだけ持っていく。どこで何を使うかは、暮らしに合わせて選べます。今の使い方のままでも、最後まで遊べます」。
- 〔この使い方を見る〕〔専用デバイスについて見る〕〔今の使い方を続ける〕。
- 〔この使い方を見る〕：短い暮らしの例（朝、相棒をポケットへ／外で一言メモ／夜、部屋で正方形の宇宙を開いて続きを作る）→MO-1。
- 入口は月に残る。押さない人には出ない。

### MO-7 開発者から

- 白い背景に、ふつうの文字。キャラクターは出ない（L2-REST-S016 の文のまま）。
- 商品の説明は、決まっている条件だけ。決まっていない間は「準備中」で、注文・支払いは受け付けない。
- 注記：「道具がなくても、物語は最後まで遊べます。道具の有無で、有利・不利はありません。」
- 〔月へ戻る〕だけ。値段の数字と「obolo」の語は出さない。

## 9. 決まっていないこと（確認待ち）

1. **水盤で描く回数**：決定（M-R108(2)）。2日目と同じ「4枚→言い直し1回→決める」。全部で8枚まで（MO-3）。

2. **バティに聞ける回数**（利用者の確認待ち・お金とマナにかかわる）：spec 2.2 は「一日30回までは無料、そのあとは1回1マナ」。台本は回数に触れていない。おすすめ：回数の数字は画面に出さず、上限に来た時だけ「今日は、ここまで。また明日、聞いてね」と一行（マナで続けるかは出さない）。
3. **元気さ・話し方の三つの名前**：UIで決めてよいか。
4. **記録を残すの初めの設定**（利用者の確認待ち・個人の情報にかかわる）：〔残す〕と〔残さない〕のどちらを初めにするか。おすすめは〔残さない〕（親が安心できる）。
5. **体や心の悩みを聞かれた時**：決定（M-R111(1)）。調べた答えのあとに「家の人や、信じられる大人にも話してね」と一行（MO-2）。医学の言葉は使わず、治せるとも言わない。

## 10. アプリの今と違う所（`docs/spec.md` 2.2 との差）

| アプリの今（spec） | この文書（台本） | 直してほしいこと |
|---|---|---|
| バティはキャラクターとの会話（雑談） | 調べて答える役。雑談・悩み相談の形にしない | 入口の言葉を〔💬 バティに聞く〕に。話しかけ例も質問の形に |
