# 月 画面設計（UIチーム向け）

- 版：第20稿（ループ見直し R1）・2026-10-26
- もとにしたもの：今の台本（parts/P02・P05・P10）、利用者の決定 M-R1〜M-R106（とくに M-R73・M-R94・M-R102）、レビューの申し送り、アプリの `docs/spec.md` 2.2
- 渡す先：アプリ（ブランチ `claude/solar-system-home-planets-ew766y`）を作るUIチーム
- あつかう範囲：二周目からの月（バティに聞く・水盤で姿を変える・バティの設定・家の宇宙と持ち歩く相棒）。2日目の月（ネオの姿・名前・たまご・バティ誕生）は確定稿のまま。ここでは「一周目でどうなっているか」だけ書く。
- 書き方：〔 〕はボタンの文字（このとおりに出す）。「 」は画面に出す一行の文。

## 1. ひとことで

**月は、相棒のバティと、自分の姿の星。** バティに聞くと調べて答えてくれる。水盤で姿を変えられる。
雑談や悩み相談の場所にはしない（親が安心できる形。L2-MOON-S001 の設計注）。

## 5. 画面ごとの中身

画面は正方形。月には「流れ・作る・my場所」の下の3ボタンは出さない。神殿の一枚の絵が目次になる。

### MO-1 月の神殿（トップ）

```
┌──────────────────────────┐
│ 月の神殿                 〔⚙︎ バティの設定〕│
│        ◯ 光の柱（OBOLON）        │
│     ◎ {bati}     ≈ 水盤 ≈       │
│                                  │
│ 〔💬 バティに聞く〕〔🪞 水盤〕          │
│ 〔バティと宇宙を、別々に使う〕（星休めから）│
└──────────────────────────┘
```

| ボタン | 押すと |
|---|---|
| 〔💬 バティに聞く〕 | MO-2 |
| 〔🪞 水盤〕 | MO-3 |
| 〔⚙︎ バティの設定〕 | MO-5 |
| 〔バティと宇宙を、別々に使う〕 | MO-6（星休めから出る。押した時だけ案内が始まる） |

### MO-2 バティに聞く

```
┌──────────────────────────┐
│ バティに聞く                〔閉じる〕│
│                                  │
│   {bati}：「氷と、石のかけらが、     │
│    いっぱい集まってるんだって！」    │
│                                  │
│ 「土星の輪って、何でできてるの？」    │ ← 自分の質問
│ 〔🎙〕  ⌨（すみに小さく）            │
└──────────────────────────┘
```

| ボタン | 押すと |
|---|---|
| 〔🎙〕 | 押して話す→もう一度押すと送る（声の入力の印） |
| ⌨ | 文字で聞く |
| 〔閉じる〕 | MO-1 |

- 一問一答。見えているのは、いまの質問と答えだけ。前の質問は〔前を見る〕を押した時だけ出る（下へ流し続けない）。
- バティは調べて答える役。悩み相談・恋愛相談の形にしない。体や心の悩みを聞かれた時の答え方は**確認待ち**（§9 問い5。医学の言葉は使わない）。
- 記録を残さない設定の時は、閉じると消える。一行：「この話は、閉じると消えます」。
- 一日に聞ける回数・残りの回数は出さない（決め方は§9 問い2）。

### MO-3 水盤（姿を試す）

```
┌──────────────────────────┐
│ 水盤                        〔もどる〕│
│   ≈≈≈ 水面に、いまの{neo} ≈≈≈     │
│ 〔もっと明るく〕〔もっとクールに〕      │ ← ふちの札
│ 〔色を青に〕〔目をやさしく〕〔小物を足して〕│
│ 〔🎙〕 ⌨     〔前の姿にもどす〕       │
│            〔この姿にする〕           │
└──────────────────────────┘
```

| ボタン | 押すと |
|---|---|
| ふちの札 | その言葉を水盤に言ったことになる |
| 〔🎙〕／⌨ | 変えたいところを声か文字で言う（色・髪・服・持ち物・翼など、現実にない姿でもよい） |
| 〔前の姿にもどす〕 | ひとつ前の姿に戻る |
| 〔この姿にする〕 | MO-4 |
| 〔もどる〕 | 何も変えずに MO-1 |

- 作る前に「マナを使います」の確認〔描く〕〔やめる〕。数は出さない（二周目から）。
- 描く手順は**確認待ち**（§9 問い1）。おすすめ：2日目と同じ「4枚→言い直し1回→4枚から選ぶ」。
- 姿の決まり：セミリアルの絵、大きめのフード、動物の耳、細い金ぶちの丸いサングラス（目は見せない。M-R94）。サングラスは外せない。
- 途中で閉じたら、姿は変わらない（下書きは残る）。

### MO-4 プロフィールの確認

- 一行：「この姿が、あなたのプロフィールとして表示されます」〔この姿にする〕〔もどる〕。
- プロフィールの顔の丸（丸く切り抜いた顔）も、ここで合わせる（指で引きずらず、〔大きく〕〔小さく〕〔上へ〕〔下へ〕を押す）。
- 決めたあと一行：「姿は、あとから、いつでも変えられます」。
- 見える範囲：二周目はダチだけ。三周目からは「みんな」にも（L2-REST-S020 の保存の決まり）。

### MO-5 バティの設定

| 項目 | 選び方 | 一行 |
|---|---|---|
| 名前 | 文字で入れる〔この名前にする〕 | 「名前は、あとでいつでも変えられます」 |
| 元気さ | 〔おだやか〕〔ふつう〕〔元気〕の三つから選ぶ（数字・目盛りは出さない） | — |
| 話し方 | 〔ていねい〕〔ふつう〕〔くだけた〕の三つから選ぶ | — |
| 声 | 〔{neo}の声を少し高くした声〕〔はじめの声〕（土星 D04-S005 の確認の続き） | — |
| 聞いたことの記録 | 〔残す〕〔残さない〕と〔記録を消す〕 | 「消した記録は、戻せません」〔消す〕〔やめる〕 |

- 選んだ数字（元気さのレベルなど）は物語にも画面にも出さない（L2-MOON-S002 の設計注）。
- 元気さ・話し方の三つの名前は仮。UIで決めてよい（三つまで）。

### MO-6 家の宇宙と、持ち歩く相棒

- バティの一言「ボクを外に連れていって、／宇宙は家で待ってる使い方もあるんだ。」のあと、一行：「家では、壁に宇宙を開く。出かける時は、バティだけ持っていく。どこで何を使うかは、暮らしに合わせて選べます。今の使い方のままでも、最後まで遊べます」。
- 〔この使い方を見る〕〔専用デバイスについて見る〕〔今の使い方を続ける〕。
- 〔この使い方を見る〕：短い暮らしの例（朝、相棒をポケットへ／外で一言メモ／夜、部屋で正方形の宇宙を開いて続きを作る）→MO-1。
- 入口は月に残る。押さない人には出ない。

### MO-7 開発者から

- 白い背景に、ふつうの文字。キャラクターは出ない（L2-REST-S016 の文のまま）。
- 商品の説明は、決まっている条件だけ。決まっていない間は「準備中」で、注文・支払いは受け付けない。
- 注記：「道具がなくても、物語は最後まで遊べます。道具の有無で、有利・不利はありません。」
- 〔月へ戻る〕だけ。値段の数字と「obolo」の語は出さない。

## 7. 出さないもの

| 出さないもの | かわり・理由 |
|---|---|
| 聞いた回数・残りの回数・「今日はあと〇回」 | 出さない（§9 問い2） |
| 元気さ・話し方の数字や目盛り | 三つの言葉から選ぶ |
| 描き直しの残り回数 | 「言い直しは一回です」と最初に一行だけ（おすすめ案の場合） |
| マナの数字（二周目から） | 「マナを使います」の確認だけ |
| 「AI」という言葉 | 「バティに聞く」 |
| 悩み相談・恋愛相談への誘い | 調べて答える役にとどめる |
| 専用の道具の値段 | 「準備中」 |

## 9. 決まっていないこと（確認待ち）

1. **水盤で描く回数**（利用者の確認待ち・マナにかかわる）：台本 L2-MOON-S002 は「試すだけなら何度でも、決めた時だけ一枚描く」。でも試す姿を見せるにも描く必要がある。おすすめ：2日目と同じ「4枚→言い直し1回→4枚から選ぶ」。決まったら台本係が L2-MOON-S002・L2-REST-S020 の〔画面〕をそろえる。天王星の〔新しく描く〕も同じ形にするか一緒に決める。
2. **バティに聞ける回数**（利用者の確認待ち・お金とマナにかかわる）：spec 2.2 は「一日30回までは無料、そのあとは1回1マナ」。台本は回数に触れていない。おすすめ：回数の数字は画面に出さず、上限に来た時だけ「今日は、ここまで。また明日、聞いてね」と一行（マナで続けるかは出さない）。
3. **元気さ・話し方の三つの名前**：UIで決めてよいか。
4. **記録を残すの初めの設定**（利用者の確認待ち・個人の情報にかかわる）：〔残す〕と〔残さない〕のどちらを初めにするか。おすすめは〔残さない〕（親が安心できる）。
5. **体や心の悩みを聞かれた時**（利用者の確認待ち・安全にかかわる）：おすすめは、調べた答えのあとに「家の人や、信じられる大人にも話してね」と一行（地球の通報の画面の「こまったときは、おうちの人にも話してね」と同じ考え）。医学の言葉は使わず、治せるとも言わない。

## 10. アプリの今と違う所（`docs/spec.md` 2.2 との差）

| アプリの今（spec） | この文書（台本） | 直してほしいこと |
|---|---|---|
| バティはキャラクターとの会話（雑談） | 調べて答える役。雑談・悩み相談の形にしない | 入口の言葉を〔💬 バティに聞く〕に。話しかけ例も質問の形に |

| 長い記憶をいつも持つ | 記録を残すか消すかを本人が選ぶ | 設定に〔残す〕〔残さない〕〔記録を消す〕 |
| デモUI〔記憶と履歴をリセット〕 | 〔記録を消す〕 | 言葉をそろえる |
