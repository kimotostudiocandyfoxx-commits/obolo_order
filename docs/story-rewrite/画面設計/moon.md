### MO-2 バティに聞く

```
┌──────────────────────────┐
│ バティに聞く                〔閉じる〕│
│                                  │
│   {bati}：「氷と、石のかけらが、     │
│    いっぱい集まってるんだって！」    │
│                                  │
│ 「土星の輪って、何でできてるの？」    │ ← 自分の質問
│      〔🎙 話してみよう〕（大きく）     │
│                     ⌨（すみに小さく）│
└──────────────────────────┘
```

| ボタン | 押すと |
|---|---|
| 〔🎙 話してみよう〕（まん中に大きく） | 押して話す→もう一度押すと送る（声の入力の印）。知りたいことを話すと、バティが調べて答える |
| ⌨（すみに小さく） | 文字で聞く（声が出せない時だけ。第21稿 M-R130） |
| 〔閉じる〕 | MO-1 |

- 入口の一行は台本 L2-MOON-S001 と同じ「〔💬 バティに聞く〕を押すと、まん中に〔🎙 話してみよう〕。知りたいことを話すと、バティが調べて答えます（声が出せない時は、すみの小さな⌨）。月に来れば、いつでも使えます（たくさん聞いた日は、マナを使うことがあります。使う前にたずねます）」。
- 一問一答。見えているのは、いまの質問と答えだけ。前の質問は〔前を見る〕を押した時だけ出る（下へ流し続けない）。
- バティは調べて答える役。悩み相談・恋愛相談の形にしない。答えの下に、毎回、小さく一行「バティの答えが、まちがっていることもあります。大事なことは、自分でも確かめてね」（M-R111(1)。台本 L2-MOON-S001）。体や心の悩みの質問には、調べた答えのあとに、バティが一言だけ「家の人や、信じられる大人にも話してね。」と添える（台本 L2-MOON-S001 の設計注。吹き出しの文字でも出す。医療の言葉は使わない。治せるとも言わない。悩み相談の続きには誘わない）。
- **前の話の一覧**（M-R119。よくある会話の画面の、左にある過去の会話の一覧と同じ考え）：
  - MO-2 の左上に〔📜 前の話〕。押すと、左から一覧がすべり出る（広い画面では、左に一覧の列をずっと出してよい）。
  - 一覧は、残した話がバナーで一本ずつ縦に並ぶ。バナーには、題（最初の質問から自動でつける。あとで変えられる）と日付だけ。新しい順。数・件数は出さない。
  - バナーを押すと、その話が開き、続きから聞ける。
  - バナーの〔⋯〕：〔題を変える〕〔この話を消す〕（「消した話は、戻せません」〔消す〕〔やめる〕）。長押しは使わない。
  - いちばん上に〔＋ 新しい話〕。
- **記録のはじめの設定は〔残さない〕**（M-R119。M-R118までの確認待ちを決定に）：
  - 残さない設定の時は、話の下に一行「この話は、閉じると消えます」と、小さく〔この話を残す〕。押した話だけが一覧に入る。
  - 設定で〔いつも残す〕にすると、すべての話が一覧に入る。
  - 一覧は本人だけが見られる。バティの答えも、残した話も、ほかの人・ダチには見えない。
- 聞いた回数・残りの回数は、どの画面にも出さない。一日の上限に来た時だけ、一度〔画面：今日は、たくさん聞いたね。ここからは、1回ごとにマナを使います。使う前に、毎回たずねます〕［使う／今日はここまで］を出す。以後はマナを使う前に毎回、小さな確認［使う／やめる］を出す（M-R116(3)）。

### MO-2 の補足（第21稿 M-R138・M-R139）
- はじめて使うのは一周目の2日目（D03-S008）。{bati}から「宇宙のことで、知りたいこと、ある？」と聞く。例の札：「ビッグバンって、いつ起きたの？」「ブラックホールの正体って、なに？」「宇宙の果てって、あるの？」
- 画面は、よくある会話の画面に近い形：上に吹き出し（{bati}と自分）が並ぶ。下のまん中に大きく〔🎙 話してみよう〕、すみに小さな⌨。左上に〔📜 前の話〕。はじめての時だけ、使い方を3行で出す（①話す ②{bati}が魔法で調べて、言葉と絵で答える ③続けて聞ける・前の話の続きも聞ける）。
- 答えは、短い言葉が先（マナを使わない）。写真・図は〔🖼 絵で見る〕を押した時だけ出す。絵はウィキメディア・コモンズとNASAの画像ライブラリから探し、だれでもマナを使わない（M-R147。M-R140 の「絵はマナを少し使う」を置きかえ）。将来ふつうのネット検索まで広げる時は〔もっと広く探す（マナを少し使う）〕を足す。月は、宇宙に限らず何でも調べられる場所（検索のように使う）。絵には出どころの名前を小さく添える。使ってよい画像を優先する（宇宙の写真は公的機関の公開画像など）。検索は子ども向けの安全な設定。絵が見つからない時は言葉だけ。
- 調べる時の演出：{bati}が目をつぶり、短い呪文「〈…〉——ここに、こたえを。」→マナジェムがほのかに光り、光の文字がくるくる回ってほどける（数字は出さない）。
- {bati}の表情の絵：生まれた時の一枚から画像生成で作る（ふつう・にっこり・目をきらきら・びっくり・目をつぶって考える・しょんぼり・あくび／眠い）。会話の内容に合わせて切りかえる。動画にはしない。

### MO-3 水盤（姿を試す）

2日目（D03-S003〜S005）と同じ流れ（M-R108(2)）。三つの段を、別々の画面で一つずつ見せる。

| 段 | 画面 | ボタン |
|---|---|---|
| ① 言う | 水面に今の{neo}。まん中に大きく〔🎙 話してみよう〕。ふちに小さな札が並ぶ | 〔🎙 話してみよう〕で変えたいところを話すと〔描く〕が光る。ふちの小さな札〔もっと明るく〕〔もっとクールに〕〔色を青に〕〔耳の形を変えて〕〔小物を足して〕は押して足してもよい。すみに小さな⌨（声が出せない時だけ）。〔今の姿のままにする〕（第21稿 M-R130） |
| ② 確認 | 「マナを使って、4枚の姿を描きます」 | 〔描く〕〔やめる〕 |
| ③ 選ぶ | 4枚を2×2で並べる | 〔この姿にする〕〔言い直す〕（1回だけ）〔今の姿のままにする〕〔もどる〕 |

- ② の画面に出す文は「マナを使って、4枚の姿を描きます」の一行だけ。使うマナの数は出さない（二周目から。M-R75）。「数字なし」はUI向けの注記なので、画面の文には入れない。

```
③ 選ぶ
┌──────────────────────────┐
│ 水盤                        〔もどる〕│
│   ┌────┐ ┌────┐                 │
│   │ 1  │ │ 2  │   ← 4枚（2×2）     │
│   └────┘ └────┘                 │
│   ┌────┐ ┌────┐                 │
│   │ 3  │ │ 4  │                 │
│   └────┘ └────┘                 │
│ 〔この姿にする〕 〔🎙 言い直す〕       │
│ 〔今の姿のままにする〕                 │
└──────────────────────────┘
```

| ボタン | 押すと |
|---|---|
| 〔🎙 話してみよう〕／ふちの札／すみの⌨ | 変えたいところを話す（色・髪・服・持ち物・翼など。現実にない姿でもよい）。札を押すと、その言葉が足される。⌨は声が出せない時だけ |
| 〔描く〕 | ② 確認→〔描く〕で、言ったことの入った4枚を描く→③ |
| 4枚の1枚 | 押すと大きく見られる。選んだ1枚に印がつく |
| 〔この姿にする〕 | 選んだ1枚で MO-4（1枚選ぶまでは薄い色） |
| 〔🎙 言い直す〕 | 要望を〔🎙 話してみよう〕で言って（例「もっとかっこよく」。すみに小さな⌨）、新しい4枚を描く（使う前に②の確認）。1回だけ。使ったあとは灰色にして一行「言い直しは、使いました」。言い直したあとは新しい4枚から選ぶ |
| 〔今の姿のままにする〕 | 姿を変えずに MO-1 |
| 〔もどる〕 | 何も変えずに MO-1（描いた絵は下書きに残る） |

- 一回に描けるのは全部で8枚まで（4枚＋言い直しの4枚）。描き直しの残り回数は数で出さない。
- 作らないもの：〔前の姿にもどす〕、「何度でも試す」、決めた一枚だけを描く形。
- 途中で閉じた時：姿は変わらない。描いた絵は下書きに残り、次に水盤を開くと ③ 選ぶ から（言い直しを使ったかどうかも、そのまま）。
- 姿の決まり：セミリアルの絵、大きめのフード、動物の耳、細い金ぶちの丸いサングラス（目は見せない。M-R94）。サングラスは外せない。
- 星休め（L2-REST-S020）では、①の上に一度だけ水盤の使い方の一行（「水盤のまん中の〔🎙 話してみよう〕で変えたいところを言うと、4枚の姿が浮かびます（1回だけ描き直せます。描く前に使用の確認。すみに小さな⌨）」）を出す。

### MO-6 家の宇宙と、持ち歩く相棒

- バティの一言「ボクを外に連れていって、／宇宙は家で待ってる使い方もあるんだ。」のあと、一行：「家では、壁に宇宙を開く。出かける時は、バティだけ持っていく。どこで何を使うかは、暮らしに合わせて選べます。今の使い方のままでも、最後まで遊べます」。
- 〔この使い方を見る〕〔専用デバイスについて見る〕〔今の使い方を続ける〕。
- 〔この使い方を見る〕：短い暮らしの例（朝、相棒をポケットへ／外で一言メモ／夜、部屋で正方形の宇宙を開いて続きを作る）→MO-1。
- 入口は月に残る。押さない人には出ない。

### MO-7 開発者から

## 9. 決まったこと・決まっていないこと

**決まったこと**
- 問い1 水盤で描く回数（M-R108(2)）：2日目と同じ「4枚→言い直し1回→決める」。全部で8枚まで（MO-3）。
- 問い2 バティに聞ける回数（M-R116(3)）：数字は出さない。上限で一度だけ知らせ、そのあとは1回ごとにたずねる（MO-2）。
- 問い5 体や心の悩みを聞かれた時（M-R111(1)）：調べた答えのあとにバティが一言「家の人や、信じられる大人にも話してね」。医学の言葉は使わず、治せるとも言わない（MO-2）。

**確認待ち**
4. **記録を残すの初めの設定**：決定（M-R119）。はじめは〔残さない〕。話ごとに〔この話を残す〕で一覧に残せる。設定で〔いつも残す〕にもできる（MO-2・MO-5）。

**UIチームが決めてよいもの**
3. **元気さ・話し方の三つの名前**：三つまで（MO-5）。数字・目盛りは出さない。番号は前の版のまま。

### 姿づくり（第21稿 M-R148・M-R149）
- D03-S004 の最初に〔📷 お気に入りの自分の写真を選ぶ〕（主）／〔写真を使わずに作る〕（従）。写真からはセミリアルの絵＋動物の耳・秘密結社のフード・選んだ色・丸いサングラス。写真は作り終えたら残さない。二周目の水盤（L2-MOON-S002）でも写真から作れる。
- 姿を決めた時に、背景のない絵と丸いアイコンも作る。決めた時は画面いっぱいにドーンと出す。〔💬 バティに聞く〕では{neo}の吹き出しの右にアイコン、話すあいだは大きな姿（index.md 0.12）。
