# 立ち絵を「止まった絵で動いているように」見せる（UIチャットへの依頼）

利用者の決定（2026-10-25）：Live2D はまだ使わない。まず、止まった絵（背景透過）と画面の動きで、キャラが生きているように見せる。範囲は土星まで（1日目〜3日目）。

## 1. 絵の形式
- 背景透過の **WebP**（ふちがきれいで軽い）。GIF は使わない（256色でにごる、ふちがギザギザ、重い）。
- 全身の立ち絵。会話のとき、画面に大きく出す。
- 見た目は**今のデザイン**に合わせる（`design/refs/cast/` の各キャラ）。
- `kimorin-pose-*.webp` の3枚は前のデザインなので、そのままは使わない。ポーズと表情の参考だけにする。
- 差分の絵は、同じキャラの参考画像を入れて生成し、顔・服・色がぶれないようにする（Seedream など）。

## 3. 画面でつける動き（全キャラ共通の仕組み）
1. **ポーズの切りかえ**：台詞ごとに、そのキャラのポーズを指定する（台本の台詞に、ポーズの印をつける）。切りかえは0.15秒ほどで、ふわっとつなぐ。
2. **口パク**：声の大きさに合わせて、口を閉じた絵と開けた絵を切りかえる。口が見えないキャラ（OBOLON、MONBAN など）は、声に合わせてほんの少し縦に伸び縮みさせる。
3. **呼吸**：待っている間、2〜3秒の周期で、ほんの少し上下させる（1〜2%）。
4. **話す人の交代**：話している人を少し前に出して明るく、話していない人を少し小さく暗くする。交代の瞬間に、話し出す人を小さく一回跳ねさせる。
5. **まばたきや光**
   - KIMORIN：面の目の青い光を、ゆっくり明滅させる（サングラスのときはしない）。
   - OBOLON：ゆっくり浮き沈みさせ、ふちの白い光を明滅させる。
6. **尾の揺れ（KIMORIN）**：扇の尾を別の絵（別レイヤー）に分けて、ゆっくり左右に揺らす。鼻歌の場面では、鼻歌に合わせてぱたぱた揺らす（台本どおり）。
7. **感情の小さな動き**
   - 驚く：一瞬ぴょんと跳ねる。
   - 無言で見つめる（「シーン……」）：動きを全部止めて、呼吸だけ残す。
   - 動揺：小刻みに震える。
8. **登場と退場**：MONBAN は黒い煙と一緒に出入りする。ほかのキャラは、横からすっと入る、またはその場にふわっと出る。

## 4. 台詞とポーズの合わせ方（例）
- KIMORIN「これは私が発明した、持ち運び式完全肯定型デバイス『ピンポン2.5』です。」→ 説明する
- KIMORIN「さらに、気づきましたか？」→ 言い張る・推理
- KIMORIN「……めちゃくちゃすごい！」→ 喜ぶ
- KIMORIN「ア、、、アイ//？」→ 照れる・動揺
- KIMORIN「え？なんと失礼な。発明は遊びではありません、仕事です！」→ むっとする
- KIMORIN「、、、ふふふふ。もももちろん発明はとても楽しい遊びです。…」→ 言い張る
- MONBAN「おい待て、そこまでだ。」→ 制止
- たこ焼きシスターたち「……」（無言で見つめる）→ 無言で見つめる

ほかの台詞も、台本の流れから同じように当ててください。

## 5. 進め方
1. **試作**：KIMORIN の差分を先に作り、2日目の KIMORIN 登場（D02-S002）と、月の神殿のピンポン2.5の場面（D03-S003）で動きを全部入れる。
2. スクショと動画（または Vercel のリンク）を利用者に見せて、動きの強さ・速さを決めてもらう。
3. 決まったら、ほかのキャラの差分を作り、土星まで全部の会話に入れる。
4. 動きの数値（呼吸の幅、交代の速さなど）は1か所にまとめて、あとから一括で調整できるようにする。
