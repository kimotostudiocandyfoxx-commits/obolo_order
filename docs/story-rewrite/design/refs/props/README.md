切符の注意（台本とのすり合わせ）：
- 台本では、切符に「星の形のスタンプ欄が4つ（土星・木星・水星・火星）」があり、星に行くたびにスタンプが押される（7日目に4つそろう）。この絵にはスタンプ欄がないので、裏面か、もぎりの部分に4つの欄を足す。
- 切符が届くのは2日目の最初（KIMORINに会う前）。そのため「同行者 KIMORIN」は、届いた時点では空欄にしておき、KIMORINに会ったあと（ロケットに乗る時）に名前が浮かび上がる形にする。
- 「三日間」は、物語の見学の期間（一周目は7日間・星は4つ）と合わない。利用者に確認する。
