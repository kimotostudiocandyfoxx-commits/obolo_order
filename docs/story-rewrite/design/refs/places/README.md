# 場所・乗り物の参考画像（利用者から・イメージ図）

本番の背景を作るときの基準。生成するときは参考画像として使い、雰囲気・色・建物の形をそろえること。縦長（スマホ縦向き）。

| ファイル | 場所 | 特徴と、台本とのつなぎ方 |
|---|---|---|
| moon-temple-inside.jpg | 月の神殿（中） | 白い大理石の柱とアーチの回廊。床いっぱいに、青と銀の魔法陣の模様。アーチの向こうに大きな青い地球と星空。奥にもう一つの小さな神殿。→ 台本の「床の真ん中の水盤」は、床の中央の大きな魔法陣の位置に、浅い水を張った丸い水盤として置く。KIMORINの変身で水が立ち上がるのはここ。奥の小さな神殿が「たまご二つの祭壇」 |
| moon-temple-aerial-1.jpg | 月の神殿（上から・正面） | 月面のクレーターの中に建つ、白い神殿の全景。青い魔法陣の床が奥へ続き、両脇に青いドームの小塔。空に地球。→ ロケットが月に着く場面、神殿の外観 |
| moon-temple-aerial-2.jpg | 月の神殿（上から・斜め） | 同じ神殿を斜めから。月で眠る夜（2日目の終わり）や、3日目の朝の外観にも |
| rocket.jpg | ロケット | 黒い細長い機体に、金の唐草のような模様。ピンクと水色のネオンの線、オレンジの紋章の光。尾翼は鋭く後ろへ。噴射口は3つ。→ 台本の「細長い古いロケット。胴体に、いろんな星の紋章」は、この金の模様と紋章の光で表す。中は「広すぎる」くらい広い |
| earth-temple-hall.jpg | 地球の神殿・奥の大広間（OBOLONが現れる場所） | 金色に光る、天井の高い大広間。磨かれた床に光が映りこむ。正面の階段の上に、巨大な金色の光の輪（魔法陣の円盤）。両脇にランタン。→ OBOLONは、この光の輪の前（光の柱の中）に浮かぶ黒い球として現れる。台本の「天球儀が並ぶ、暗い神殿の大広間」は、この金色の大広間に合わせる（OBOLONの「天井が夜空になる」演出は、この天井で） |
