# キャラクターの設定画（利用者から・本番の見た目の基準）

土星まで（1日目〜3日目）を本番品質で作るための、キャラクターの基準の絵。生成するときは、必ずこの絵を参考画像として使い、形・色・模様を変えないこと。

|---|---|---|

| takoyaki-brother.jpg | たこ焼きブラザー | 大柄な筋肉の体。黒い岩のようなうろこの肌に青く光る筋。頭は金色にひび割れた球（たこ焼き）で、大きく歯をむいた口。口の両端から曲がったひげ。肩にとげ、腰と手首と足首に鎖、腰に丸い紋章、ぼろぼろの黒い腰布 |

| kimorin-normal.jpg | KIMORIN（通常時） | 丸いサングラスをフードの上（おでこ）にかけた姿。赤いフードつきローブ（銀の縁取りの模様）、狐の耳（内側が青）、白い面に青い目（光る細い切れ目）と青い渦巻きの頬、おでこに青い紋様、ねこ口。胸に青い宝石のブローチと青い房飾り。白い手袋と靴に青い肉球。背中に白・黒・朱の羽の尾が扇のように広がる。※右下の「Genspark」の透かしは使わないこと |
| kimorin-entrance.webp | KIMORIN（登場時） | 丸いサングラスを目にかけた姿（ほかは通常時と同じ）。2日目の登場「待ちなさい。」から、ユーザーに最初に話しかける「気をつけなさい。」の場面まで、この姿。そのあとサングラスをおでこに上げて通常時になる |

メモ：
- OBOLON・たこ焼きの二人は、写実寄りのダークファンタジー（3DCGの質感）。KIMORINは、同じ質感の中で、かわいいデフォルメの体型。
- 月の神殿でKIMORINが変身して戻ったあと「扇の尾のあいだに、小さなドラゴンの羽が一枚。おでこに丸いサングラス」とある。サングラスは通常時の絵どおり。ドラゴンの羽は、この絵に足す形で作る。
