### 0-5. 音の決まり（切れ目を作らない）
- **動画には音を焼きこまない**（Seedance は `audio:false`）。効果音は Seed Audio で別に作り（M-R137）、BGMといっしょに編集かアプリで重ねる。
- **BGMは一本の流れ**：映像のために曲を止めない。映像用の曲（`bgm-film-*`）に替える時は、前の曲から2秒のクロスフェードで入り、映像が終わっても次の台詞まで同じ曲を流し、場面の曲へ2秒で戻す。
- **映像のあいだに台詞が入る場面**（OBOLON・月の変身・コロリン）は、映像を分けても曲は一本で流し続ける。映像の最後の絵を止め絵（または2秒のループ）にして台詞を待つ。
- 0.3秒より長い無音は作らない。例外はわざとの間（V01 の頭、「シーン……」）だけ。
- 利用者の音（`docs/story-rewrite/音/pinpon-press.wav`）は加工しない。くぐもった音は lowpass 650Hz を2回（quality-notes）。

## 3. 品質チェック（止め絵が「完璧」かどうか）

### 3-1. 止め絵（キーフレーム）の共通チェック
すべてに ○ がつくまで、動画に進まない。
1. **体のつくり**：手の指の数、腕と脚の数（ドラゴンの80本だけ例外）、耳は2つ、尾は体から生えている、首と頭のつながり、立ち姿が浮いていない（足が床に接している）。
2. **人物の一致**：参照画像と並べて同じに見える。
   - KIMORIN：おでこの青い葉の紋、頬の青い渦巻き、ω の口、耳の内側の青、青い肉球。服が時期どおり（0-4 の1）。ゴーグル・サングラスの下の目が光っていない。
   - MONBAN：額の金の目がひとつ、頭の後ろの金の輪、金の線の模様。
   - OBOLON：まん丸、ふちの白い光、三日月の目、口なし。
   - たこ焼きの二人・うんちピンポンくん・コロリン：模様と色が参照どおり。
3. **立ち位置**：0-4 の3 のとおり（MONBAN 左、KIMORIN 右、ブラザー左、シスター右）。前後のカットで同じ。
4. **光**：場所の光（0-4 の5）と時間帯が合っている。対になる2枚（最初の絵・最後の絵）で、光の向き・色温度が同じ。
5. **構図**：9:16。主役は上〜まん中。下の約22%に顔・手元を置かない。カメラの高さが前後のカットとつながる。
6. **汚れなし**：文字・数字・記号の読める形・ロゴ・透かし（参照画像の「Genspark」）・崩れた文字のような模様がない。指や物の溶け、二重の輪郭、継ぎ目、変な人がまぎれていない。
7. **絵柄**：今の決まった絵と並べて浮かない（暗いファンタジー、金の光、細かい装飾、人物は3DCGの質感、KIMORINはかわいいデフォルメ）。
8. **対の2枚**：変わるのは「動くもの」だけ。背景・人物の形・服・カメラの位置は、動きで説明できる差だけ。前のカットの最後の絵＝次のカットの最初の絵（同じファイル）。
9. **実写の部分（V01 の K1〜K7）**：写真と見分けがつかない、有名な場所に見えない、看板や文字がない、人は後ろ姿だけで小さい。

### 3-2. 動画のチェック（つないだあと）
- 途中で顔・服・尾が変わらない（とくに KIMORIN の服、MONBAN の目の数）。
- 文字が湧いてこない。動きがなめらか、ちらつきなし、急な閃光なし。
- 最後の数フレームが、次の止め絵と同じに見える（つなぎ目が見えない）。ループは継ぎ目が見えない。
- スマホの縦画面で、字幕とボタンが乗っても大事なものが隠れない。

## 4. 制作の回し方（だれが何をするか）

### 4-1. 流れ
1. **参照シート**（UIチャット）：[KIMORIN-LAB]・[KIMORIN-ROBE]・[KIMORIN-DRAGON]（白衣版）・[MONBAN]・[ROCKET] の三面図を灰色の背景で作る → 台本チャットが3-1で見る → **利用者がOK**。以後、すべての生成でこのシートを参照に入れる。
2. **試しの1本**：V02（KIMORINの登場）でループ全体を一度通し、利用者に絵の質・動きの強さを決めてもらう。
3. **キーフレームを作る**（UIチャット）：1枚につき候補を **背景・物だけは4枚、人物の入る絵は6〜8枚**作り、レビューの置き場へ push。候補を並べた一覧の絵（シート）も一枚つける。
4. **見る**（台本チャット）：3-1 で採点し、①選ぶ（番号）②直しの指示（何が・どこが・どう違うか、直しのEN一行つき）③全部だめ（作り方を変える）のどれかを書く。
5. **直す**（UIチャット）：小さな直しは編集（顔だけ・手だけ。quality-notes の「見本の顔だけを切り出して2枚目に」）、大きなずれは描き直し。3回直しても通らない絵は、構図を変える・カットを分ける・参照を足すなど、作り方を変えて台本チャットと相談。
6. **一本ぶんがそろったら**：その映像のキーフレームを順に並べた**絵コンテの一枚**を作る → **利用者がOK／作り直し**を押す。
7. **動画にする**（UIチャット）：OKになったキーフレームの間だけ、Seedance 2.5（720p・5秒・`audio:false`）で、1カットにつき2本作り、3-2 で良いほうを選ぶ（台本チャットも見る）。だめなら動きの文だけ直して作り直す（止め絵は変えない）。
8. **組む**（UIチャット）：カットを切ってつなぎ、BGM を一本で通し、効果音を重ねる（0-5）。台詞が間に入る映像は、止め絵・ループの長さをアプリ側で台詞に合わせる。
9. **スマホで見る**（利用者）→ OK でアプリにはめこむ（`豪華映像_制作とはめ込み_依頼.md` の4章の決まりのまま：スキップ可、途中で閉じたら頭から、見終えたら再開で流さない）。

## 8. 確認したいこと（利用者へ）
1. **2日目の切符**：台本 D02-S002 は「紙飛行機」、今のアプリと利用者の言い方は「折り鶴」。折り鶴にそろえてよいか（よければ台本のト書きを台本チャットが直す）。
2. **変身後のサングラスの位置**：この台本では「目にかける」を基本にした（M-R100、D04-S007 の「押し上げて」と合う）。目が光る演出（涙など）はおでこに上げてから。設定画の README の「通常時はおでこ」と違うので、どちらにするか。
3. **「KIMORINはMONBANの右」**：画面から見て右（今のアプリの絵と同じ）でよいか。
4. **KIMORINの登場の長さ**：台本の約7秒から、約16秒（MONBANの煙まで）にした。
5. **二人だけの船室（V03b）**：主人公は映さない決まりなので、「二人」はKIMORINと、空いたもう一つの席（主人公＝カメラの席）で見せる。これでよいか。
6. **一人ひとり違うもの**（{bati}の誕生、主人公の変身の水面、{neo}のコロリン）：一人ずつ動画を作らず、作りおきの映像に、その人の絵をアプリが重ねる形にした（費用。M-R139・M-R154）。
7. **土星の夜のリレー（V21）**：歌うのは住人のコロリンだけにした。{neo}とKIMORIN⭐︎のコロリンも最後に加えるか。

## 9. 利用者の答え（M-R170）
1. 変身後のKIMORINのサングラスは、ふだんは目にかける。目が光る時だけ、おでこに上げてから（M-R100）。
