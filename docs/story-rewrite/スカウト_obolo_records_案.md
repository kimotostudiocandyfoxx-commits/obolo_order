# スカウト：obolo records と公式チャンネル（案）

作成：2026-10-25。**決定済み（M-R92）。** 名前は「使者」、完全スカウト制、配信は1曲ごとにMANA、公式チャンネルは運営が選ぶ。台本は特別編 EX-SCOUT-S001・S002。

---

## 1. 考え方
- **アプリの中は、数のない町。外の世界は、数の流れる「ナガレ」。**
- スカウトは「すごい人へのごほうび」ではなく、「oboloの音を、ナガレの中へ運ぶ役目」です。
- 外のサービス（Spotify や YouTube）に曲が流れれば、それを聴いた誰かが自分の声を思い出すきっかけになる。oboloが広まれば、oboloの考え方も、おのずと広まる。
- だから、**数字を目指させない**。目指して取りにいくものにすると、数を競うナガレがアプリの中に入ってきてしまうためです。

## 2. 物語の中での名前と位置づけ
- **役目の名前（案）**：「**使者**」
  - 外の世界へ、oboloの音を運ぶ役目。称号ではありません（称号は今の7つのまま。コスモスも称号にしない、という決まりと同じ考え方）。
  - ほかの候補：「運び手」「灯り持ち」。
- **選ばれた戦士にしない理由**：謎5の答えは「救世主は、選ばれた一人ではなく、仲間一人ひとり」です。スカウトを「選ばれた者」にすると、ここと食い違います。
  - そこで「選ばれた＝上」ではなく、「**この音は、いま外へ運ぶのに向いている**」という、役目の話にします。
  - 選ばれなかった人も、同じ DJ で、同じ仲間です。台詞でもそう言い切ります。

## 3. いつ、どう届くか
- **時期**：コスモスを見つけたあと（太陽の終章を終えたあと）だけ。
- **届き方**：ある日、突然。地球の郵便受けに、銀色の封筒が一通。
  - 新着通知やバッジでは知らせない（引き戻す通知を送らない、という今の決まりのまま）。次に開いたときに、そっと置いてある。
- **中身（案）**
  - 封筒：銀色、『obolo records』の刻印。
  - MONBAN（スクリーンの中）「……届け物だ…。」
  - 手紙：「あなたの〈曲名〉を、外の世界へ運ばせてほしい。　obolo records」
  - **短い豪華映像（約30秒）**：アプリの中の灯りが、門の外のナガレの中へ一つ流れていく → 流れの中で、それを聴いた誰かが、ふと顔を上げる → その人の部屋に、小さく色が戻る。
  - OBOLON「、、、外へ、運ぶ、役目だ。」「上も、下も、ない。、、、向いている、だけだ。」
  - KIMORIN（受けとった人がKIMORINの隣のアトリエの場合など、出せる場面で）「……私の所には、まだ来ていませんが。ええ、待っていませんとも。」
  - ［引き受ける］［今回は、見送る］（見送っても、何も失わない）

## 4. 選び方
- **運営の人が、作品を聴いて・見て選ぶ**（音楽の担当者による選定）。
- **数字では選ばない**：再生数、☆、フォロワー数は使わない（今の仕様の「1,000 Loops かつ 100 Stars でスカウト」は、この案に置き換える）。
- **条件は公表しない**：「どうすればスカウトされるか」のチェックリストは出さない。目指して作るものにしないため。
- 見るもの：曲やアニメの完成度、その人らしさ、obolo の考え方に合っているか。
- 対象：公開・届けてもよいと本人が設定した作品だけ。自分だけに保存した作品は、運営も見ない。

## 5. スカウトされたら受け取れるもの
1. **obolo records からの配信**：LabelGrid を通して、Spotify・Apple Music などへ。
   - 名義は秘密結社の名前のまま（姿と名前を変える、の掟どおり）。
   - 収益は作者 92%、obolo 8%（今の仕様どおり）。円で記録し、本人の口座へ振り込む。
2. **会社の YouTube 公式チャンネルでの公開**：曲、MV、アニメ。広告収入を分配する。
3. **費用**：スカウトでの配信は無料をおすすめします（会社がアプリの宣伝として投資する形）。今の仕様の「配信は 500 MANA」は、自分から配信を申し込む仕組みを別に作る場合だけ残す。

## 6. アプリの中で数を出さないための線引き
- 配信や公開をしても、アプリの中には再生数・リスナー数を出さない。
- 入ったお金だけは、お金として地球の銀行に「収入」で出す（人気の数字ではないので）。
- 物語の中で一言だけ添える：MONBAN「……外の数は、外のものだ…。持ち帰らなくて、いい…。」

## 7. 気をつけること（法律・ルール）
- **未成年**：配信の契約と収益の受け取りは、18歳未満は保護者の同意が必要。スカウトの手紙からそのまま同意の手続きへ進める。
- **生成した曲の扱い**：Spotify は2025年9月に、生成の使い方の表示（業界の標準づくり）、他人の声のなりすましの禁止、大量投稿のスパム対策を打ち出しています。生成の道具を使うこと自体は禁止していません。人の手で選んで少数だけ出す今回の形は、スパムにならない点で相性がいいです。
  - 配信するときは、生成の使い方の表示に対応する。
  - 他人の声のクローンは配信しない（本人の声と、アプリのキャラの声だけ）。
  - 権利の確認：本人が作ったものであること、使ったモデルの利用条件が商用配信を許していること。
- **LabelGrid**：API で配信・印税の計算・分配まで組める（自社のブランドで出せる仕組みあり）。分配の細かい仕様は、契約前に LabelGrid に確認が必要。
- **YouTube**：公式チャンネルで公開するには、作者との利用許諾の取り決めが必要。

## 8. 決めてほしいこと
1. 役目の名前：「使者」でいいか（ほかに「運び手」「灯り持ち」）。
2. スカウトでの配信を無料にするか、88円にするか、500 MANA にするか。
3. 自分から配信を申し込む道も残すか（残すなら、スカウトとの違いをどう見せるか）。
4. スカウトの封筒が届く場面を、特別編（EX）として台本に入れるか。
