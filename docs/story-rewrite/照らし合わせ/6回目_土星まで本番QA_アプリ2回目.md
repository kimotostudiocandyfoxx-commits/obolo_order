## 3. 土星（D04-S003〜S007）の遊びやすさ・楽しさ

見た所：`d3/d3_125`〜`d3_191`（着いてから神殿の中）、`sat/`（練習。光る輪のコロリンを押して進めた）、`sat2/`（練習の終わり〜その夜）、`d3b/`（その夜）。一覧：`sheet2_C_saturn.png`。

### 流れ（今のアプリ）

1. 土星への豪華映像 → 金の宮殿の静止画（N15）→ 神殿の中で、たこ焼きブラザー（左）とシスター（右）が大きく出て話す（`d3/d3_136`〜`d3_189`）。ここは絵も声も大きく、見やすい。
2. 「ころりんぱ」の世界（うすむらさきの空、輪、下にコロリンの山 約30個）に切り替わり、上の細い帯で台詞が進む。KIMORIN⭐︎の石→ピンポンくんがタッチ→KIMORIN⭐︎のコロリン→〔👆 コロリンをタップ〕（光る輪と👇）→歌（紙吹雪とポッキーのような光の棒、`sat/d3_015`）。
3. ブラザーの説明 → 自分の声を吹きこむ（大きなオレンジの〔🎙〕、すみに「⌨ 文字で」、`sat/d3_023`）→ 自分のコロリンをタップ（`sat/d3_024`）→ 3人の受け → 〔🏠 自分の部屋に飛ばす〕（`sat/d3_028`）→ 説明 → 「もうひとつ／次へ」。
4. デザイン：KIMORIN⭐︎の80本腕 → 自分の〔おまかせ〕→ マナの確認 → 4つの絵から選ぶ（`sat/d3_050`）→ 「並べると、私のほうが、腕が多いですね。」

### 分かりやすい所・楽しい所

- 1つの画面で、やることは1つ。〔🎙〕〔🏠 自分の部屋に飛ばす〕は大きく光っていて、迷わない。「⌨ 文字で」も見える（N12）。
- 押すコロリンに光る輪と👇が付いた（N11）。押さないと進まない所で止まらなくなった。
- KIMORIN⭐︎のコロリンが歌うと紙吹雪と光の棒が出て、にぎやか。夜になると空が暗くなって輪が光り、場面が変わったことが分かる。
- デザインの4つの絵は大きな札で並び、選びやすい。BGMが小さく流れ続けるので、間が持つ（N14）。
