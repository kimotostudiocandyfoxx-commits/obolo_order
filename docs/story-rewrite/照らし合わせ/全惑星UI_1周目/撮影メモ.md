共通して目立つこと：
1. **デモの注意帯のぶん、下のナビが画面からはみ出す**。土星・木星・水星・火星の `/星` は、ワールドの高さが `calc(100svh-56px)` で、その上に `DemoBanner`（約40px）が乗るので、下のボタン列の中心が y≈849〜858（画面は844）。最初の画面では下のナビが半分切れている（`jupiter/01`・`mercury/01`・`mars/01`・`saturn/01`）。確認用ページの `?world=` では切れない（`*/kakunin-world`）。本番（API あり）では帯が出ないので起きない可能性が高い。
2. **確認用ページ `?world=…` の「← 確認用ページ」が、上のタブや見出しに重なる**（`saturn/10`・`jupiter/11`・`mercury/12`・`mars/11`・`venus/03`）。確認用ページだけの問題。
3. **確認用ページの飛び先のずれ**（`kakunin-index.png`、`app/kakunin-5798f28713/page.tsx`）：`at=` に存在しない step 名を渡すと `findIndex` が −1 → 0 になり、その日の最初から始まる。
   - `day=1&at=riddles`「1日目：8つの謎の札から」→ day1 に `riddles` はない（day2 にある）。1日目の最初（開く前の画面）から始まる。
   - `day=2&at=pause`「2日目：やめておく」→ day2 に `pause` はない（day1 にある）。
   - `day=7&at=branch`「7日目：太陽の神殿から」・`day=7&at=made`「上映7日間」→ day7（金星）にない。今は `day=8` が太陽（`STORIES[8]=DAY8`）。`day=7&at=ticket` は金星のスタンプの切符で、見出しの「地球でORDERになるか決める」ではない。
   - 一覧の「8日目 金星（一周目には出ない・旧台本）」と `day=8`「金星：ゴリラ3人組（旧8日目の台本）」は、今は**太陽の日**（DAY8）が開く。
4. 声で答える場面は、作りものマイクだと「うまく聞き取れませんでした、もう一度どうぞ」（`earth/25`）。「例で進む」かキーボードで先へ進める。
