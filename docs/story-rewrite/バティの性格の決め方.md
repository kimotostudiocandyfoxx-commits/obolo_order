## 2. 種から性格を決める決まり（上から順に見る）
1. **答えが食べ物でない・ふさわしくない時**
   - ふさわしくない言葉（下品すぎる、悪口、危ない物）：OBOLONが「、、、食べられるものを、言ってみろ。」と、もう一度聞く（性格は決めない）。
   - 冗談のような答え（「うんち」「石」「空気」など、笑いで済むもの）：めずらしい性格から選ぶ（例：空気→忍者、石→哲学者）。KIMORINの「うんち」と同じように、笑って受け取る。
2. **土地の食べ物（地方の名物）**：その土地のことばの子にする。
   - 関西（たこ焼き・お好み焼き・串カツ・551 など）→ 関西弁の子
   - 福岡・九州（もつ鍋・明太子・とんこつラーメン・ごまさば など）→ 博多弁の子
   - 東北（きりたんぽ・牛たん・ずんだ・芋煮 など）→ 東北のことばの子
   - 沖縄（ゴーヤチャンプルー・ソーキそば・サーターアンダギー など）→ 沖縄のことばの子
   - ほかの地方の名物は、その食べ物の感じ（下の4）で決める。
   - 海外の料理は、ことばのまねはしない（その国の人をからかう形にしない）。食べ物の感じで決める。
3. **王道の食べ物か、マイナーな食べ物か**
   - 王道（多くの人が好きと言う物：からあげ・カレー・ラーメン・寿司・ハンバーグ・焼肉・おにぎり・パスタ・チョコ・アイス など）→ **ふつうの性格**から選ぶ。
   - マイナー（あまり聞かない物、組み合わせが変な物、細かすぎる物：「ほや」「くさや」「いなごの佃煮」「ポテチにアイスをのせたもの」「近所の店の〇〇定食」など）→ **めずらしい性格**から選ぶ。マイナーなほど、めずらしい性格にする。
4. **食べ物の感じ**（2・3で決まらない分を決める）
   | 食べ物の感じ | 合う性格 |
   |---|---|
   | 甘い・やわらかい・小さい（プリン、マシュマロ） | 赤ちゃん言葉／のんびり |
   | 辛い・熱い・がっつり（激辛、カツ丼） | 熱血／元気 |
   | 高い・上品（ステーキ、うに、フレンチ） | 王様気どり／敬語／執事 |
   | 冷たい・さっぱり（冷やし中華、そうめん、レモン） | クール |
   | 手間がかかる・こだわり（自家製、手打ち） | 哲学者／武士 |
   | 屋台・おやつ・ジャンク（ポテト、駄菓子） | おっちょこちょい／ギャル |
   | 音が鳴る・リズムがいい（せんべい、ポップコーン） | ラッパー |
   | 名前がきれい・季節もの（桜餅、かき氷） | 詩人 |
5. **同じ種でも、少しだけゆらぐ**：同じ食べ物でも、いつも同じ性格になるとは限らない（合う性格が2つある時は、どちらかになる）。「何と言えば、どんな子になるか」を楽しんでもらう。
6. **KIMORINと同じ性格は避けない**（ダチと同じでもよい）。

## 3. バティのカード
生まれた時に、チャットの中にカードで出る。Bluenaの最初の棚（顔の記号）にも入る。画像として書き出せる（SNS・待ち受け用）。
- 名前／生まれた日／たまご（月か太陽か）
- 好物：答えた食べ物（そのままの言葉）
- 性格と口ぐせ：例「関西弁の子｜口ぐせ：めっちゃええやん！」。めずらしい性格は、カードの縁が金色に光る。
- 紹介文（AIが種に合わせて書く・40字くらい）：例「たこ焼きの湯気から生まれた。うれしいと、くるくる回る。」

## 5. 決めたこと（同じ日の決定）
- {bati}は3体まで。3体そろったら、新しいたまごは出てこない（「月で眠らせる」はなし）。
- {bati}のトレード（交換）はしない（会話の記憶が渡ってしまう・お金の取り引きや詐欺のもと・手放すのが悲しい）。
- 代わりに「遊びに行かせる」：自分の{bati}を、ダチのチャットに一日だけ遊びに行かせる。ダチの{bati}と話して、帰ってきて「{neo}のダチの子と、こんな話をしたよ」と教える。記憶と{bati}は持ち主のもとに残る（ダチの会話の中身は持ち帰らない）。
