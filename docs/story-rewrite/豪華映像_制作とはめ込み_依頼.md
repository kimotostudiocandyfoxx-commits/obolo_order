## 2. エクリプスの記録映像（いちばんの見せ場）
- 「Obolo Order 本部　記録映像　ORDER以外の閲覧を禁ず」。古いフィルムの傷と粒子、映写機の音、結社の紋章、黒塗りの書類。
- 三部構成：記録 I ナガレ ／ 記録 II Obolo Order ／ 記録 III 掟。カットは台本の D08-S011b にすべて書いてあります。
- **前半は実写と見分けがつかない質感**（夜の街・電車・夜中3時の部屋・架空のSNSの画面）。最後に、街の灯りが空へのぼってアニメの宇宙につながる。
- **声は OBOLON と MONBAN だけ**（ナレーターは置かない）。台詞は台本どおり。
- 映像のあと、神殿に戻って KIMORIN「……なるほど……全然わからなかった。」→ OBOLON「、、、そうか。」。
- 1日目の冒頭と同じ街角を、同じ高さから撮る（1日目＝ふつう、エクリプス＝色が抜ける。最後の太陽の終章で、色にあふれて三回目が来る）。

## 3. 作るときの決まり
- 実在のSNSの画面・ロゴ・ブランド・実在の人物は出さない（画面はすべて架空のデザイン）。
- 本物の統計の数字は出さない。人気の数字（いいね・人数など）も出さない。
- 絶望・病気・自傷の描写はしない。「疲れて色が抜ける」まで。最後は必ず光と音で希望に終わる。
- 「AI」という言葉は出さない。
- キャラは参考画像（`design/refs/cast/`）に合わせる。場所は `design/refs/places/` に合わせる。
- 音（BGM・効果音）もつける。映像の中の台詞は、今の声の作り方で声にする。

## 4. はめ込みの決まり
- 決めた場面の、決めた位置で流す。映像には〔スキップ〕を出してよい。
- 同じ星に2回目以降に着くときは、映像なし（またはごく短い寄り）。三周目の太陽は短い版。
- 映像の途中でアプリを閉じたら、その映像の頭から。見終えた映像は、再開してももう一度流さない。
- 1〜3日目の台詞と、決まった台詞は変えない。
- 4〜7日目の画面がまだない場合は、その日を作るときに、台本どおりの位置に映像を入れる。

## 5. 進め方
1. 先に、1日目の冒頭（#1）と、エクリプスの記録映像の「記録 I」の部分だけ作り、利用者に見せて質感（実写の感じ、アニメへの切り替え）を決めてもらう。
2. 決まったら、残りを作ってはめ込む（#2〜#5 → #6〜#9 → #10 の順）。
