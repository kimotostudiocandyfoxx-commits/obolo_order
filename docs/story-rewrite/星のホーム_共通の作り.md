# 星のホーム：全部の星の共通の作り（決定 M-R258・2026-11-23）

> どの星も「**手前に自分の場所、そのまわりにダチと推しの新しい作品**」の1画面。星ごとに変わるのは、自分の場所の見た目と、飛んでくる物の形だけ。開発は「星のホーム」の部品を1つ作り、絵と動きを入れかえて全部の星に使う。土星の詳しい決まりは `土星_自分のレコード.md`（M-R257）。

## 1. ひとことの説明（全部の星で同じ形）
「**あなたの○○のまわりに、ダチと推しの作品が88時間あつまる。○○の中には、あなたの作品がずっと飾られる。**」
（土星だけ：「あなたのレコードに、ダチと推しのコロリンが88時間降ってくる。再生すると、針のマイクの前で歌う。」）

## 3. 共通の操作
- **まわりの作品をタップ**：手前へ来て、再生される／大きく開く。下に作った人の名前（ダチ＝白・推し＝ピンクの小さな印）。長押しで〔推す〕〔外す〕〔通報〕。
- **自分の場所をタップ**：中に入る（土星だけは再生ボタン）。中では、自分の作品を新しい順に並べる。並べかえ・外すもできる。
- **遠くの景色をタップ**：知らない人の作品を一つ近くで見られる。〔推す〕で推しになり、次からまわりに来る。〔通報〕〔見えなくする〕あり。**15歳未満には遠くの景色を出さない。**
- **新しく届いた物**：前に開いてからまわりに来た物だけ、小さくきらめく。数（何人・何回）は出さない。
- **88時間たった物**：その星らしく帰っていく（蝶は飛び去る、船は沖へ、UFOは上へ、電波は消える、コロリンは空へ）。
- **飛ばした時**：月の工房やBluenaで〔○○へ飛ばす〕を押すと、作品が空へ飛んでいく短い演出のあと、{bati}「{neo}の○○と、ダチ・推してくれている人の○○に届いたよ」。自分の作品は自分の場所の中にずっと入る。

## 4. 画面の形（全部の星で同じ）
- 縦長。下の3分の2に「自分の場所」を大きく（少し見上げる角度、名札つき）。上と左右の空・海に「まわり」の作品が浮かび、ゆっくり動く。いちばん奥に「遠くの景色」。
- 上に星の名前と、ひとことの説明（初めての時だけ大きく、2回目からは小さく）。右上に〔推し〕の一覧（推した人と外す）。
- M-R255 の星のエフェクト（空と手前の漂う物）を重ねる。背景は「キャラの大きさに合わせた背景」の作り方で、人がいない絵。

## 5. 前の決まりとの関係
- M-R208 の表の「88時間のあいだ（星の広い場所）／88時間のあと（自分の場所）」は、「自分の作品は飛ばした時から自分の場所の中にずっと／ダチ・推しの作品は自分の場所のまわりに88時間」に読みかえる。
- M-R213 の「星の広い場所に知らない人の作品も並ぶ」は、「遠くの景色」に置きかえる（近くには出さない）。推しはダチと、遠くの景色から推した人。
- 本番に出す順（最初の人が着く前の日まで）：土星 11/27・木星 11/28・水星 11/29・火星と金星 11/30。
