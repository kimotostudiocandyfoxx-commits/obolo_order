## 1. 日ごとの流れ（一周目は7日間。ここでは1〜3日目）

**1日目（地球の本部）**
招待状が届く（封を開く→正式な招待カード）→ 本部の門でMONBAN →〔招待状を見せる〕→ 地球の神殿でOBOLON（光の柱の中の黒い球）→ 名前と年齢 → 話を聞く／やめておく → 8つの謎の札（1・7・8だけ字が出る）→ 謎の書を手に入れる → 招待者からの手紙とマナジェム → 2日目までのカウントダウン＋〔明日まで待てない〕

**2日目（地球 → 月）**

**3日目（月 → 土星）**
メール認証 → KIMORIN「おはようございます…今日行く場所は、どこですか？」→ OBOLON「土星だ」「俺は、地球と、月と、太陽の間しか、移動できない」→ **Bluenaを手に入れる** →〔Bluenaで投影する〕でMONBANが正方形のスクリーンに映る（一日88分のルール）→ ロケット → 中でもう一度投影してMONBANと話す（「今日、謎が一つ解ける」）→ 土星の神殿（趣味の悪い金ぴか）→ たこ焼きブラザーとシスター → **コロリンの遊び方**（KIMORIN⭐︎のお手本→本人がつぶやく→自分の部屋へ）→ 空を舞うコロリンのリング、くしゃみのコロリンに☆ → **謎2「OBOLO ORDERは全員」＝「表現者」が解ける** → 夜：木星の王様の手紙 → 4日目までのカウントダウン

## 5. 守るルール
- 画面に「AI」という言葉を出さない。88マナの表示を出さない。人気の数字（☆の数・フォロワー数など）を出さない（P-UI-4 と同じ）。
- 〔テロップ〕は短い文字だけ。ナレーションは使わない。
- 「やめておく」（D02-S004の stop）はその日を本当に終えられて、次はその選択から再開できる。ほかの「やめる・言わない・パス」は、そのまま先へ進める（押しつけない）。
- **OBOLONは地球・月・太陽にしか本人で出ない。MONBANは地球の本部（門・神殿・地下の発射場）から離れない。** それ以外の場所で話す時は、Bluenaの正方形のスクリーン越し（話者は「MONBAN（スクリーンの中）」）。
- 一周目のコロリンは自分の部屋だけ（広場は二周目から）。
- 見た目：OBOLON＝光の柱の中の黒い球（閉じた目のにっこり顔）。MONBAN＝黒いフードのローブ、金色の目がひとつ、背中に金の光の輪、黒い煙から現れる。本部＝夕焼けの下の金と黒の都。KIMORIN＝深い赤のローブ、狐の耳の白い面（秘）、白・黒・朱の羽の扇のような尾。月の後は、尾のあいだにドラゴンの羽一枚、おでこに丸いサングラス（参照画像 `docs/story-rewrite/design/kimorin.jpg`、`kimorin_sunglasses.jpg`）。

## 8. 台本の書き方の読み方
- `〔テロップ：…〕` 声に出さない短い文字。`〔画面：…〕` 操作の案内。`〔ボタン：…〕` 押すボタン。`〔入力：…〕` 入力欄。`［選択肢：A→a ／ B→b］` 分岐（矢印の後は分岐の名前）。`（a）` その分岐の中身。
- `〔…〕` そのほかは絵・動き・音の演出。`（架空の入力例）` は表示しない（作る時の例）。
- `→D04-S003` 次の場面（書いていない所は§3の表のとおり）。`## D04-S005｜コロリン` 場面IDと題。
