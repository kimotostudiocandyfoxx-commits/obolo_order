# 本番UI化：UIチャットへの依頼文（物語チャットで作成）

決まったこと：絵柄は「暗いファンタジー＋金色の光」に統一（惑星ごとの色と素材の違いは少し残す）／授業のあいだ、サンプルの住人の投稿は隠す。

---

これまでの物語（一周目：1〜7日目）を、本番に近い見た目と体験にしたいです。文字だけで先に進めるのはいったん止めて、画面を見ながら続きを作ります。目標は「ゲームとアニメの間」の手ざわりです。次の順で進めてください。

1. 物語ブランチ（claude/hopeful-pascal-udqkh2）の最新を読み込み直して、古い部分を直してください：3日目の声の録音と話題のヒント、7日目の新しい太陽（OBOLONだけ、太陽の中へ飛び込む、太陽の中の背景を新しく描く）、招待は二周目へ移す。
2. スマホ幅で各日の画面のスクショを撮る仕組みを作って、変更のたびにチャットに貼ってください。
3. 物語画面の下に、共通の「舞台」部品を作ってください。層は背景（奥・中・手前）→キャラ→効果→文字→UIの順です。台本で〔カメラ：寄る／揺れ〕〔表情：驚き〕〔カットイン：MONBAN〕〔登場：煙〕〔移動：惑星到着〕〔テロップ：到着〕のような指定を使えるようにしてください。何度も出る場面（登場・到着）は、使い回せる「型」として1回だけ作ってください。
4. キャラは表情を差し替えられるようにし、話していないキャラは少し暗くし、声に合わせて口パク、ときどきまばたきさせてください。
5. 本番の物語画面でも、行ごとの声を鳴らしてください。セリフの間はBGMを下げ、BGM・効果音・声の音量をまとめて調整できるようにしてください。
6. 会話ウィンドウ・名前札・テロップ・選択肢を、世界観に合わせて作り直してください（Webのボタンらしさをなくす）。部品はSeedreamで文字なしで作り、1ページに並べて見せてください。「動画準備中 · PLACEHOLDER」と絵文字の🔊は消してください。
7. 軽さ：動かすのは位置と透明度だけ。粒子は約150個まで。動画は720×1280・1本1MB以下。
8. まず1日目の冒頭（招待状からMONBAN登場まで）を試作して、スマホで見られるようにしてください。次に3日目の「ロケット→Bluena→土星に到着」、最後に7日目の日食（Veoの動画1本＋演出を重ねる）。
9. そのあと4日目の木星から、授業を仮の枠（LessonShell）から本物の遊ぶ画面（PatapataWorld など）の上に作り直してください。水星・火星も同じように。授業のあいだ、サンプルの住人の投稿は隠してください。1日できるごとにpushして、スクショとVercelのリンクをください。
10. 声：一周目は全部作ってください。原稿を変えたら、変わった行だけ自動で作り直されるようにし、1行だけ録り直せるようにし、使わなくなった古い声は掃除してください。

11. 喋っているキャラを大きく：複数のキャラがいる場面は、ふだんは全員を引きの絵（全身・横並び）で見せ、誰かが喋るときは、そのキャラだけのバストアップに切り替えてください（例：たこ焼きブラザーが喋る→ブラザーのバストアップ、シスターが喋る→シスターのバストアップ）。いまはキャラが全体的に小さめなので、画面の中で大きく見せてください。
12. 背景もカットに合わせて変える：同じ場面でも、背景を1枚で使い回さないでください。引きの絵の背景と、キャラのアップのときの背景（寄りの背景・ぼかした背景・そのキャラの色の背景など）を描き分け、アップに切り替わると背景も一緒に変わるようにしてください。
13. バティの声：バティのしゃべる声は、ユーザー本人の声を、キーを2つほど（半音2つ）上げて使います。月の神殿（D03-S005）で好きな食べ物を声で答えたとき、同意を取ってその声を登録します（〔確認：いまの声を、少し高くして、{bati}の声にします［いいよ］［ふつうの声にする］〕）。文字で答えた人・ふつうの声を選んだ人は、バティ用の標準の声。あとで登録し直せるようにしてください。
14. コロリンの声：土星（D04-S005）では、つぶやく前に、まず変な声を登録してもらいます（KIMORINのお手本「おならぷっぷー！」→ユーザーが吹きこむ→KIMORINのコロリンが、その裏声で「たこ焼き食べたい。」）。吹きこまなかった人のコロリンは、バティの声でしゃべります。

決めた台詞は勝手に変えないでください。台詞の直しは物語チャットでやります。
