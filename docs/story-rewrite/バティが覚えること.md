# バティが覚えること（決定 M-R222・2026-11-22。M-R219〜M-R221 の手帳・調味料は取りやめ）

## 決まり
- 特別な場面や名前はつけない。ふつうのチャットの中で、本人が「覚えといて」と言った時だけ、{bati}が覚える（「覚えた！」と返す）。例：「金曜が曲の締め切りだから、覚えといて」。
- {bati}が自分から「覚えていい？」と聞いたり、毎日質問したりはしない。
- 覚えていることは、{bati}のカードの「覚えてること」に並ぶ。一つずつ消せる。全部消すこともできる。
- 1体に5つまで（一つ30字くらい）。いっぱいの時に頼まれたら、{bati}が「いっぱいだから、どれか忘れてもいい？」と聞く。
- 呼び方は、秘密結社の名前（{neo}）。呼び方を変えたい時は、カードから変えられる（会話で「〇〇って呼んで」と言ってもよい）。
- 返事の長さは、こちらで決めておく：ふだんは心地よい短さ。本人が「くわしく」「もっと教えて」と言った時だけ長くする。
- 話し方の調子は、生まれた時の性格のまま（頼まれたら一回だけ遊びでまねして戻る：M-R221）。
- 最近のチャットは{bati}がそのまま読めるので、直近の話は覚えさせなくても通じる。Haiku 5.5 に毎回渡すのは、性格・名前・呼び方・「覚えてること」（5つまで）だけ。

## 覚えない物（{bati}がうまくかわす）
- 住所・電話番号・メール・学校や会社の名前・パスワードや暗証番号・お金や口座のこと・ほかの人の個人のこと・体や病気の細かいこと。
- {bati}の言い方（性格に合わせる）：「それは、覚えないでおくね。大事なことは、{neo}がしまっておいて！」
- サーバーでも弾く。15歳未満の人には、とくに強く守る。

## 相方の役目（2体目・3体目から）
- 名前のあとに{bati}が聞く：「ボクは、{neo}の、なんの相方になる？」〔なんでも〕〔遊び〕〔仕事・勉強〕〔作ること〕。役目で話の向きが変わる。1体目は〔なんでも〕から。あとで変えられる。
