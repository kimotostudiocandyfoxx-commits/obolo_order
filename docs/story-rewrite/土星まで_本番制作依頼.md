## 2. 見た目の基準（必ず参考画像として使う）
`docs/story-rewrite/design/refs/` の3つのフォルダ。各フォルダの README.md に、特徴と台本とのつなぎ方を書いてあります。
- **cast/**：OBOLON、MONBAN、KIMORIN（通常時＝サングラスをおでこ／登場時＝サングラスを目に。2日目「待ちなさい。」〜「気をつけなさい。」は登場時の姿）、KIMORINのドラゴン形態、たこ焼きブラザー、たこ焼きシスター、うんちピンポンくん（最新）、バティの見本（おにぎり）
- **places/**：本部の正面、地球の神殿の大広間（OBOLONが現れる金色の大広間）、ロケット発射場（ロケットあり／なし・らせん階段つき）、ロケット、月の神殿（中・上から2枚）、土星の神殿（上から・正面・中）
- **props/**：招待状の封筒、招待状、宇宙行きの切符（デザインだけ。文字は README の「本番の文字」）、マナジェム、ピンポン2.5
- 「Genspark」の透かしが入っている絵（KIMORIN通常時・MONBAN・発射場ロケットなし・バティの見本6枚・たまご二つ）は、透かしを使わないこと。
- 絵の中の文字（「招待信号を受信しました」「本部に到着しました」など）は、画像に焼き込まず、コードで重ねる。
