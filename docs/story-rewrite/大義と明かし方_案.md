# Obolo Order の大義と、物語での明かし方（案）

作成：2026-10-25。**決定済み（M-R87・M-R88）。台本に反映しました。** 敵の呼び名は「ナガレ」、フェスは「oboloフェス」、チケットは1日入場88円。
1〜3日目（確定稿）の台詞は変えない前提です。

---

## 1. 大義

### ひとことで
**流されるだけの毎日から、自分で作って届ける毎日へ。宝は、目の前の自分の暮らしにある。**

### 三行で
1. 世界は、勝手に流れてくる情報であふれている。人は、他人の暮らしを眺めて、比べて、疲れて、自分の声を忘れていく。
2. Obolo Order は、そこから人を連れ戻す秘密結社。全員が DJ で、自分の声・言葉・曲・映像・物語を混ぜて、誰かに届ける。
3. 最後は、画面を閉じて、88日間ひらくフェスの町に集まり、現実を楽しむ。コスモスは自分自身で、宝は目の前に広がっている。

### 秘密結社の目的（台本の指針。台詞にそのまま書く文ではない）
- **守るもの**：一人ひとりが、心も体も健やかに、楽しく生きること（謎3の答えと同じ）。
- **連れ戻す先**：見るだけの側から、作って届ける側へ。うらやむ側から、自分の暮らしを宝だと思える側へ。
- **やり方**
  - 流れてこない場所を作る。無限スクロールがなく、自分で押したものしか出てこない。
  - 数で人を測らない。いいね・フォロワー・再生数を出さない。
  - 区切りを作る。扉は1日88分で閉まり、届けたものは88時間で戻ってくる。
  - 最後は、画面の外の町へ集まる。
- **秘密である理由**
  - 流れは、広告と数と騒ぎで広がる。Obolo Order は、その逆に、静かな招待だけで広がる。
  - 姿と名前を変えるのは、外の世界の肩書きや数字で比べられないため（2日目・月の神殿の「SNSに書くなら姿と名前を変える」決まりの理由になる）。

### 物語の中の「敵」：人ではなく現象にする
- **呼び名の案：「ナガレ」**
  - 終わりなく流れてくる、他人の暮らしの川です。眺めているうちに自分の色が抜け、自分の声を忘れていきます。
  - 誰かが悪者なのではなく、宇宙に起きている「現象」として描きます。実在のSNSや会社を悪者にしない。
  - ほかの呼び名の候補：「ナガレボシの川」「ミズモノ」「流れ」。決めてもらえれば、それで統一します。
- **ボスはいない**（MONBAN「……ボスは、いない…。」のまま）。戦って倒すのではなく、自分で作ることで、そこから出ていきます。

### 書き方の決まり
- アプリの中の台詞では、医学の言葉を使わない（ドーパミン、セロトニン、鬱、依存症など）。たとえで表す。
- 「このアプリで健康になれる」「治る」とは言わない（すでにある決まり v5 M2 と同じ）。
- 楽しさを押しつけない。作らない日、見るだけの日、休む日も、責めない。
- 外の世界を見下さない。KIMORIN が疑う役なので、説教くさくなりそうな所は KIMORIN のツッコミで軽くする。

### 場面ごとの案（台詞は仮。確定稿の 1〜3日目は触らない）

**① 木星（4日目）D05-S009：謎3の言いかけ**
- 今：カイザーが結社の目的を言いかけ、MONBAN が止める。
- 足す：カイザー「外の宇宙には、ナガレというものがあってダ……」→ MONBAN「……そいつらは、まだネオだ…。」で止める。
- ねらい：「ナガレ」という言葉を、意味がわからないまま一度だけ聞かせる。

**② 火星（6日目）D07：ヒポキンの一言**
- 足す：ヒポキン「外の画面は、勝手に流れてくる。ここの画面は、自分で押したものしか、映らない。」
- ねらい：このアプリに無限スクロールがない理由を、世界のルールとして見せる。

**③ 7日目 D08-S002：MONBAN の広告の一行（今ある台詞）**
- 今：「……ここには、勝手に流れてくる広告もない…。知らない誰かの『おすすめ』も、流れてこない…。」
- 足す（一言）：MONBAN「……外は、ナガレだらけだ…。」

**④ 7日目 D08-S009：謎2「全員、DJ」の答えのあと**
- 足す：OBOLON「浴びる、だけの側から、、、混ぜて、届ける、側へ。」
- 決まり：謎2の答えの台詞には「お前」「君」を使わない（今の決まりのまま）。

**⑤ 二周目の終わり L2-RETURN-S006：謎3（大義の本体）**
- 今：「結社の目的は、、、一人ひとりが、心も、体も、健やかに。楽しく、、、生きることだ。」
- 足す（その前）
  - OBOLON「外の宇宙には、、、ナガレがある。」
  - OBOLON「終わりなく、誰かの暮らしが、流れてくる。眺めているうちに、、、自分の声を、忘れる。」
  - KIMORIN「……耳が痛いですね。私は、忘れたことはありませんが。」（KIMORIN のツッコミで重くしない）
- 足す（秘密である理由）
  - OBOLON「ナガレは、数と、騒ぎで、広がる。だから、、、ここは、静かな招待だけで、広がる。」
  - OBOLON「姿と名前を変えるのは、、、外の数で、比べられないためだ。」

**⑥ 星休め L2-REST-S001：謎4「なぜ扉は閉じる」**
- 今：OBOLON「画面の外へ帰るため、だ。」
- 足す：OBOLON「ナガレには、、、終わりがない。だから、ここには、区切りがある。」

**⑦ 二周目の天王星 L2-URANUS-S001／三周目の SHAPER：町の伏線**
- 足す：ブラザー「このテントは、いつか、どこかの野原に、ぜんぶ集まるらしいZE。」
- SHAPER で KIMORIN のテントが隣に越してくる場面は、そのまま「町ができかけている」に使う。

**⑧ 三周目の始まり L3-RECORDER-S001：フェスの招待状**
- 足す：MONBAN から、金色の招待状が届く。
  - 〔招待状：obolo フェス。88日間ひらく、DJの町〕
  - MONBAN「……DJになったら、来い…。」
- 三周目の称号の旅を、フェスの準備として見せる。
  - 曲（RECORDER・WEAVER）＝自分のセットの曲
  - MV（MOVER）＝セットで流す映像
  - グッズ（SHAPER）＝自分のテントで売る物販
  - ゲーム（PLAYER）＝自分のテントの出し物
- 三周目の火星のマイクリレーは、フェスの前夜祭として扱う。

**⑨ 太陽の終章：フェス**
- S004（日食）：光の輪の向こうに見える景色を、「白い丸テントが通りをなして並ぶ町。中央にDJブース。灯り」に変える。謎6の台詞は変えない。
- S005：KIMORIN が先に回す（お約束どおり、おかしなセット）。
- 新しい場面（S005b）：{neo} の DJ プレイ。
  - 金星で覚えた回し方で、旅で作った自分の声・曲・映像を混ぜる。
  - 誰でも回しきれるように「おまかせ」を用意する（材料を3つ選ぶとアプリがセットを組み、本人はつなぐ瞬間とコロリンを落とす瞬間だけ押す）。
  - 住人・ダチ・MIKIE たちのコロリンやシールが飛び交う。観客の数や点数は出さない。
- 曲が止まる → 静けさ → S006（「コスモスを見つけよ」の想起）→ S007 の核心の二行と無言（**変えない**）。
- S010：町が88日間ひらく。OBOLON「多くのコスモスが、、、ここで、出会う町だ。」は、そのままフェスの町の意味になる。
- S011：「今日はその続きを生きてこい。」（**変えない**）。画面を閉じて、現実へ。

**⑩ 特別編 EX-KIMORIN-S001：現実へのフェスの招待**
- 今の手紙（草原のテント、DJブース、「入るのは、タダです。」「来られなくても、いいのです。いつか会えたら、現実で。」）が、すでにひな形になっている。
- テントを白い丸テントの町に、期間を88日間に合わせる。

### 謎1とのつながり
7日目の謎1「oboloは、、、街の名前だ。」の答えが、太陽の終章で「88日間ひらく、DJの町」として回収されます。表記は「町」にそろえるのがいいと思います。

## 3. 決めてほしいこと
1. **敵（現象）の呼び名**：「ナガレ」でいいか。
2. **フェスの名前**：「obolo フェス」（町の名前＝obolo）でいいか。
3. **現実の町を物語のゴールにするか**：今の決まりは「現実の町は本編の目標にしない。『いつか、どこかで会えたら』程度」です。フェスを最後に置くなら、この決まりを次のように変えるのがいいと思います。
   - 物語の中の到達点は「物語の中のフェスの町」にする。
   - 現実のフェスは、参加無料・行くかどうかは自由・行かなくても物語は完結する、のまま。
   - 15歳以下は家の人と一緒。
4. **三周目で「フォロー」が開くこと**：大義（数で比べない）とぶつからないか。フォローしても数は出さない、で十分か。

決まったら、この案のとおりに台本へ入れます。1〜3日目の台詞には触りません。
