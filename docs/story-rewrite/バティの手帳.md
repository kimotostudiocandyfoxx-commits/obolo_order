# バティの手帳（決定 M-R219・2026-11-22）

{bati}が「ずっと覚えておくユーザーの情報」をしまう所。ふだんの会話（左のバナーの過去のチャット）とは別にする。
画面の上では、{bati}が持っている小さな手帳。{bati}のカードから開ける。

## 1. 手帳の形
- **共通のページ**（どの{bati}も読む）：呼ばれたい名前、生まれた年（年齢の確かめ用。手帳には出さない）、好きなもの・苦手なもの、今がんばっていること、作りたいもの、話してほしくないこと。
- **その子のページ**（その{bati}だけが読む）：その子の役目（下の3）に合わせたこと。例：仕事の相方なら「今の仕事のこと」「使っている道具」、遊びの相方なら「好きなゲーム・推し」。
- **量**：1ページ8行まで。共通とその子のページを合わせて、1体あたり16行まで。1行は短い一文（30字くらいまで）。
  - 少ない方が{bati}は迷わない。多すぎると、話がずれたり、古い話を持ち出したりする。いっぱいになったら、{bati}が「どれか消してもいい？」と聞く。
- いつでも、ユーザーが直す・消すことができる。全部消すボタンもある。

## 2. 書く・書かないの決まり
- **書く**：呼ばれたい名前、好き・苦手、今ハマっていること、がんばっていること、作りたいもの、話し方の好み（短め・長め、ツッコミ多め など）、話してほしくないこと。
- **書かない**（{bati}が書くのを断る。「それは、手帳には書かないでおくね」）：住所・電話番号・メール・学校や会社の名前・パスワードや暗証番号・お金や口座のこと・ほかの人の名前と個人のこと・体や病気の細かいこと。
- 15歳未満の人には、とくに「書かない」を強く守る。

## 3. どうやって集めるか（かたい説明はしない）
- **最初（2日目・D03-S008）**：{bati}が手帳を見せ、最初の質問「ボク、{neo}のこと、なんて呼んだらいい？」。OBOLON「、、、書いてほしくないことは、書かせなくていい。手帳は、、、いつでも、お前が開ける。」
- **毎日一つの質問**：その日はじめて話した時に、{bati}が性格の言い方で一つだけ聞く（答えなくてもいい）。例：
  1. 「最近、ハマってることある？」
  2. 「{neo}が、ちょっと苦手なものって、なに？」
  3. 「今、がんばってることは？」
  4. 「いつか、作ってみたいものは？」
  5. 「話すとき、ボクは、短めがいい？　いっぱいがいい？」
  6. 「これは話さないでほしい、ってこと、ある？」
- **会話の中で**：大事そうなことが出たら、{bati}が「それ、手帳に書いていい？」と聞く。「いいよ」の時だけ書く（勝手に書かない）。
- 書いた時は、手帳がきらっと光って、一行増える（何を書いたか見える）。

## 4. 相方の役目（2体目・3体目から）
- 2体目・3体目が生まれた時、名前のあとに{bati}が聞く：「ボクは、{neo}の、なんの相方になる？」
  - 〔なんでも〕〔遊び〕〔仕事・勉強〕〔作ること〕（言葉で答えてもいい）。
- 役目で、その子のページの質問と、話の向きが変わる（仕事の子は、要点を短く、など）。
- 1体目は〔なんでも〕から始まる。あとで変えられる。
- チャットの相方を入れかえれば、プライベート用・仕事用などを切りかえられる。
