# シンプル版 全体の流れ（案・2026-11-21）

利用者の方針：物語はシンプルに。3周の旅・八つの謎・7つの称号・フェスの町・太陽終章などは無理に入れず、蛇足は外す。
大事な場面だけ映画のように1カットずつ作り、ほかは操作の分かりやすさを優先する。

## 物語の芯（一文）
宇宙の秘密結社 Obolo Order に招かれた{neo}が、相棒の{bati}と月の工房で作品を作り、星々に届けていく。

## 決まり（覚えることは3つだけ）
1. **作るのは月、しまうのはブルーナ、見せるのは星。**
2. **星への門は1日88分**（月の工房・ブルーナ・ダチとの通信はいつでも）。
3. **会員（ORDER）になると、バティにマナを渡せて、もっと遠くの星へ行ける。**

## 最初の旅（8日・1日3〜5分）
| 日 | 場所 | すること（1日1つ） | 映画にする場面 |
|---|---|---|---|
| 1 | 地球（結社の本部） | 招待状 → 本部の門 → OBOLON に名前を伝える | ★ 招待状と本部の門 |
| 2 | 月 | ネオの姿を作る → バティのたまごを受け取る → ブルーナを受け取る（作る・しまう・見せる） | ★ 月の神殿・ネオの姿ができる |
| 3 | 土星 | 朝、バティが生まれる → 声でつぶやく（コロリンが転がる）→ 招待してくれた人と KIMORIN がダチになる | ★ バティの誕生 |
| 4 | 木星 | 月の工房で初めてアートを作る → 蝶になって公開 | 到着カット・初めての公開 |
| 5 | 水星 | アートをジャケットにして曲を作る → 船になって公開 | 到着カット |
| 6 | 火星 | 曲に MV をつける → UFO になって公開 | 到着カット |
| 7 | 金星 | 自分の曲で短いラジオ番組を作る（DJ） | 到着カット |
| 8 | 地球 → 太陽 | バティのマナが切れる → エクリプス（会員になる・月88円）→ 住人のままでいる道もある | ★ エクリプス |

- 各星の住人は1人（1組）ずつ。その星の作品が「どう生きるか」を教えて、すぐ体験させる。
- 案内は KIMORIN、作るのはいつもバティと月の工房。

## 会員になった後
- 天王星（グッズ・クロコパトラ）、冥王星（物語）、海王星（ゲーム）が、1つずつ開く（各1日の短い紹介のお話）。
- そのあとは物語の縛りなし。自由に作って、星を見て回る。
- **星の物語**：季節ごとの追加のお話（短い章）として足していく。外した場面・人物・謎はここで使う。

## 大きな謎は1つだけ
- 「obolo とは何か」：旅の中で少しずつ匂わせ、星の物語でゆっくり明かす。

## 外したもの・形を変えたもの
| これまで | シンプル版 |
|---|---|
| 3周の旅＋太陽終章 | 最初の旅は1つ（8日）。その先は季節ごとの星の物語 |
| 八つの謎 | 1つ（obolo とは何か） |
| 7つの称号 | 物語の関門にしない。作った実績のバッジにする |
| フェスの町 | 外す（必要になったら季節のお話で） |
| 二周目の仲間を増やす・各星の奥の遊び | 物語ではなく、アプリの機能としていつでも使える |

## 映画のように作る場面の決まり
- 1場面30〜90秒、飛ばせる、あとで見返せる。
- 絵コンテ（何秒・アップか引きか・カメラ・動き・台詞）→ 利用者が直す → 止め絵 → 動画 → 声 → 効果音、の順に作る。
- キャラクターの顔は参照画像でそろえる。
- 映画にしない場面：止め絵＋ゆっくりしたカメラ＋表情の差分＋声（紙芝居・ノベルゲームの形）。
