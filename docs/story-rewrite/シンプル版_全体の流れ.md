# シンプル版 全体の流れ（案・2026-11-21）

利用者の方針：物語はシンプルに。3周の旅・八つの謎・7つの称号・フェスの町・太陽終章などは無理に入れず、蛇足は外す。
大事な場面だけ映画のように1カットずつ作り、ほかは操作の分かりやすさを優先する。

## 物語の芯（一文）
宇宙の秘密結社 Obolo Order に招かれた{neo}が、相棒の{bati}と月の工房で作品を作り、星々に届けていく。

## 決まり（覚えることは3つだけ）
1. **作るのは月、しまうのはブルーナ、見せるのは星。**
2. **星への門は1日88分**（月の工房・ブルーナ・ダチとの通信はいつでも）。
3. **会員（ORDER）になると、バティにマナを渡せて、もっと遠くの星へ行ける。**

## 最初の旅（8日・1日3〜5分）
毎日の形（M-R208・M-R210・M-R211）：朝、月の神殿でOBOLONが「お前は、ついに〜を作れるようになる。その魔法を、今日は教える」→ {bati}とのチャットの中で、話して作る（できた物は自動でBluenaへ）→ 星へ飛ばす → ロケットで見に行く。飛ばした作品は88時間その星で生き、そのあと自分の場所に帰る。

- 1日目の終わりだけ〔明日まで待てない〕がある（M-R269）。2日目の終わり（{bati}誕生）からは、24時間ごとに1つずつ星が開く。

## 会員になった後
- 天王星（グッズ・クロコパトラ）、冥王星（物語）、海王星（ゲーム）が、1つずつ開く（各1日の短い紹介のお話）。
- そのあとは物語の縛りなし。自由に作って、星を見て回る。
- **星の物語**：季節ごとの追加のお話（短い章）として足していく。外した場面・人物・謎はここで使う。

## 大きな謎は1つだけ
- 「obolo とは何か」：旅の中で少しずつ匂わせ、星の物語でゆっくり明かす。

## 外したもの・形を変えたもの

## 映画のように作る場面の決まり
- 1場面30〜90秒、飛ばせる、あとで見返せる。
- 絵コンテ（何秒・アップか引きか・カメラ・動き・台詞）→ 利用者が直す → 止め絵 → 動画 → 声 → 効果音、の順に作る。
- キャラクターの顔は参照画像でそろえる。
- 映画にしない場面：止め絵＋ゆっくりしたカメラ＋表情の差分＋声（紙芝居・ノベルゲームの形）。
