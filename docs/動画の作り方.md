# 動画の作り方（R13・2026-11-25）

> **決定（クライアント 2026-11-25）**：動画生成そのもの（テキスト→動画・画像→動画のモデル）は失敗が多く高いので、このアプリでは**使わない**。
> 動画は **「絵を作って、その絵を動いて見えるように見せて、つなぐ」**＝**絵が動く映像**で作る。
> 以前このアプリで曲にMVを付けた仕組み（`apps/api/src/mv/`・MV lab の実験）をそのまま土台にして、月のバティとのトークから使えるようにした。

## 1. 流れ（会話で始めて、スペルで決めて、会話で直す）

1. **会話で始める**：「動画を作りたい」「夏の海のポップにMVつけて」など。バティが短く聞く（ボタンなし、例は文の中）。
   - なにを作る？（きみの曲のMV／持ってる絵や写真をつないだ短い映像／お話のスライドショー）
   - どの曲にのせる？（「夏の海のポップ」や「星のバラード」…と、その人の曲の名前を出して聞く。言葉に曲名があれば聞かない）
   - 絵は、どんなふうに動かす？（ゆっくりズーム／奥行きが出るパララックス／横に流れる）
2. **スペルで決める**：答えをスペルの札（C の巻物ルーン）にまとめ、マナと一緒に浮かべて「このスペルで作る？　それとも、どこか変える？」。言わなかったところはバティが埋める。
   はい（「OK」「いいよ」「作って」）→ 確認トークン・値段・スペルのハッシュ付きでサーバーへ → 詠唱アニメ → 「これは、ちょっと大物。だいたい{n}分。できたころに、このトークに戻ってきてね。」
3. **会話で直す**：できたら「できたよ！　絵が動く映像だよ。「カメラをもっとゆっくり」「歌詞は消して」みたいに言えば、マナを使わずに直せるよ。」
   - 動かし方だけの直し → **新しい絵なし・CPU だけで作り直し（マナ 0）**
   - 絵を描き直す直し（「3番目の場面を水彩で描き直して」）→ **小さなスペル（マナ 2）**
   - それ以外（「もっと切ない感じで全部」）→ 新しいスペル（ふつうの値段）

## 2. スペルの札 → 作り方の設定（`packages/shared/src/video.ts` の `videoParams`）

| 札のグループ | 札（日本語） | 設定 | 既定（バティが埋める） |
|---|---|---|---|
| なにを作る（purpose） | 曲のMV／絵をつなぐ／お話スライド | `purpose` mv・pictures・slideshow | 曲のMV |
| 曲（source） | その曲の名前（裏に曲のID） | `songId` | 言った曲、なければ一番新しい曲 |
| 絵のタッチ（style） | 水彩・アニメ風・絵本風・クレヨン…（絵のスペルと同じ） | 描く絵の言葉 | アニメ風（「絵をつなぐ」では出さない） |
| 場面の数（scenes） | 4場面・8場面・12場面 | `scenes` | 8場面 |
| 長さ（length） | サビだけ（約30秒）・1分・まるごと | `length`＋曲のどこから（`part`） | サビだけ（サビの1秒前から） |
| カメラ（camera） | パララックス・ゆっくりズーム・横に流れる・空を飛ぶカメラ | `camera`・`pace` | パララックス |
| 切りかえ（transition） | ふわっと・パッと・ピカッと | `transition` fade・cut・flash | ふわっと切りかえ |
| 歌詞（caption） | 歌詞を出す・歌詞なし | `captions`（`captionStyle`） | 歌詞を出す |
| 気分・色 | 明るい・切ない・あざやかな色・モノクロ… | 描く絵の言葉（自分の絵なら色補正 `grade`） | — |

描く人（絵のモデル）に渡すのは「どんな絵か」だけ（`spellPrompt('video')`）。曲のID・場面の数・カメラなどは設定で、絵の言葉には入れない。

## 3. パイプライン（`apps/api/src/mv/`）

```
曲（歌詞と時間・サビ・テンポ・伴奏の雰囲気）＋主人公の絵
  → 絵コンテ（storyboard.ts planStory：Gemini Flash-Lite、JSON スキーマ固定／キーなしは決まった組み方）
  → 1場面1枚の絵（keyart.ts / styled.ts：MV_PLAN A＝Runware の FLUX.2 [klein] 4B、B＝自社 GPU）
       ※「絵をつなぐ」は描かない：その人の絵（ブルーナの木星フォルダの写真・作った絵）をそのまま使う
  → 絵はすべて保存（VideoCut：絵の URL・順番・時間の割合・2.5D の動き）
  → 奥行き（depth.ts：Depth Anything V2 Small を API の CPU で、1枚約1秒）
  → カメラ（cut.ts cutPlan → render.ts）
       ケンバーンズ（ズーム・パン、速さ＝pace）／2.5D パララックス（parallax.ts：近い物と遠い物が別々に動く、
       動きは Gemini が1回だけ選び、以後は保存したものを使う）／空を飛ぶカメラ（上へ・前へ）／止め
  → 切りかえ（新しい絵の頭で、黒にふわっと／白くピカッと／パッと）
  → 拍に合わせたカット（2小節ごと、サビは1小節、速い曲のサビは半小節。ゆっくり＝4小節ごと）
  → 歌詞（render.ts burnLyrics：ASS 字幕、1文字ずつ・カラオケの色・サビはハデ）
  → 色補正（自分の絵だけ：明るく・暗く・あざやか・やわらかい・モノクロ）
  → 720×720・24fps の mp4（ffmpeg、libx264）＋ポスター
  → 火星の裏スタジオ（mars_backstage）に入る → 〔星へ飛ばす〕で火星へ（KIND_HOME_PLANET.video = mars）
```

**作り直し（無料）**は、保存した絵を読み直して、上の「奥行き」から先だけをもう一度回す（`MvService.edit`）。新しい絵は描かない。裏スタジオの同じ映像が新しいものに置きかわる。月のカードには前の版も残る（左右にめくれる）。

## 4. 費用と時間

| 作り方 | マナ（MAKE_COST） | お金の目安 | 時間の目安 |
|---|---|---|---|
| 曲のMV・お話スライド（絵を描く） | `mv`（R17 から原価＋手数料＋8%：既定 **7**、[マナの値段.md](マナの値段.md)） | 8場面 ≈ **1.5円**（klein 4B 0.19円/枚、Model scout s02）＋ Gemini 数十銭。12場面 ≈ 2.3円 | 約3分半（`ETA_BASE_MS.mv`、最近20本の中央値で直す） |
| 持ってる絵をつなぐ（描かない） | `mvPictures`（既定 **3**） | Gemini の動き選び（数銭）＋CPU だけ | 約1分半（`mvEdit`） |
| 場面の描き直し（1〜4場面） | `mvRedraw`（既定 **4**） | 1枚0.19円＋CPU | 約1分半 |
| 動かし方の直し | **確認なし**（1日 `VIDEO_EDITS_PER_DAY`＝20回まで。CPU の小さな原価はためて引く） | CPU だけ | 約1分半 |

作れなかった時（2回失敗）はマナを返す（`JobsService.refundVideo`、1回の「はい」に1回だけ）。

## 6. 動画生成モデルは使わない

- 利用者の操作から動く経路（`apps/api/src`、`apps/web` のアプリ部分、`packages/shared`、`packages/ai`）に、動画生成モデル（Seedance・Veo・Kling・画像→動画など）の呼び出しは**ない**。テスト `apps/api/src/mv/cut.test.ts` がソースを調べ、作り直しが ffmpeg だけでネットワークを使わないことも確かめている。
- 例外は開発用の台本素材づくり：`scripts/story-video/make.mjs`（Seedance 2.5）・`scripts/art/generate.mjs`（Veo）。Claude Code が物語の固定動画（`public/onboarding/m*.mp4`）を作るためのもので、デプロイされず、利用者からは呼ばれない。
- バティのプロンプト（`packages/ai/src/prompts/bati.ts` JA/EN）にも「絵が動く映像」「本物の動画を生成するとは言わない」と書いた。

## 7. おためし（デモ）

サーバーがないので、決まった絵コンテ（`apps/web/components/atelier/video.ts` の FRAMES：海・船・島・夜明け…）を、カードの中で同じ規則で動かす（`ReelPlayer.tsx`：ズーム・パン・遠い絵と近い切り抜きが別々に動くパララックス・ふわっと切りかえ・歌詞）。曲は「夏の海のポップ」「星のバラード」「ネオンの帰り道」。直しも同じ（無料の直しは12秒、描き直しは2分の仮の仕事）。

## 8. まだのこと・こわれていること

- **自社 GPU（プラン B）の klein はまだ**：`gpu/music/paint.py` は Animagine XL 4.0。A と同じ絵にするには klein 4B を入れる（mv-plans.md）。
- **曲がないと作れない**：映像は必ず曲にのせる（無音の映像はない）。「絵をつなぐ」も曲を選ぶ。→ 決めること：曲なしの短い映像を許すか。
- **R13 より前に作ったMV**は絵を保存していないので、言葉で直せない（新しいスペルになる）。
- 歌詞の時間は、曲の行の始まり（ACE-Step の時間）から。行の長さが合わない曲では少しずれる。
- 作り直しのたびに mp4 が増える（前の版をカードに残すため）。古い版の掃除はまだ。
- 火星の裏スタジオには最新の版だけ。月のカードの前の版は月にだけある。
- 「場面の描き直し」は場面の番号で言う（「3番目」）。絵を見て指でえらぶ方法はまだ。
- MV lab の採点（m19）：全体 5.9／10。主人公のお面が変わる・同じ構図が続く、が残りの課題（`art/lab/mv/`）。
