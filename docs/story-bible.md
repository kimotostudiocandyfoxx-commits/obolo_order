# OBOLO ORDER 物語の設計書（ストーリーバイブル）

物語・セリフ・世界観の決定事項をまとめる場所です。チャットで決まったことは必ずここに反映します。
**台本の実体**は `apps/web/lib/onboarding/day1.ts`〜`day3.ts`（以降も同じ形式）にあり、ここは全体像と決まりごとです。

- ✅ = クライアントの台本・指示どおり
- ✏️ = Claude の仮のセリフ・仮の流れ（あとでクライアントが直す前提）

## 6. 土星「ころりん」

- みんなの声が、デフォルメされた丸いアイコンになって土星の輪を回ったり、地面を転がったりする。
- タップ → 止まって吹き出し（名前・つぶやき・☆・もう一度きく）→ 声が流れる。
- 下のバー：ゆらす／声をおとす（ひとこと＋録音 → 自分のアイコンが空から落ちてくる）／おまかせ。
- 上：みんな／ともだち／星をあげた声、「いま土星に○人がころりん中」。
- ✏️ アイコンはネオの姿をもとにした仮の絵。本番はデフォルメ画像に差し替え。
- ✏️ 登録した自分の声でテキストを読む（ボイスクローン）は後のフェーズ。今は「録音した声」、サンプルの住人はブラウザの読み上げ。
