# OBOLO ORDER 物語の設計書（ストーリーバイブル）

物語・セリフ・世界観の決定事項をまとめる場所です。チャットで決まったことは必ずここに反映します。
**台本の実体**は `apps/web/lib/onboarding/day1.ts`〜`day3.ts`（以降も同じ形式）にあり、ここは全体像と決まりごとです。

- ✅ = クライアントの台本・指示どおり
- ✏️ = Claude の仮のセリフ・仮の流れ（あとでクライアントが直す前提）

## 6. 土星「ころりん」

- みんなの声が、デフォルメされた丸いアイコンになって土星の輪を回ったり、地面を転がったりする。
- タップ → 止まって吹き出し（名前・つぶやき・☆・もう一度きく）→ 声が流れる。
- 下のバー：ゆらす／声をおとす（ひとこと＋録音 → 自分のアイコンが空から落ちてくる）／おまかせ。
- 上：みんな／ともだち／星をあげた声、「いま土星に○人がころりん中」。
- ✏️ アイコンはネオの姿をもとにした仮の絵。本番はデフォルメ画像に差し替え。
- ✅ ネオのうちは「ネオの声」：書いた文字を、選んだ読み方（元気に・ささやき風・叫ぶ風 など7種類）で読み上げる。ネオの姿ごとに声の高さが少し違う。
- ✅ ORDER になったら登録した自分の声にできる（ボイスクローン、後のフェーズ）。今は「自分で録音」も選べる。
- 4日目のチュートリアル：声をきく → 星をあげる → シスター「試しに呟いてみたらいいわ。」→ 書いて読み方を選んで投稿 → ブラザー「今はネオだから、ネオの声だZE!!」→ シスター「ORDERになったら、登録した声にできるわ。」


## バティ（✅ 2026-10-05 クライアント決定）
- 3日目に月の神殿で **好きな食べ物** を聞かれ、たまごを受け取る → **4日目の朝に生まれ、名前をつける**
- 見た目は **好きな食べ物をモチーフに生成**（AI の画像生成。失敗したときは絵文字の仮の姿）
- 4日目からずっと、作曲（水星）・撮影（火星）・つくる（金星）の **相棒はバティ**（KIMORIN は旅の案内人）
- ORDER になると、2回目の月の神殿でバティが目覚めて成長する（声・記憶・作れる量などで差をつける ✏️）

## ネオの姿（✅ 2026-10-05 クライアント決定）
- 入口は2つ：**イメージに近い画像から創る**（メイン）／**質問に答えて創る**（画像がない人用：好きな動物・好きな色・なりたい雰囲気）
- 画像から創るときは、**できる限りオリジナルになるよう KIMORIN が2回質問する**
  1. 「この絵の、どこがいちばん好きだ？ そこだけを、いただくぞ。」
  2. 「そのままだと、ただのマネだからな。君だけのアレンジを足すケン。何を変える？ 何を足す？」
- 送った画像は **イメージの参考に読むだけで保存しない**。生成の指示で既存キャラのコピーを禁止（著作権対策）
- 候補は **4枚**（最初からの作り直し3回まで）→ 選んだ1枚を **言葉で描き直し3回まで**（ORDER は制限なし）。生成に失敗したときだけ、用意した8つの姿から選ぶ
- 絵柄（タッチ）は OBOLO の世界観に固定
- 生成した姿は、木星の蝶・水星の船・火星の UFO・地球のプロフィールに出る
