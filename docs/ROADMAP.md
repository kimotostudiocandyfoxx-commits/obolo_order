# Obolo Order ロードマップ

最終目標：世界で10億ダウンロード。
その前に、**「続く」「広がる」「払ってもらえる」を、少人数の本物のユーザーで確かめる**。

決まったことは [DECISIONS.md](DECISIONS.md) に集める（全部のチャットがここを読む）。

---

## いまの段階：第1段階「見本を仕上げて、課金まで通す」

| 範囲 | 目標の品質 | 中身 |
|---|---|---|
| 1〜3日目（地球・月・土星） | **本番品質** | Seedanceの動画・声・効果音・チャット画面。これが品質の基準と作り方の型になる |
| 4〜6日目（木星・水星・火星） | **遊べる品質** | 静止画と立ち絵を中心にする。動画は大事な場面だけ。最後まで止まらずに遊べて、声がすべてそろっている |
| 7日目のエクリプス（課金） | **本番品質** | 払う気持ちになる演出。本物の決済、特定商取引法の表示、やめ方の画面 |

### 終わったと言える条件
- 1日目から7日目のエクリプスまで、iPhoneとiPadで止まらずに最後まで遊べる
- すべての台詞に声がある（名前入りの台詞は、名前なしの声で代わりに流れる）
- 本物の決済で ¥88/月 を払える（テスト用カードでも確認する）
- 裏側の計測がそろっている：何日目まで来たか、その日を最後まで見たか、どこでやめたか、何人招待したか、払ったか（**画面には一切出さない**）

## 第2段階「数百人で試す」
- 7日目までたどり着く人が100人以上になる人数を集める（最初に遊ぶ人は数百人）
- 友だちだけにしない：招待の招待くらいの、少し遠い人を混ぜる
- 見る数字：次の日に来た割合、7日目まで来た割合、払った割合、1人が招待した人数、やめた場所

## 第3段階「直して、4〜7日目を本番品質に」
- テストの結果で、いちばん人がやめた場所から直す
- 4〜6日目を本番品質に引き上げる（1〜3日目と同じ作り方で）

## 第4段階「世界に出す」
- App Store・Google Playに出す
- 多言語（台詞と声を言語ごとに差し替える）
- ストアページ、予告映像、招待の仕組みの磨き込み

## チャットの役割分担

| チャット | 役割 |
|---|---|
| 物語 | 台本・台詞・世界観を決める（台詞を変えるのはここだけ） |
| 本番制作 | 画面・演出・動画・声・効果音の組み込みと、品質の確認 |
| 土台・品質 | 決済、計測、ストアへの出し方、性能、テスト、セキュリティ、一人あたり費用、多言語の土台。依頼文は [briefs/foundation.md](briefs/foundation.md) |
| 成長（第2段階から） | ストア、招待の仕組み、海外展開、数字の分析 |

## 本番品質の作り方（1〜3日目で固めた手順）
1. 物語チャットで台本を決める
2. 本番制作チャットが、動画のプランを文字で出す（例：[story-rewrite/day2-video-plan.md](story-rewrite/day2-video-plan.md)）
3. 利用者がプランの文字を直す
4. 絵（Seedream）→ 動画（Seedance）→ 声 → 効果音・BGM の順で作る
5. 全部の動画をコマ送りで確認し、不自然なものは作り直す
6. スマホ幅で通しで撮って、流れ・つなぎ・文字の位置を確認する
7. 利用者が見て直し → 4〜6をくり返す
