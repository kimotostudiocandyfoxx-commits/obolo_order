# 土星までの豪華カット：止め絵の確認用

台本チャットの `土星まで_豪華カット台本.md` のキーフレーム（止め絵）候補です。

- `<映像>/<キー>-a.jpg`・`-b`・`-c`：同じ指示で描いた3枚の候補。
- 「同じ画角」の終わりの絵（例：V02/K4）は、同じ記号の始まりの絵（V02/K3-a → K4-a）を描きかえたものです。始まりと終わりを、同じ記号どうしで組みにして見てください。
- `sheets/`：カットの前に OK をもらう参照シート（白衣の KIMORIN・白衣を着たドラゴン・ロケットの三面）。
- 直してほしい点は、キーと記号（例：「V02/K6-b の耳をもっと長く」）で返してください。描き直しは `design/review-art-queue.json` の redo に足して回します。
- 作り方：`scripts/review-art/make-queue.py` が台本から指示文を作り、`.github/workflows/ui-art.yml` が Seedream 5.0 Pro で描きます（1枚 約5〜8円）。
